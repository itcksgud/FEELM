# FM-v4

현재는 대체된 MovieLens FM 기제 실험이다. 가장 오래된 앞부분 이력 대신 최근 N개를 순차적으로 사용하고, 사용자별 상대 평점 강도를 보존하며, 정확히 대응하는 가산 모델과 장르+태그 제한형 필드 인지 잔차 FM을 새 검증 모집단에서 비교하도록 설계했다.

자세한 내용은 `DESIGN.md`에 있다. 구현 시험, 정답을 보지 않은 10% 준비·적합 자원 사전 점검, 소스·입력 고정, 독립 실행 전 검토까지 완료했다. 그러나 2026-09-19 Jira `S15P21E106-623` 계약이 바뀌어 전체 준비를 중단했다. 이 버전은 S15P21E106-621의 고정 에피소드·후보 digest를 사용하지 않고 새 필수 순위·분포·제거 실험·K별 정책 판정을 구현하지 않았으므로 다시 시작하면 안 된다.
