# FM-v4 최근 N개 이력·부호 있는 콘텐츠 실험

상태: `SUPERSEDED_BEFORE_FULL_PREPARE_BY_JIRA_20260919_233805_KST`(2026-09-19 23:38:05 Jira 변경으로 전체 준비 전 대체됨)

이 사전등록은 당시 독립 실행 전 검토를 통과했지만 전체 준비가 끝나기 전에 Jira 계약이 바뀌었다. 대체 계약은 고정된 S15P21E106-621 에피소드·후보 digest, 후보 순위 지표, 기준선·제거 실험 행렬, K별 정책 비교를 요구한다. 이 설계는 다른 분할과 MSE 단일 주 지표를 사용하므로 다시 시작하거나 갱신된 업무의 근거로 인용하면 안 된다. 완료된 사전 점검과 중단된 전체 준비 시도만 변경하지 않는 감사 근거로 남긴다.

## 의사결정 질문

FM-v1은 교란돼 있었고, 이를 바로잡은 FM-v2·v3은 작고 안정적인 점 개선을 보였지만 짝지은 신뢰구간이 0을 포함했다. FM-v4는 MovieLens에서 마지막으로 계획한 FM 기제 실험이다. 가장 오래된 앞부분 이력과 사용자별 상대 평점 강도 손실이라는 남은 두 설계 문제를 바로잡았을 때, 엄격하게 기여도를 분리한 콘텐츠 상호작용이 실질적으로 유용한지를 묻는다.

서비스 사용자 연구, 운영 모델 선택, 한국 사용자 만족도 근거가 아니다. 실패하면 이 업무에서 MovieLens FM 반복 실험을 중단한다.

## 새 모집단과 정답 경계

- 분할 초기화값: `4623`.
- 역할 배정: SHA-256 사용자 버킷으로 학습 `<70`, 검증 `70..84`, 최종 시험 `85..99`.
- 학습 대상: `(2017-01-01, 2019-12-31]`.
- 검증 대상: `(2020-01-01, 2021-12-31]`.
- 최종 시험은 준비·적합·예측·평가에서 만들거나 열지 않는다.
- 초기화값 622·3623의 기존 검증 사용자를 새 검증 역할에서 모두 제외한다. 정확한 소스 파일, 사용자 수, digest, 교집합, 최종 합집합 digest를 적합 전에 고정한다.
- 조건을 충족한 새 검증 사용자를 모두 선택하며 정답 기반 표본 추출은 하지 않는다.
- 사용자별 조건 충족 사건을 고정 SHA-256 순위로 최대 4개 선택하며 평점은 선택에 쓰지 않는다.
- 검증 특징 에피소드에는 대상 평점이 없다. 평점은 별도 봉인 정답 산출물에 저장하고 모든 예측과 해시를 고정한 뒤에만 결합한다.

고정 소스 집계는 학습 사용자 21,102명과 새 검증 사용자 2,389명이다. 학습 대상 83,293개 중 82,215개, 검증 대상 9,359개 중 9,224개에 양의 이력이 있다. 새 검증 모집단은 기존 두 검증 모집단의 합집합 5,500명과 겹치는 사용자가 0명이다. 최종 시험은 2,142명 집계만 있으며 에피소드나 정답은 만들지 않았다.

## 최근 N개 이력 교정

선택한 각 대상 사건의 `prediction_at`은 대상 사건 시각이다. `(timestamp, movie_id)` 키가 대상보다 엄격히 앞선 사건만 이력이다. 가장 최근 N개를 고른 뒤 직렬화할 때 시간순으로 복원한다.

이력 길이가 H일 때 변형은 다음과 같다.

```text
{0} union {k in [1,2,4,7,15,25,40,50] where k <= min(H,50)} union {min(H,50)}
```

전체 이력 변형도 최대 50개다. 앞서 선택한 대상이 이후 대상의 이력이 되는 것은 허용된다. 추론 단위는 행이나 대상이 아니라 사용자다.

## 콘텐츠 표현

영화 ID와 사용자 ID는 특징으로 사용할 수 없다.

### 장르

알려진 장르가 G개인 영화는 각 활성 장르에 `1/G` 값을 둔다. 장르 메타데이터가 없으면 요인 벡터는 0이며 가산 결측 표시기를 켠다.

### 시점 기준 상위 자유 태그 128개

- 원천 `tags.csv`를 해시로 고정한다.
- 텍스트 정규화: 유니코드 NFKC, 소문자화, 앞뒤 공백 제거, 내부 연속 공백 축약.
- 실험의 학습·검증 사용자는 태그 제공자에서 제외한다.
- 학습 기간 시작 전에 외부 사용자가 남긴 태그만으로 어휘를 고른다.
- 중복 `(제공자, 영화, 정규화 태그)`는 한 번만 센다. 중복 묶음의 최초 시각이 처음 보인 시각이다.
- 영화 문서 빈도가 20 미만인 태그를 제거하고 `df DESC, tag ASC` 순서의 처음 128개를 고정한다.
- IDF는 `log((1 + M) / (1 + df)) + 1`이며 M은 어휘 적합 영화 수다.
- 예측 때는 `prediction_at`보다 앞선 외부 사용자 태그만 사용하고 `log1p(제공자 수) * idf`를 적용한 뒤 L1 정규화한다.
- 태그 누락은 알 수 없는 메타데이터이며 비선호나 0점 관측이 아니다.

## 사용자별 상대 부호 프로필

최근 N개 사건을 최신순으로 놓고 사건 순위 가중치를 `w_j = 2 ** (-j / 10)`으로 둔다. `mu0`는 학습 내부 적합 집합의 가중 전역 평점 평균이다. 축소한 사용자 중심은 다음과 같다.

```text
mu_u = (5 * mu0 + sum(w_j * rating_j)) / (5 + sum(w_j))
s_j  = (rating_j - mu_u) / 4.5
```

각 장르·태그 필드 값 f에 대해 다음을 계산한다.

```text
A_uf = sum(w_j * z_jf)
Q_uf = sum(w_j * z_jf * s_j) / (2 + A_uf)
gate = sqrt(sum_f(A_uf) / (sum_f(A_uf) + 5))
```

`A`는 지원량, `Q`는 부호 있는 선호다. N=0이거나 해당 필드 메타데이터가 모두 없으면 통과 계수는 0이다.

## 고정 비교

`matched_additive_v4`는 같은 정규화 후보 콘텐츠, A/Q 프로필 주효과, 이력 수, 평점 중심·분산, 최신성, 연도 특징, 결측 표시기, 기존 양성·음성 장르 겹침 진단을 사용한다. 가중 ridge 계수는 학습 내부에서 고른 뒤 비트 단위로 공유한다.

`signed_genre_tag_fm_v4`는 장르와 태그 필드마다 다음 항을 별도로 더한다.

```text
gate * [sum_g d_g * candidate_g * Q_g
        + sum_{g != h} candidate_g * Q_h * dot(U_g, V_h)]
```

- 대각 가중치 d는 같은 속성 선호를 모델링한다.
- 비대각 U,V는 비대칭 4차원 요인이며 대각은 가린다.
- 장르×태그, 후보×후보, 이력×이력, 관계×요인, 사용자 ID, 영화 ID 상호작용은 금지한다.
- 상호작용 적합 중 가산 계수는 고정한다.
- 초기화값은 `623, 1623, 2623`; 검증 도전 모델은 세 결과의 고정 평균 앙상블이다.
- 상호작용 정규화는 학습 내부 보류 사용자 평균 MSE로 `{0.001, 0.01}` 중 고른다.
- 차원, 최신성 반감기, 축소 상수, 필드, 특징 어휘 크기는 조정하지 않는다.

이 실행 계약에는 제거 실험이나 기제 진단 프로필이 없다. 유일한 도전 모델은 위의 고정 장르+태그 모델이다. 따라서 결합 상호작용을 지지하거나 기각할 수는 있지만 효과를 장르·태그·대각·비대각 하위 항으로 나눠 귀속할 수 없다.

## 가중치와 내부 선택

내부 분할은 사용자끼리 겹치지 않는다.

```text
SHA256("fm-v4-inner-4623:" + uid) mod 5 == 0 -> HOLDOUT
otherwise -> FIT
```

어휘, IDF, 전역 평점 평균, 수치 스케일은 적합 사용자 또는 명시한 외부 태그 집합으로만 만든다. 가산 행은 대상 내부와 사용자 내부에서 같은 총 가중치를 갖는다. 상호작용 적합과 선택은 N=0을 제외하고 `1 / (사용자 활성 대상 수 * 대상의 양수 N 변형 수)`를 가중치로 사용한다.

## 주 추정량과 판정

주 집단은 N>0 대상이 하나 이상인 모든 새 검증 사용자다. 사용자마다 대상 안의 양수 N 변형과 사용자 안의 활성 대상에 같은 가중치를 주고, 마지막으로 사용자에 같은 가중치를 준다.

주 차이는 다음과 같다.

```text
signed_genre_tag_fm_v4 앙상블 사용자 평균 MSE - matched_additive_v4 사용자 평균 MSE
```

사용자와 그 안의 대상을 차례로 다시 뽑는 짝지은 계층 부트스트랩 10,000회, 초기화값 `4623001`로 양측 백분위 95% 구간을 만든다. 다음 둘을 모두 만족할 때만 상호작용을 유지한다.

1. 신뢰구간 상한이 0보다 작다.
2. 상대 MSE 개선이 `0.30%` 이상이다.

그 외에는 대응 가산 모델을 오프라인 기준선으로 유지한다. 신뢰구간 실패는 `INCONCLUSIVE`(결론 불충분), 유의하지만 더 작은 효과는 `STATISTICALLY_POSITIVE_BUT_IMMATERIAL`(통계적으로 양수지만 실질적으로 작음)이다.

안전 조건:

- N=0 예측 최대 절댓값 차이 `<= 1e-12`.
- 시간·미래 특징·기존 검증 겹침·ID 특징·고정 가산 위반은 0건.
- 사용자가 200명 이상인 모든 N 셀에서 단측 95% MSE 차이 상한이 `+0.005`보다 작음.
- 전체 N>0 사용자 평균 MAE 차이의 95% 상한이 `+0.005`보다 작음.
- 지원률은 가산 모델보다 낮아지면 안 되고 잘림은 최대 `0.1`백분율점 증가만 허용.

이 계약에서는 순위 지표나 태그·장르 제거 실험을 하지 않는다. 통과하더라도 이후 눈가림 사용자 평가 후보가 될 뿐 서비스 채택을 허용하지 않는다.

## 자원 승격

사용자 단위 결정적 10% 사전 점검(`SHA256_USER_MOD_10_EQ_0`)은 검증 정답과 최종 시험을 열지 않고 완료했다. 준비는 학습 64,858행과 검증 7,411행을 137.193초에 처리했고 cgroup 최대 메모리 1,924,448,256바이트, 출력 70,163,173바이트였다. 적합은 119.596초, 최대 메모리 1,147,138,048바이트, 출력 1,154,884바이트였다. 디스크 넘침 파일은 없었다. 해시 고정 자원 보고서는 `fresh-preflight-fmv4-v2/resource-report.json`이다. 준비 단계가 에피소드 구조를 유지해 전체 모집단 메모리 증가가 정확히 선형일 필요는 없으므로 전체 실행 제한은 32GB, 단계별 제한 시간은 4시간으로 정했다.
