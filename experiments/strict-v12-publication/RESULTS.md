# v12 결과와 완료 범위

GBT를 서비스 구현 방향으로 선택했지만, **v12가 이전 모델보다 품질이 좋아졌다는 결론은 아니다**.
모델 학습/개인 추론 재현과 개인·파티 서비스 전환을 분리한다. 원본 수치는
[training-metrics.json](training-metrics.json), 위치·해시는 [artifact-index.json](artifact-index.json)에 있다.

## 학습과 결과

- 2026-09-22 고정 데이터·설정으로 실제 재학습. 학습 목표 836,700개 / 개발 목표 59,814개(3,003명).
- MovieLens 32M 전체 행을 직접 학습한 것이 아니다. 실제 관측 목표와 그 이전 전체 이력으로 구성했다.
- GBT: 113특징, 80 trees, depth4, learning_rate0.05, seed625. FM: 8 factors, 3 epochs 중 기존 개발 MAE로 epoch1 선택.
- 같은 설정의 이전 v12 가중치와 개발 예측을 재현했다. 새 holdout·최종 시험은 사용하지 않았다.

| 사용자 평균 절대 별점 오차(MAE, 낮을수록 좋음) | v12 | 같은 목표의 이전 v9 |
| --- | ---: | ---: |
| GBT | 0.698495 | 0.695598 |
| FM | 0.710818 | 0.692842 |

개발 사용자 재사용 비교이며 두 모델 모두 악화했다. MovieLens 오차를 한국 서비스 만족도로
일반화하지 않는다. 추천 자격 적용 후의 화면은 모델 원점수만의 결과가 아니다.

## 확인된 동작과 미검증

기존 로컬 전달 검증 기록: 57개 pytest, ZIP을 독립 폴더에 푼 뒤 K0/1/3/17/37/101와
실평점 우선·관심없음 K18의 두 모델 검산. 비어 있지 않은 6상태×2모델 Top100의 1,200행에서
순서와 점수 오차0. 이 수치는 이번 게시 과정에서 새로 수행한 품질 시험이 아니다.

입력 K≥1은 현재 평가 전부를 사용하며 버튼 값으로 자르지 않는다. 학습 K1~100 누락0,
학습 최대 K7,128. 가변 K를 받는다는 뜻이지 모든 K의 품질·처리량을 보장하는 뜻은 아니다.
실평점이 있으면 관심없음 1점보다 우선한다. 감상-only는 부정 평점이 아니라 후보 제외다.

이번 파일 정리에서는 43파일 ZIP CRC/manifest와 핵심 원본 11파일의 bytes/SHA를 다시 확인했다.
선별 게시 worktree에서 위 README의 4개 테스트 파일을 새로 실행해 **51개 통과**를 확인했다.
학습 행 구성·학습·번들 추출·ZIP 구성·ZIP 검증·개인 core의 6개 진입점은 `--help` 호출에
성공했다. 기존 57개 기록 전체를 이번에 다시 실행한 것으로 계산하지 않는다.
독립 검토자도 51개를 재실행하고 소스·외부 파일 해시와 게시 범위를 대조했다.
`training-metrics.json`은 원본과 JSON 내용이 같지만 LF 게시본이다. 게시본 SHA는
`0d6f0add813c6b68916423b6b73ecb9891e0fd474f6567d358b174ac31ff7b22`이며,
색인의 외부 `metrics.json` SHA는 원본 파일 식별자로서 이 값과 구분한다.
Linux/서버 성능, 개인·파티 통합, 발견 품질 gate 우회, 전체 재게시와 rollback은 미검증이다.
서비스 모델 채택 승인과 현재 개인 연구 번들의 `NOT_ADOPTED` 표기를 혼동하지 않는다.

- 623은 FM-v6 미채택 결론과 GitHub 병합 근거가 있다. 하지만 현 Jira의 상세 분포/기여도 제거
  실험 요구와 최신 prefix 결과의 대응, 노트북 원본 재검증 자료가 부족하여 전체 완료는 보류한다.
