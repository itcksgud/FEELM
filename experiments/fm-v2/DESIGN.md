# FM-v2 교정 실험 설계

상태: `PREREGISTERED`(사전등록 완료) — 코드 독립 검토와 점검용 판정 통과 전에는 10% 실행 금지

## 질문

FM-v1의 열세가 FM 계열 자체의 한계인지, 학습 표본·결측값·스케일·무제한 all-pairs
상호작용 설계 때문인지 판별한다. FM-v1 산출물은 수정하지 않는다.

## 고정 입력과 누수 방지

- FM-v1과 동일한 S15P21E106-620 고정 분할·후보와 초기화값 622를 사용한다.
- 어휘, 영화 ID 어휘, 최소-최대 범위, 내부 모델 선택에는 학습 자료만 사용한다.
- 내부 보류 집합은 학습 사용자별 마지막 대상을 사용하며 해당 대상의 모든 N 변형을 함께
  보류한다. 검증 자료로 매개변수·반복 수·프로필을 고르지 않는다.
- 최종 시험 행은 직렬화된 역할을 확인한 뒤 JSON 파싱 전에 제외하며 준비물에도 쓰지 않는다.

## FM-v1에서 교정하는 네 항목

1. **표본**: 사용자-target의 모든 N variant를 학습한다. 각 행의 가중치는 같은 target에 속한
   variant 수의 역수로 두어 target별 총 가중치를 1로 고정한다.
2. **값 의미**: 연속형은 TRAIN 적합 min-max와 clip으로 `[0,1]`에 둔다. 이력이 없을 때 정의되지
   않는 평균·표준편차·연도·거리 값은 활성화하지 않고 별도 결측·비어 있음 표시기만 사용한다.
3. **상호작용 범위**: 모든 쌍을 곱하지 않는다. factor 항은 candidate와 positive-history,
   후보와 음성 이력 사이에만 허용한다. 명시적 관계와 수치 특징은 선형항이다.
4. **희소성**: 장르 외에 학습에서 관측한 후보 영화 ID 이름공간을 넣고 독립 미등록 값 버킷을 둔다.
   사용자 ID는 넣지 않는다. `cross_content`는 movie-ID를 factor에서 제외하고,
   `cross_hybrid`는 포함해 항목 ID 효과를 분리한다.

## 모델과 비교

- `sparse_linear_v2`: FM-v2 전체 벡터의 가중 ridge 기준선.
- `cross_content_fm_v2`: 같은 선형 벡터 + 후보 콘텐츠 × 양성·음성 이력 장르 요인.
- `cross_hybrid_fm_v2`: 같은 선형 벡터 + 후보 콘텐츠·영화 ID × 양성·음성 이력 장르 요인.

FM은 선형 기준선 계수에서 시작한다. 내부 홀드아웃 탐색과 전체 TRAIN 재적합 모두 epoch 0의 선형
상태를 후보로 보존한다. 따라서 factor 학습이 이득을 못 내면 FM은 선형 상태로 되돌아가며,
FM-v1처럼 최적화 실패 때문에 학습 오차부터 더 나쁜 모델을 채택하지 않는다.

## 사전 고정 탐색과 판정 조건

- 선형 정규화 `reg`: `1e-4, 1e-3, 1e-2`
- FM: 요인 `4/8`, 학습률 `0.01/0.02`, 정규화 `1e-4/1e-3`의 고정 설정 4개
- 최대 80회 반복, 인내 횟수 10, 전체 배치 Adam, 기울기 크기 10 제한
- 선택 기준: 학습 내부 보류 집합의 가중 MSE. 검증은 최종 보고에만 사용한다.

10% 실행은 다음 점검용 판정을 모두 통과할 때만 한다.

- 인위적 후보×이력 효과가 있는 합성 점검 자료에서 FM이 선형 모델보다 낮은 MSE
- 모든 변환값이 `[0,1]`, N=0에서 요인 이력 활성값 0
- target별 학습 가중치 합 1, 동일 target의 모든 N variant가 같은 내부 split
- 전체 학습 재적합 FM 가중 MSE가 같은 벡터의 선형 모델보다 나쁘지 않음
- NaN/Inf 예측 없음

## 해석 범위

VALIDATION에서 FM이 개선되면 FM-v1 설계 결함 가능성을 지지한다. 개선되지 않아도 장르·movie-ID
범위에서의 결과일 뿐 director/actor/keyword 또는 실제 서비스 만족도에 대한 FM 일반 기각으로
확대하지 않는다. MovieLens 실제 K1~K49 사용자 수가 작으므로 사용자 내부 앞부분 이력과 실제 저이력 집단을
구분한다. 미평가 후보는 미관측 상태를 유지하며 음성으로 학습하지 않는다.
