# FM-v2 교정 실험 결과

실행일: 2026-09-19
상태: **합성 점검·점검용 실행·10% 검증·즉시 실패 검증기 통과 / 전체 데이터·서비스 채택 진행 불가**

## 결론

FM-v1을 그대로 폐기하지 않고 표본·스케일·결측·상호작용 범위를 교정해 다시 실험한 판단은
옳았다. v2 희소 선형 모델의 사용자 평균 MSE는 0.90489로 v1 선형 모델 0.93477보다 3.20% 낮았고,
v2 콘텐츠 FM 0.90438은 v1 선택 FM 0.96653보다 6.43% 낮았다. v1에서 N=1~9가 N=0보다
악화되던 현상도 v2에서는 평점 MSE 개선 방향으로 바뀌었다. 따라서 **여러 설계·학습 문제가
v1의 열세에 실질적으로 기여했다**는 근거를 얻었다.

그러나 요인 상호작용의 추가 이득은 입증하지 못했다. 콘텐츠 FM의 선형 모델 대비 짝지은
사용자 평균 MSE 차이는 -0.000508(-0.056%)이고 95% 신뢰구간 [-0.001953, +0.000946]가 0을 포함한다.
행 평균 MSE는 오히려 +0.000421 나빠졌다. 혼합 FM은 전체 학습 재적합에서 반복 0으로
되돌아가 선형 모델과 예측 해시까지 같았다. 그러므로 다음 주장은 하지 않는다.

- 필드 교차 FM이 선형 모델보다 우월하다.
- 특정 한 가지 v1 결함이 실패의 단독 원인이다.
- MovieLens의 사용자 내부 앞부분 이력 개선이 실제 저이력 서비스 사용자 개선을 증명한다.

결론은 **FM-v1 폐기는 부당했지만, 교정된 FM-v2도 full-data 학습이나 서비스 채택 근거는
충분하지 않다**이다. 다음 우선순위는 선형 기준선과 실제 사용자 평가이며, FM을 더 연구한다면
평점 회귀가 아니라 별도 합의된 순위 인지 목적함수와 검증된 콘텐츠 시점 자료를
사용하는 새 실험이어야 한다.

## 무엇을 교정했는가

| 항목 | FM-v1 | FM-v2 |
| --- | --- | --- |
| 학습 N 변형 | 대상당 임의 1개, 59,030행 | 모든 N, 197,931행; 대상별 가중치 합 1 |
| 연속형 | z 점수, 결측 대체값도 활성 | 학습 최소-최대 `[0,1]` 제한, 미정의 값 비활성 + 표시기 |
| 요인 범위 | 모든 활성 특징 쌍 | 후보×양성·음성 이력 장르만 |
| N=0 요인 | 결측·z 점수 값으로 상호작용 발생 | 이력 요인 활성값 0, 요인 기여 정확히 0 |
| 희소 ID | 없음 | 후보 영화 ID + 독립 미등록 값; 사용자 ID 없음 |
| 선택 | 단일 FM 설정 | 학습 최신 대상 내부 보류만 사용 |
| 최적화 안전장치 | 선형 모델보다 학습 MSE가 나빠도 유지 | 선형 반복 0 보존, 악화 시 되돌림 |

세 변경 묶음이 동시에 들어갔고 선형 벡터 자체도 달라졌다. 따라서 개선량을 개별 교정 항목의
인과 효과로 분해할 수는 없다.

## 10% 검증 비교

모든 프로필은 모델 지원률과 후보 재현율이 1.0이며 예측값 잘림은 0건이다. 미관측 후보는
음성으로 바꾸지 않고 원래 순위에 남겼다.

| 프로필 | 사용자 평균 MSE | 행 MSE | MAE | 대상 R@10 | 관측 NDCG@10 | 미관측@10 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `sparse_linear_v2` | 0.904888 | **0.923598** | 0.740325 | 0.247757 | **0.243159** | 0.902881 |
| `cross_content_fm_v2` | **0.904380** | 0.924019 | **0.740288** | **0.250456** | 0.236205 | 0.901892 |
| `cross_hybrid_fm_v2` | 0.904888 | **0.923598** | 0.740325 | 0.247757 | **0.243159** | 0.902881 |

콘텐츠 FM 대 선형 모델의 짝지은 결과는 42,239행/3,000명에서 다음과 같다.

- 사용자 평균 MSE 차이: -0.000508, 사용자 부트스트랩 95% 신뢰구간 [-0.001953, +0.000946]
- 평균 행 MSE 차이: +0.000421
- 개선 사용자 비율: 52.3%
- 대상 Recall@10: +0.002699, 관측 NDCG@10: -0.006953

점추정은 지표별로 방향이 갈리고 MSE 신뢰구간도 0을 포함한다. 상호작용 이득으로 채택할 수 없다.

## 학습 내부 선택과 되돌림

검증은 매개변수 선택에 사용하지 않았다. 학습 사용자별 마지막 대상과 그 대상의 모든 N을
보류 집합으로 묶었다. 적합/보류 대상 가중치는 44,030/15,000이다.

| 프로필 | 내부 보류 상대 MSE | 선택 반복 | 가중 학습 MSE |
| --- | ---: | ---: | ---: |
| 선형 모델 | 1.000000 | 해당 없음 | 0.885737 |
| 콘텐츠 FM | 0.998394 | 36 | **0.884343** |
| 혼합 FM | 0.998760 | 6 → 최종 최적 0 | 0.885737 |

내부 개선도 0.12~0.16%에 불과하다. 혼합 모델의 최종 결과는 반복 0 선형 모델로 되돌아갔으며 대상·후보
예측 트리 SHA-256도 선형 모델과 동일하다.

## 점검용 실행과 해석 한계

- 합성 교차 점검 자료에서는 FM/선형 모델 상대 MSE가 0.00162로 구현이 상호작용을 회복할 수
  있음을 확인했다.
- 사용자 200명의 점검용 검증에서는 콘텐츠·혼합 모델이 선형 모델보다 각각 +0.01778/+0.01946 나빴고
  부트스트랩 신뢰구간도 0 위였다. 사전 점검 조건은 학습 내부 조건이었으므로 계약 위반은 아니지만
  일반화 주장을 약하게 한다.
- 실제 K1~K9 이력 집단은 총 12명뿐이다. 위 결과는 주로 고이력 사용자의 앞부분
  절단이며 실제 저이력 사용자 효과가 아니다.
- 상위 10개 중 미관측 후보가 약 90%다. MovieLens 순위 지표는 서비스 만족도 증거가 아니다.
- 감독·배우·키워드는 검증된 snapshot이 없어 사용하지 않았다. movie-ID factor의 실패를 더 풍부한
  콘텐츠 FM 전체의 실패로 확대하지 않는다.
- 채택한 FM-v2 처리 흐름은 최종 시험 행을 역할 문자열로 판별해 JSON 파싱 전에 제외했고
  학습·선택·평가에 사용하지 않았다. 세션 전체에서 FINAL_TEST를 한 번도 열지 않았다고 주장하지는
  않는다. v1 초기 폐기 run의 이력은 v1 결과 문서에 별도로 남아 있다.
