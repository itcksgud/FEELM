# 625 마감: v26 GBT 채택과 로컬 검증 종료

2026-09-23 사용자 승인: **v26 GBT 채택·로컬 검증 종료**로 연구를 마감한다.
개인·파티 모두 GBT로 전환하며 별도 공개근거 품질 필터를 붙이지 않는다.
새 실사용자·실제 파티 만족도와 동일 최신 특징 스냅샷 ALS 대조는 미실시 한계로 남긴다.
이는 운영 구현·배포 완료나 모든 입력에서의 품질 보증이 아니다.

## 동결한 모델·해석

- 859,363개 학습 행, 순서 고정 71특징, 80트리, 깊이4, seed625.
- 공개 도달 근거는 `MAX(TMDB 평가 수, 0.0007732457348003972 × 검증 KOBIS 관객 수)`.
  별도 TMDB 평가 수/precision 경로는 제거했고 TMDB 원평점과 개인 관계 특징은 유지한다.
- 검증 KOBIS 목록 1,741편에는 추가 관객수 하한을 적용하지 않는다.
- 학습 목표는 실제 관측 평점과 구분한다. TMDB 2,294표 이상 또는 검증 KOBIS 목록,
  또는 공개근거 격차에 필요한 개인 연결 조건을 충족하지 못한 관측행의 **파생 학습 목표**를
  0.5로 억제했다(202,103행). 원별점·입력은 보존했다. 미시청 FEELM 영화의 가짜 싫어요는 아니다.
- 점수는 추천 정책 점수다. 예상 별점·만족 확률이 아니다. K≥1의 유효 입력 전체를 사용하며,
  실제 평점이 관심없음 가상1점보다 우선한다. K0은 별도483 경로로 넘긴다.
- TASTE와 PARTY는 원점수/확정 집계 순위다. DISCOVERY의 기존 그룹 공급 의미는 유지한다.
  기평가·감상·관심없음·서비스 불가 제외와 Backend 최종 제외는 그대로 유지한다.

## 확인한 결과

| --- | --- |

파티 공통 후보는 237,532~237,671편이었다. 개인 Top100 합집합은 공동 Top100의
878슬롯을 놓쳤으므로 Top500 공급을 인계 기준으로 유지한다. Top500의 공통 제외 후 후보는
538~690편이다. 이는 해당10명/스냅샷의 구조 검산이며 모든 사용자 조합의 보장이 아니다.

파티는 같은 공통 후보에서 구성원별 midrank 백분위를 동등 가중 평균하고 최저fit·분산·ID로
동점을 푼다. doubled midrank의 정수합/최솟값/분산분자로 순서를 안정화한다. K0 구성원은
평균에 가짜0점으로 넣지 않고 제외 목록만 반영한다. 전원K0은483으로 인계한다.
상대 백분위는 전원이 낮게 평가한 후보도 상위에 둘 수 있어 절대 만족도를 보장하지 않는다.

## 테스트 입력에 대한 정정

영어 제목6행은 **테스트가 넣은 입력**이라는 사용자 확인을 반영한다. 주평가 입력은322개다.
328개를 넣었던 `all-titles` 결과는 입력 수용 시험일 뿐 실제 취향 검증으로 세지 않는다.
`source=RATING` 같은 입력 타입이 실제 행동의 증거는 아니다.

기존 비교 HTML은 이6개가 취향 입력에서는 빠졌지만 본영화 제외에는 남아 있던 검토본이다.
원본은 보존했다. 최종 원순위 파티 검산에서는 테스트 제외를 풀어 누락된6개 사용자–후보
점수만 복원했고, 기존303개 대조 후보 점수가 정확히 같음을 확인했다. 기존점수·모델은 불변이다.
영어 제목 전체를 운영에서 차단하라는 정책은 아니다.

## 남는 한계와 후속 구현

- 새 실제 만족도·실제 파티 반응을 수집하지 않았다. 기존 FEELM 개발 입력 재사용이다.
- 예약 MovieLens는 현재 학습·개발과 사용자 분리됐지만 연구 전체의 완전 미사용을 보증하지
  않는다. 미래 **관측 영화** 안의 비교이며 전체 카탈로그 회수율이나 한국 서비스 만족도가 아니다.
- 현재 공개지표를 과거 MovieLens에 붙인 시점 차이가 있다. 입력 증가가 항상 좋아지는 것도 아니다.
- ALS 비교는 9/14 서빙 번들·현재 Consumer 코드·기본50:50이다. 활성 서버 설정은 미확인.
  ALS는 전체32M으로 학습해 같은 예약평가를 깨끗한 ALS 홀드아웃으로 재사용하지 않았다.
- ALS 역순 점수 불변은36상태 FAIL, 9상태에서 Top100 내부순서 변화(집합은 전부 동일).
  기존 scorer를 고치거나 실패를 숨기지 않았으며 이 문제는 선택한 GBT의 검증 실패가 아니다.
- GBT 최대K 경계의 원순위에는 근거 부족 후보6편이 있었다. 필터 없음은 사용자 결정이며
  모델이 모든K에서 학습 정책을 완벽히 재현한다고 주장하지 않는다.
- 626 번들, 627 개인 scorer, 747 파티 scorer, 483 K0, 644 런타임, 628/735 종단·재게시는
  별도 업무다. 공개 API·DB·운영 설정은 이 게시에서 바꾸지 않는다.
