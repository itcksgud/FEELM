# FM-v3 전체 데이터 기여도 실험

상태: `PREREGISTERED_DRAFT`(사전등록 초안). 적합 전에 결정적 입력 고정과 독립 실행 전 검토가 필요하다.

## 의사결정 질문

FM-v1/v2에서 사용한 10%라는 이름은 실제 조건 충족 학습 모집단의 10%가 아니라 계획 이름이었다. FM-v3는 새 사용자 분할 초기화값 `3623`을 쓰고 초기화값 622의 v1/v2 검증 사용자를 새 검증 역할에서 모두 제외한다. 제외 사용자 집합 digest와 사용자 교집합 0명을 고정한다. 같은 시간 규칙에서 새 분할은 조건을 충족한 학습 사용자 21,075명과 새 검증 사용자 2,766명을 만든다. FM-v3는 학습 사용자 전원과 새 검증 사용자 2,500명을 선택하고 전체 평점 파일 집계를 기록한다.

주 질문은 좁게 정의한다. 남은 기여도 설계 결함을 바로잡았을 때 콘텐츠 후보×이력 요인 항이 정확히 대응하는 가산 모델보다 검증 사용자 평균 평점 MSE를 개선하는가?

## FM-v2에서 바로잡은 항목

1. 어휘와 수치 스케일은 학습 내부 `FIT` 부분에만 적합한다. 모든 학습 사용자의 마지막 대상과 해당 대상의 모든 N 변형은 `HOLDOUT`에 두고 전처리에 사용하지 않는다.
2. 두 모델은 같은 전체 배치 Adam 절차로 학습한 가산 계수를 공유한다. FM은 그 가산 모델에서 시작해 계수를 고정하고 콘텐츠 교차 요인만 학습한다. 따라서 예측 차이는 정확히 요인 항에 귀속된다.
3. 후보 영화 ID는 특징 벡터와 요인 필드에서 제외한다. v2 혼합·영화 ID 질문은 다시 시험하지 않는다. 해당 검증 행의 84.9%가 영화 ID 미등록 값 버킷을 사용했기 때문이다.
4. 요인 학습은 초기화값 623·1623·2623으로 반복한다. 세 초기화값의 학습 내부 보류 MSE 평균으로 하나의 요인 초매개변수 집합을 고른다. 주 검증 예측은 세 결과의 고정 평균 앙상블이며 초기화값별 대상 MSE는 진단 지표다.
5. 준비 컨테이너에는 격리한 학습+검증 입력과 `movies.csv` 하나만 연결한다. 원시 평점과 최종 시험이 든 원천 입력은 연결하지 않는다. 모델 컨테이너에는 읽기 전용 저장소, 준비 산출물, 전용 빈 출력 디렉터리만 연결한다. 최종 시험 행과 다른 실행 디렉터리는 보이지 않는다.

## 고정 비교

- `matched_additive_v3`: 콘텐츠·이력·관계 희소 벡터, ridge 초기화 뒤 대응 Adam 학습.
- `content_cross_factor_v3`: 정확히 고정한 가산 모델에 후보 콘텐츠×양성·음성 이력 장르 요인을 추가. N=0에서는 활성 이력 요인이 없어 요인 기여가 정확히 0이다.

모든 N 변형을 사용한다. 한 사용자-대상의 변형은 같은 내부 분할에 속하고 대상별 가중치 합은 1이다. 검증은 보고에만 쓴다. 평점 사용자 평균 MSE가 유일한 주 지표다. 행 MSE, MAE, Recall@10, 관측 NDCG@10, 미관측 후보@10, N 구간은 진단 지표이며 주 결정을 뒤집을 수 없다.

학습과 검증은 의도적으로 다른 시간 창을 사용하므로 원천 분포 보고서 상태는 `DISTRIBUTION_SHIFT`다. 정확한 보고서 해시와 역할 분포를 고정한다. 이는 측정하려는 시간 일반화 조건이지 승격 실패가 아니다. 결과를 본 뒤 재가중하거나 판정 조건을 바꿀 수 없다.

## 고정 의사결정 규칙

전체 조건 충족 학습 실행에서 `content_cross_factor_v3 − matched_additive_v3` 사용자 평균 MSE의 짝지은 사용자 부트스트랩 95% 신뢰구간 상한이 0보다 작을 때만 상호작용을 지지한다. 그 외에는 가산 모델을 오프라인 기준선으로 유지한다. 이는 다른 FM 특징 공간, 순위 목적함수, 서비스 사용자 효용을 기각하지 않는다.

전체 조건 충족 모집단은 기존 학습 사용자 수의 약 1.41배뿐이고 요인 추정을 바꾸므로 과거 10% 점추정과 무관하게 전체 실행을 수행한다. 이 실험은 최종 시험 개봉, 서비스 채택, 커밋, 푸시, Jira 변경, 배포를 허가하지 않는다.
