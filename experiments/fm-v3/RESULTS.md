# FM-v3 전체 조건 충족 데이터 결과

상태: `PASS — KEEP_MATCHED_ADDITIVE_BASELINE`(통과 — 대응 가산 기준선 유지)

## 결론

전체 조건 충족 데이터 FM 실험을 실행했다. FM의 점추정은 대응 가산 기준선보다 `0.0945%` 좋았지만 짝지은 구간에는 0과 작은 악화가 모두 포함됐다. 사전등록된 오프라인 규칙에 따라 대응 가산 모델을 오프라인 실험 기준선으로 유지한다. 이는 FM이 더 나쁘다는 결론도, 서비스 배포 결정도 아니다.

이는 근거 강도에 따른 결정이다. 요인 상호작용이 해롭다거나 FM을 영구 폐기해야 한다는 뜻이 아니다. 교정된 설계는 가산 예측을 정확히 고정한 채 희소 콘텐츠·이력 상호작용의 기여만 분리한다.

## 이전 FM 실험에서 바꾼 점

- 가산 절편과 선형 가중치를 비트 단위로 공유한다. FM은 사전등록한 후보 콘텐츠×양성·음성 이력 장르 상호작용만 더할 수 있다.
- 후보 영화 ID가 없어 항목별 잠재 ID가 효과를 흡수할 수 없다.
- 전처리 어휘와 스케일은 내부 적합 분할에만 맞춘다. 사용자별 마지막 대상과 모든 N 변형은 보류 집합에 남긴다.
- 이전 초기화값 622 검증 사용자와 겹치지 않는 새 검증 집단을 만들었다.
- 최종 시험 행은 JSON 파싱 전에 거부했고 격리 준비·학습 컨테이너에서 사용할 수 없었다. 평가는 고정 검증 예측만 사용하고 최종 시험을 열지 않았다.
- 주 비교, 부트스트랩 단위, 세 초기화값, 채택 규칙을 전체 실행 전에 고정했다.

기존 학습 사용자 15,000명은 실제 조건 충족 모집단의 10%가 아니었다. 교정 집계에서 전체 조건 충족 학습 사용자는 21,075명이므로 이전 실행은 이미 약 71.2%를 포함했고, 전체 실행은 1.405배 크기였다. 따라서 이전에 전체 실행을 하지 않았다는 사실은 전체 데이터 FM 점수가 더 낮을 근거가 아니었다.

## 진단 순위 지표

모델은 평점을 최적화하고 상위 10개 표본 후보의 약 97.5%는 관련성을 알 수 없으므로 다음은 보조 진단 지표다.

| 지표 | 대응 가산 모델 | 콘텐츠 교차 FM |
|---|---:|---:|
| 대상 Recall@10 | 0.060776 | 0.064141 |
| 관측 NDCG@10 | 0.033280 | 0.035545 |
| 관측 양성 Recall@10 | 0.069385 | 0.074672 |
| 관측 상위 10개 중 낮은 평점 노출 | 0.373735 | 0.361408 |
| 상위 10개 중 미관측 표본 비율 | 0.976010 | 0.974680 |
| 상위 10개 평균 고유 장르 수 | 11.4583 | 10.2511 |
| 상위 10개 평균 장르 Jaccard 거리 | 0.832171 | 0.837125 |

평점·관련성 순위 진단은 대부분 FM에 유리했지만 다양성은 엇갈렸다. 고유 장르 수는 줄고 장르 간 거리는 늘었다. 이 진단은 사전등록된 주 결과를 뒤집을 수 없다. MovieLens는 FEELM 서비스 만족도의 약한 오프라인 대리 지표다. 이 실험에서는 사용자 평가를 하지 않았으며, 신뢰할 수 있고 시험할 가치가 있는 오프라인 이득을 보인 후보에 한해서만 눈가림 사용자 연구가 적절하다.
