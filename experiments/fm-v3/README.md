# FM-v3

이 디렉터리는 FM-v2 뒤에 수행한 전체 조건 충족 데이터 기여도 실험을 기록한다. 사전등록 비교는 `DESIGN.md`, 완료 결과는 `RESULTS.md`에 있다. 대용량 입력, Parquet 파일, 모델, 예측, 로그는 Git 밖 `runs/S15P21E106-623`에 보관한다.

최종 오프라인 상태: `PASS — KEEP_MATCHED_ADDITIVE_BASELINE`(통과 — 대응 가산 기준선 유지).

교정한 전체 데이터 FM의 사용자 평균 MSE 점추정은 가산 모델보다 `0.0945%` 좋았지만, 짝지은 95% 구간에 0과 작은 악화가 모두 포함됐다. 사전등록된 오프라인 규칙에 따라 대응 가산 모델을 오프라인 실험 기준선으로 유지한다. 이는 FM이 더 나쁘다는 결론도, 서비스 배포 결정도 아니다.
