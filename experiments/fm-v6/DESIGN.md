# FM-v6 사용자별 이력 수 공통 입력 설계

상태: `IMPLEMENTATION_IN_PROGRESS_NOT_REVIEWED`(구현 진행 중·미검토). 이 상태 문자열은 실행 당시 고정한 이력 값이며, 최종 완료 판정은 `RESULTS.md`와 실행 보고서를 따른다.

FM-v6는 고정 달력 시점을 사용한 v2/v7 판정 경로를 대체한다. 기존 산출물은 변경하지 않는 감사 이력으로 남기며, MovieLens에 저이력 사용자가 부족하다는 근거로 해석해서는 안 된다.

## 모집단과 시간 모형

- 각 사용자의 MovieLens 평점을 `(timestamp, source_row_number, movie_id)` 순서로 정렬한다.
- 주 짝지은 모집단은 평점이 30개 이상인 모든 사용자다. 편의 표본이 아니라 조건을 충족한 전체 모집단이다.
- 정확한 이력 `K={0,1,2,5,10,20}`을 만든다. 모델은 앞의 K개 사건만 볼 수 있다.
- 사용자별 위치 20~29의 동일한 관측 판단 10개를 모든 K에서 사용한다. 이로써 NDCG@2/4/6/10을 정의할 수 있고, 판단 대상 변화와 이력 추가 효과를 분리한다.
- 정답을 보지 않는 결정적 미관측 후보 표본을 추가한다. 사용자별 후보 순서와 판단 상태는 모든 K에서 같다. 미관측 후보를 음성 정답으로 바꾸지 않는다.
- 고정된 SHA-256 규칙으로 사용자를 학습·검증·최종 시험으로 나눈다. 최종 시험은 별도 봉인 산출물에 쓰며 준비·학습·검증 평가에는 연결하지 않는다.

노출은 단일 달력 절단점이 아니라 사용자별 이력 순서로 정의한다. `prediction_at`은 진단용 메타데이터이며, 누수 방지의 기준은 안정적인 사용자별 순서 위치다. 따라서 타임스탬프가 같아도 정확한 K가 조용히 줄어들지 않는다.

## 모델과 기여도 분리

인기도 모델은 학습 사용자마다 위치 20의 정답 하나만 사용해 적합한다. 학습 모델도 같은 정답 계약과 사용자 모집단을 사용하며, 여섯 K 변형의 사용자별 총 가중치는 1이다. 콘텐츠 선형, 집계 선형, 기존 집계 FM, 희소 선형, 희소 ID-이력 FM, 희소 이력+콘텐츠 FM은 같은 사용자·K·후보·판단 집합을 사용한다. FM 요인은 대응 선형 모델의 절편과 계수를 고정한 채 학습한다. 초매개변수 선택용 어휘와 스케일은 내부 적합 사용자만으로 만들고, 선택 뒤에는 전체 학습 사용자로 전처리와 모델을 다시 적합한다.

## 주장 범위와 판정 조건

이 결과로 제안할 수 있는 것은 입력 수 기준 정책 후보뿐이며 실제 신규 사용자 성능을 주장할 수 없다. 임계값이 유효하려면 사용자 단위 짝지은 NDCG@2에서 FM이 인기도와 콘텐츠를 모두 이겨야 하고, 세 모델 초기화값의 차이가 모두 양수여야 하며, 낮은 평점 노출과 다양성 안전 구간을 통과해야 한다. 후보 재현율과 지원률은 변하지 않아야 하고, NDCG@4/6/10도 같은 방향이어야 한다. 점진 혼합은 해당 임계값 이후의 전체 안정 K 구간이 이 K별·초기화값별 조건을 통과하지 않으면 허용하지 않는다.

관측 평점 10개의 이득이 모두 0인 에피소드는 모든 모델에서 NDCG 0을 부여하고 모든 짝지은 비교에 남긴다. 보고서에는 해당 수를 기록한다. 이 규칙은 검증 개봉 뒤 추가됐으며 사전등록된 규칙이 아니다. 낮은 평점 노출은 고정된 상위 L 분모를 사용한다. 미관측 후보는 노출에 0을 기여하지만 음성 정답으로 바꾸지 않는다.

최종 시험은 `S15P21E106-625`를 위해 봉인 상태로 남긴다.
