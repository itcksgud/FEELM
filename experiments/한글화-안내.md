# FM 실험 문서 한글화 안내

2026-09-20에 `fm-zero-n`, `fm-v2`, `fm-v3`, `fm-v4`, `fm-v5`, `fm-v6`의 사람이 읽는 Markdown 문서를 한글화했다.

## 적용 원칙

- 제목, 본문, 표 머리글, 판정 설명, 실행 안내를 한글로 바꿨다.
- 수치, 날짜, 해시, 파일 경로, 명령어, 수식은 바꾸지 않았다.
- 프로필 ID, JSON 키, 명령행 인자, 상태 상수는 실행 계약이므로 원문을 유지하고 한글 뜻을 덧붙였다.
- Python·Docker 명령어 블록은 실행 가능성을 보존하기 위해 번역하지 않았다.
- 모델 코드, 설정 JSON, 입력 데이터, 학습 산출물, 평가·검증 보고서는 수정하지 않았다.

## 재현성 주의

일부 과거 실행은 `DESIGN.md` 같은 문서도 소스 묶음에 포함해 SHA-256으로 고정했다. 따라서 현재 한글 문서는 당시 실행 시점의 소스 묶음과 바이트 단위로 같지 않다. 이는 문서 번역에 따른 예상된 차이다.

실험 당시의 정확한 소스 해시와 판정은 Git 밖 실행 디렉터리의 불변 `manifest.json`, `validation-report.json`, `verification.json`을 기준으로 삼는다. 한글화는 실험 수치·모델·판정 결과를 변경하지 않는다.
