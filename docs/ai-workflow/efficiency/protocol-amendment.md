# 파일럿의 출력 조건 보완

1차 결과를 보존한 뒤 2026-09-12에 결정했다. 두 조건 모두 엄격한 포함 기준은 3/5였다.
짧은 답변에서 데이터 재사용, 남은 검증, 게시 권한 등의 세부사항이 생략됐다.
문서와 정답·채점 기준은 바꾸지 않고 두 조건에 동일한 2차 요청을 적용한다.

- 답변 한도: 900자에서 1,400자로 변경.
- Q3: 데이터 사용 이력을 명시적으로 묻는다.
- Q4: 연결 대상·중복 방지·환경 비용/응답 검증을 포함한 남은 작업을 묻는다.
- Q5: Jira·MR·커밋·Push·배포 각각의 권한 경계를 명시적으로 묻는다.
- 새 대화 두 개, 같은 Astra/ultra, 같은 봉인 문서 묶음, 도구 읽기 각 1회.
- 1차를 삭제하거나 독립 반복 성공으로 바꾸지 않는다. 두 차수의 사용량·품질을 모두 보고한다.
- 2차도 실패하면 더 반복해 유리한 결과를 고르지 않는다. 관측 결과와 한계를 그대로 남긴다.

이 보완은 원래 연구 결과나 모델 정책을 바꾸지 않는다. 2차의 효과에는 더 명확한 출력 요구가 포함되므로 문서만의 인과 효과로 일반화하지 않는다.
