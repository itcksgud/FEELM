# 사람이 읽고 AI가 이어받는 문서

- 첫 문단에 현재 질문과 결론을 쓴다. 독자가 결정할 내용과 다음 행동을 먼저 보여준다.
- 현재 상태는 `active-experiment.md` 한 곳에서 갱신한다. 과거 상태를 누적하지 않고 이력으로 연결한다.
- 한 페이지 결과 요약과 재현 근거를 분리한다. 원본 수치·config·검토 기록·실패는 보존한다.
- 내부 코드명은 필요한 곳에서만 쓴다. 지표는 의미·좋은 방향·분모를 설명하고 핵심 2~3개만 본문 표에 둔다.
- 확정 / 가정 / 미검증을 구분한다. 근거 없는 원인 설명·완료 선언·새 정책을 추가하지 않는다.
- 결과 요약을 마치기 전에 원문과 대조한다: 판정 기준의 사전 고정 여부, 데이터 이름·재사용 여부, UNKNOWN의 의미, 남은 성능 검증, 외부 변경 권한이 필요한 질문에서 빠지지 않았는지 확인한다.
- 모든 문서에 같은 승인 경고·과거 채팅·Jira 과정을 반복하지 않는다. 현재 결론의 의미를 바꾸는 한계는 요약에도 남긴다.
- 새 사실은 그 사실을 소유한 문서에 한 번 쓰고 링크한다. 기존 양식이 정보를 충족하면 별도 파일을 더 만들지 않는다.
- 문서만 바꿀 때는 링크·필수 의미·근거 보존·diff를 검증한다. 모델 학습·제품 전체 테스트를 다시 실행하지 않는다.

작업 요청은 다음 정도로 시작한다. 필수 계약을 생략시키는 지시로 쓰지 않는다.

```text
목적: 이번에 판단하거나 바꿀 것 한 가지.
입력: 현재 상태 문서와 관련 설계/결과 경로.
완료 기준: 필요한 결과와 검증 조건.
범위: 변경 대상, 보존할 기존 계약.
출력: 결론 먼저, 핵심 지표 3개 이내, 상세 근거는 링크.
```
