# AI와 FEELM 작업하기

현재 추천 연구는 [현재 결론](../recommendation/active-experiment.md), 작업 위치는 [폴더·브랜치 지도](../workspace-map.md)에서 확인한다.

1. 이번에 판단할 질문과 완료 조건을 정한다.
2. AGENTS의 작업별 표에서 필요한 문서를 고른다. 현재 상태를 설명하는 일에 과거 실험 전체를 넣지 않는다.
3. 연구 설계·실행에는 [연구 절차](../recommendation/research-workflow.md), 기능 변경에는 [구현 규칙](implementation.md)을 추가로 읽는다.
4. 결과는 [실험 요약 양식](../recommendation/experiment-summary-template.md)과 [작성 규칙](writing.md)으로 정리한다. 재현·검토 근거는 링크한다.
5. 실제 사용량은 root·검토 에이전트·재시도를 포함해 측정한다. [이번 개선 결과와 재현 방법](efficiency/README.md)을 참고한다.

일상 문서 정리·단순 수정에는 더 작은 모델과 낮거나 중간 추론을 먼저 비교하고, 어려운 설계·오류 분석에 더 강한 모델을 배정하는 운영을 권한다. 품질·재작업까지 비교한 뒤 채택한다.
이번 실험은 문서 개선 효과를 보기 위해 모두 Astra/ultra를 유지했다. 계정·앱의 기본 모델 설정은 변경하지 않았다.

이 작업공간에는 원본 연구의 로컬 문서·스크립트를 복사했다. 대용량 데이터·모델·출력과 자격증명은 복사하지 않았으므로 모델 실험을 즉시 재현할 수 있다고 가정하지 않는다.
