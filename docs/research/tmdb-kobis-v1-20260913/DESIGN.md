# TMDB–KOBIS 관측량·평균평점 분포 분석 설계

상태: **DRAFT · 실행 전 독립 검토 대기** · 2026-09-13.

## 목적과 입력

보유 KOBIS·TMDB의 관측량 관계와 영화 평균평점의 분포를 별도 장표·문서로 설명한다.
추천 모델의 학습·평가·채택, 인과효과 검정, 새 자료 수집은 수행하지 않는다.
기존 봉인·문서·원본은 수정하지 않는다.

- `kobis-service-final-20260913/movie-comparison.parquet`: KOBIS 한국·외국 Top200씩 400행, 제목·제작국·개봉연도 조건의 고유 연결 371편.
- 기존 수집 manifest·독립 감사·B 민감도 정의를 입력 해시와 함께 보존한다.
- MovieLens 영화별 집계와 보유 `ml-32m.zip`은 별점 SD의 두 번째 모멘트를 계산하는 데만 읽는다.
- KOBIS 조회: 2026-09-13; 보유 TMDB: 서비스 스냅샷 2026-09-09, 개별 조회 시각 미확보; MovieLens: 2023-10-13까지.

## 고정한 모집단

| 집합 | 포함 조건 | 입력 검사 결과 | 사용 |
| --- | --- | ---: | --- |
| TK | `match_status=MATCHED`, KOBIS 관객>0, TMDB 투표>0, TMDB `VALID` | 371편 = 한국181·외국190 | 모든 TMDB–KOBIS 관측량·평점 분석 |
| B | TK 중 ML 평가>0이며 TMDB 개봉일≤2023-10-13, ML 제목 연도>2023 아님 | 337편 = 한국163·외국174 | 동일 영화 ML–TMDB 평균 및 ML 개별별점 SD |
| B-SD | B 중 ML 평가≥2 | 334편; 1개 평가 영화 3편은 SD 계산 불가 | 영화 안의 개별별점 SD |

TK에는 ML 평가가 없는 33편과 미래개봉 연결 위키드가 포함된다: 이번 TMDB–KOBIS 비교에 ML 보유 여부를 조건으로 걸지 않는다.
B는 기존 보수 집합이며 시점이 일치한 평가셋이나 실제 감상 여부를 보증한 집합으로 부르지 않는다.
ML 제목 연도 누락과 자료 간 개봉연도 차이는 이상 후보로 보존하고 자동 오매핑으로 확정하지 않는다.

## 통계

1. 관측량: KOBIS 관객·TMDB 투표의 합·중앙값, Spearman 순위 상관, 로그10 값의 Pearson 상관.
2. 비율: 영화마다 `KOBIS 관객/TMDB 투표`를 계산한 5·25·50·75·95백분위와 `TMDB 투표/KOBIS 관객×100만`의 중앙값; 합계의 비율은 별도 열로 표시한다.
3. 규모 구간: KOBIS 관객 `<300만`, `300만~500만 미만`, `500만~1,000만 미만`, `1,000만 이상`; 한국·외국 각각의 n과 관측량 비율을 표시하며, 비율 분자에 조건을 건 구간이라는 제한을 기록한다.
4. 개봉 구간: KOBIS 개봉연도 2004~2009·2010~2019·2020~2023·2024~2026의 한국·외국별 표본 수·통계는 보조 CSV로 남긴다.
5. 평균평점 관계: TMDB 원평균(10점)과 관객·투표의 Spearman, TMDB 원평균과 로그 관측량의 Pearson; 전체·한국·외국을 분리한다.
6. **영화 간 SD**: 영화별 평균을 한 영화 한 표로 보고 `ddof=1` 표본 SD·평균·분위수를 계산한다; TK의 TMDB 원10점/÷2 환산5점, B의 ML5점/TMDB환산5점을 구분한다.
7. **영화 안 SD**: B337에 대해 원본 ML 평점의 n·합·제곱합만 스트리밍 집계하고 `sqrt((sum(r²)-sum(r)²/n)/(n-1))`를 계산한다; 기존 n·평균과 정확히 대조하고 n<2는 결측으로 유지한다.
8. 영화 안 SD의 평균·중앙값·분포도 한 영화 한 표로 요약하되 개별 평가행 가중값과 혼동하지 않고, TMDB 개별 투표 SD와 KOBIS 만족도 SD는 관측할 수 없다고 기록한다.

분위수는 선형 보간, 상관은 유효한 관측 n≥3이고 양쪽 변수가 비상수일 때만 계산한다.
평균의 표준편차는 표준오차·평점의 불확실성·같은 영화에 대한 관객 의견 차이가 아니다.
TMDB÷2는 눈금 변환일 뿐 두 집단의 평점이 같은 척도로 보정됐다는 뜻은 아니다.
