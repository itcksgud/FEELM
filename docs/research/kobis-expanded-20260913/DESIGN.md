# KOBIS 연도별 전체 자료 수집

상태: DRAFT — 로컬 자료 수집 설계. 모델 실험·서비스 적용은 포함하지 않는다.

사용자 요청은 역대 한국/외국 Top200으로 제한된 자료를 연도별 전체 목록과 영화별
누적 관객 수로 확장하는 것이다. 2004–2025 완전한 달력 연도, 2026-01-01–09-12
진행 연도를 수집한다. 전국·국적 전체·영화구분 전체 조건이다. 2004 이전 영화도
이 기간에 발권 실적이 있으면 보존하되 과거 전체 생애 관객 수라고 주장하지 않는다.

## 수집과 검증

1. 공식 기간별 박스오피스 Excel 전체 행: 연간/누적 관객·매출, 국가, 장르, 감독, 배우.
2. 공식 연도별 Excel 전체 행과 영화명·개봉일·국가·배급사·관객/매출의 다중집합 일치 검증.
3. 기간별 화면의 총 건수와 전체 Excel 행수 일치, 화면 코드와 해당 행의 값 일치 검증.
4. Excel에는 영화코드가 없으므로 영화코드 확보/보수적 연결을 별도로 진행한다.
   연결되지 않은 행을 삭제하거나 동명 작품을 임의 합치지 않는다.
5. 영화 상세 통계는 공식통계와 KOBIS 발권통계를 분리한다. 전국 KOBIS 발권 누적만
   같은 출처로 연결하며 기준일을 남긴다. 연도별 누적값을 합하거나 연간값과 max 혼합하지 않는다.
6. 음수 정정값도 원문 그대로 보존하고 별도 flag를 부여한다. 모델 입력 유효값으로 자동 승인하지 않는다.

서로 다른 조회의 총합·행수·내용이 다르면 중단하여 원인을 확인한다. 성공 파일은 해시와
조회 조건을 저장하고 재개 시 확인한다. 네트워크 요청은 순차 처리, 사이 0.5초 간격,
403/429/권한 오류는 중단한다. 대량 영화 상세 조회보다 공식 전체 다운로드를 우선한다.

## 산출물과 주장 범위

원문·조회 조건·시간·SHA256, 연도별 Parquet, 전체 관측 Parquet/CSV, 영화 식별 연결 상태,
누적 관객 수의 기준일, 수집 범위/결측/정정 현황을 별도로 저장한다. 기존 Top200 결과와
서비스 v1 계약은 덮어쓰지 않는다. TMDB 연결은 엄격한 제목·개봉연도·국가 조건의 확정/모호/
미연결 상태를 구분한다. 수집 성공은 추천 성능 개선이나 2026 한국 사용자 만족도 검증이 아니다.
