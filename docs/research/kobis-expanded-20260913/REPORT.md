# KOBIS 연도별 전체 수집 결과

상태: DRAFT — 자료 수집·원문 정합성 및 연결 후보 처리 독립 검산 PASS. 서비스 구현 계약이 아니다.

**2004년부터 2026년 9월 12일까지의 전국·전체 국적 박스오피스 자료를 수집했다.**
역대 상위 200편이나 연도별 화면 상위 50편으로 자르지 않고, 공식 Excel의 전체 행을 받았다.

| 항목 | 수집 범위 |
|---|---:|
| 연도 | 2004–2026, 23개 연도 |
| 영화·연도 관측 기록 | **72,700행** |
| 2025년 전체 기록 | 4,756행 |
| 2026년 진행 중 기록 | 3,752행, 9월 12일까지 |
| 연간 관객 수 1만 미만 | 66,445행, 0 포함 |
| 연간 관객 수 1만 이상·100만 미만 | 5,352행 |
| 연간 관객 수 100만 이상 | 887행 |
| 음수 정정 기록 | 16행, 원값 보존 |

**72,700은 고유 영화 수가 아니다.** 같은 영화가 여러 해 상영되면 여러 행에 들어간다.
위 관객 구간도 해당 연도 실적이며 영화의 누적 흥행 규모와 다르다.
특히 연간 관객 1만 이상·100만 미만 5,352행을 누적 관객 기준 `KO_LOW` 영화 5,352편으로 읽지 않는다.

## 저장한 정보

- 영화명, 개봉일, 대표국가·제작국가, 장르, 감독, 배우, 제작사, 배급사, 관람등급.
- 해당 연도 관객 수·매출액, 스크린 수, 상영 횟수.
- **조회 기간 말 기준 누적 관객 수·누적 매출액**과 기준일.
- 원문, 조회 조건·시각, SHA256, 영화 코드·TMDB 연결 여부와 근거.

예를 들어 명량은 2025년 말 누적 관객 **17,616,661명**이고, 별도 영화 상세 조회의
2026-09-12 누적은 **17,616,791명**이다. 이 둘을 같은 시점의 수치로 취급하지 않는다.
연도별 누적을 더하거나 연간 관객 수와 최댓값으로 섞지 않았다. 2004년 이전 개봉작의
재상영 기록도 보존하지만 원개봉부터의 완전한 평생 관객 수라고 표시하지 않는다.
과거 연도 자료도 현재 조회한 통계이며, 그 당시 확보할 수 있었던 정보의 스냅샷을 재현한 것은 아니다.
초기 연도에는 전산망 가입 범위의 영향도 있으므로 전 기간의 관측 범위가 같다고 가정하지 않는다.

## 영화 식별과 사용 범위

전체 Excel에는 영화 코드 열이 없다. 기간별 화면에 표시되는 연도당 100행에서 직접 얻은
코드는 2,300행·고유 **2,176개**다. 같은 제목·정확한 개봉일·대표국적에 유일하게 대응해도
다른 행에 코드를 확정 전파하지 않고 연결 후보로 남긴다. 영화 단위 집계는 직접 조회된
코드가 있는 행만 사용한다. 동명·날짜 미상·모호한 행은 그대로 남긴다.
**전체 관측 수집은 순위로 자르지 않았지만 직접 코드 영화 표본은 연도별 상위 100행에서 선택됐다.**
이2,176개 영화의 분포를 전체 72,700행이나 국내 모든 영화의 분포로 일반화하지 않는다.

코드를 확정하지 못한 **70,400행**에도 관객 수와 영화 정보는 수집돼 있다. 이 중 코드 제안
2,682행은 확정 코드 집계에 넣지 않는다. TMDB 연결 후보는 별도 열에
남기고, 확정한 영화 표와 합쳐 고유 영화 수를 부풀리지 않는다. 제목·연도·국가의 일치는
공유 식별자 검증이 아니므로 TMDB 제안을 서비스 영화 ID나 MovieLens ID로 자동 확정하지 않는다.
개봉일이 없는 기록은
28,424행이므로 제목만으로 자동 연결하지 않는다.

직접 확인한 KOBIS 영화 2,176개 중 **1,792개**에는 TMDB의 유일한 대응 후보가 있다.
직접 코드가 없는 행 중 **13,779행**에도 행별 TMDB 후보를 남겼다. 두 숫자를 더해 확정
영화 수로 부르면 안 된다. 현재 공유 식별자로 검증하여 확정한 TMDB 연결은 0개다.
TMDB·서비스·MovieLens의 확정 ID와 연결된 평점 값은 비워 두었다. ML 평점이 없다는 뜻이 아니라,
이 수집본에 동일 영화임을 확인해 붙인 ML 값이 없다는 뜻이다.

직접 코드별 누적 요약도 각 영화의 **마지막 직접 관측 행의 기간 말** 값이다. 오래된 연도에만
코드가 보인 영화도 있어 모든 영화의 값이 2026-09-12 기준은 아니다. 마지막 관측이라는 이유로
`CURRENT`를 부여하거나 완전한 생애 누적으로 표시하지 않는다.

현재 모델에 바로 넣는 자동 변환이나 새 모델 학습은 수행하지 않았다. 수집 범위 확대와
모델 입력으로 확정할 영화 연결·값 검증은 구분한다.

## 분석과 서비스 설계에 반영할 내용

**Top200 밖의 자료가 없다는 설명은 이제 맞지 않는다. 수집됐지만 영화별 일대일 매핑·동일 범위 누적값·평가 교집합은 미검증이다.**

| 질문·사용 목적 | 현재 확보한 근거 | 지금의 판단 |
| --- | --- | --- |
| 연도별 관측 규모·작은 연간 실적 확인 | 전체 72,700행과 연간 관객 구간 | 관측행 단위 기술통계의 기반을 확보했다. 고유 영화 수나 누적 저관객 영화 집단은 별도 확인해야 한다. |
| 영화별 KOBIS 누적 비교 | 직접 코드 2,176개와 마지막 직접 관측 `period_end` | 그 코드 표본과 기록된 기간·전산망 범위 안에서 읽는다. 연간값·다른 연도 누적을 더하거나 최댓값으로 섞지 않는다. |
| TMDB 투표·평균과 KOBIS 관객의 관계 | 영화 단위 TMDB 제안 1,792개·코드 미확정 행의 제안 13,779행 | 확정 ID 0개이므로 확대 표본의 상관·평균·표준편차는 아직 계산·검증하지 않았다. |
| MovieLens 동일 영화 비교·추천 평가 | 확정 ML 연결값 없음 | 평가 교집합·지원량을 검증해야 한다. 수집 성공이나 후보 수를 추천 품질 근거로 삼지 않는다. |
| 서비스 후보·학습 입력 | 원관측·코드·제안·기준일·결측 상태 | 서비스 영화 ID와 누적값 유효성 검증이 필요하다. 코드 미확정·누락을 관객0 또는 선호 부족으로 바꾸지 않는다. |

[기존 TMDB–KOBIS 분석 보고서](../tmdb-kobis-v1-20260913/REPORT.md)에는 이번 확대 수집과의
대비를 반영했다. 그 문서의 TK371/B337 상관·평균·SD·그림은 당시 Top200 탐색 비교로 보존한다.
새 표본의 관계로 확대 해석하지 않으며, 당시 `verified`는 제목·국가·개봉연도 기반 탐색 규칙의
표기였으므로 현재 서비스의 출처 간 일대일 ID 검증을 대신하지 않는다.
[서비스 v1 KOBIS 자료 설계](../../recommendation/service-v1-20260913/KOBIS-DATA.md)에서 모델·후보 적용 조건을 확인한다.

## 검증 결과

23개 연도의 원문 69개와 조회 메타데이터를 보존했다. 두 전체 다운로드 경로의 행수·내용,
공식 합계와 각 행의 연간/누적 관객·매출, 모든 저장 셀, 조회 조건과 날짜를 독립 검산했다.
최초 파서가 잘랐던 제목·회사명 텍스트 138셀은 원문에서 복구했고 재검산을 통과했다.
숫자는 변경되지 않았다. 수정 전 파일과 실패 기록도 보존했다.
연결 후보 처리 검산도 PASS이며, 원래 72,700행 보존·직접 코드만 영화 집계에 사용·제안과 확정 ID 분리·
CSV/Parquet 일치를 확인했다. 이 PASS는 후보의 실제 동일 영화 여부를 검증한 상태가 아니다.

원문과 조회 메타데이터는 `outputs/recommendation-evidence/kobis-expanded-20260913/raw/`,
연도별 파일은 같은 상위 폴더의 `year-YYYY.parquet`에 있다. 기존 역대 Top200 보고서는 보존한다.
연결 현황 JSON의 검토 대기 표시는 생성 당시 상태이며 후속 연결 후보 검산은 PASS다.
기존 검토 PASS와 manifest의 문서 해시는 당시 본문 스냅샷의 기록으로 유지했다.
그 원문은 위 갱신 전 문서 보관 기록에 같은 SHA256으로 보존했고, 이번 반영본은 통합 문서 검토에서 따로 추적한다.
이번 문서 갱신에서는 원자료·그림·수치 파일과 봉인을 바꾸지 않았다.

검증 환경은 Python 3.12.5, pandas 2.2.3, pyarrow 23.0.1이다. 저장소 루트에서 아래 명령으로
동일 원문 캐시를 다시 파싱하고 검산할 수 있다. 캐시가 완전하면 추가 다운로드가 발생하지 않는다.

```text
python scripts/collect_kobis_expanded.py --execute --start-year 2004 --end-year 2026
python scripts/audit_kobis_expanded.py --execute
```
