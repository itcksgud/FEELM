# MovieLens 개봉연도별 관측 분포 점검

상태: DRAFT — 2026-09-09 사용자 요청에 따른 기술적 자료 감사. 모형 비교·제품 계약이 아니다.

질문은 MovieLens 자체의 시대별 관측 쏠림과, 현재 REC045 채점 자료가 추가로 생긴 쏠림을
구분하는 것이다. 특정 군집 수·맛 분류·추천 후보 수를 사용하지 않는다.

## 입력과 집계 경계

- 원본 `C:/higher/projects/MM/data/raw/ml-32m.zip` 전체. 고정 SHA256는 실행 코드에 기록한다.
- movies.csv의 제목 끝 `(YYYY)`를 기본 개봉연도로 읽는다. 1800~2026 밖 또는 추출 실패는
  UNKNOWN으로 별도 보존한다. 알려진 표기 오류를 임의로 고치지 않는다.
- ratings.csv에서 userId/movieId/timestamp만 읽는다. 별점 값은 불러오거나 채점하지 않는다.
  ‘리뷰 수’는 리뷰 문장 수가 아닌 관측 별점 기록 수다. 보호된 평가 별점도 열지 않는다.
- 전체 MovieLens 사용자·영화의 관측량 집계는 이번 명시적 전수 점검 범위다. 새 학습이나
  보호 집단의 모델 평가에 사용하는 승인으로 확장하지 않는다.
- REC045 input.npz에서 movie_ids/user_keys/e_index/e_offsets만 읽는다. 원평점·예측·라벨은
  필요하지 않다. 세 회차의 관측 건수, 고유 user–movie 쌍, 실제 지표 가중치 분포를 구분한다.
- TMDB 개봉연도는 누락·불일치 규모를 교차 점검한다. 원본 전체 연도 분포를 TMDB 매칭
  성공 영화로 줄이거나 기본 개봉연도를 교체하지 않는다.

## 사전 고정 집계

매년 및 UNKNOWN/1980이전/1980·1990·2000·2010·2020년대별로 영화 수, 평가 수,
고유 평가자, 영화당 평가량 중앙값·90백분위, 평가0/<10/<50/<100 영화 수를 계산한다.
기본 영화 분모는 movies.csv 전체이며 평가0인 영화도 포함한다. 연대별 고유 평가자는
영화연도별 평가자의 합이 아니라 해당 연대의 사용자 합집합이다.

평가의 상위1%/10% 영화 집중도는 전체 카탈로그 및 각 개봉연도/연대 안에서 각각 계산한다.
상위 영화 수는 ceil(영화 수×비율), 평가는 실제 기록 수로 합산한다. 최소1편을 사용하며
평가가 하나도 없는 구간은 집중도를 판단하지 않는다.

전체 단순 관측 비중과 전체 사용자 동일가중 비중을 함께 계산한다. 후자는 사용자 안에서
연도별 평가 비중을 구한 뒤200,948명에게 동일 가중치를 준다. REC045의 실제 가중치는
각 E쌍에 `1/고유평가사용자수/그사용자의회차등장수/그회차사용자의E편수`를 부여한다.
작은 K의 반복 입력 추출은 E를 바꾸지 않아 연도별 채점 가중치를 추가로 바꾸지 않는다.
MovieLens 사용자 동일가중과 REC045의 가중치를 비교하되 사용자 선정·E 선정 차이를 따로
분리한 인과효과로 해석하지 않는다. 단순 관측 쏠림과 실제 채점의 쏠림을 보여주는 기술통계다.

개봉연도×평점 입력연도의 전체 교차표를 만든다. 같은 연도에 기록했다고 실제 개봉 직후
감상했다고 단정하지 않는다. 연도 차이가 음수인 기록도 제거하지 않고 별도 집계한다.
평점 입력연도−개봉연도의 정수 차이별 평가 수 표도 저장하며 제목 연도 미상은 여기에 넣지 않는다.
2015년 이후 개봉작은 해마다 제시하고2024~2026은 데이터 관측 기간 밖임을 표시한다.

## 검증과 한계

독립 검토 후 실행한다. 전수 평가수32,000,204·고유사용자200,948·영화87,585개,
모든 연도/시간 교차표의 합과 REC045 지표 가중치 합1을 확인한다. source hash와
과거 입력 봉인을 확인하며 기존 출력을 덮어쓰지 않는다. 실행 상한15분이다.
별도 검토자가 ID·timestamp 집계와 분모·비중을 독립 계산해 결과를 검산한다.

이 카탈로그 자체도 전체 세상의 개봉 영화 목록이 아니다. MovieLens에서 평점 또는 태그가
있는 영화 목록이다. 사용자도 MovieLens 참가자 중 최소20편 평가한 사람들이다.
분포 차이가 실제 시장 구성과 얼마나 다른지는 별도의 목표 모집단 없이 정량화하지 않는다.
자료 종료 시각, 신작의 짧은 관측 기간, 영화 선택·평가 기록 행동이 함께 작용할 수 있다.
관측이 부족한 구간의 미확정 결과를 취향이 없다는 결론으로 바꾸지 않는다.

실행: `py -3.12 -B -X utf8 scripts/audit_movielens_release_distribution.py`
결과는 로컬에 저장하며 Jira·GitLab·GitHub에 게시하지 않는다.
