# FEELM REC-EV-030 최종 발표 스크립트

## 1. MovieLens의 빈틈을 콘텐츠로 검증한 과정

이번 실험의 결론은 복잡한 모델이 인기도보다 높았다는 이야기가 아닙니다. 한국 영화와 실제 신작의 정답이
없는 상황에서 콘텐츠 벡터에 사용자별 선호 신호가 있는지, 영화 자체의 쉬운 순위를 반복한 것인지 분리한
과정입니다.

## 2. 서비스 개발에서 만난 두 문제

MovieLens 평점의 78.73%가 유명 외국 영화 proxy에 집중됐고 한국 제작 영화는 0.33%였습니다. 수록 이후
영화에는 상호작용도 없습니다. 출시 전에는 추천 뒤 시청과 평가를 다시 받는 실제 사용자 순환도 만들 수
없었습니다.

## 3. 데이터 역할과 주장 범위

MovieLens는 사용자 평가 행동과 오프라인 정답에만 사용했습니다. TMDB 구조 특징과 E5는 영화 콘텐츠를
표현하는 데 사용했습니다. 콘텐츠 정보가 한국 사용자의 선호 정답을 만든다고 가정하지 않았습니다.

## 4. 입력 정책과 Top2 대리 평가

K는 짝수 2부터 30까지 확인했고 Binary와 사용자별 percentile을 비교했습니다. 고정 별점은 사용자마다
기준이 달라서 쓰지 않았습니다. 서비스 화면처럼 두 편을 평가하고, 평균 선호 외에 두 편 중 최저 선호와
하위 20% 영화 포함 위험을 함께 봤습니다.

## 5. Selection 결과

구조 콘텐츠 direct profile, percentile magnitude, K30이 selection winner였습니다. raw E5와 구조·E5
RRF도 비교했습니다. K30은 탐색 상한의 winner이므로 제품 최적 입력 수라는 결론은 내리지 않았습니다.

## 6. Untouched 사용자 결과

앞선 실험에서 열지 않은 사용자 3,345명과 영화 24,167편을 primary로 사용했습니다. 본인 profile의
HARM20은 25.25%, 다른 사용자 profile은 33.88%, 무작위는 38.16%였습니다. 본인 profile은 다른 사용자
profile보다 위험을 8.63%p 낮췄습니다.

## 7. 동시 신뢰구간

사용자 6개와 영화 4개 지표를 각각 동시에 보정했습니다. 가장 작은 95% 하한도 사용자 +5.07%p, 영화
+2.17%p였습니다. 10개 사전 조건이 모두 통과했고, 별도 작업이 5,000회 bootstrap을 다시 계산했습니다.

## 8. 사용자와 영화 구간

사용자 이력 50~99, 100~499, 500 이상에서 모두 본인 profile의 harm이 가장 낮았습니다. 영화 등장 횟수
구간에서도 본인 profile의 utility가 가장 높았습니다. 한 번만 등장한 영화 10,148편에서도 방향이 같아 인기
영화 몇 편만의 결과라는 설명과 맞지 않았습니다.

## 9. 한국 영화와 최근 영화

KR 247명과 RECENT 382명은 설명값으로만 남겼습니다. KR은 본인 profile이 무작위보다 좋았지만 다른 사용자
profile보다 좋지 않았습니다. RECENT는 좋은 방향이었지만 실제 MovieLens 수록 이후 신작의 정답이 아닙니다.

## 10. 최종 판정

TMDB 구조 콘텐츠 profile이 가린 관측 영화에서 사용자별 선호 신호를 낸다는 점은 확인했습니다. 한국 사용자
만족도, 실제 신작 품질, 제품 최적 K는 확인하지 못했습니다. 따라서 콘텐츠 후보화 근거만 남기고 Locked
Test와 제품 정책은 바꾸지 않았습니다.
