### 5-4. 평가·상태

| 용어 | 정의 | 주의 |
|---|---|---|
| 평가 (Rating) | 감상 후 입력하는 5단계 만족도 | 온보딩 입력은 좋아요/싫어요 2단계로 별도 매핑 |
| 관심없음 | 추천 노출에서 제외하기 위한 상태값 | 평가가 아님. 평점 테이블에 저장하지 않음, 추천 로직에는 반영됨. |

| 감상 완료 | 감상 확인 후 평가까지 완료한 상태 | 이 시점에 프레임이 생성됨. 팝콘 맛 별 양은 여기서만 증가 |
| 감상 확인 | 재접속 시 실제 감상 여부를 묻는 절차 | 링크 클릭 발생 2~3일 후 |
| 만료 | 감상 확인에 7일간 응답이 없어 소멸한 상태 | 신호로 활용하지 않음 |
| 감상평 | 영화에 대한 사용자의 감상평 | |

## 1. 프로젝트 개요

사용자의 영화 감상·평가 데이터를 분석해 개인 취향을 파악하고, 감상한 영화를 필름 형태로 시각화하는 영화 추천 서비스이다.

ALS와 콘텐츠 기반 추천을 활용해 취향 맞춤 추천, 취향 발견 추천, 유사 추천을 제공하며, 여러 사용자가 함께 영화를 고를 수 있는 파티 추천 기능도 제공한다. 감상과 평가가 쌓일수록 필름이 확장되어 사용자가 자신의 취향을 발견해 나가도록 하는 것을 목표로 한다.

## 6. 추천 시스템 구성

| 유형 | 흐름 |
|---|---|
| 개인 맞춤 추천 | 사용자 평가·감상 데이터 → ALS → 예상 선호도 계산 → Top-N 추천 |
| 유사 영화 추천 | 영화 메타데이터·임베딩 → 콘텐츠 유사도 계산 → 유사 영화 추천 |
| 취향 발견 추천 | 선호 가능성 + 기존 취향과의 연결성 + 미경험요소 → 발견 영화 선정 |
| 파티 추천 | 구성원별 예상 선호도 → 평균 만족도·최저 만족도·편차 고려 → 그룹 Top-N 추천 |
| XAI | 추천 점수 + 사용자 취향 데이터 + 영화 특성 → 추천 근거 추출 → 사용자에게 설명 |
