# 와이어프레임 충돌 검토 및 결정 기록

- 검토 대상: `FEELM UI Mockups 찐최종 (1).html`
- 검토일: 2026-08-27
- 목적: 와이어프레임과 요구사항 정의서의 충돌 사항 및 `04-open-questions.md`에 대한 팀 답변을 공유한다.
- 개발 범위: 1차 MVP와 2차 MVP 전체를 유지한다. 누락된 2차 MVP 화면은 범위에서 제외하지 않고 추후 와이어프레임에 추가한다.

## 4. 용어 및 구현 원칙

- 감상 확인과 평가는 분리할 수 있지만, Rating이 없으면 Frame·Popcorn을 생성하지 않는 기존 원칙은 후속 결정 전까지 유지한다.
- 온보딩의 좋아요/싫어요는 일반 Rating에 저장하지 않는다.
- 필름은 전체 프레임 모음이다.
- 리포트는 반기 단위다.
- 리포트 공유 링크는 서버에 저장하고 생성 후 1개월 뒤 만료하며, 외부 사용자가 접근할 수 있다.
- 사용자는 리포트를 휴대폰에 내려받을 수 있다. 파일 형식은 추후 결정한다.
- `Party`를 사용하고 `Group`과 혼용하지 않는다.
- 파티는 최대 4명이며 앱 안에서 닉네임으로 초대하고 수락한다.
- 기본 추천 3개는 맞춤 2개와 발견 1개로 구성하고, 발견 후보가 없으면 맞춤 3개로 채운다. UI는 추천 유형을 표시한다.
- 구독하지 않은 OTT의 영화도 추천 후보에서 제외하지 않는다.
- 팝콘 맛은 8개로 구성하되 명칭과 매핑은 데이터 분석 후 확정한다.
- 소셜 로그인은 구글·카카오·네이버를 지원한다.
- `관심없음` 기능은 현재 범위에서 제외한다.
- 취향 리포트의 상세 구성은 아직 미정이다.
