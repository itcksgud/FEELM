## P0 — API 계약을 막는 질문

### 인증·사용자

- 인증은 세션 쿠키, JWT Bearer, 소셜 로그인 중 무엇인가?
- 회원가입 필수 필드, 중복 기준, 로그아웃의 세션·토큰 무효화 범위는 무엇인가?
- 비회원이 영화 검색·상세·유사 추천을 볼 수 있는가?
- 사용자 공개 범위는 무엇이며 `FR-25`의 공개 설정은 어디서 관리하는가?

### 온보딩·평가

- 온보딩 영화는 몇 편이며 어떤 기준으로 제공하는가?
- 온보딩 완료에 필요한 최소 평가 수, 건너뛰기, 재수행 정책은 무엇인가?
- 좋아요/싫어요를 5단계 평점 또는 사용자 벡터에 어떻게 매핑하는가?
- 감상 후 5단계 평가는 정수 1~5인가, 0.5 단위를 허용하는가?
- 평가 수정·삭제, 같은 영화 재감상, 수동 감상 기록을 허용하는가?

### 감상 상태

- 감상 확인 노출 시점은 정확히 클릭 후 2일인가, 용어 정의의 2~3일인가?
- 사용자가 `감상하지 않음`이라고 답하면 어떤 상태가 되며 추천 신호로 사용하는가?
- 같은 영화·OTT 링크를 여러 번 클릭하면 기존 `WatchIntent`를 갱신하는가 새로 만드는가?
- 7일 만료의 기준 시각과 사용자 시간대는 무엇인가?
- 감상 확인과 별점 저장은 반드시 한 요청에서 원자적으로 완료하는가?
- 감상평은 별점, 한줄평, 메모 중 무엇을 포함하며 1차 MVP에서 작성·수정 가능한가?

### 필름·팝콘·취향

- 사용자·영화당 프레임은 최대 1개인가, 재감상마다 새 프레임이 생기는가?
- 영화가 여러 장르에 속할 때 팝콘 맛 한 개를 어떻게 결정하는가?
- 예정된 8개 맛의 목록과 장르 매핑은 무엇인가?
- `새로운 맛`의 임계치는 사용자별 고정 수량인가, 비율·기간을 고려하는가?
- 취향 분석의 장르·국가·시대·감독 점수 범위와 갱신 시점은 무엇인가?
- 취향 키워드 사전, 3~5개 선택 규칙, 동점 처리 방식은 무엇인가?
- 적합도 표기는 %, 예상 별점, 구간 라벨 중 무엇인가?

### 추천

- 세 추천이 모두 마음에 들지 않을 때 추가 추천을 제공하지 않을지, `다른 추천 보기` 또는 `관심없음`을 제공할지?
- 감상 이력이 있는 영화는 Rating 삭제 후에도 제외한다. 관심없음과 이용 불가능한 OTT의 제외·감점은 어떻게 할 것인가?
- 배치 Top-500의 생성 주기와 새 사용자 fold-in 직후 처리 방식은 무엇인가?
- XAI 근거는 구조화된 코드와 자연어 문장 중 무엇을 계약으로 제공하는가?
- 추천 서비스 장애 시 빈 목록, 인기 영화 fallback, 캐시된 결과 중 무엇을 반환하는가?

### 파티

- 파티 생성 후 초대·참여 방식, 최대 인원, 유효기간은 무엇인가?
- 파티원은 모두 서비스 회원이어야 하는가?
- 파티장만 가능한 행위와 파티 종료·삭제·나가기·위임 정책은 무엇인가?
- 취향 유사도와 파티 추천 점수의 정확한 계산식·표기법은 무엇인가?
- 멤버가 변경되면 결과를 동기로 재계산하는가, 비동기로 갱신하는가?

### 2차 MVP 공개·소셜 계약

- 필름과 팝콘 버킷의 공개 범위는 `비공개/회원 공개/전체 공개` 중 무엇을 지원하는가?
- 취향 비교를 허용하려면 두 사용자 모두 공개 상태여야 하는가?
- 공유 리포트는 비회원도 토큰 링크로 볼 수 있는가? 링크 만료와 공유 중단을 지원하는가?
- 한 사용자는 영화당 한줄평을 하나만 작성하는가? 수정·삭제를 허용하는가?
- 한줄평에 사용자 이름·프로필·별점 중 어떤 필드를 노출하는가?
- 트렌드 응답의 집계 기간과 `asOf` 시각을 어떻게 표현하는가?

## P1 — 구현·운영 기준

- 영화 데이터와 OTT 제공 정보의 출처, 갱신 주기, 지역 기준은 무엇인가?
- 영화 검색은 형태소·초성·오타 허용을 지원하는가? 기본 정렬은 무엇인가?
- 필터 값은 ID, 코드, 한글 이름 중 무엇을 사용하며 여러 조건은 AND/OR 중 어떻게 결합하는가?
- 캐시 목표 지연시간, TTL, 평가·감상 후 무효화 기준은 무엇인가?
- 추천 장애 timeout, 재시도, circuit breaker, fallback의 정량 기준은 무엇인가?
- 서비스 DB와 HDFS 간 데이터 동기화, 재처리, 중복 제거 책임은 어디에 있는가?
- 배치 성공 SLA, 실패 알림, 마지막 정상 결과 유지 기간은 얼마인가?
- API 감사 로그와 추천·평가 이벤트의 보존 기간은 얼마인가?
- 반기 리포트의 기준 기간, 최초 생성 조건, 재생성 정책은 무엇인가?
- 리포트 공유 카드의 이미지 생성 주체와 보관 기간은 무엇인가?
- 한줄평 길이, 신고·차단·비공개 전환 시 노출 정책은 무엇인가?
- 급상승 영화의 시간 창, 최소 평가 수, 이전 기간 대비 산식은 무엇인가?

| 랭킹 | `상영관 매출 랭킹`인데 기준은 팝콘 수와 새로운 맛 발견 횟수 | 매출의 정의 또는 기능명 수정 |
| 감상 기록 | 용어에는 평가·한줄평·감상 메모, FR-19에는 별점만 명시 | 1차 MVP 입력 범위 확정 |
| 상태 | 원문 문서 자체가 `검토 중` | 확정 전 OpenAPI를 계약으로 배포하지 않도록 표시 |
