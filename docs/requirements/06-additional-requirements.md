# 추가 합의 요구사항

Notion 원문 `FR-*`를 수정하지 않고, 와이어프레임 검토와 팀 결정으로 새로 추가된 요구사항을 `AR-*`로 관리한다. `AR-01`~`AR-12`는 기능 묶음이며 실제 개발·테스트 단위는 `AR-01.1`처럼 분리한 원자 요구사항 ID를 사용한다.

- 기준일: 2026-08-26~2026-08-27
- 최신 결정: 3차 결정 · 2026-08-27
- 결정 이력: 1·2차 누적 기준 2026-08-26(Notion), 3차 결정 2026-08-27
- 이력 한계: 1차에서 2차로 바뀐 상세 내역은 확인할 수 없어 두 차수를 분리해 귀속하지 않는다.
- 관련 결정 기록: `05-wireframe-decisions.md`
- 상태 표기: `확정`은 구현 계약에 반영할 수 있는 항목, `결정 필요`는 구현 전에 팀 답변이 필요한 항목이다.
