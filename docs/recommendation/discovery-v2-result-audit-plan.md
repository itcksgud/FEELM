## Bounded execution and interpretation

The audit loads one user's detailed JSON at a time, uses read-only memory-mapped content arrays, fixes numerical threads to2, and records elapsed time and script/source hashes. A CLI execution flag is required to read stage outcomes. Synthetic tests can run without reading outcomes. The audit fails on any unexplained mismatch; no numerical tolerances are widened after seeing results. Floating scalar comparisons use absolute tolerance1e-12 and relative tolerance1e-10; candidate IDs, ordering, gates and decisions are exact. Profile/score arithmetic uses float64. Hash verification is exact.

An aggregate PASS means the saved result and prescribed finite decision were reproduced within this scope. It does not establish human discovery satisfaction, fresh temporal generalization, or production readiness. Metadata examples and all-catalog final mutation invariance are separate audits.
