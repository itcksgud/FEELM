# FEELM 추천 실험 총정리

상태: DRAFT — 개인 연구 총정리. REC041의 분류·발견 정책 진단을 반영하며 품질·최종8맛·전환K는 보류한다.

2026-09-08 최신: [분류2안×발견 정책2안의 실제 연결 결과](../../experiments/rec-ev-041/RESULT.md).
같은 원별점 ALS·입력30편·2,180명에서 연결형의 발견 제공은 개선 규칙97.2%/장르KM94.3%,
맞춤3번째 영화보다 ALS 점수가 낮으면 보류하는 안은77.1%/58.9%였다. 네 조합 모두3편을 제공했다.
그러나 최종 선택 영화의 알려진 정답 슬롯은 이번 E에서 전부0개여서 실제 선호·불호 감소는 미판정이다.
전체 카탈로그의 관측 고선호 발견 기회는824명/675명에게 있었지만 최종100에서는1명/2명에게만 남았다.
후보 존재·정답 관측·고선호 존재를 분리하며, 미평가 후보를 오답으로 보지 않는다.
ALS에 맛을 추가 학습하지 않았다. 맛은 T/D 자격에 사용했고 두 TV-only 배정은 역할에서 동일하게 제외했다.
최신 연구 역할은 맛별 평균 상쇄 대신 개별 긍정 관측을 보존한다. 아래 과거 역할안은 당시 기록이다.
다음 입력량·영화 선정 축은 설계만 했으며, 품질 자료 없이 n별 결과를 늘려 K를 선택하지 않는다.
실제 슬롯 판단 자료 → 입력량/선정 비교 → 고정 정책의 전환K → 온보딩 부담 확인 순서를 따른다.
REC040 당시 상위 문서5개는 REC041 master-before에 원 해시로 보존했다.

다음 추천 비교에는 개선 RULE_GENRE_SET과 고정 KM_GENRE를 포함하며 기존 첫 장르 RULE은 변경 원인의 대조로 보존한다.
이는 최적 규칙·추천 품질 승자·최종8맛 채택을 결정한 결과가 아니다. 새 fit·128재채점·평점·slot 실행은 없다.

**장르 단독을 우선 검토할 방향으로 좁히고, 단순 장르 규칙과 장르 K-means를 잠정 후보로 남긴다.**

장르 K-means의 28편보다 많았다. 이 상충 때문에 최종 승자를 정하지 않는다.
태그 K-means는 지원 영화의 88.84%가 한 그룹에 몰렸고, 태그 전용 두 안은 23,575편에 입력 근거가 없었다.
점수는 고정 군집과 4편으로 만든 설명을 합친 구성의 AI 진단이다. 알고리즘 일반의 우열·추천 품질·8맛 완성을 뜻하지 않는다.
이번 고정 비교는 종료하며 새 탐색·재채점·추천 품질 실험을 자동 추가하지 않는다.
REC034 공급 결과는 기존 전체 텍스트 K-means에 대한 것이므로 새 장르 K-means 후보에 그대로 옮길 수 없다.
전체 8안의 [군집 설명과 영화 사례](../../experiments/rec-ev-038/GROUPS.md)를 함께 보존한다.

앞선 [장르·키워드 분리와 줄거리 대조 결과](../../experiments/rec-ev-037/RESULT.md):
**01·02·04의 설명은 구체적으로 보강할 수 있었지만, 서로 다른8취향이라는 근거는 아직 부족했다.**

**현재 K-means의 계산·출처는 맞지만, 서로 다른8취향으로 충분히 설명된다는 근거는 부족했다.**

원별점 ALS에 이진 응답을 환산해 넣는 안은 원별점 입력과 분명한 차이를 확인하지 못했다.**

## 목표와 확정 범위

**인기 추천으로 시작해 취향 정보가 쌓이면 개인화하고, 맞춤2편·발견1편을 제공한다.
온보딩은 그 정보를 적은 부담으로 얻는 수단으로 검증한다.**

- 유지: 외부 맛·색상8종, 영화별 대표 맛 하나, 별점0.5~5.0·간격0.5, 맞춤2·발견1과 정해진 fallback.
- 유지: 온보딩 skip, 온보딩과 감상 평가의 구분, 온보딩은 팝콘을 만들지 않음.
- 분류 연구 현황: **REC040 개선 규칙과 장르 K-means를 REC041에서 같은 추천 경로에 연결했다. 공급은 확인했지만 실제 선호·최종 우위·8맛 채택은 미확인.**
- 아직 정하지 않은 것: 유형 구분·선정의 세부 규칙, 최종 전환 K, 온보딩 권장 분량.

공식 계약의 K-means는 현재 유지되며 이번 변경은 연구 설계에만 적용한다.

## 전체 순서

| 단계 | 할 일 | 여기서 얻을 결정 |
| --- | --- | --- |
| 1. 입력·평가 기준 | 별점/온보딩 해석, 선호·불호·발견 지표, 정답 범위와 재현 설정 정리 | 무엇을 좋은 추천이라 판단할지 |
| 2. 기본 추천 | 보정 평균 별점 기준·ALS 단독을 확인하고 기존 결합의 추가 이득 점검. 이미 확인한 근거는 재사용 | 기본 추천의 취향 반영과 콘텐츠 결합의 필요성 |
| 3. 분류 준비·내용 비교 | REC038의8개 구성 비교 후 REC039 추론 계약, REC040 전체 장르 개선 규칙을 고정 | 개선 규칙도 다음 추천 비교에 포함. 최종 8맛 채택은 보류 |
| 4. 맞춤2·발견1로 비교 | REC041 네 조합의 공급·보류 확인 완료. 실제 슬롯 판단 자료를 연결하고 입력량·영화 선정 축을 별도 검증 | 품질 근거가 있을 때 분류·유형·입력 정책 선택. 현재 품질 미판정 |
| 5. 전환 K | 고정 정책에서 입력량별로 인기 대비 이득과 손실을 확인 | 개인화 전환 K 또는 근거 부족에 따른 미판정 |
| 6. 온보딩·서비스 확인 | K 도달 시간·이탈·부담, skip·수정·삭제·추가추천·교체 확인 | 편의성과 실제 동작에 관한 채택 근거 |

**분류 방법은 3단계에서 준비하고 4단계의 실제 추천 결과로 선택한다.
최종 K는 모델·분류·유형 규칙·입력 처리를 고정한 뒤 5단계에서 정한다.**
평가 삭제로 K 아래로 내려간 경우의 전환 원칙도 4단계에서 정하고 5·6단계에서 확인한다.

## 끝없이 늘리지 않는 기준

기본적으로 각 결정은 기준안 하나와 필요한 대안 하나로 제한한다. REC038은 사용자가 명시적으로 확장한 8개 구성의 고정 비교였다.
REC040은 기존 첫 장르 규칙만으로 규칙 방법을 대표할 수 없다는 사용자 지적에 따른 개선 ONE이다. 결과를 본 뒤 규칙을 반복 튜닝하지 않았다.
그 비교는 종료했으며 모든 미정 사항을 새 실험으로 만들지 않는다.
모델·내부 k·카드 선정·후보500/100 크기 등의 추가 비교는 구체적인 결함이 드러난 경우만 검토한다.

분류 비교의 실질적 이득·허용 손실·운영 비용·자료 정밀도·종료 시점은 결과 전에 정한다.
K-means의 추가 복잡성을 감수할 이득이 있으면 채택 후보로 삼고, 실용적으로 비슷하면 단순한 쪽을 택한다.
근거가 부족하면 품질 우열은 미판정으로 남긴다. 기본 요건을 충족한 단순안을 잠정 개발 후보로
둘 수 있지만 성능 승리나 서비스 채택 근거라고 하지 않는다. 결과가 아쉽다고 세 번째 방법을 추가하지 않는다.

| 10 | 평균 선호·저선호 포함은 각각2/3회 유리. 낮은 쪽 선호는0/3회 | 일부 이득, 반복 확인은 미충족 |
| 30 | 평균 선호·낮은 쪽 선호·저선호 포함 모두3/3회 유리 | 이3개 분할에서 이득 재현 |

그 전 [ALS 단독 비교](../../experiments/rec-ev-032/als-only/RESULT.md)는 같은 checkpoint에서 콘텐츠
결합만 제거했다. 기존 결합 M0 대비로는5/10/30 모두 세 지표가 유리했다. 이번 반복에서는 M0를 다시 비교하지 않았다.
학습 정보가 없는 영화의 지원 방식도
다르므로 RRF 수식만의 인과 효과를 분리한 결과는 아니다. ALS가 충분히 수렴했는지도 검증하지 않았다.
앞선 결합의 불리함을 ALS 자체의 실패로 확대하지 않는다. 이후 연구의 기본 비교 기준은 ALS 단독으로
두고 콘텐츠는 추가 이득이나 부족한 영화 지원 등 역할별 근거를 확인한다. 같은 가중 결합을 자동 유지하지 않는다.
이는 연구 판단이며 공식 Hybrid 계약·제품 코어를 변경한 것이 아니다.
기본 추천의 추가 모델·분할 탐색은 여기서 멈췄다. 이어 단계3 두8맛 분류안도 준비했다.

원래 실제 추천에는 평점 누락이 많았고 [정답 보충](../../experiments/rec-ev-032/label-extension/RESULT.md)도
이를 해결하지 못했다. 같은 추천의 원본 재조회는 종료했다. 위 ALS 결과는 관측 영화 안의 비교이며
실제 새 추천·맞춤2/발견1·최종 K·온보딩 편의성의 판정으로 확대하지 않는다. K=30을 선택하지 않았다.
이번 반복도 이미 평가한 개발 자료 안의 안정성 점검이며 완전히 새로운 자료의 최종 확증은 아니다.
REC030의 기존 조건부 콘텐츠 근거는 유지하며 실제 서비스 품질에는 대상 사용자 판단 자료가 필요하다.

입력·채점 정의는 [1단계 설계](stage-1-input-evaluation.md), 처음의 실행과 결합 비교는
[원래 결과](../../experiments/rec-ev-032/RESULT.md)와 [조건부 결합 결과](../../experiments/rec-ev-032/conditional-ranking/RESULT.md),
평가 방향을 바꾼 근거는 [평가 문제 수정안](evaluation-repair.md)에 보존했다.

전체 설계와 종료 기준, 연구 모델·8맛 배정 산출물을 확보했다. 슬롯별 품질·최종 K·온보딩 부담은 미확정이다.
연구 문서·실험 코드만 변경했으며 공식 계약·코드는 변경하지 않았다.

## 앞선 분류 산출물·역할·공급 결과

[단계3 결과](../../experiments/rec-ev-033/RESULT.md): 같은85,517편에서 단순 장르안은85,505편,
K-means안은85,517편을 배정했다. 단순안의12편 미배정은 TV Movie만 있는 경우다.
단순안은 장르 역순 진단에서49.70%가 바뀌었고, K-means는 seed 진단의 최적 코드 정렬 뒤99.72%가 일치했다.
일부 K-means 군집은 원언어 분포 차이가 뚜렷해 이름/맛 해석 검수가 필요하다. 안정성을 품질 우위로 읽지 않는다.
영화별 배정·거리·대표 문구/영화·언어 집계·원천 캐시까지 독립 전수 검산했다.

[단계4 역할 제안](stage-4-policy-proposal.md)은 좋아하는 맛의T2와 관측 경험이 없는 다른 맛+연결 근거의D1을
분리하는 연구안이다. 온보딩·삭제·미배정·T부족·같은 타입 교체 등 합성 검사13개와 독립 검토를 통과했다.
K1 전환·이진 입력의 raw ALS 연결·공식 제품 의미를 승인한 것은 아니다.
[REC034 원결과](../../experiments/rec-ev-034/RESULT.md)는 같은ALS n30에서 raw500→타입적격→100→입력제외→슬롯을
확인했다. A2,168명·B2,026명이2+1을 구성했다. A3명·B141명은 양수 선호 영화가 있어도 맛별 평균이 상쇄돼
T지원 맛을 잃었고, B13명은100개 절단에서T2를 잃었다.

[후속 대안 결과](../../experiments/rec-ev-034/gating-repair/RESULT.md)는 개별 양수 선호 근거를 보존하는 규칙 하나다.
같은2,180명에서 A2,171명·B2,180명이2+1을 구성했고 기존 성공자의 새 공급 실패는0명이었다.
두 결과 모두 실행·독립 전수 검산을 마쳤다. 실제 전체 감상 경험이 아닌 관측 입력 내 미경험 proxy이며,
B의100%는 공급률이다. 사용자 만족·분류 승자·K30을 뜻하지 않는다. 이 공급 비교는 여기서 종료한다.
