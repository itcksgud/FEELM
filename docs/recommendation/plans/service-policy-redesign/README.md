# 추천 정책 재설계: 먼저 요구사항 분류, 다음 실험 설계

상태: DRAFT — 2026-09-07 사용자 지적에 따른 재설계. 신규 실험은 실행하지 않았다.

1. [요구사항 분류](requirements-classification.md): 유지할 제품 목적·사용자 제약, 수정 우선 기술선택, 의미를 확정할 공백.
2. [실험 설계](experiment-design.md): 상태·자격→후보공급→맞춤2편/발견1편의 별도 품질→입력·군집 순서.
3. [자료 준비 상태](data-readiness.md): 기존 자료로 가능한 검증과 추가준비/불가능 범위.
4. [검토 기록](review-log.md)과 [출처 버전](source-manifest.json).

현재 기준은 맞춤2+취향발견1이다. 발견은 새맛자격과기존취향연결을 모두 요구한다.
외부팝콘8종·반별점간격은 유지한다. 내부군집수, 임계치, 입력·점수변환, 후보유입과재정렬은
목적에맞는변수로비교한다. 일반Top3 또는인기도3편으로제품목적을대체하지않는다.

먼저 결정할 공백은 온보딩만있거나맛경험이적은사용자의TASTE2 자격, 새로운맛임계치,
발견1편의연결판정이다. 숫자와예외를임의로채택하지않고대안·영향·검증방법을썼다.
실제노출된각슬롯의품질을판정할수없는자료로추천정책의승자를정하지않는다.
