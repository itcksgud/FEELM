# 별점 서비스를 유지하며 온보딩 응답을 ALS에 연결한다

상태: DRAFT. 사용자의 서비스 조건을 반영한 우선순위 수정. 새 변환값·학습·성능 결과를 확정하지 않았다. 2026-09-08.

**감상 평점은0.5~5.0·간격0.5로 계속 받고, 온보딩 LIKE/DISLIKE를 별점 기반 ALS에 연결하는 방법을 먼저 검증한다.**
전체 별점 학습 자료를 이진화하는 것은 필수가 아니다. 기존 [세 표현 학습 설계](als-input-representation-design.md)는
학습 목표와 입력을 함께 바꾸는 정보 표현 연구였으며, 현재 서비스의 온보딩 연결에 필요한 최소 실험과 달랐다.
전체 이진 ALS 학습은 이번 우선 실행에서 제외한다. 아직 그 설계의 학습·채점을 실행하지 않아 되돌릴 모델은 없다.

## 별점으로 변환한다는 의미

원별점으로 학습한 영화 벡터를 유지하고, 온보딩 응답에서 같은 목표 척도의 추정값을 만들어 사용자 벡터 계산에 사용한다.
영화 모델 전체를 이진 목표로 재학습할 필요는 없다. 학습과 사용 시 목표 의미를 맞춘다는 원칙도 유지된다.
별점 UI를 유지한다는 사실이 내부 상대값 학습을 금지하는 것은 아니며, 원별점 ALS와 상대값 ALS의 비교는 별도 질문으로 남는다.

LIKE는 좋아한다는 방향을 알려주지만3.5점과5.0점을 구분해 주지 않는다. DISLIKE도 정확한 한 별점으로 복원되지 않는다.
`LIKE=4.0, DISLIKE=2.0` 같은 규칙은 가능한 단순 비교안의 예일 뿐 현재 확정값이나 검증된 대응이 아니다.
극단값 대입·선호 강도·신뢰도를 실제로 관측한 것처럼 가정하지 않는다.
따라서 변환 결과는 **추천 계산용 추정 목표**이며 사용자가 남긴 감상 별점이 아니다.

## 출처와 상태를 보존한다

- 원별점과 LIKE/DISLIKE 원응답을 그대로 보존하고, 변환 버전·추정값·적용 근거를 별도로 둔다.
- 추정값을 `RawRatingPacket` 또는 실제 ratings에 몰래 넣지 않는다. 별도의 온보딩 adapter가 모델 목표를 만든다.
- 실제 별점의 반별점 검증은 그대로다. 내부 추정 목표는 확률 평균 등 연속값일 수 있으며 그 범위·유한값 검증은 별도 계약이다.
- LIKE/DISLIKE는 감상 기록·팝콘·실제 별점을 만들지 않는다. SKIP·미응답·미평가는 부정 선호가 아니다.
- 같은 영화에 현재 실제 별점이 있으면 그것을 우선하고 온보딩 추정값을 이중 집계하지 않는다.
- 평점 삭제 시 남아 있는 원온보딩 응답을 복원하되 WATCHED_UNRATED와 감상 경험·제외는 유지한다.
- 이진 응답에서 추정한 값과 직접 받은 별점의 정밀도가 같다고 가정하지 않는다. 상대 가중치는 따로 검증할 항목이며 지금 숫자를 정하지 않는다.

기존 [입력 경계](input-adapter-boundary.md)와 모듈은 이런 의미 혼동을 차단한다. 추정값 연결을 구현할 때도
기존 raw 검증을 느슨하게 만드는 방식은 쓰지 않는다. 혼합 랭킹 구현이 이미 끝났다는 뜻도 아니다.

## 변환의 근거와 한계

실제 별점 척도의 대응을 확인하려면 같은 응답 채널의 LIKE/DISLIKE와 감상 별점이 연결된 자료가 도움이 된다.
대상 사용자·응답 시점·관측 선택 편향을 함께 다뤄야 한다. 현재 그런 실제 대응 자료는 확인되지 않았다.
당장 가능한 MovieLens 대리 실험에서는 이진화 규칙과 변환값 추정 절차를 먼저 고정하고,
학습 사용자만으로 변환을 보정한다. 평가자의 숨긴 원별점·평가 이력으로 개인 변환값을 맞추지 않는다.

예를 들어 학습 자료에서 이진 범주별 평균 별점을 구하는 방법은 단순 추정안으로 정의할 수 있다.
그러나 이진 범주를 애초에 별점으로 만들었다면 그것은 그 가정 안의 압축·복원 실험이지
실제 온보딩 응답이 그 평균 별점에 대응한다는 검증은 아니다. 사용자별 후함/박함을 이진 응답만으로 알아냈다고 하지 않는다.
개인화된 변환을 사용하려면 현재 실제 별점 등 허용된 추가 근거와 저입력 처리 계약이 먼저 필요하다.

## 비교 질문과 순서

1. **온보딩 연결:** 기존 원별점 ALS 영화 벡터를 고정한다. 같은 관측 영화에서 실제 원별점을 제공했을 때와,
   이진 대리 응답만 받아 사전 고정 변환으로 추정값을 만들었을 때의 추천 차이를 공통 정답으로 판단한다.
   숨긴 원별점은 변환 입력에 들어가지 않는다. 이진화·중립·유효 입력 수·가중치·fallback을 실행 전에 봉인한다.
   전체 영화 모델을 새로 이진화해서 학습하지 않는다. 변환이 더 좋은지는 실행 후 판단한다.
2. **별점 학습 표현:** 원별점 ALS와 사용자 상대값 ALS의 비교 필요성은 유지한다. 실제 별점 입력은 같게 보존하고,
   내부 학습 목표와 신규 사용자 처리를 일치시켜 비교한다. 전체 이진 학습을 이 비교의 필수 세 번째 모델로 넣지 않는다.
3. **실제 혼합 상태:** 실제 별점과 온보딩 응답이 함께 있을 때의 중복·추가·수정·삭제부터 검증한다.
   별점이 늘면서 온보딩 추정이 추천에 끼치는 영향과 최종 K는 고정된 입력 정책에서 후속 확인한다.

한 비교에서 학습 표현·온보딩 변환·가중치를 동시에 바꾸지 않는다. 원별점 factor로 검증한 adapter가
상대값 factor에도 그대로 유효하다고 가정하지 않고, 목표 척도가 바뀌면 연결을 다시 확인한다.
기존8맛·공급 결과는 보존해 이후 연결한다. 새 추천 품질과 실제 온보딩 부담의 자료 한계도 유지한다.
