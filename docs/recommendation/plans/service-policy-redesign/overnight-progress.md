# 야간 연구 진행 상태

상태: 야간 후속에 이어 사용자 요청의 REC035 세 입력 경로 계산까지 완료. 최신 검산 상태는 REC035 결과 문서를 따른다. 2026-09-08.
이 문서는 실행을 이어가기 위한 상태 기록이다. 공식 제품 계약이나 검토 전 실험의 실행 허가를 대신하지 않는다.

사용자 복귀 후 갱신: ALS에서 절대 별점·상대값·LIKE/DISLIKE를 비교하고 학습값도 바꿔야 하는지 검토하도록 지시했다.
아래 야간 완료 기록은 보존한다. 이어 감상 별점 서비스를 유지한다는 사용자 조건이 추가되어,
그 조건을 [REC035 세 결과 비교](../../experiments/rec-ev-035/RESULT.md)로 실행했다. B 상대값 ALS만1회 학습했고 A/C는 기존 원별점 factor를 공유했다.
원별점 기준을 유지하며 이번 상대값 안은 채택하지 않는다. 이진 환산안은 차이 미확인으로 연결 후보를 유지하되 동등성·실제 온보딩 효과를 주장하지 않는다.
추가 mapper·모델·분할 탐색은 종료한다. 전환 K나 온보딩 분량은 이번 결과로 선택하지 않는다.
야간 자동 재개는 PAUSED를 유지하며 현재 사용자 지시로 작업한다.

## 현재 위치

- 완료: REC032 기본 추천·평가 문제 진단·ALS 단독·학습 사용자 배제 감사·사용자 분할3회 반복.
- 앞선 ALS 근거: 입력30개의 이득이 세 지표 모두3개 분할에서 재현됐다.5개는 이득 미확인,10개는 일부만 유리했다.
- 최신 결과: REC035 원별점/상대값/이진환산 비교. 기존 단계3 분류와 단계4 공급 준비·대안·입력 경계·슬롯 보존 반례·품질 판단 양식은 보존한다.
- 다음 순서: 입력 adapter·역할/후보 정책 및 품질 평가 계약 고정 → 실제 품질 판단 → 통합 정책 고정 후 K → 온보딩·서비스 확인.
- 기본 모델·분할 실험을 더 늘리지 않는다. 이미 완료한 결과는 [총정리](README.md)와 봉인을 재사용한다.

## 작업 경계

다른 저장소 문서로 확인 범위를 넓히지 않는다. 기존 미커밋 변경과 봉인된 코드·설정·결과를 보존한다.
root만 수정하고 독립 검토자는 읽기 전용으로 맡긴다.

각 새 실험의 순서는 요구·자료 역할 확인 → 설계·코드 → 독립 검토 → 필수 지적 수정·합성 검사

미정 제품 의미는 영향이 보이는 연구 제안으로 남기고 공식 계약·제품 코드에 임의 반영하지 않는다.
확인이 필요한 항목이 있어도 의존하지 않는 문서·설계·로컬 준비는 이어간다.
커밋·Push·MR·Jira 변경·배포·타인 메시지·모집·유료 호출·새 대규모 다운로드는 별도 명시적 지시 없이 수행하지 않는다.
