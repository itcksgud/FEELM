# 추천에 평점이 없어 채점하지 못한 문제의 수정안

상태: DRAFT — 후속 평가 방향과 기존 근거 대응표. 새 실험 실행 계약이나 제품 채택 결정이 아니다.

후속: [별도 실행 계약과 조건부 비교](../../experiments/rec-ev-032/conditional-ranking/RESULT.md)를 완료했다.
모든 슬롯을 채점했으며9개 비교 중8개가 현재 개인화 결합에 불리했다. 이 안으로 K를 정하는 단계로
진행하지 않고 현재 구성의 원인 점검을 이어갔다. [ALS 단독 후속](../../experiments/rec-ev-032/als-only/RESULT.md)은
재학습 없이 콘텐츠 결합을 제거했고5/10/30의 세 지표 모두 기존 결합보다 유리했다.
MovieLens 보정 평균 별점 P0보다도 입력30개에서 세 지표 모두 유리했으며5/10개는 지표별로 갈렸다.
기본 비교 기준을 ALS 단독으로 두고 콘텐츠의 역할·추가 이득을 구분한다. K·실서비스 품질은 미확정이다.
이후 [학습·평가 사용자 분할3개 반복](../../experiments/rec-ev-032/user-resplits/RESULT.md)에서
입력30개의 세 지표 이득이 모두 재현됐다.5개는 전부 미판정이며10개는 일부만 유리했다.
회차마다 새 ALS/P0를 만들었지만 관측 영화·기존 개발 자료라는 평가 범위는 그대로다.
아래는 최초 조건부 실행에 앞서 검토한 방향의 기록이다.

## 먼저 고칠 것

**분류3단계로 넘어가는 것으로 이번 품질 미판정을 해결할 수는 없다.
먼저 기존 근거로 확인한 것과, 이번 기본 추천 구성에서 아직 확인하지 못한 것을 구분한다.**

REC032의 추천 목록 대부분에 원본 평점이 없다는 사실은 그대로다.
기존 결과·추가 조회 결과·봉인은 보존한다. 모르는 평점을 불호로 만들거나 다른 모델의 예상 평점을
정답으로 넣지 않는다.

기본 취향 반영은 이미 평점이 있는 영화를 숨기는 조건에서 확인할 수 있다.
전체 카탈로그에서 실제로 받은 새 추천의 품질은 해당 사용자 판단이 필요하다.
두 질문을 구분하는 것은 결과가 다를 수 있기 때문이다. 기존 평점의 누락이 오프라인 순위 평가를
왜곡할 수 있다는 연구도 이 한계를 보고한다. [Tian·Ekstrand, CHIIR 2020](https://arxiv.org/abs/2001.09455)

## 지금 준비할 추가 진단은 한 쌍만

질문은 **“같은 사용자의 취향 입력을 받았을 때, 이번 고정 개인화 구성이 인기 기준보다
그 사용자가 좋아한 영화를 위에 놓는가?”**다.

1. 기존에 개봉한 평가 영화 목록 E를 결과 전에 고정한다. 모든 입력량과 두 방식에 같은 E를 쓴다.
   E와 최대 입력30편은 겹치지 않는다. 정답은 각 사용자의 기존 원별점과 고정 상대 선호 Q다.
2. 기존 모델·학습집단·입력 처리·P0·M0를 유지한다. 새로운 모델/가중치/입력량을 탐색하지 않는다.
3. **원래 전체 카탈로그에서 계산한 최종 순서를 유지하고, 평가측이 E에 속하는 영화만 추린다.**
   그중 앞선 두 편을 골라 두 편의 평균 선호·낮은 쪽 선호·저선호 포함을 채점한다.
4. 전체 조건의 순위를 먼저 봉인하고 채점한다. 이미 개봉한 자료 재사용이므로 후속 탐색으로 기록한다.
   최종 K·서비스 승자·새 확증을 선언하지 않는다.

이렇게 하면 진단에서 고르는 두 편 모두에 실제 평점이 있다. 높은 별점 한 편의 회수 여부나
Recall500으로 판정하지 않는다. 다만 **평가 가능한 영화 안에서의 순서만 확인하는 과제**이며,
REC032 원래 추천2편의91% 평점 부재가 사라지는 것은 아니다.

실행 계약에 반드시 고정할 사항:

- E는 REC032 최초 평가에 사용한 기존 SELECTION union을 기준으로 하고 입력/공통 영화 범위를 확인한다.
  원래 추천을 따라 추가 조회한2,244개 평점을 후보 확대에 사용하지 않는다.
- RRF는 후보 범위에 따라 순위값이 달라진다. E 안에서 성분별 순위를 새로 매겨 결합하지 않는다.
  기존 전체 카탈로그·현재 O(n) 제외·유효 성분·동률·fallback 의미를 보존한다.
- 학습 사용자와 평가 사용자 분리, 기존 factor/feature/prior/입력의 정확한 산출물 대응을 확인한다.
  새 학습이나 모든 영화의 상호작용 제거를 자동 추가하지 않는다.
- 공통 E의 크기·입력 비중복·반별점 격자·모든 후보의 채점 가능 여부를 사전 점검한다.
  정책별·입력량별 지원 영화의 교집합으로 E를 다시 줄여 누락을 숨기지 않는다.
  두 편을 제공할 수 없는 경우의 처리와 집계 분모는 결과 전에 정한다.
- 효과·허용 손실·정밀도·중단 조건 및 실제 실행 코드의 독립 검토를 완료한 뒤 한 번 실행한다.
  이 문서는 그 조건을 다 채운 실행 계약이 아니다.

## 실제 추천의 정답은 어떻게 확보하나

실제 FEELM 대상 사용자에게 자신의 입력으로 생성한 추천을 보여주고 직접 판단을 받는 평가를 설계한다.
두 정책이 추천한 영화의 합집합은 같은 사용자에게 중복 없이 평가받고, 정책명은 숨기고 노출 순서를
무작위화한다. 화면의 맞춤2·발견1 구성과 집계는 유지하며 평가용 합집합을 제품 추천 목록으로 바꾸지 않는다.

- 지금 확인 가능한 값: 추천을 보고 보고 싶은지, 이미 본 영화인지, 사용자에게 새롭게 느껴지는지.
- 감상 후 확인할 값: 실제 만족 별점0.5~5.0·간격0.5.
- 응답하지 않거나 보지 않은 경우: 불호로 채우지 않고 누락을 별도로 기록한다.
- 온보딩 편의성: 응답량뿐 아니라 시간·이탈·부담을 실제로 측정해야 한다.

이런 사용자별 추천 합집합 평가를 활용한 MovieLens 확장 연구도 있다.
그 연구의 목적은 관람 관심 평가이며 감상 후 만족과는 구분된다.
현재 FEELM 사용자·추천의 정답을 자동 보충하는 자료는 아니다.
[Smucker·Chamani, SIGIR 2025](https://arxiv.org/abs/2504.01863)

모집·연락·수집을 시작한 것은 아니다. 대상·노출·필요 정밀도·부담·종료 기준은 실행 전에
별도 설계한다. 사용자 평가를 당장 할 수 없다면 오프라인 조건부 근거까지로 결론 범위를 제한한다.

## 다음 순서

**기존 근거 재사용과 차이 확인 → 고정 P0/M0 조건부 진단의 실행 계약·독립 검토
→ 필요한 진단 한 번 → 두8맛 배정안 준비 → 실제 맞춤2·발견1 비교 → 정책 고정 후 K.**

분류안의 문서 준비는 병행할 수 있지만 이번 기본 추천의 품질 문제를 해결했다고 표시하지 않는다.
원실험/보충 결과의 수치·판정은 변경하지 않는다.
