# REC-EV-027~030 콘텐츠 개인화 검증 최종 보고서

> 상태: `REC_EV_030_FINAL_RESULT_AUDIT_PASS`
>
> 결론 범위: MovieLens에서 평점을 남긴 영화를 가린 대리 평가
>
> 유지 경계: Locked Test 미사용, final reserve 미사용, 제품 정책 미변경

## 1. 해결하려던 문제

FEELM은 한국 영화를 포함한 맞춤 추천을 만들고자 했지만 두 가지 데이터 한계가 있었다.

1. MovieLens 평점의 78.73%가 유명 외국 영화 proxy에 집중됐고 한국 제작 영화 평점은 0.33%뿐이었다.
   MovieLens 수록 이후 영화에는 상호작용도 없다.
2. 출시 전에는 추천, 시청, 평가로 이어지는 실제 사용자 피드백 순환을 반복할 수 없다.

TMDB 특징은 한국 영화와 신작을 표현할 수 있지만 사용자가 좋아할지에 대한 정답을 만들지 못한다. 반대로
MovieLens는 사용자 행동 정답을 제공하지만 한국 사용자나 실제 신작 성능을 증명하지 못한다. 따라서 두
데이터의 역할을 분리했다.

| 데이터 | 역할 |
| --- | --- |
| MovieLens 평점 | 사용자 행동 학습, 입력 구성, 오프라인 평가와 검증 |
| TMDB 구조 특징 | 장르, 국가, 언어, 연대, 인물, 키워드 기반 영화 표현 |
| 384차원 multilingual E5 | 제목과 줄거리의 텍스트 의미 표현 |

## 2. 검증 논리

정답이 없는 한국 영화와 실제 신작을 곧바로 평가하지 않았다. MovieLens에서 사용자가 이미 평가한 영화를
후보로 가리고, 남은 평가 이력만으로 만든 콘텐츠 profile이 가린 영화 중 상대적으로 선호한 두 편을 고르는지
확인했다. 이 대리 과제가 통과해야 상호작용이 없는 영화를 같은 콘텐츠 공간에서 후보화할 최소 근거가 생긴다.

평점 4점 같은 고정 기준도 쓰지 않았다. 사용자마다 별점 사용 습관이 다르므로 각 사용자의 전체 평점
히스토그램에서 midrank percentile을 계산했다.

```text
q = (현재 별점보다 낮은 평가 수 + 0.5 × 같은 별점 평가 수) / 전체 평가 수
```

서비스가 맞춤 추천을 두 편씩 보여주므로 평가도 Top2로 맞췄다.

- `HARM20`: Top2에 사용자 하위 20% 영화가 포함된 비율. 낮을수록 좋다.
- `TOP2_MIN_Q`: 두 편 중 덜 선호한 영화의 percentile. 높을수록 좋다.
- `TOP2_MEAN_Q`: 두 편의 평균 percentile. 높을수록 좋다.
- 영화 동일가중 지표: 자주 평가된 영화가 결론을 지배하지 않도록 영화별 평균 후 다시 동일가중한다.

## 3. 설계와 수정 과정

### 3.1 입력 수와 표현 방식

입력 수는 짝수 `K=2, 4, ..., 30`을 모두 비교했다. 입력은 Binary와 사용자별 percentile magnitude를
비교했고 출력은 항상 두 편으로 고정했다. K=8을 미리 정답으로 두지 않았다.

### 3.2 모델과 콘텐츠 표현

인기도, ItemKNN, BPR, TMDB 구조, raw E5, 구조와 E5의 RRF, LightFM을 단계별로 비교했다. E5를 BPR
공간에 정렬하는 방법만 남기지 않고 raw E5 direct profile과 순위 결합도 함께 검사했다.

초기 LightFM 결과는 높았지만, REC-EV-028에서 사용자 profile을 다른 사용자와 바꿔도 이점이 남았다.
따라서 그 차이를 개인화 성능으로 인정하지 않고 item bias 가능성으로 분리했다.

### 3.3 개인화 귀속 대조군

같은 사용자와 같은 가린 후보를 유지한 채 세 시스템을 비교했다.

| 시스템 | 사용 정보 | 묻는 질문 |
| --- | --- | --- |
| OWN | 해당 사용자의 profile | 콘텐츠 표현에 사용자별 선호 신호가 있는가 |
| SHUFFLE | 같은 outer의 다른 사용자 profile | 결과가 영화 자체의 쉬운 순위만 반영하는가 |
| RANDOM | 후보 중 두 편의 분석적 기대값 | 복잡한 방법이 무작위보다 나은가 |

REC-EV-029의 selection과 replication 사용자를 분리했고, REC-EV-030은 앞선 실험에서 한 번도 열지 않은
future user phase를 다시 사용했다. profile 평점을 읽고 일곱 outer의 OWN/SHUFFLE 순위를 모두 봉인한
뒤에만 가린 후보 평점을 열었다.

## 4. 모델 선택 결과

REC-EV-029 selection에서 최종 후보는 다음과 같았다.

```text
STRUCTURED_DIRECT + PERCENTILE_MAGNITUDE + K=30 + Top2
```

이 결과는 K=30이 제품 최적값이라는 뜻이 아니다. 탐색 상한에서 선택됐으므로 더 많은 입력이 오프라인
대리 과제에 유리했다는 뜻이며, 실제 사용자의 입력 부담과 한계효용은 온라인 또는 사용자 조사로 따로
확인해야 한다.

selection의 사용자 동일가중 결과는 다음과 같았다.

| 시스템 | HARM20 ↓ | TOP2_MIN_Q ↑ | TOP2_MEAN_Q ↑ |
| --- | ---: | ---: | ---: |
| OWN | 0.2567 | 0.3986 | 0.5409 |
| SHUFFLE | 0.3371 | 0.3426 | 0.4866 |
| RANDOM | 0.3832 | 0.3139 | 0.4633 |

분리된 REC-EV-029 replication에서도 사용자 지표는 재현됐다. 다만 48개 동시 비교를 묶은 보수적 영화
동일가중 구간에서 OWN 대 SHUFFLE 두 지표의 하한이 0을 넘지 못했다. 이를 성공으로 바꾸어 해석하지 않고
`DIRECT_PROFILE_PERSONALIZATION_NOT_REPLICATED`로 기록했다. 이후 새 사용자와 10개 primary 비교만
사전 고정한 REC-EV-030을 설계했다.

## 7. 한국 영화와 최근 영화의 해석

KR 247명과 RECENT 382명 결과는 사전에 descriptive-only로 고정했다.

- KR에서 OWN은 RANDOM보다 나았지만 SHUFFLE보다 HARM20과 평균 percentile이 소폭 나빴다.
- RECENT에서는 OWN이 두 대조군보다 나은 방향이었다.
- 두 결과 모두 실제 한국 사용자나 MovieLens 수록 이후 신작의 정답이 아니다.

따라서 이번 실험은 한국 영화·신작 추천 품질을 증명하지 않는다. 대신 TMDB 구조 벡터가 MovieLens의
가린 관측 영화에서 영화 자체의 인기만이 아닌 사용자별 선호 신호를 만든다는 점을 확증했다. 이 결과는
상호작용이 없는 영화를 콘텐츠 공간에서 후보화할 기술적 근거이며, 목표 시장 성능은 별도의 한국 사용자
평가가 필요하다.
