## 현재 판단할 핵심 질문

2026-09-09 사용자 목적 재확인: **ALS가 영화의 학습 평점 부족으로 직접 점수를 만들 수 없는

서로 다른 영화·사용자에서 나온 지원/미지원 점수의 숫자가 비슷하다는 이유로 동급 판정을 하지 않는다.

[모든 개봉연도 표](../research/movielens-release-distribution/BY_YEAR.md)를 먼저 확인한다.
87,585편·32,000,204개 별점 기록·200,948명 집계와 독립 전수 검산을 완료했다.
1990·2000년대 영화는 카탈로그의27.06%/평가의61.47%, 평가 상위1% 영화는 전체 평가의55.76%다.
REC045 최근작의 상대 비중은 원본보다 높지만2020~2023년작의 평균 가중치는1.57%,2023년작은0.14%다.
2024~2026년작의 관측 평점은 이 자료에 없다. 이 분포 감사에서는 모델 학습·별점 채점을 하지 않았다.
**기존 전체 성능 개선을 최신작·평가가 적은 영화·현재 서비스의 개선으로 확대하지 않는다.**
후속 성능 실험 전에 개봉 시기×학습 평가 지원량별 검증 범위와 목표 영화 구성을 먼저 검토한다.
집중도는 자료 내부의 기술통계이며 실제 시장과의 편향 크기나 새로운 가중치 정책을 확정한 것은 아니다.

현재 기준은 [분류 수를 전제하지 않는 데이터 관계 분석](analysis-scope.md)이다.
최신 사용자 지시에 따라 **8개 분류·팝콘 맛·K-means를 관계 분석의 전제에서 제외한다.**
복수 장르·인물·국가 등 원래 속성을 유지하며, 정보 묶음의 개수도 고정하지 않는다.
REC045의 ‘8개 블록’은 입력 필드 묶음 수였고 영화8군집이나 맛 ID를 사용한 것이 아니다.
분류·표현 방식과 개수는 데이터의 관계를 확인한 뒤 별도 판단한다.

앞선 [다각도 데이터 탐색·안정성 분석안](plans/multidimensional-preference-analysis.md)은
필드 목록과 이전 탐색 순서의 참고 자료이며, 거기에 남은8맛 문구는 현재 분석 조건이 아니다.
최신 사용자 지시대로 자료 전반의 분포와 정보 간 관계를 먼저 보고, 적은 입력/반복 근거와
서로 다른 사용자·영화 집단에서도 관계가 유지되는지 확인한 뒤 모델 입력을 결정한다.
앞선 [메타데이터 지원 범위](plans/multidimensional-feature-support.json)를 바탕으로
[REC045 복합 정보 설계](experiments/rec-ev-045/README.md)와
[시간 진단](experiments/rec-ev-045/temporal-design.md)을 작성하고 독립 검토·실행·결과 감사를 완료했다.
전체 85,517개 기존 TMDB 캐시의 해시를 검증하고 추가 필드 전처리를 완료했다.
감독/상위5배우의 O→E 연결은8.22%/31.53%, 입력에서 같은 인물2편 이상 조건이면1.46%/6.01%다.
이는 평점 값을 읽지 않은 자료 가용성 통계이며 새로운 개인 취향·성능 결과가 아니다.
[REC045 결과](experiments/rec-ev-045/RESULT.md): 고유3,819명·사용자재분할3회에서 복합 개인 보정의
공통 보정 대비MSE 감소는K5/10/30에서0.87%/1.80%/4.51%다. K30 장르 개인 보정 대비2.49% 추가 감소.
장르·대중 평가 특성의 기여가 상대적으로 크고, 키워드·인물·제작사/시리즈는 작은 보조 기여가 있었다.
국가/언어·연대/길이의 추가 기여와 학습평가50개 미만 영화의 개선은 미확정이다.
고유300명의2019 시간 진단에서 복합은 장르 개인 보정보다2.44% 낮은MSE였지만 공통 보정만
추가한 단계는 기본보다 악화됐다. 인물×연대의 시간 추가 이득은 미확정이다.
원자료·전체 지표·집단·독립수식·고정밀 수치 민감도 감사PASS. 이미 사용한 개발 자료와 현재
정적TMDB를 조건으로 한 관계 진단이며, 인과관계·ALS우열·실서비스추천·최종K의 결론은 아니다.
현재 분석에 분류 수를 요구하지 않는다. 공유는 사용자가 범위를 정해 요청할 때 진행한다.

아래 REC044 이전의8분류 관련 내용은 과거 실험 이력이며 후속 분석의 전제는 아니다.

[REC044 설계](experiments/rec-ev-044/README.md): 영화의 대중 평가와 개인의 별점 습관을
감안한 뒤 장르·키워드·현재8분류의 개인별 편차가 다른 영화에서도 반복되는지 분석한다.
동일 O30/E와 학습 사용자 전용 영화 평균으로 다섯 표현을 공통 고정 진단기에 비교한다.
[결과](experiments/rec-ev-044/RESULT.md): 기준 대비 MSE 감소는 장르2.04%, 키워드0.55%,
결합2.20%다. 현재 규칙8/KM8의 개선은 미확인, 결합의 장르 단독 대비 이득도 미판정이다.
장르별 입력/가린별점 편차 표와 타인 프로필 대조를 기술통계로 남겼다.
사전 두 독립 검토 PASS·합성13검사 후 실행32.547초. 결과 독립 검산과 읽기 전용 재검증을
완료했다. 이전 개발 표본 재사용이며 실서비스·인과관계·ALS 우열의 결론은 아니다.
Jira·GitLab 게시 대상이 아니며 외부8맛·최종K·추천/발견 정책은 변경하지 않았다.

[REC043 설계](experiments/rec-ev-043/README.md): 추천 정책 전에 분류와 사용자 별점의 관계를 분석했다.
동일 O30/E에서 개선8장르규칙·8장르KM·원본18장르를 비교했다. ALS지원 필터와 추천 목록은 사용하지 않았다.
사전 독립 검토3명·합성15검사 후 실제 분석과 독립 결과 검산3명까지 완료했다.
[REC043 결과](experiments/rec-ev-043/RESULT.md): 현재 규칙8/KM8의 개선 미확인,
TMDB18복수 장르는 영화 평균 보정 기준 대비 MSE1.70% 감소. 실서비스/표현 간 우열 검증은 아니다.
팀 재실행 집계 완전 일치, 새15+기존24=39검사 및 Ruff통과.

앞선 [REC042 결과](experiments/rec-ev-042/RESULT.md)도 보존한다. 분류를 붙인 앞2편의 개선 미확인,
발견교체의 관측선호손실을 기록했으며, ALS 비교 기준 유지·분류와 발견 정책 채택 보류 결과다.
