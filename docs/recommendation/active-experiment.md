상태: DRAFT — 개인 연구 업무 추적이며 제품 정책 계약이 아니다. 갱신2026-09-08.

## 현재 작업 방식

최신 사용자 지시에 따라 Jira 선등록 및 중간 실험별 자동 MR 생성을 중단했다.
**로컬 설계 → 실행 전 독립 검토 → 실험 → 독립 결과 검토 → 전체 질문에 대한 결론 정리**를
먼저 수행한다. 이후 사용자가 공유할 결론과 범위를 정해 요청할 때 Jira·GitLab에 기록한다.
개별 실험이 끝났다는 이유로 게시 시점을 임의로 정하지 않는다. 현재 로컬 연구에 활성 Jira는 없다.
세부 규칙은 `AGENTS.md` 9절을 따른다.

과거 실험 문서와 봉인에 적힌 Jira-first 순서는 당시 실행 기록이며 현재의 외부 게시 승인이 아니다.
아래 종료는 중간 단계의 외부 게시 철회다. 기존 코드·분석·독립 검증 결과는 로컬에 보존한다.
