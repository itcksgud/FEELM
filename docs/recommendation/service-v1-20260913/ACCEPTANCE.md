# 추천 v1 구현 검수

이 문서는 **구현 후 실행할 인수 테스트 명세**다. 아래 테스트가 이미 통과했거나 새 GBT를
학습·서버에 배포했다는 뜻은 아니다. 문서·통계 검토 결과와 구현 테스트 결과를 따로 남긴다.

[정책](POLICY.md) → [모델](MODELS.md) → [계약](CONTRACTS.md) → [운영](OPERATIONS.md)의
동일 버전을 사용한다. 계약의 R-v1-OPS-01~16과 다음 경계를 함께 통과해야 구현 완료다.
그룹 산출물은 [GROUPS의 G01~G07](GROUPS.md)도 통과해야 한다. 원파일 구조 감사는 원237,817편
전처리·그룹 할당 재현 테스트의 실행을 대신하지 않는다.

### 확장 KOBIS 데이터 경계

[KOBIS 데이터](KOBIS-DATA.md)와 CONTRACTS의 원행→매핑→snapshot 구분을 검증한다.
아래 D01~D06은 R-v1-OPS-06/12/13의 데이터 조건이며 구현 후 실행할 명세다. 현재72,700행의
수집·연결 검토 PASS는 원행과 제안의 정확성에 대한 결과이고, 이 인수 테스트의 실행 PASS가 아니다.

## 4. 구현과 모델 평가의 완료 기준

개발자는 각 ID에 실행 명령·입력 fixture/seed·기대한 값·실제 값·코드 SHA·환경을 연결한다.
DB migration·API payload·별점 이벤트 round-trip부터 배치·Consumer·최종3슬롯까지 이어지는
통합 시나리오를 최소 한 번 실행한다. 실제 배포 환경의 지연·메모리는 별도로 기록한다.

모델 평가는 MSE/MAE, 맞춤@2/4/6/10, 발견 첫1·누적2/3/5/10, 낮은 별점 비율,
지원률·UNKNOWN·대체/부분반환·중복·국적/시기/원천별 구성을 함께 보고한다.
최신 외부 수치와 과거 MovieLens 정답을 결합한 개발 결과로2026 한국 사용자의 만족도 우위를
확정하지 않는다. 데이터 분포 분석, 기존 모델 개발 점수, 새245열 모델의 평가를 한 표의 동일
실험 결과처럼 합치지 않는다.

실제 구현·새 학습·팀 계약 반영·배포는 이번 문서 작성의 완료 범위에 포함되지 않는다.
이번 산출물의 검토 기록은 최종 README에 연결하며, 위 테스트의 실행 완료로 대체하지 않는다.

## 5. 상세 유사 영화

[SIMILAR-MOVIES §7의 S01~S08](SIMILAR-MOVIES.md)을 별도 기능 인수 조건으로 추가한다.
기존 P/M/이벤트·세트 검수를 이 기능으로 대체하지 않는다. 요구사항은 FR-11/API-031에 연결하고
GKT export·Spring similar API/Repository·Redis cache·프런트 detail의 테스트에서 검증한다.
기본10편/size1~20·자기제외·로그인 제외·공용 캐시·부족/장애·버전·비부작용을 확인하고,
정확 Top10 복원율과 사람의 내용 유사성 검토를 분리한다. 현재 S01~S08은 미실행이며 문서 검토 PASS를
인덱스 성능 또는 영화 유사 품질 PASS로 표시하지 않는다.
