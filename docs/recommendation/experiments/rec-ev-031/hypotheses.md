# 추천 정책 가설과 미결정 사항

상태: DRAFT — 연구 가설 목록이며 공식 계약을 변경하지 않는다.

| 질문 | 현재 고정된 제약/공식 계약 | 검증할 가설 | REC-EV-031로 답하는 범위 |
| --- | --- | --- | --- |
| 입력 방식 | 사용자 지시: 별점 간격 0.5. 공식 감상 API: integer1~5. LIKE/DISLIKE는 별도 입력 | 별점 정보량이 실제 입력 부담을 상쇄하는가 | 실제 UI 비교 없음. half-star 구조 콘텐츠의 후보 회수만 평가 |
| 입력 범위 | 0.5~5.0은 연구 가정 | 최저/최고점과 건너뛰기·모름의 명시 방식 | 원별점10bin 그대로 보존. 모름을 평점으로 만들지 않음 |
| 응답 수 | 공식 카드 요청 기본20/최대40, 실제 노출·응답 수 미정 | 같은 사람의 입력 증가로 추천 정보가 얼마나 늘어나는가 | 고정 profile30의 K5/10/30 진단. 카드 수·최소 응답·실제 UX 확정 불가 |
| 입력 해석 | 사용자 원평점과 내부 점수는 별도 | 관측 입력만으로 만든 상대 가중치가 유용한가 | 상대 가중치 구조 모델의 귀속·인기도 대조. raw 대비 우열은 비교하지 않음 |
| 누적 평가 | 공식 ALS fold-in은 전체 최신 평가·온보딩 | 전체 관측 이력을 쓰는 것이 제한 prefix보다 유리한가 | 입력30까지만 사용. 누적 전체 활용 가설은 미검증 |
| 후보/순위 | 공식 ALS+TMDB 및 후보500 | 구조 콘텐츠가 단독 후보 또는 인기도와 결합할 가치가 있는가 | 동일 common85517와 예산500에서 직접 비교. ALS/E5 증분은 후속 |
| 내부 군집 | 공식 고정 k8·맛1:1·predict | 군집이 추천과 해석에 각각 필요한가, 다른 k가 나은가 | 이번 모델에 군집을 사용하지 않음. 군집 품질·추천 ablation은 별도 필요 |
| 외부 표현 | 사용자 지시: 팝콘 맛·색상 8종 | 내부 k와 독립적으로 안정된 외부8종 표현이 가능한가 | 표현 제약 유지. 의미·색상·영화별 배정·매핑은 이번 결과로 확정하지 않음 |
| 맞춤/발견 | 공식 맞춤2+발견1와 fallback | 선호 유지와 경험 확장을 함께 만족하는 구성은 무엇인가 | 후보/상위3 관측 진단만 수행. 발견 슬롯의 실제 효용은 미검증 |
| 인기도 우위 | 이전 특정 조건에서 CF 우위·구조 개인화 귀속 | 현재 half-star 구조 모델이 실제 두 인기도 기준선을 이기는가 | K30 후보 Recall 4개 비교를 사전 primary로 판정 |

공식 문서에 적힌 선택은 서비스 설계의 기준이다. 이 표의 품질 가설이 이미 실증됐다는 뜻은 아니다.
기존 결과에서 재사용하는 근거와 직접/간접의 구분은 evidence-audit.md에 있다.
