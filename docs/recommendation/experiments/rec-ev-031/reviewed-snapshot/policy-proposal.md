# FEELM 추천 정책 제안 — REC-EV-031 이후

상태: DRAFT — 개인 연구 운영 후보. 팀 API·DB·화면·추천 정책의 변경 승인이 아니다.
사용자 제약: **외부 팝콘 맛·색상8종, 입력 별점 간격0.5점**.
별점 범위0.5~5.0은 이번 연구 가정이며 최저/최고점이 제품 확정된 것은 아니다.

현재 연구 운영 후보는 **인기도 후보를 기본으로 유지하고, 구조 콘텐츠 단독 검색과 이번
250+250 후보 교체를 채택하지 않는 것**이다. 입력은 정확한 원별점을 보존한다. 개인화의
다음 검증은 후보를 유지한 순위 조정으로 좁힌다. K-means와 발견 슬롯을 먼저 추가해
후보 회수의 문제를 덮지 않는다.

K30 후보 Recall은 COUNT26.49%, BAYES21.92%, CONTENT3.39%, UNION15.83%였다.
CONTENT와 UNION의 두 기준선 대비98.75% CI가 모두 음수여서 사전 기각 조건에 해당한다.
이는 알려진 선호 영화의 회수 판단이다. 상위3 미채점 비율이98% 이상이므로 서비스 만족도
우열과 채택 확증으로 확대하지 않는다. 자세한 수치·사용자별 차이는 comparison.md에 있다.

## 온보딩과 별점 해석

연구 프로토타입에서는 인기도 목록으로 먼저 진입할 수 있게 하고, **추천 진입을 막는 최소
응답 개수를 두지 않는 운영안**을 선택한다. 이는0개로 개인화가 충분하다는 성능 결론이 아니다.
기존 근거로 최소5/10/30개를 확정할 수 없고, 이번 K10→30 증분도 불명확하기 때문이다.
정해진 응답 목표나 총 카드 수를 임의로 채우지 않는다. API의 기본20/최대40은 카드 요청량이며
동시 노출수·실제 응답 목표와 별개다.

보여줄 영화의 첫 운영 후보는 인지도를 기대할 수 있는 평점 수 상위 영화다. 장르·시대·외부8맛의
과도한 편중을 점검하고 모르는 영화는 넘길 수 있게 한다. 인기도가 인지도를 대리한다는 가정,
맛 균등 노출의 효용과 순서는 실제 카드 인지도·응답률 검증이 필요하다. 검수 전 목업 맛 이름과
색상이나 이번 평가 정답으로 카드 구성을 맞추지 않는다.

별점은 `{0.5,1.0,1.5,2.0,2.5,3.0,3.5,4.0,4.5,5.0}` 원값을 보존한다. 미평가·모름·건너뛰기는
별도 상태다. 상대 콘텐츠 점수를 진단할 때만 관측 입력 histogram과 분리된 calibration prior로
midrank를 계산한다. 동점은 중간순위를 사용하고 q=0.5의 가중치는0이다. 입력3.5와4.0은 서로
다른 bin이며 같은 이진 응답으로 자동 변환하지 않는다. 내부 점수·평균값은0.5로 반올림하지 않는다.

기존 sign 실험은 상대 가중치의 부호를 비교한 것으로 실제 LIKE/DISLIKE 입력 실험이 아니다.
향후 binary 대리를 비교한다면3.5/4.0 경계, 중립과 동점, binary 모델에 전달할 정보만을 사전에
정해야 한다. 지금은 이를 결정할 실제 UI·raw/relative 대조가 없다. 실제 사용자에게는
반별점 UI를 연구할 수 있지만 “입력 부담 대비 더 좋음”은 별도의 입력 시간·이탈·이해도 측정 전까지
주장하지 않는다. 화면 취향 일치%나 만족확률로 내부 percentile을 변환하지 않는다.

## 협업·콘텐츠·군집·발견의 역할

MovieLens 협업 모델은 학습 허용 사용자의 충분한 이력으로 영화 벡터를 만들고, 신규 사용자의
관측 입력으로 fold-in하는 후보로 남긴다. 011/019C에 유망한 기존 근거가 있어 후속 우선순위가
있다. 과거 CF 모델에 이번 평가자가 학습됐을 가능성이 있어 이번 실행에는 재사용하지 않았다.
현재 half-star 정책으로의 전이는 새 공정 비교가 필요하다. ALS가 후보를 만들 경우 후보 밖 영화를
콘텐츠 재정렬로 찾을 수 없다는 한계도 따로 평가한다.

TMDB 구조 특징은 관측 선호의 표현과 재정렬 검토 대상으로 유지한다. 이번 결과로 후보의
절반을 구조 콘텐츠로 교체하지 않는다. E5는 이번 점수에 사용하지 않았고 공통 카탈로그 정합성에만
쓰였다. E5 증분과 협업 결합 비중을 확인한 것처럼 취급하지 않는다.

이번 연구 목록에는 **군집에 의한 후보 제한·가산점·발견 선택을 넣지 않는다.** 군집 효과와
내부 k의 선택 근거가 아직 없다. 외부8종은 유지하고 현재 검수된 분류기가 있다면 설명 표시만
별도로 연결하는 방안이 가능하다. 내부 k가 달라지는 연구에서는 cluster_id와 외부 taste_code를
분리하고, 사전 의미/대표 영화로 고정한8종 프로토타입에 centroid를 대응하거나 독립8종 분류기를
유지하는 방안을 비교한다. 이것은 미검증 설계 후보이며 현재 공식 k8·1:1·predict 계약이 아니다.
평가 정답에 맞춰 맛 의미·매핑을 조정하지 않는다. 재학습 시 안정성, 다대일 매핑의 정보 손실,
영화별 배정과8종의 해석 가능성을 먼저 확인해야 한다.

현재 연구 목록에서는 발견1편을 의무적으로 끼워 넣지 않는다. 013의 특정 세 번째 교체 손실과
031의 후보 교체 손실을 고려하면, 지금은 선호 유지 없이 다름만 보장하는 규칙을 추가할 이유가
부족하다. 공식2+1을 제품에서 제거했다는 뜻은 아니다. 후속 발견은 **선호가 유지되면서 관측상
경험이 적은 영역을 제안하는 것**으로 정의한다. 관측 이력이 적다고 실제 경험도 없다고 단정하지
않으며, 사용자가 새롭다고 느꼈는지 확인해야 한다. 특히 온보딩만 있는 사용자의 실제 새 취향은
이 자료로 판정하지 않는다. 다른 내부 군집으로 이동한 횟수를 외부 새 맛 발견으로 세지 않는다.

맛별 감상량과 선호도는 별도다. 미관측 맛의 count0/averageScore null을 불호로 바꾸지 않는다.
맛 이름·색상·매핑과 newFlavorThreshold는 미확정이며, 내부 점수나 카드 개수로 대신 정하지 않는다.
