# REC-EV-031 정책 제안 — 철회됨

상태: SUPERSEDED. 2026-09-07 사용자 지적에 따라 제품 정책 제안을 철회했다.

후보 Recall@500의 제한된 진단으로부터 인기도 Top3, 발견 슬롯 비강제, 군집 표시 전용,
COUNT500 고정 재정렬 우선순위를 제안한 것은 공식 맞춤2+발견1의 서로 다른 목적과 자격을
충분히 반영하지 못했다. 이 제안을 현재 정책이나 다음 실험의 기준으로 사용하지 않는다.

현재 작업 기준은 [요구사항 분류](../../plans/service-policy-redesign/requirements-classification.md)와
[맞춤2·발견1 실험 설계](../../plans/service-policy-redesign/experiment-design.md)다.
외부8종·별점0.5 간격과 제품 목적을 유지하고, 수정 가능한 선택과 미정인 의미를 구분한다.

[정정 기록](POLICY-RETRACTION.md)에 철회 범위와 감사 이력을 기록했다.
[당시 검토된 원문](reviewed-snapshot/policy-proposal.md)은 기록 보존용이며 현재 지시가 아니다.
당시 result-review.json의 policy SHA는 이 원문 snapshot에 대응한다.
