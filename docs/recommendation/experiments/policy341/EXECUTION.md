# 맞춤2편·발견1편이 실제로 나아지는가

상태: DRAFT — 로컬 개발 평가 명세. 서비스 정책 확정 문서가 아니다. 2026-09-11.

combination340에서 독립 검토한 모델 하나를 고정한다. 새 기준 B와 그 모델에 동일한5정책을 적용한다.
정책 결과로 모델을 다시 선택하지 않는다. 추가 학습은0회다. 기존270명의 동일 H10/O/J와 전체 후보를 사용한다.
미평가는 UNKNOWN이고, 관측 후보 순위 및 전체 카탈로그의 공급·채점 가능성은 따로 본다.

## 다섯 정책

TMDB 원래19개 복수 장르(TV Movie 포함)를 multi-hot→L2정규화한다. 입력 영화 벡터의 동일가중 합을
다시 L2정규화한 벡터와 후보 영화의 cosine을 익숙함s, `1-s`를 novelty proxy로 쓴다.
별점으로 장르 프로필을 가중하지 않는다. 이 지표는 익숙함이고 좋아함은 고정 모델이 담당한다.
장르가 없거나 입력이 없으면 발견을 정의하지 않고 맞춤으로 대체한다. 고정8군집은 없다.

각3편 묶음마다 남은 후보의 점수 순위 t1/t2/t3를 구한다. t1/t2는 유지한다.
발견 후보 조건은 `s>=.25`와 `novelty(i)-novelty(t3)>=d`이다.
novelty 차이의 부동소수 경계에만 고정 절대오차1e-12를 허용한다. 예를 들어.7−.6이.10보다
미세하게 작게 계산되어 경계 후보가 배제되는 것을 막는다. 연결.25 및 예측점수 경계는 원 float64 비교를 유지한다.

| 정책 | d | 추가 조건 | 후보 선택 |
|---|---:|---|---|
| P0 | 해당 없음 | 없음 | 점수순 t1/t2/t3 |
| P1_010 | .10 | 없음 | 발견 조건을 만족하는 점수 최고 영화 |
| P1_020 | .20 | 없음 | 동일 |
| P2_010 | .10 | 예측점수(i)>=예측점수(t3)−.30 | 동일 |
| P2_020 | .20 | 동일 | 동일 |

동률은 movie_id 오름차순. 이미 반환한 영화와 t1/t2는 후보에서 제외한다.
없으면 t3를 TASTE로 반환한다. 다음 묶음은 반환한3편을 제외한 전체 후보에서 같은 규칙으로 만든다.
장르 novelty가 더 작아지는 교체는 상대증분 조건으로 막는다. .30은 예측 별점 단위의 제약이며
실제 별점 손실.3점 보장이 아니다. P1 최고점 후보가 이 조건을 못 넘으면 P2는 fallback한다.
출발 후보는 전체 J 또는 전체 카탈로그다. 기존Top10/100/500만 재정렬하지 않는다.

## 고정 판정

모델 확인 대조는 H10 h>0·J≥2·IDCG>0의 NDCG2(기존176명)에서 선택 모델−B다.
정책 주 cohort는 H10 h>0·J≥3인158명이며 fallback을 포함한다. ALL242명과 h0 84명은 별도 보고한다.
ID·장르만 확인했을 때 h>0 중 J가 정확히3인5명은 교체할 영화가 없으며 h0 84명도 fallback이다.
이는 조건 적용 전의 최소값이며 실제 공급률을 보장하지 않는다.

공식 가족은 모델 확인1개와 P2두 정책의3개 대조씩, 총7개다.
20,000회 사용자 짝 bootstrap·seed341, Bonferroni 양측99.285714% 명목 구간을 사용한다.
정책6대조는 정렬된 동일158 UID 재표집을 공유한다. 모델 대조176명은 별도의 고정 분모다.

P2 채택 자격은 다음 모두를 만족해야 한다.

1. **선택 모델 자신의 P0 대비** 첫3편 평균 novelty 증가의 구간 하한>0.
2. **B의 P0 대비** 최종 첫3편 평균 실제 별점 차이의 구간 하한≥−.1점.
3. **B의 P0 대비** 최종 첫3편 낮은별점(≤2) 비율 차이의 구간 상한≤+.03.
4. h0에서 B P0 대비 평균별점−.1점/낮음+.03의 점추정 veto 통과.

fallback도 세트 품질에 포함하고 novelty 추가효과는0이다. 실제 발견을 받은 사용자만 골라 주검정을 하지 않는다.
각P2가 자기P0 대비 갖는 별점 손실은 분해 기술통계로 함께 보고한다.
둘 다 통과하면 d=.10 우선, 둘 다 실패하면 고정 모델의 P0를 연구 권고로 유지하며 발견 개선은 미입증이라고 쓴다.
P1과 B의 정책 결과는 진단용이다. 모델 확인 대조는 우월성 표현만 제한하고 모델을 다시 고르는 데 쓰지 않는다.
앞 단계들의 같은 개발 정답 사용·모델당1fit·현재 TMDB 편향 때문에 전체 절차의 확증적 오류율이나2026한국 품질을 보장하지 않는다.
