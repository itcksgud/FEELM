# 단계3 결과 — 두 분류안은 만들었고, 품질 선택은 다음 단계다

상태: DRAFT 연구 보고. 실제 실행·독립 결과 검산 완료. 제품 채택은 미확정. 2026-09-08.

**같은 영화85,517편에 적용할 두8맛 분류안을 준비했다.**
단순 장르안은85,505편을 배정했고, TV Movie 정보만 있는12편은 미배정으로 남겼다.
K-means안은85,517편 전부를8개 군집에 배정했다. 어느 쪽이 추천을 더 잘하는지는 아직 결정하지 않았다.

이번 결과에서 눈여겨볼 점은 두 가지다. 단순안은 장르 목록 순서를 거꾸로 했을 때49.70%의 배정이 바뀌었다.
K-means는 초기화 seed를 한 번 바꿔도99.72%가 같은 군집에 남았지만, 일부 군집 사이의 원언어 분포 차이가
뚜렷했다. **안정적인 군집이라는 사실과8개의 이해하기 쉬운 취향이라는 사실은 다르다.**

## 실제로 만든 것

| 항목 | A: 첫 내용 장르8그룹 | B: 기존 E5-small K-means8 |
| --- | --- | --- |
| 공통 대상 | 85,517편 | 같은85,517편 |
| 배정 | 85,505편(99.986%) | 85,517편(100%) |
| 미배정 | 12편, TV Movie만 있음 | 0편 |
| 맛별 영화 수 범위 | 1,130~25,483편 | 7,865~13,626편 |
| 고정 산출물 | 장르ID→연구코드 규칙과 영화별 배정 | centroid8개·고정 연구코드·영화별 배정 |
| 신규 영화 | 같은 장르 순서 규칙 | 같은 모델/전처리 descriptor의 vector→최근접 centroid |

카탈로그 전체87,585편 가운데 공통 범위 밖2,068편도 제외 사유를 보존했다.
identity 부적격1,129편, 구조 정보만 부족692편, 텍스트만 부족216편, 양쪽 부족31편이다.
공통 범위에는 TMDB ID 중복이 없었다. 기존 TMDB ko-KR 요청 캐시85,517개를 파일 hash와 원응답 body hash로 검증했다.
새 다운로드·TMDB 호출·텍스트 인코딩·사용자 평점/평가 정답 조회는0건이다.

## A를 읽는 방법

첫 내용 장르를 다음8그룹에 연결한다. TV Movie는 음악 내용의 증거가 아니므로 건너뛰었다.
표의 설명은 연구용이며 공식 팝콘 이름·색상으로 승인한 값이 아니다.

| 연구 코드 | 의미 | 영화 수 |
| --- | --- | ---: |
| ADRENALINE | 액션·모험 | 8,665 |
| WONDER | 애니메이션·판타지·SF | 6,422 |
| JOY | 코미디·가족 | 18,342 |
| HEART | 드라마·로맨스 | 25,483 |
| SHADOW | 범죄·공포·미스터리·스릴러 | 13,836 |
| REAL | 다큐멘터리 | 9,085 |
| LEGACY | 역사·전쟁·서부 | 2,542 |
| RHYTHM | 음악 | 1,130 |

장르 목록을 역순으로 한 진단에서는42,504/85,517편(49.70%)이 다른 그룹으로 바뀌었다.
원래 장르 순서에 배정이 의존함을 보여준다. 첫 장르의 중요도 의미는 이번 진단으로 확인하지 않았다.
실제 고정 배정은 원래 순서 그대로다.
역순 결과를 보고 우선순위를 다시 고르거나 세 번째 분류안을 만들지 않았다.

## B를 읽는 방법

E5-small384의 기존 영화 표현을 사용했다. 공식 ADR의 MVP E5-base 재현은 아니다.
제목·줄거리·장르·인물·키워드를 함께 표현한 좌표이므로 A와의 차이를 K-means 알고리즘만의 효과라고 해석할 수 없다.

| 연구 코드 | 영화 수 | c-TF-IDF 상위 문구 일부 | 원언어 분포의 관찰 |

| SEMANTIC_01 | 13,521 | 코미디·로맨스·드라마·TV 영화 | 영어92.78% |

| SEMANTIC_08 | 9,933 | 드라마·코미디·로맨스 | 러시아어17.50%, 독일어8.56%, 힌디어7.78%, 영어7.42% |

01·04 등은 문구상 내용 특징이 보이지만,03·05·06의 상위 문구는 상당히 겹친다.
07·08은 원언어 분포가 다른 군집과 뚜렷하게 다르다. 언어·자료 표현의 영향이 섞였을 가능성을 검수 대상으로 남긴다.
이번 집계만으로 그 원인이 언어라고 인과적으로 확정하거나, 모든 군집에 명확한 취향 이름을 붙이지 않는다.
전체 상위15문구·원언어 집계·고정 hash 표본5편·centroid 근접5편은 taste-summary.json에 있다.

주 seed20260908과 진단 seed20260909를 각각 한 번 실행했다(n_init=10씩).
군집 번호를 최적으로 맞춘 배정 일치율은99.7194%, 번호 순열에 영향을 받지 않는 ARI는0.993048이다.
주 모델의70회, 진단 모델의37회 반복은 max_iter300에 도달하지 않았다.
진단 모델을 더 좋은 모델로 선택하지 않았고 주 seed의 centroid와 코드 매핑을 유지했다.
이 값들은 초기화에 대한 배정 민감도이며 추천 만족도나 새 영화 품질이 아니다.

## 실행·검증 범위

설계 독립 PASS →실행 코드 검토·합성 검사11개 PASS →4파일 hash 봉인 후 수행했다.
예산 파일에 기록된610.69초, 프로세스 트리 최대 약1.075GiB로30분/12GiB 상한 안에 종료했다.
실행 기록의 KMeans 호출은2회이며 새 ALS 학습은 없다. c-TF-IDF는10,837개 장르/키워드 ID 문구를 사용했다.
메타데이터는2026-09-05에 수집한 retrospective snapshot이라는 기존 한계를 유지한다.

독립 검산은 두 모델171,034개 배정 전부 일치, 거리 최대오차2.50e-16을 확인했다.
A 전행 규칙·미배정·역순 진단,10,837토큰 c-TF-IDF(최대오차2.78e-17), 상위 문구240개·대표 예시120개·언어 집계가 일치했다.
8! 전체40,320개 코드 매핑을 비교해 최적 일치율을 검산했고, 입력11개·출력16개·봉인 의존4개·캐시85,517개도 전수 확인했다.
완료본 재사용은 `VERIFIED_EXISTING_COMPLETION_NO_FIT_OR_ASSIGNMENT`로 확인했으며 추가 fit은 없었다.
새 영화 검증은 동일 descriptor의 vector에 대한 predict 계약까지다. 새 텍스트 encoder의 재현·공식 centroid·
공식8맛 이름/색상 매핑·실제 서비스 통합을 검증했다고 보고하지 않는다.
