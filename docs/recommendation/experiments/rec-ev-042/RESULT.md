# 분류 기반 추천 비교 결과

상태: 연구 결론 검증 완료. 제품 정책 계약이 아니다. Jira [S15P21E106-300](https://ssafy.atlassian.net/browse/S15P21E106-300). 2026-09-08.

**이번 고정 조건에서는 분류를 추가한 맞춤2편의 선호 개선을 확인하지 못했다. 발견1편으로 교체하면 관측 선호가 낮아졌다. ALS 기준선을 유지하고, 두 분류의 최종 채택과 현재 발견 정책의 서비스 적용은 보류한다.**

이것은 K-means 자체가 무효라거나 발견 추천이 불필요하다는 결론이 아니다. 이미 별점이 있는 후보 안에서 두 분류와 연결형 발견 정책을 비교한 결과다. 실제 미평가 영화의 새로움·만족도·설명 납득은 측정하지 않았다.

## 무엇을 비교했나

- 같은 MovieLens 사용자 2,180명, 고정 입력30편, 같은 원별점 ALS checkpoint와 순위를 사용했다. 학습 사용자46,376명과 평가 사용자 겹침은0명이다. 이번 새 학습·fold-in은0회다.
- 기준선은 분류 제한 없는 ALS 상위3편이다. 두 분류안은 맞춤2+연결형 발견1을 선택하고, 발견이 없으면 맞춤3으로 대체했다. 기준선의 세 번째 영화는 GENERAL3이며 발견으로 부르지 않는다.
- 분류는 TMDB 장르 기반 개선 규칙과 장르 K-means다. 맞춤은 긍정 입력이 속한 그룹, 발견은 입력30편에 없는 그룹이면서 긍정 입력과 장르·감독·키워드 연결이 있는 후보다. 입력30편 밖의 시청 이력까지 안다는 뜻은 아니다.
- 기존 관측 평가 후보191,933쌍에서 ALS 미지원779쌍과 지원 TV-only1쌍을 제외해 세 안 모두191,153쌍을 사용했다. 사용자당18~106편이다. 입력 영화와 평가 후보는 겹치지 않는다.
- 새 추천 목록을 먼저 SHA256으로 봉인하고 그 뒤에만 평가 별점과 histogram을 열었다. 기존 개발 자료를 재사용한 탐색적 조건부 비교로, 새로운 독립 확증 자료는 아니다.

## 앞2편: 분류를 붙여 더 좋아졌는가

아래 상대 선호는 Q×100이다. Q는 각 사용자의 전체 별점 분포에서 해당 별점보다 낮은 비율에 동점 비율의 절반을 더한 값이다. 68은 만족도68%나 별점6.8점이 아니다. 실제 별점은0.5~5.0·간격0.5를 유지한다. 저선호는 Q≤0.2로 고정했다.

| 추천안 | 평균 상대 선호 ↑ | 두 편 중 낮은 상대 선호 ↑ | 저선호가 1편 이상인 사용자 ↓ |
| --- | ---: | ---: | ---: |
| 분류 없는 ALS | 68.13 | 57.40 | 8.99% |
| ALS + 개선 장르 규칙 | 67.99 | 57.30 | 8.94% |
| ALS + 장르 K-means | 68.03 | 57.33 | 8.94% |

세 안 모두 같은2,180명을 비교했고 제외 사용자는0명이다. 세 쌍×세 지표의 보정 구간9개가 모두0을 포함한다. 따라서 우열 미판정이며, 차이가 없음을 증명했거나 동등성·비열등성을 통과했다는 뜻은 아니다.

관측상 손실은 현재 연결형 발견 제약이 가져오는 교체 비용이다. 그만한 새로움·탐색 가치가 있었는지는 별도의 관측 근거가 필요하다.

- **유지:** 원별점 ALS를 비교 기준으로 사용한다. 맛을 ALS 학습 입력에 추가해야 한다는 근거는 이번 실험에서 얻지 않았다.

- **다음 결정:** 발견에 허용할 선호 손실과 제공/보류 조건을 먼저 정한 뒤 보수적 발견 정책을 비교한다. 입력 개수·입력 영화 선정·개인화 전환K는 이번 결과로 정하지 않는다. 새 실험은 Jira 확인부터 별도 사이클로 시작한다.

## 검증과 재현 범위

실행 전 구현·통계 독립 검토와 합성16검사를 통과했다. 실험은5.5초, 최대 프로세스 트리 RSS 약201.5MiB로15분·4GiB 한도 안에서 완료했다. 결과 감사에서 원자료→정규화 입력 전필드와 선택19,620슬롯, 모든 집계가 일치했다. 별도 방식으로 재계산한20,000회 bootstrap의 최대 오차1.56e−17, 구간 오차6.94e−18이다.

로컬 NumPy1.26.4에서 실행했고 NumPy2.2.6의 팀 인계 코드로 전체 선택·채점 재생 시 summary 바이트가 일치했다. 두 실행의 Python은3.12.5다. 팀 선언 Python3.10과 EC2·Spark 서비스 연결 실행은 아직 검증하지 않았다.

사용자별 후보·평점·선택·bootstrap 원자료는 Git에 올리지 않는다. 외부 파일 해시와 LOCAL_ONLY 상태를 기록한다. Git만 받아서는 실제2,180명 재생이 불가능하며 입력 파일 전달이 필요하다. 장르 추론 코드도 제공하되 저장 패키지를 외부에서 받아야 한다. 이 인계는 장르ID→그룹 추론과 고정 점수/역할 이후 선택·채점 재생을 지원한다. TMDB 수집·새 군집 학습·ALS 학습·사용자별 T/D 생성·운영 Consumer 전체 재현은 포함하지 않는다.
