# 팝콘 맛 구성을 위한 TMDB 정적 자료 확인

상태: SUPERSEDED / 실행 취소. 개인 연구 제안이며 서비스 계약이 아니다.

사용자 정정: TMDB 약 130만 편 전체를 확인해야 한다. 85,517편 표본은 모집단 범위가 부족하다.
이 계획의 집계 코드는 실행하지 않았다. 모델과 기존 준비 작업의 중지는 계속 유지한다.
새 범위는 공식 일일 영화 ID 목록과 공개 상세 메타데이터의 범위를 대조한 뒤 전량을 집계하는 것이다.

사용자 요청: TMDB 자료를 확인해 팝콘 맛의 적절한 개수와 복수 장르 처리 방식을 제안한다.
2026-09-11의 실험 중지 지시는 유지한다. 이번 범위는 기존 메타데이터의 읽기와 기술 통계뿐이다.
군집/분류/추천 학습, 임베딩 생성, 사용자 평점 읽기, 기존 준비 작업 재개는 포함하지 않는다.

- 입력: FEELM-standalone의 rec-ev-033/metadata.parquet 및 rec-ev-045/metadata.parquet. 입력 SHA256은 코드에 고정한다.
- 모집단: 기존 연구에서 확보한 구조화/텍스트 공통 카탈로그 85,517편. TMDB 전체나 최신 한국 서비스 카탈로그가 아니다. 모집단 선정으로 결측이 줄어든 자료다.
- 분석: 원본 19개 장르를 모두 보존하고, 영화별 장르 수/복수 장르 비율/장르별 빈도/정확한 조합/공동 출현을 집계한다. 키워드, 줄거리, 언어, 연도, 국가 정보의 채움도 확인한다.
- 원본 확인: 명시한 예시 영화의 기존 캐시 body만 선택적으로 확인하고 응답 body 해시 및 장르 목록을 대조한다. 요청 헤더와 자격증명은 읽거나 출력하지 않는다.
- 판정: 모든 행의 식별자와 두 자료의 장르가 일치해야 한다. 영화별 장르는 중복 ID가 없어야 한다. 빈도 합계 및 조합 합계를 대조한다. 원본 해시가 달라지면 중단한다.
- 맛 이름/개수는 설명을 위한 설계 가설이다. 공동 출현이나 카탈로그 공급량을 감정 라벨 정답, 분류 정확도, 추천 만족도 또는 최적 개수로 해석하지 않는다.
- 복수 장르 영화는 다중 소속을 허용한다. 장르마다 팝콘 하나를 강제로 정하거나 첫 장르만 사용하지 않는다. 형식/주제 보조 태그와 감정 판단의 미확정 상태를 보존한다.
- 독립 검토: 집계 코드와 이 계획을 검토한 뒤 실행하고, 별도 검토자가 집계와 제안의 주장 범위를 다시 확인한다.
- 산출물: 이 디렉터리의 소형 audit.json 및 설명 문서. 원본 자료와 기존 실험 봉인은 수정하지 않는다.
