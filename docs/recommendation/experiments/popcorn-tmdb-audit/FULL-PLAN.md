# TMDB 전체 범위 대조와 팝콘 맛 제안

상태: DRAFT. 개인 연구의 정적 자료 확인. 모델 실험은 계속 중지한다.

기존 85,517편은 MovieLens 연계 표본이므로 전체 맛 체계를 결정할 모집단으로 사용하지 않는다.
전체 범위 기준은 2026-09-10 TMDB 공식 일반 영화 ID export와 별도 adult 영화 ID export의 합집합이다.
2026-09-11 02:41 UTC 당시 당일 export의 공식 공개 시각(08:00 UTC) 이전이므로 전일 것을 쓴다.
상세 자료는 asaniczka가 공개한 Kaggle TMDB_movie_dataset_v11.csv의 다운로드 스냅샷이다.
공식 ID export에는 장르/키워드가 없으므로 상세 자료의 ID 커버리지를 실제 대조한다.
Kaggle 자료는 제3자 수집본이며 파일 갱신일이 모든 행의 갱신일을 보장하지 않는다.
출처/다운로드 시각/원본 바이트 수/SHA256은 outputs/.../popcorn-tmdb-full-audit/sources.json에 기록했다.

실행은 CSV 전체를 순차로 읽는 기술 통계다. 학습, 임베딩, 평점 기반 추천 평가, 개별 영화 API 대량 호출은 하지 않는다.
러닝타임이 비어 있거나 수치 변환 불가/비유한/0 이하이면 UNKNOWN으로 처리한다.
모든 원본 행을 포함해 장르 결측, 장르 수, 19장르별 빈도, 원본 복수 장르 조합, 공동 출현,
키워드/줄거리 채움도, 개봉 상태/언어/러닝타임 분포를 집계한다. 결측을 제거한 집계만 보고하지 않는다.
별도 분모로 공식 ID와 일치하는 전체, 그중 장르가 있는 행, 일반 영화 export에 속한 행도 보인다.
최근(2020년 이후), 한국어 원어, 개봉+adult=False+러닝타임60분이상은 성격 차이를 보는 보조 집계이며 서비스 제외 정책이 아니다.
확인용 예시는 미리 지정한 TMDB ID의 제목과 모든 장르만 저장한다. 키워드는 쉼표 평탄화로 경계가 모호할 수 있어 정답 라벨로 쪼개지 않는다.

실제 CSV에서 ID 144430의 장르가 Animation, Animation으로 중복되어 최초 집계를 중단했다(결과 파일 생성 전).
원본은 보존하고 집계에서는 영화 내 동일 장르를 한 번만 세며, 중복 장르가 있던 행수도 기록한다.
두 번째 집계에서도 CSV 영화 ID 중복이 발견되어 결과 생성 전 중단했다. CSV의 첫 ID 행을 유지하고
중복 ID의 추가 행은 별도 개수로 기록해 영화별 중복 계산을 막는다. 첫 행의 최신성은 보장하지 않는다.
입력 해시와 고유 ID, 공식 export 내 중복, 장르 미지 명칭, 행수=조합합=장르수빈도합,
전체=공식일치+미일치, 공식전체=상세확보+미확보를 확인한다. 불일치가 있으면 중단한다.
공식 목록에 있으나 상세가 없는 영화는 장르 UNKNOWN이며 관측 장르 분포의 분모에서 숨기지 않는다.

군집 수/맛 개수 최적화는 실행하지 않는다. 데이터는 충분한 후보 공급, 혼합 장르, 미포괄 항목을 확인하는 근거다.
맛의 의미와 개수는 잠정 설계 제안이며 독립 검토가 통과해도 추천 성능과 감정 라벨의 타당성이 검증된 것은 아니다.
실행 전 코드/설계 독립 검토와 실행 후 계산/주장 범위 독립 검토를 진행한다.
