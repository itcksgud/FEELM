# 현재 K-means의 TMDB 입력과 8맛 준비도 점검

상태: DRAFT — 개인 연구 결과. 공식 추천·맛 이름·색상 채택 문서가 아니다. 2026-09-08.

**현재 K-means는 계산·출처 검사를 통과했지만, 서로 구별되는8가지 취향으로 충분히 만들어졌다고
판단할 근거는 부족하다.** 준비도는 `INCONCLUSIVE`다. 이 버전을 완성된8맛으로 확정해 후속 품질
비교의 준비가 끝났다고 처리하지 않는다. 아래 사례는 K-means 전체의 실패나 단순 장르안의 승리를 뜻하지 않는다.

## 무엇으로 K-means를 만들었나

**TMDB 데이터를 사용했다.** 이번 점검이 새 군집을 만든 것은 아니며, REC033의 기존 군집을 검사했다.

```text
TMDB 제목 + 줄거리 + 장르 + 감독 + 주요 배우5명 + 키워드
→ 기존 multilingual-e5-small 텍스트 임베딩(384차원)
→ K-means가 가까운 영화들을8개로 묶음
```

MovieLens는 영화 ID·TMDB 연결을 제공했다. **사용자의 별점, 좋아요/싫어요는 군집 fit에 넣지 않았다.**
TMDB popularity·vote_average·vote_count도 임베딩·fit·대표 영화 선정에 사용하지 않았다.
TMDB가 이미 정리한 장르 ID로 직접 나눈 단순안도 TMDB를 쓰지만, 이 K-means안은 장르를 포함한
여러 텍스트 정보를 함께 E5 공간으로 옮긴 것이다. 따라서 두 안의 차이는 표현·분류 방식 전체의 차이다.

제목은 ko 제목→en 제목→ko 원제→en 원제, 줄거리는 ko→en 순으로 fallback한다. 장르·인물·키워드 이름은
ko 응답에서 가져온다. MovieLens 제목을 대신 넣는 경로는 없다. 원언어 코드는 입력 문장에 없지만,
실제 제목·인물명·줄거리 언어와 지역적 내용이 군집에 연관될 가능성은 있다.
전체 입력은512토큰에서 잘릴 수 있어 뒤쪽 필드가 모든 영화에서 완전히 반영됐다고 보장하지 않는다.
이번에는 문자열만 복원했으며 과거 토큰·벡터를 다시 생성하지 않았다. 공식 E5-base768 모델의 재현도 아니다.

## 실행 사실

독립 설계·실행 검토 후, 고정85,517편 전체의8개 중심 거리를 계산했다. 모든 배정과 저장 거리가
runner의 같은 직접 계산에서 정확히 일치했다. 독립 합산 구현에서도 배정은 동일하고 부동소수점 오차만 있었다.
군집마다 기존 근접5편·hash5편·경계5편, 총120편을 같은 규칙으로 골랐다. 선택 역할 간 중복은 없었다.
120편 모두 검증된 TMDB 캐시로 복원한 인코딩 전 입력 문자열이 기존 저장 SHA256와 일치했다.

새 fit0회, 새 인코딩0회, MovieLens 사용자 평점 접근0회, 네트워크 조회0회다.
계산 약3.9초, 감시한 최대 프로세스 메모리 약743MiB. 합성4개와 독립 합성45사례를 통과했고,
완료 재실행은 파일·출처 봉인 검사만 수행했다.

첫 AI 검수는 군집/거리/원언어/선정역할을 가린120개 카드에서 내용 기술을 작성했다.
제목에서 언어·지역을 추정할 수 있고 이전 집계를 알던 검수자이므로 완전한 맹검이 아니다.
이후 기술을 봉인하고 군집 연결 자료와 함께 검토했다. 이는 **AI의 메타데이터 내용 감사**이며,
실제 사용자 선호·8맛 이해도·발견 만족도를 검증한 결과가 아니다.

못했다고 수학적 오배정으로 단정할 수는 없다. 아직 승인된 개별 맛의 의미도 없다. 따라서 여기서는
“잘못된8맛임을 확정”보다 “8맛 설명에 충분하다는 근거를 확보하지 못함”으로 판정했다.

## 숫자는 이 해석을 어디까지 뒷받침하나

모든 장르를 센 군집별 빈도 벡터의 cosine은03–05 **0.9823**, 03–06 **0.9572**,
05–06 **0.9800**, 07–08 **0.9773**이었다. 장르 분포가 겹친다는 진단이며
“영화 내용이98% 같다”거나 “같은 군집이 정답”이라는 뜻은 아니다.

원언어 분포도 다르다. 예컨대07은 이탈리아어29.26%·프랑스어27.13%·스페인어22.26%이고,
08은 러시아어17.50%·독일어8.56%·힌디어7.78%다. 이는 **영화의 원언어**이며
실제 입력 줄거리의 언어와 동일하지 않다. 해당 분포만으로 “언어가 군집을 갈랐다”고 인과를 확정하지 않는다.

검수 카드에서는03/05/06에 한국어 줄거리 사례가 이어지고, 다른 군집에는 영어 fallback 사례가 보였다.
같은 영어 원어 영화라도 입력 줄거리의 언어와 상세도가 달랐다. 예컨대 03의〈헷지〉와04의〈Cop〉는
둘 다 원언어en이지만 전자는 한국어, 후자는 영어 줄거리를 썼다. 이 차이는 입력 표현을 점검할
가설이지 원인 확정이나 전체 카탈로그의 번역 언어 통계를 대신하지 않는다.

margin 중앙값은01~08 순서로0.0208/0.0230/0.0546/0.0231/0.0317/0.0326/0.0273/0.0263이다.
03의 중앙값이 다른 군집보다 커도 내용 설명은 어렵다. 이 사례에서 **기하적 구별과 해석 가능한
취향의 구별이 서로 다른 질문**임을 확인할 수 있다. margin 통과선을 사후에 만들지 않았다.

## 여기서 결정한 것과 다음 순서

| 대상 | 이번 판단 |
| --- | --- |
| 데이터 출처·현재 배정 계산 | PASS: TMDB 입력·기존 임베딩·현재 centroid의 연결과 배정 재현 확인 |
| 설명 가능한8맛 후보의 준비도 | INCONCLUSIVE: 특히03/05/06과07/08의 내용 구별 근거 부족 |
| 실제 사용자 취향·발견 품질 | 미평가. AI 내용 기술이나 후보 공급률로 대신하지 않음 |
| 수정해야 할 단일 원인 | 미확정. 문장 언어·상세도·인물명·표현 공간·내부 k의 영향을 분리하지 않았음 |

**현재 군집을 완성된8맛으로 확정하는 결정은 보류한다.** 외부8종·반별점 입력·원별점 ALS 기준은 유지한다.
전체 K-means를 폐기하거나 장르안을 승자로 선언하지 않는다. 기존 군집·공급 결과도 원본대로 보존한다.

다음에 풀 질문은 하나다: **영화 내용이 같아도 줄거리의 언어·상세도가 바뀌면 현재 배정이 달라지는가?**
이 대조도 언어·길이·정보량이 함께 바뀌면 개별 요인을 분리하지 못한다. 일부 배정이 바뀐다는 것만으로
그 요인이 전체 군집 분리의 주원인이라고 결론 내리지 않는다.
먼저 이 입력 표현 가설을 좁힌 뒤, 원인이 확인되면 그 문제만 겨냥한 수정안1개를 별도 설계·검토한다.
언어 연관성을 이유로 원언어 코드를 제거하는 수정은 하지 않는다. 그 코드는 원래 입력에 없었다.
근거 없이 k·seed·임베딩 모델을 늘리지 않는다. 수정 후보의 준비도를 확인한 뒤 같은 ALS·맞춤2/발견1
품질 비교로 넘어가며, 그 정책이 고정된 뒤 전환 K·실제 온보딩 부담을 판단한다.

이번 승인 범위의 진단은 종료했다. 새 수정안 학습이나 실제 품질 비교는 수행하지 않았다.
