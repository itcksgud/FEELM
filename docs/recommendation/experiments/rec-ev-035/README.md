# REC035 — 원별점·상대값·이진 응답 환산의 세 결과 비교

상태: DRAFT — 사전 고정 연구 실험 계약이며 제품 구현 계약이 아니다. 독립 설계·코드 검토 PASS와 fingerprint 봉인 뒤에만 실데이터 실행한다. 2026-09-08.
실행 검토 상태는 review.json, 완료와 해석은 RESULT.md에서 확인한다.

사용자는 감상 별점을 유지하며 세 결과를 실제로 비교하고 직관적으로 정리하도록 요청했다.
같은 학습/평가 사용자와 관측 영화에서 세 입력 경로를 비교한다. 전체 이진 ALS를 새로 학습하지 않는다.
기존8맛·T2/D1·500/100·K를 이번 기본 입력 비교에 섞지 않는다. 추천 품질의 범위는 기존 관측 영화 안의 순서다.

## 세 경로와 실제 변경

| 코드 | 학습된 영화 모델 | 현재 사용자 계산 |
| --- | --- | --- |
| A_RAW | 기존 REC032 원별점 ALS | 공통 유효 입력의 원별점 |
| B_RELATIVE | 동일 학습 행의 상대값 ALS를1회 새 학습 | 같은 상대값·동일 RMS 배율 |
| C_BINARY_BRIDGE | A와 정확히 같은 원별점 영화 factor | 이진 대리 응답을 학습 전체 이력으로 정한 두 평균 별점에 환산 |

새 영화모델 학습은 B 한 번이다. 각 입력량별 재학습·새 분할·다른 모델·mapper/λ 탐색은 하지 않는다.
A는 공통 중립 마스크가 적용돼 기존 raw 입력 전체와 다를 수 있다. 중립0인 상태에서만 기존 A0 점수/순위를 재현한다.
B-A에는 학습과 입력 표현 변경이 함께 포함된다. C-A에는 부호화·환산 오차·학습/입력 분포 차이가 함께 포함된다.
이를 순수한 이진화 정보 손실이나 실제 UI 응답의 효과로 분리해 주장하지 않는다.

## 원천·역할·순서

config에 bytes/SHA256으로 고정한 연구 저장소 안의 파일만 사용한다.
원 REC032 training.parquet의7,355,439행·46,376명, prepared의85,517영화/prior, profiles의2,180명·30개 입력을 재사용한다.
학습 사용자 전행을 검사해 평가자의 user_key 유입0과 학습 사용자 집합/행 수를 확인한다. 중복 사용자-영화 행은 거부한다.
원학습은 카탈로그 필터 전 허용 전체 행이며 B도 같은 행·영화 ID를 유지한다. 별점은0.5~5.0·간격0.5다.

기존 conditional targets의 E191,933개 사용자–영화 조합은 평가 요청 명세로만 사용한다.
모델 학습·prior·mapper·사용자 벡터·전체 카탈로그 점수에는 E의 ID/별점/H를 넣지 않는다.
각 전체 카탈로그 순서를 만든 뒤 E의 부분순서에서 상위2편을 고른다. E/H 값은 세 경로의 모든 n점수를 봉인한 뒤 읽는다.
E/H는 이미 개봉된 개발 자료의 고정 Q 검산·채점에만 사용하며 새 확증이 아니다.
Locked Test/reserve·원 archive·다른 사용자 이력·네트워크·TMDB/콘텐츠 값은 사용하지 않는다.

## 상대값과 공통 입력

학습 사용자별 허용 전체 histogram에서 사용자 동등 prior G를 재계산하고 기존 prepared prior와 대조한다.
수축5·mid-CDF의 기존 정의를 그대로 사용하되 수학적0 판정을 안정화하는 분자식으로 계산한다.

```text
w = [2·count(<r) + count(=r) + 10·G(r) - (n+5)] / (n+5)
```

학습에서는 모든 관측 행의 w를 보존한다. w=0인 학습 행도 삭제하지 않으므로 A/B 학습 그래프와 factor ID가 같아야 한다.
평가의 O(n)은 기존 hash순서 입력의 앞0/5/10/30개다. 각 n의 전체 O(n)에서 w를 한 번 계산하고,
w가 정확히0인 관측만 세 경로 모두의 사용자 벡터 계산에서 제외한다. 이후 w를 재계산하지 않는다.
추천 제외는 **전체 O(n)**이다. 중립·factor 없는 관측도 제외하며 O30 전체를 n5에서 제외하지 않는다.
`n_observed / n_nonzero / n_factor_used`와 각 n의 양수/음수/중립 수를 기록한다. 입력0이나 factor없음/0벡터는 기존 P0 fallback이다.
실패/미지원 사용자를 보고 분모에서 빼지 않는다. E의2편 공급 부족이 한 셀이라도 있으면 채점을 중단하고 실패를 보존한다.

## B: 수치 규모와 학습

같은 학습 행에서 s=RMS(raw)/RMS(w)를 계산한다. s가 양수 유한값이 아니면 중단한다.
학습 목표와 신규 사용자 목표 모두 s·w다. 평균을 빼거나 사용자별 배율을 추가하지 않는다.
학습 parquet는 Spark ALS 입력에 맞게float32이며 변환의 반올림 최대오차·0행 보존·원본 행 순서 hash를 기록한다.
Spark4.2.0 explicit ALS, nonnegative=False, rank32, seed42, maxIter10, λ0.1, local[4], Java driver4g를 사용한다.
관측쌍만 학습하고 미관측쌍을0/불호로 채우지 않는다. 반환 user/item factor·최종 학습 오차/목적함수를 보존한다.
동일 RMS·λ·10회 반복은 최적 λ나 수렴을 보장하지 않는다. 이번 고정 구성의 결과로 한정하며 특정 안만 반복을 늘리지 않는다.

## C: train 전체 이력으로 정한 두 값 환산 adapter

학습 각 행의 w_train 부호별로 원별점의 행 가중 평균을 구해 LIKE/DISLIKE의 두 환산값을 고정한다.
한 부호 표본이 없으면 임의 기본값 대신 중단한다. 이진 모델을 새로 학습하지 않는다.
평가 시 별점은 대리 응답 생성 경계에서 sign(w_O(n))을 만드는 데만 사용한다.
환산 함수는 LIKE/DISLIKE enum만 받으며 원별점·상대 강도·사용자 H를 전달하지 않는다.
환산값은 반별점으로 반올림하지 않는 연속 pseudo-target이며 실제 감상 별점/RawRatingPacket에 저장하지 않는다.
부호가 같은 영화는 같은 환산값을 받는다. 평가 사용자별 별점 보정이나 평가자의 숨긴 원별점 복원은 하지 않는다.
각 항목의 계산 가중치는 세 경로 모두1인 통제 조건이다. 실제 이진 응답과 별점의 신뢰도가 같다는 주장은 아니다.

훈련 전체 이력의 부호와 짧은 O(n)의 부호 분포는 다를 수 있다. 이 mapper가 각 n에 calibration됐다고 하지 않는다.
n이 바뀌면 이전 영화의 대리 부호도 바뀔 수 있다. 실제 응답 누적·K·온보딩 시간 비교로 사용하지 않는다.
실제 온보딩과 감상 별점의 대응 자료가 없으므로 이 가정 안의 환산 진단이며, C가 불리하다고 온보딩 전체를 기각하지 않는다.

## 비교·불확실성·정리

모델 내부 점수/RMSE 단위가 달라 이를 세 결과의 승패로 쓰지 않는다. 모든 추천은 같은 고정 H/Q로 채점한다.
주 지표는 기존 MEAN_Q, MIN_Q, HARM20이다. 각각 두 영화의 평균 개인 선호 위치, 낮은 쪽 선호 위치,
고정 개인 상대점수 Q≤0.2인 영화가 하나 이상 포함된 추천의 비율이다. 동점 때문에 정확히 하위20%는 아닐 수 있다.
원별점 평균은 설명용 보조 집계다.
짝 차이는 B-A, C-A, B-C × n5/10/30 ×3지표의27개 family다. 사용자 단위 짝 bootstrap20,000회,
seed20260908, alpha.05, Bonferroni 양쪽 분위수 구간을 고정한다. 방향 기준0이며 실질 채택 기준은 정하지 않는다.
정수 Q 분자를 빼서 수학적 동률을 보존하고 사용자별 개선/동률/악화도 보고한다.
n0은 세 안의 P0 일치 확인만 하며 주 비교에 포함하지 않는다. 새 P0 경쟁 모델을 추가하지 않는다.
결과는 n별 세 열의 표와 공통 척도 그림으로 정리한다. Q를 정확도·만족도 백분율로 이름 붙이지 않는다.
원 데이터·모델·recipe·source/score hash 및 집계/짝 차이를 독립 검산하고 보고 문장도 별도로 검토한다.
