# 콘텐츠 그룹 8·10·12개 비교안

상태: 개인 연구의 설계 비교 초안. 팝콘 맛 이름·색상·화면 표시 제약은 이번 비교에서 제외한다.
영화 한 편은 대표 그룹 하나에 속한다. DB 적용, 실제 영화별 배정 생성, 모델 학습 및 추천 실험은 하지 않는다.

## 세 가지 안

아래에서 **` / `는 별도 그룹**, **`·`는 한 그룹 안에 함께 포함되는 장르**다.
같은 행을 따라가면 무엇을 합치거나 분리했는지 볼 수 있다.

| 8개안 | 10개안 | 12개안 |
|---|---|---|
| 다큐멘터리 | 다큐멘터리 | 다큐멘터리 |
| 음악 | 음악 | 음악 |
| 역사·전쟁 | 역사·전쟁 | 역사·전쟁 |
| 액션·모험·서부 | 액션·모험·서부 | 액션·모험 / 서부 |
| 드라마·로맨스·가족 | 드라마·로맨스·가족 | 드라마·로맨스 / 가족 |
| 코미디 | 코미디 | 코미디 |
| 공포·범죄·미스터리·스릴러 | 공포 / 범죄·미스터리·스릴러 | 공포 / 범죄·미스터리·스릴러 |
| 애니메이션·SF·판타지 | 애니메이션 / SF·판타지 | 애니메이션 / SF·판타지 |

세 안은 기존 14개 대표 분류의 합집합이다. 원래 장르를 삭제하거나 서로 같은 장르라고 간주하는 안이 아니다.
범주 이름은 의도적으로 포함 범위를 드러낸다. ‘감동’, ‘상상’ 같은 감정명만으로 부르면 범위와 어긋나는 영화가 생긴다.

## 통합 이유와 포기하는 구분

| 단계 | 합치는 기존 그룹 | 설계상 이유 | 한계 |
|---|---|---|---|
| 14→12 | 드라마 + 로맨스 | 인물과 관계를 다루는 넓은 후보군으로 묶음 | 비연애 드라마와 연애 중심 영화의 차이는 그룹 이름만으로 구분할 수 없음 |
| 14→12 | 역사 + 전쟁 | 시대·역사적 사건을 다루는 상위 후보군으로 묶음 | 전쟁이 항상 역사물인 것은 아니며 역사물이 항상 전쟁물인 것도 아님 |
| 12→10 | 액션·모험 + 서부 | 서부극을 행동·여정 계열과 함께 탐색할 수 있게 묶음 | 모든 서부극이 액션물은 아니며 서부라는 배경 선호가 가려짐 |
| 12→10 | 드라마·로맨스 + 가족 | 인물·관계 계열을 넓게 묶음 | Family는 관객층 성격도 있으므로 모두 관계 중심·감동물이라고 설명할 수 없음 |
| 10→8 | 공포 + 범죄·미스터리·스릴러 | 사건·위협을 다루는 넓은 후보군으로 묶음 | 범죄 선호와 공포 선호를 같은 취향으로 취급하면 안 됨 |
| 10→8 | 애니메이션 + SF·판타지 | 그룹 수를 줄이기 위해 표현 형식과 세계관을 한 상위 후보군에 수용 | 사실적 애니메이션과 실사 SF가 섞임. 세 안 중 특히 의미 구분이 약해지는 통합 |

이는 비교 가능한 후보 설계다. 의미 손실이 가장 작은 조합이나 추천 성능이 가장 좋은 그룹 수로 검증된 것은 아니다.
다큐멘터리와 음악은 세 안 모두 별도 그룹으로 남긴다. 기존 전체 범위 집계에도 이 장르만 있는 입력이 각각
161,681편과 28,100편 있어, 이번 축소에서는 독립된 탐색 경로를 유지하는 판단을 했다.
이 빈도만으로 독립 그룹의 추천 효과를 증명하지는 않는다.

표시 제약을 없앤 현재 조건에서는 **12개안을 기준안**, **10개안을 절충안**, **8개안을 강하게 압축한 비교안**으로 제안한다.
12개안은 가족과 서부를 독립적으로 탐색할 수 있고, 10개안은 적어도 공포와 사건 계열 및 애니메이션과 SF·판타지를 분리한다.
원본 특징을 분류기에 남겨도 후보를 그룹 단위로 줄이는 순간의 손실이 자동으로 복구되는 것은 아니다.
특히 8개안은 그룹 벡터 하나만으로 사용자의 낯섦이나 선호를 설명하기에 내부 차이가 클 수 있다.

## 복합 장르: 배정 규칙은 공유하고 마지막 통합만 다르게

1. 기존 14개 규칙으로 대표 분류를 하나 정한다. 원본 장르 ID를 검증하고 중복을 제거한 뒤, 고정 우선순위의 첫 항목을 선택한다.
2. 각 안의 매핑으로 그 분류를 최종 그룹 하나에 대응시킨다.
3. 영화의 원본 복수 장르·키워드 등은 보존한다. 나중에 그룹 안의 선호 분류 모델이 사용할 수 있다.

공유 우선순위는 **다큐 → 애니메이션 → 음악 → 전쟁 → 서부 → 역사 → 공포 → SF·판타지 → 가족 → 범죄·미스터리·스릴러 → 액션·모험 → 로맨스 → 코미디 → 드라마**다.
이 순서는 작품의 중심 감정이나 주제를 추론한 결과가 아니라, 복합 입력을 한 그룹으로 정리하기 위한 기존 정책이다.

`g14 = 기존 대표 분류(입력 장르)`로 두고 `g12 = M12(g14)`, `g10 = M10(g14)`, `g8 = M8(g14)`로 정의한다.
M10과 M8도 각각 앞 단계의 그룹들을 통째로 합치므로 12→10→8의 포함 관계가 유지된다.
그룹 수를 바꿀 때 원본 장르에 새 우선순위를 다시 적용하지 않는다.
예를 들어 역사와 전쟁을 합친 행을 앞으로 이동해 재판정하면, 기존 서부·역사 영화가 역사·전쟁으로 옮겨갈 수 있다.
이 안에서는 먼저 서부로 정한 뒤 각 안의 서부 포함 그룹으로만 보낸다.

아래는 규칙을 설명하기 위한 장르 조합이며 실제 영화 데이터를 재배정한 결과가 아니다.

| 입력 장르 | 공유 14개 분류 | 12개안 | 10개안 | 8개안 |
|---|---|---|---|---|
| 코미디·드라마·로맨스 | 로맨스 | 드라마·로맨스 | 드라마·로맨스·가족 | 드라마·로맨스·가족 |
| 코미디·드라마 | 코미디 | 코미디 | 코미디 | 코미디 |
| 애니메이션·음악·가족·판타지 | 애니메이션 | 애니메이션 | 애니메이션 | 애니메이션·SF·판타지 |
| 공포·미스터리·스릴러 | 공포 | 공포 | 공포 | 공포·범죄·미스터리·스릴러 |
| 액션·범죄·드라마 | 사건 계열 | 범죄·미스터리·스릴러 | 범죄·미스터리·스릴러 | 공포·범죄·미스터리·스릴러 |
| 서부·역사·액션 | 서부 | 서부 | 액션·모험·서부 | 액션·모험·서부 |
| 드라마·로맨스·SF | SF·판타지 | SF·판타지 | SF·판타지 | 애니메이션·SF·판타지 |
| TV Movie·가족·코미디 | 가족 | 가족 | 드라마·로맨스·가족 | 드라마·로맨스·가족 |

대표 그룹이 하나인 것과 모든 장르가 대표 그룹의 이름에 드러나는 것은 다르다.
예를 들어 애니메이션·공포는 세 안 모두 애니메이션을 포함한 그룹으로 간다. 내부 추천에서는 공포 특징을 유지해야 한다.

## 공통 예외·불변성·연결 조건

- 기존 18개 콘텐츠 장르는 모두 포함한다. TV Movie(10770)는 별도로 보존하고 함께 있는 콘텐츠 장르로 배정한다.
- 장르 없음·TV Movie 단독·미지 장르 ID는 PENDING_METADATA다. 대기는 9/11/13번째 그룹이 아니며 대표 그룹 수에 포함하지 않는다.
- 이 상태는 메타데이터 재확인 또는 근거를 기록한 사람의 콘텐츠 장르 검수를 거쳐 같은 규칙으로 해소한다. 근거가 부족하면 대기를 유지한다.
- 고정된 규칙은 새 영화에만 적용한다. 신작 수, 전체 장르 빈도, 군집 중심, 사용자의 취향이 기존 소속을 바꾸지 않는다.
- 기존 영화의 메타데이터 정정은 검토한 개별 변경으로 처리한다. 세 안 중 하나를 선택한 뒤 8↔10↔12로 바꾸는 것은 별도 체계 변경이며, 단순한 이름 변경과 다르다.
- 바깥 그룹은 모든 사용자에게 공통이다. 그룹 안의 선호 분류기는 추후 별도로 설계·학습한다. 미시청을 비선호 정답으로 삼지 않는다.
- 개인 연구안이며 현재 팀의 고정 8군집 DB/API 계약을 변경하지 않는다. 최종 채택 뒤 필요한 팀 변경 범위는 별도로 확인해야 한다.

## 아티팩트와 검토 범위

`proposals.json`은 맛 표시 정보 없이 세 안의 코드와 기존 분류 멤버십을 명시한다. 기존 `taxonomy.json`의
SHA256을 기록해 공유 배정 규칙이 바뀌면 비교안의 근거 변경을 알아볼 수 있게 한다. DB 버전 컬럼이 존재한다고 가정하지 않는다.
기존 14개 설계 파일은 수정하지 않는다.

검토 대상은 8/10/12개 개수, 기존 14개 분류의 누락·중복 없음, 단계별 포함 관계, 복합 입력과 대기 상태의 일관성이다.
통과는 설계 정합성에 한정한다. 그룹별 분포, 사용자 이해도, 발견 추천 효과의 실증 검증은 포함하지 않는다.
