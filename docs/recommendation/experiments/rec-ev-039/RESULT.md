# REC039 — 두 장르 후보의 설명과 추천 단계 인계

상태: 실제 adapter 적용·구성 집계·독립 결과 검토 완료, PASS. 2026-09-08. 개인 연구 자료.

**장르 K-means의 8개 그룹은 장르 구성으로 읽으면 더 명확하다.** 특히 이전에 4편의 공통 줄거리
설명을 만들지 못했던 07그룹은 11,330편 모두 코미디였다. 이는 군집을 다시 만든 결과가 아니라
이미 고정된 그룹을 전체 장르 정보로 설명한 결과다.

두 후보를 같은 형식으로 불러 쓸 추론 코드도 만들었다. 기존85,517편×2안의 **171,034개 배정이 전부 일치**했다.
새 영화의 장르 ID를 넣어 같은 그룹을 반환할 수 있는 연구용 연결이 준비됐다.
새 영화에서 분류가 적절한지, 추천이 좋은지까지 검증한 것은 아니다.

## 현재 장르 K-means의 8개 그룹

상위3개는 그룹 안의 실제 영화 비율 순이다. c-TF-IDF 대표어 순서와 다르며 확정 팝콘 맛 이름이 아니다.

| 그룹 | 영화 수 | 실제 장르 구성 상위3개 |
| --- | ---: | --- |
| 01 | 7,391 | 가족68.1% · 애니메이션56.8% · 코미디47.2% |
| 02 | 11,582 | **로맨스100%** · 드라마64.1% · 코미디48.4% |
| 03 | 12,853 | 스릴러67.5% · 범죄62.2% · 드라마53.4% |
| 04 | 11,135 | 액션53.0% · 모험36.0% · 드라마31.5% |
| 05 | 8,826 | **공포100%** · 스릴러36.9% · 미스터리17.1% |
| 06 | 12,461 | **드라마100%** · 역사10.4% · 전쟁7.4% |
| 07 | 11,330 | **코미디100%** · 드라마35.7% · 음악4.8% |
| 08 | 9,939 | **다큐멘터리100%** · 음악10.4% · 역사6.4% |

100%는 반올림 때문에 생긴 표기가 아니라 각 그룹의 모든 영화에 해당 장르 ID가 있었다는 뜻이다.
한 영화가 여러 장르를 가질 수 있어서 장르 비율의 합은100%를 넘는다. 영화의 대표 그룹은 하나다.
예를 들어 드라마가02·03·06·07에 함께 나타나도 같은 영화가 네 그룹에 중복 배정됐다는 뜻은 아니다.
01·03·04의 상위 장르만으로 모든 영화의 공통 내용이 설명된다고 하지 않는다.

이전 REC038의44/27편은 당시 4편 기반 설명을 포함한 진단 점수다. 이번 장르 설명의 점수로 옮기지 않는다.
이 결과만으로 K-means의 필요성·우위나 최종8취향을 확정하지 않는다.

## 단순 규칙과 실제로 다른 부분

단순 규칙은 첫 내용 장르를 사용한다. K-means는 순서를 제거한 전체 장르 조합을 고정 centroid와 비교한다.
저장 모델로 실행한 동일 장르 조합 예시는 다음과 같다.

| 입력 장르 순서 | 단순 규칙 | 장르 K-means |
| --- | --- | --- |
| 코미디 → 드라마 | RULE_03: 첫 장르 코미디 그룹 | GENRE_KM_07 |
| 드라마 → 코미디 | RULE_02: 첫 장르 드라마 그룹 | GENRE_KM_07 |

따라서 현재 K-means에는 TMDB 장르 목록의 순서를 바꿔도 같은 조합을 같은 그룹에 넣는 동작상의 장점이 있다.
이 차이를 추천 품질의 우위로 바꾸어 말하지 않는다. 다른 단순 규칙을 새로 비교한 것도 아니다.

RULE_06은 음악1,130편 전부가 음악 장르를 가졌다. 앞선 4편 줄거리에서 붙인 ‘범죄와 욕망’ 설명을
이 음악 그룹 전체의 본질로 사용하면 안 된다. [두 후보의 전체 구성표](../../../../outputs/recommendation-evidence/rec-ev-039/GROUPS.md)와
전체19장르×16그룹의304행 수치를 보존했다.

## 연결할 때 숨기지 않을 입력 문제

- 빈 장르 또는 아는 장르가 전혀 없는 입력은 미지원으로 반환한다. 임시로 가장 큰 그룹을 채우지 않는다.
- 일부만 아는 장르 조합은 K-means가 아는 좌표로 계산하되 미지 ID와 부분 어휘 상태를 함께 반환한다.
- RULE은 첫 미지 내용 장르를 건너뛰어 뒤의 알려진 장르로 바꾸지 않는다.
- TV Movie10770만 있는12편은 RULE에서 미지원이다. K-means의 기존 모델에는10770좌표가 있어
  04에 배정되지만 형식 전용이라는 표시를 남긴다. 이것은 액션 내용의 근거가 아니다.

마지막12편은 이전85,517배정 재현을 위해 그대로 보존한 것이며 새 서비스 fallback으로 승인하지 않았다.
단계4 공급 진단에서 이12편을 어떻게 취급할지는 고정 실행 계약에 명시해야 한다.

## 무엇을 만들고 검증했나

[추론 코드](../../../../scripts/feelm_genre_candidates.py)는 학습 코드 없이 장르 ID를 받아 두 후보의 그룹·지원 상태를 반환한다.
고정 어휘19개·IDF·raw centroid·raw-to-native 매핑과 RULE 규칙을 candidate-package.json에 보존했다.
연구용 그룹 코드는 각 방법 안에서만 쓰며 공식 API의 맛 코드·표시명·색상으로 내보내지 않는다.

native-assignments.parquet에는 방법·연구 패키지 ID·영화 ID·그룹·지원 상태·형식 전용 여부가 있어
단계4에서 두 후보를 같은 인터페이스로 읽을 수 있다. REC038의 임시 display 배정은 넣지 않았다.

실행 전 별도 검수자가 정확한7파일 fingerprint와9입력 pin,9합성 검사를 확인해 PASS했다.
실제 계산은3.45초, 계산 단계 감시 최대 프로세스 메모리452.6MiB였다. 원천 검증 시간은 이 계산 단계 시간에 포함하지 않는다.
배정171,034개 일치, RULE85,505지원/12미지원, KM85,517배정, 구성304행과 고정10입력×2안 예시를 만들었다.
새 fit·임베딩·평점 해석·128편 재채점은0회다. 외부수집이나 실제 추천 슬롯 계산도 하지 않았다.
독립 전수 결과 검산과 보고서 검토가 모두 PASS했다. 필수 수정사항은0건이며
최종 문서와 산출물의 확인 기록은 [result-review.json](result-review.json)에 보존했다.

기존 REC038 검토가 핀한 상위 문서5개를 변경 전에 해시 그대로 master-before에 복사했다.
REC038의 원본 보고서·봉인은 유지하고 현재 총정리와 실행 문서만 후속 버전으로 갱신한다.
