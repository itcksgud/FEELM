## 확인한 사실

실제 사례는 4명이 아니라 3명이다: uid 5831, 2834, 16044. 생성 코드는 친숙 영화 이력이 많은 상위 3명에 최악의 approximation gap 사용자를 더한 뒤 uid를 중복 제거한다. 3명이라는 결과 자체는 결함이 아니다. 이 선정 방식은 만족도 표본이나 대표성 표본을 만들지 않는다.

기존 영화 33편, 사용자 이력 30행, 추천 90행을 합친 153개 영화 행에 대해 서비스/TMDB ID, 원제목, 원자료 장르·키워드·overview, R/v/Q, 언어·제작국·개봉연도, 분류 ID를 대조했다. 사용자 이력의 영화/별점 쌍, 저장된 예측값과 추천 순서, 실제 후보 포함 여부, 전체 viewed 제외 및 underseen 조건, signed profile과의 dot, 표시된 두 이력 연결의 unsigned dot/공유 키워드도 재계산했다. 해당 범위 불일치는 0이었다. 미래 별점 숫자 배열 1,350개는 JSON parse 전에 지웠으며 예측 모델 호출은 0회다. 원자료부터 정규화 카탈로그까지의 출처 검증은 앞선 prepare 전수 감사에 의존한다.

같은 3명의 main과 K128/K256 추천은 각각 main 대비 후보 겹침 및 Top10 겹침이 모두 0이었다. 서로 다른 E_u와 후보 예산을 가진 사례이므로 K의 전반적 우열이나 의미 품질의 우열을 뜻하지 않는다.

## 표시 문구에서 남은 수정 사항

현재 `group_name`은 상위 장르 세 개를 빈도 없이 나열한다. 이를 동등한 대표 장르로 읽으면 사실보다 강한 설명이 된다.

| 그룹 | 원자료 장르 빈도 | 현재 문구에서 주의할 점 |
|---|---|---|
| K256 g818 | 드라마 429/429, 역사 429/429, SF 2/429 | ‘드라마 / 역사 / SF’에서 SF는 극소수다. |
| K128 g488 | 드라마 312/312, TV 영화 31/312, 로맨스 20/312 | 주된 공통 근거는 드라마다. |
| main g14 | 음악 3,866/3,866, 로맨스 185/3,866, 판타지 156/3,866 | 공연 추천을 로맨스·판타지로 통합 설명하면 안 된다. |

root에 빈도/분모를 표시하거나 주된 장르로 문구 범위를 좁히도록 전달했다. 이 수정과 재렌더 실행 여부 및 수정 후 report 해시 검증은 이 문서 작성 시점의 미완료 사항이며 지정 작업으로 인계한다. 실험 코드·모델·선정 기준을 바꾸라는 뜻은 아니다.

TMDB 메타데이터는 저장된 스냅샷의 사실로 확인했다. 외부의 실제 작품 사실을 새로 조사한 것이 아니다. 현재 카탈로그에는 2022년 이후 개봉 영화가 포함되므로 사례는 developmental 결과이며 2023년 시점의 이용 가능 카탈로그를 재현하지 않는다. 한국 이용자의 친숙함·만족도·실제 발견 가치는 측정하지 않았다.
