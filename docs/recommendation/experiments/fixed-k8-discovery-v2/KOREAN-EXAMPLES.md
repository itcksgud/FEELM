# 실제 영화와 이력으로 읽는 발견 추천

상태: DRAFT — 로컬 연구 설명. 서비스 사용자나 한국 사용자 만족도 평가가 아니다. 아래 사실 확인은 봉인된 카탈로그와 MovieLens 개발 이력을 사용한다.

상위 8맛의 ID·이름·중심은 원본 그대로다. K128/K256의 그룹 ID는 해당 구성 안에서만 의미가 있으며, 서로 다른 K에서 숫자가 같다고 같은 그룹은 아니다. 영화 제목이 같아도 서비스 ID/TMDb ID를 함께 확인한다.

## 세분화로 설명이 구체화되는 경우와 남는 한계

- 기생충은 K128 그룹316의209편에서 K256 그룹529의28편으로 좁아졌다. 후자는28편 모두 드라마·코미디·스릴러이며27편에 dark comedy가 있어 블랙코미디 설명이 원자료에 잘 맞는다.
- 곡성과 곤지암은 K128 그룹236에서 함께 있었고 K256에서는278과493으로 갈라졌다. 두 그룹 모두 공포·미스터리는 전원 공통이다. 갈라졌다는 사실만으로 추천이나 의미 이해가 좋아졌다고 볼 수 없다.
- 봉준호 괴물은 K256 그룹350에 총7편, 현재 Q후보5편뿐이다. 그룹당25편 설정이라도5편 이상 가져올 수 없고 다음 E_u 그룹으로 넘어가야 한다.
- 인셉션의 K256 그룹2018은 모험·액션·SF가 공통이지만 꿈·잠재의식 작품만 모인 그룹은 아니다. 최다 키워드 giant monster도13/83편이라 괴수물로 이름 붙이면 오해를 만든다.
- 워낭소리의 K256 그룹123은 다큐106편 중96편에 키워드가 없다. 최다 키워드도1편뿐이므로 주제 태그에 근거한 강한 이름은 붙일 수 없다.

[독립 metadata 검토](KOREAN-METADATA-BLIND-REVIEW.md)는 선정 결과를 보기 전에 위 사실과33개 ID/66개 K배정을 봉인했다. Return과 Harry는 친숙한 영화 예시가 아니라 근거 부족 반례다. 자동 group_name은 상위 장르 빈도 나열일 뿐 모든 회원의 공통 장르를 보증하지 않는다. 아래 사용자 연결에는 영화 자체의 장르와 정확한 그룹 ID를 사용한다.

## 실제 사용자 사례를 읽는 법

동일한 cap10 별점 입력과 전체 관측 시청 이력에 fixed16, K128, K256을 적용한다. 각 그룹의 E_u는 자기 구성의 시청 수/비중으로 정하므로 K가 클수록 허용 그룹이 넓어진다는 점도 함께 표시한다. 후보 50편·100편의 예산 차이를 숨기지 않는다.

R/v/Q는 각각 TMDb 원평균·평가 수·고정 m300 보정점수이며10점 척도다. 개인 예상 점수는 별도의 모델 점수다. Q 순위에서 최종순위로 올라온 영화는 개인화로 선호된 후보지만, 그 이동 자체가 사람이 좋아할 것이라는 검증은 아니다. ML TRAIN 평가 수는 TMDb 평가 수와 다른 근거다.

이력과의 콘텐츠 내적/공통 키워드는 부호 없는 영화 간 연결이다. 해당 과거 영화의 원별점이 낮으면 긍정 선호 이유로 해석할 수 없다. 실제 프로필에는 `원별점 - anchor`의 부호가 반영된다. 사례 선택도 친숙한 입력 영화 수가 많은 사용자와 가장 큰 근사 오차 사례를 보여주기 위한 것으로, 평균 만족도를 대표하는 표본 추출이 아니다.

실제 수치·동일사용자3구성 목록은 check/report 봉인 이후 이 문서에 연결한다.
