# 한국 영화 사례와 K128·K256 메타데이터 설명 검토

상태: DRAFT 개인 연구 설명 검토. 2026-09-13. 검토자 `/root/asset_audit`.

이번 검토는 추천 정책의 선정 결과를 열기 전에 진행했다. 고정된 237,817편 카탈로그, 장르·키워드·줄거리, K128/K256 배정과 대표, 고정 Q 순서만 읽었다. 사용자 컨텍스트·미래 평점·predictor/sweep/check 결과는 이 검토에서 읽지 않았다. 원본 `KOREAN-EXAMPLES.md`의 서비스 ID/TMDb ID 33쌍을 모두 대조했다. Return과 Harry는 친숙한 영화가 아니라 근거 부족을 보여주는 반례다.

K128은 상위 8개마다 하위 128개, 총 1,024개 그룹이다. K256은 총 2,048개다. 아래 그룹 ID는 각 구성 안에서만 통한다. 서로 다른 구성의 ID 숫자는 같은 의미를 가리키지 않는다.

## 근거 부족과 경계 사례

- **Harry(128570/1339252)**는 장르·키워드·줄거리가 모두 없다. K256 그룹 1809는 28,386편 중 28,131편이 세 콘텐츠 모두 없다. 나머지 255편에 원자료 일부가 있어도 군집용 벡터가 0이 아닌 것은 24편뿐이며, 이 24편만 평균 대표 계산에 기여한다. 추천 가능 영화는 5편뿐이다. 대표 영화는 별도의 줄거리가 있는 ‘엉겅퀴 사랑’이며 현재 추천 가능 조건을 통과하지 않는다. 이 대표의 소재를 Harry나 전체 28,386편에 붙이면 설명 오류가 된다. K128에서도 같은 28,131개 무콘텐츠 영화가 28,476편짜리 그룹에 포함되며, 벡터 지원은 114편이다.
- **Return(111440/1268052)**은 장르·줄거리가 없고 `dance`, `short film` 두 키워드만 있다. K256 그룹 1889는 249/249편에 `short film`이 있지만 248/249편에 장르가 없다. ‘단편 형식 키워드가 공통인 자료’라고 표현할 수 있고, 안정된 장르나 분위기 유형이라고 할 수는 없다.
- **신과함께 두 편**은 지옥·저승·신·만화 원작·재판·저승사자·신화·웹툰 원작의 8개 키워드를 공유하지만 상위 배정부터 4와 7로 갈라진다. K256 죄와 벌은 1276, 인과 연은 2006이다. 전자는 모험·드라마·스릴러가 52/52이지만 키워드가 없는 영화가 39/52이고, 후자는 판타지가 51/51, superhero가 34/51이다. 시리즈 연속성이나 객관적 분위기 구분을 보장하지 않는다.
- **곡성과 곤지암**은 K128에서는 그룹 236을 공유하지만 K256에서는 278과 493으로 나뉜다. 두 새 그룹 모두 공포·미스터리가 전원 공통이다. 분리 자체를 의미 이해의 향상이라고 주장하지 않는다.
- **동명 영화**는 봉준호 괴물 863과 고레에다 괴물 88879, 픽사 인사이드 아웃 44851과 동명 액션 영화 29791로 구분했다. 동명 액션 영화에는 액션·범죄 장르만 있고 키워드·줄거리가 없다. 제목으로 원문 근거를 다른 영화에서 가져오면 안 된다.
- **굿 보이즈 74333과 포켓몬스터 엔테이 4835**는 `TMDB_ID_AMBIGUOUS` 상태를 그대로 보존한다. 콘텐츠 설명·서비스 카탈로그 배정과 MovieLens 평점의 유일한 정답 연결은 서로 다른 문제다.

## 대표와 실제 공급되는 영화가 다를 수 있다

이 검토의 Q prefix는 **사용자의 기시청 영화를 제외하기 전**, 추천 가능한 그룹 영화 중 고정 Q 순서의 앞 25편이다. 실제 개인별 prefix나 E_u를 검증한 결과가 아니다. 사용자의 시청 이력에 따라 길이가 줄거나 구성과 평균이 달라질 수 있다.

| 고정 구성 | 총 그룹 | 추천 가능 영화 25편 미만 | 추천 가능 영화 0편 | 대표 영화가 현재 추천 불가 |
| --- | ---: | ---: | ---: | ---: |
| K128 | 1,024 | 159 | 1 | 203 |
| K256 | 2,048 | 857 | 9 | 489 |

이는 구성의 특성을 설명하는 수치이며 모델 선정 조건으로 추가하지 않았다. 여기서 ‘지원’은 군집용 131차원 GKT 벡터가 0이 아니라는 뜻이며, 원자료 필드 존재나 별점 predictor의 계산 가능성과 다르다. 대표는 지원되는 전체 그룹의 평균에 가장 가까운 실제 영화이고, 추천 가능 여부나 Q 상위 조건을 만족하도록 뽑은 영화가 아니다. 따라서 대표 영화와 추천 예시를 같은 의미로 표시하지 않는다.

가장 분명한 반례는 **K256 그룹 1829**다. 27편 중 `sign languages`는 26편, `deaf culture`는 24편에 있다. 그러나 현재 추천 가능한 영화는 단 1편, Etched in Memory เธอในความทรงจำ(179261/1532965)이며 장르·줄거리가 없고 키워드는 `vampire`, `boys' love (bl)`다. 전체 평균과 이 Q prefix 평균의 L2 거리는 0.92949다. 그룹의 빈도 설명은 맞더라도 실제 공급되는 후보를 그 설명으로 대신할 수 없다는 사례다. K128의 대응 사례인 그룹 910도 전체에는 수어 관련 태그가 많지만 추천 가능 3편은 위 작품과 할로윈 관련 2편이다.

한국 영화 사례 안에서도 워낭소리의 K256 대표 ‘우리는 섬으로 갔다’, 택시운전사의 대표 ‘570’, 포켓몬스터 엔테이의 대표 ‘SEKIRO: NO DEFEAT’은 현재 추천 불가다. 괴물(봉준호)의 K256 그룹은 총 7편, 추천 가능 5편이라 그룹당 25편을 채울 수 없다. Harry 그룹은 전체 평균과 5편 prefix 평균 거리가 0.54667이다.

전체 그룹의 평균–정적 prefix 거리 중앙값은 K128 0.10415, K256 0.07676이다. 거리가 작다는 사실은 메타데이터 벡터가 가까워졌다는 뜻이며, 사람의 만족도·주제 일관성이 개선됐다는 뜻이 아니다. K256에서는 작은 후보 묶음도 더 많아진다.

## 재현 자료

동일 worktree의 `scripts/audit_dv2_korean_metadata.py`가 봉인된 입력과 원본 키워드·장르 이름을 확인하고, `outputs/dv2-korean-metadata-audit-r2/`에 전체 3,072그룹 빈도와 66개 사례, 33개 ID의 배정 CSV를 보존했다. `report.json`에는 코드·출처 해시와 결과를 읽지 않았다는 범위가 기록되어 있다. `extra-prefix-cases.json`은 위 추가 prefix 반례의 실제 영화 ID·원문을 보존한다.

최종 사용자 입력·선정 exemplar와 연결한 확인은 이 문서의 결과 비공개 검토 이후 별도로 수행한다. 현재 문서는 그 개인별 추천을 평가하거나 예측하지 않는다.
