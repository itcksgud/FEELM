# REC041 — 분류·발견 정책과 채점 가능한 기회

상태: DRAFT — 개인 연구의 고정 실행 계약. 2026-09-08. 제품 정책 채택안이 아니다.

사용자는 다음 비교를 진행하되 ALS에 맛을 넣는지, 입력 개수·영화 선정, 발견의 보수적 채점,
맞춤/발견 정책과 그 정책에 맞는 답의 존재 여부를 먼저 확인하라고 했다.
이번에는 같은 기본 순위에서 **분류2안×발견 정책2안**을 실행한다. 입력량·카드 선정까지 동시에 바꾸지 않는다.
정책·채점·입력 실험의 순서는 아래와 같이 고정하며 이번 실행과 미래 계획을 구분한다.

## 1. ALS와 세 종류의 개수

현재 REC032 raw explicit ALS는 사용자ID·영화ID·원별점으로 학습했다. 팝콘 맛은 학습 열에 없다.
이번에는 같은 저장 factor와 raw500을 재사용하고 학습·fold-in·전체점수를 새로 계산하지 않는다.
맛은 동일 순위 후보의 T/D 자격을 나누는 데 쓴다. 맛을 ALS에 함께 학습하는 별도 모델은 이번 비교에 필요하지 않다.
이를 같이 바꾸면 분류·정책 효과와 모델 변경 효과가 섞인다.

- 외부 팝콘 그룹 수: 8. 이번 두 분류도8그룹이다.
- 관측 입력 수 n: 이번에는 기존 n=30 한 상태. 감상 원별점0.5~5.0, 간격0.5를 유지한다.
- 개인화 전환 기준 K_switch: 아직 미정. n30 연결 진단을 K30 또는 온보딩 권장30편으로 발표하지 않는다.

자료는 이미 개봉된 R0 개발 사용자2,180명과 hash순서로 고른 입력30편이다. 원래2,511명 중
입력30편이 부족한331명을 제외한 집단이므로 실제 저이력 신규 사용자 전체를 대표하지 않는다.
실제 감상 시각·온보딩 카드 인지도·skip·응답 시간 자료가 아니다.

## 2. 이번 정책을 명시한다

분류는 REC040 RULE_GENRE_SET과 REC039 KM_GENRE의 고정 배정이다. 공식 API·DB·ADR-0015는 수정하지 않는다.
초기 stage-4-policy-proposal의 맛별 평균>0을 재사용하지 않는다. 기준은 REC034 gating-repair의
**긍정 관측 한 편의 근거도 보존하는 방식**이다. 과거 문서·코드는 봉인 자료로 유지하고 최신 실행은 이 문서를 따른다.

| 항목 | 두 정책 공통 |
| --- | --- |
| 긍정 입력 | 같은 O30 원별점의 기존 상대 weight>0. 학습 prior와 수축5도 유지 |
| 맞춤 T | 긍정 입력이 하나 이상 속한 그룹의 영화. 해당 그룹 전체의 선호를 입증했다는 뜻은 아님 |
| 연결 anchor | 배정 가능한 모든 긍정 입력 영화. 맛 평균으로 지우지 않음 |
| 발견 D 구조 자격 | 관측 입력에 경험이 없는 그룹이고 T지원 그룹도 아니며, 긍정 anchor와 같은 종류의 TMDB 장르/감독/키워드 ID가 하나 이상 겹침 |
| 경험 | O30에 등장한 유효 그룹만 아는 관측 입력 내 경험 proxy. 실제 전체 감상 이력이 아님 |
| 미지원·TV-only | n30 및 기존 ALS 입력에서는 유지. 두 분류 모두 맛/경험/T/D/anchor에서는 제외 |
| 연결 정보 | TV Movie10770을 내용 연결 토큰에서 제외. 같은 숫자라도 서로 다른 종류의 ID는 연결하지 않음 |
| 제외 | O30 영화 전체. 실제 LINK_CLICKED·관심없음·전체 감상 이력을 모두 재현한 것이 아님 |
| 후보 순서 | 제외 전 raw ALS500 → 그중 T/D 적격100 → O30 제외. 중간 재선정·보충·quota 없음 |
| 맞춤 선택 | 같은 제외 후 순위에서 T 상위2편. 두 D정책에서 완전히 동일 |

| D 정책 | 선택·보류 규칙 |
| --- | --- |
| CONNECTED | 구조 적격 D 중 ALS 최고점1편. D가 없고 T3가 있으면 T3 |
| T3_GUARD | 같은 D최고점이 같은 최종 T목록의 세 번째 영화 점수 이상이면 D. 동점도 허용. 더 낮으면 D를 보류하고 T3 |

GUARD는 **대체 가능한 T3보다 예측 점수가 낮은 D를 보류**하는 연구안이다.
ALS 점수는 보정된 별점·Q·불호 확률이 아니므로 실제 최악 회피·안전성이 입증됐다고 부르지 않는다.
GUARD를 통과한 영화로 top100을 다시 채우지 않는다. 같은 분류의 두 정책은 raw500·typed100·제외·T2가 같아야 한다.

T3 기준은 동일한 제외 후 TOP100의 T목록에서 구한다. T3가 없는데 D가 있는 GUARD는 NO_T3_REFERENCE로
D를 보류하고 T2만 연구 진단으로 남긴다. 정상3편 공급 성공으로 세지 않으며 제품의 일반 fallback을 정한 것이 아니다.
T<2면 INSUFFICIENT_TASTE를 우선한다. D가 없고 T3도 없으면 NO_DISCOVERY_NO_T3다.
T3_GUARD에서 D점수 때문에 T3가 된 경우와 애초에 D가 없었던 T3를 다른 사유로 기록한다.
불완전 목록의 존재 영화는 남기되 T2가2편 미만이면 T2 품질을 계산하지 않는다.

## 3. 후보가 없는 것과 좋은 답을 모르는 것을 나눈다

전체 카탈로그, ALS factor 지원, raw500, 타입 적격100에서 T/D 수를 기록한다.
각 단계에서 제외 전과 동일 O30 제외 후 수치를 모두 남긴다. 전체/ALS는 구조 자격만 계산한다.
새 전체 ALS 점수가 없으므로 이 단계에 GUARD 통과율이나 전체 순위 결과를 만들어 붙이지 않는다.
RAW500과 TOP100의 GUARD 진단은 각각 그 단계의 T3를 기준으로 하며 기준 영화·점수와 소실/변화를 남긴다.
실제 연구 출력은 TOP100이고 RAW500은 절단 원인 대조다. 서비스 후보 크기를 바꾸지 않는다.

구조 D 부재의 순서는 전체 카탈로그 무자격 → factor 부재 → 500절단 → 100절단 → 최종 제외다.
동일 제외 후 각 단계도 함께 비교해서 단순한 관측 영화 제외와 절단이 섞였는지 드러낸다.
GUARD 보류와 T3기준 부재는 이 구조 소실 원인과 별도 기록한다.

추천·자격 mask·후보 순서·실제 슬롯을 먼저 봉인한 다음 기존 평가 E/H를 연다.
각 단계의 적격 영화 중 관측 평점이 있는 수, 미관측 수, 상대 저선호/고선호 수를 계산한다.
`적격∩E=빈 집합`은 좋은 답이 없다는 뜻이 아니라 정답을 관측하지 못했다는 뜻이다.
관측 고선호가1편 이상 있으면 그 범위의 기회 존재는 확인되지만, 없고 미관측 후보가 남으면 존재 여부는 미판정이다.
GUARD의 점수 통과 기회는 점수가 있는 RAW500/TOP100 제외 후에만 계산하며 구조 D기회와 구분한다.

고선호는 고정 Q>=0.8, 저선호는 Q<=0.2, 나머지는 중간이다. Q>0.2는 비저선호일 뿐 좋은 답의 정답이 아니다.
Q는 동점을 포함한 사용자 내 상대 위치여서 정확히 상·하위20% 또는 절대 만족을 뜻하지 않는다.
정책별 기회 집합과 전체 사용자 분모를 유지한다. 양쪽 공통 기회만 남겨 전체를 대신하지 않는다.
관측 고선호가 후보에 있지만 선택하지 않은 경우도 기록하되, 미관측 추천보다 더 좋았다고 단정하지 않는다.

## 4. T와 D를 다르게 채점한다

| 대상 | 이번에 계산할 값 |
| --- | --- |
| T2 | 기존 MEAN_Q, MIN_Q, HARM20. 공급 여부와2편 중 평점 관측 수를 함께 기록 |
| D1 | 관측 Q와 저선호(Q<=0.2) 노출. 제공 D의 조건부 위험 및 전체 요청당 저선호 D 노출을 분리 |
| 보류·공급 | D 제공률, 점수보류, 기준부재, D없음 T3, T2부족, 정상3편 제공률 |
| 정답 공백 | 존재하는 슬롯의 미평가 Q를0점으로 만들지 않고 가능한 하한/상한을 기록 |
| 실제 반별점 | 알려진 선택 영화의0.5단위 원별점 분포. T2/D1/T3 fallback을 분리 |
| 실제 발견 성과 | 사용자에게 새로운가·연결을 납득하는가·감상했는가·감상후평점은 이번 자료로 미판정 |

T2가 없으면 품질은 해당 없음이다. T2가 있는데 Q를 모르면 그 슬롯의 미관측 범위를 계산한다.
평균 Q의 미관측 값은[0,1], MIN_Q는 알려진 값과[0,1]로 범위를 잡고,
HARM20은 알려진 저선호가 있으면[1,1], 없고 미관측이 있으면[0,1], 모두 알려진 비저선호면[0,0]이다.
이는 누락 때문에 생기는 식별 범위이며 표본 오차의 신뢰구간이 아니다.
D가 없으면 D의 Q/조건부 저선호는 null이다. 전체 요청당 D저선호 노출에서는 노출 없음=0으로 계산하되
반드시 D제공률·T3대체·보류와 나란히 보고한다. D를 전부 생략해서 저선호0만으로 우승할 수 없다.
같은 분류에서 두 정책이 둘 다 D를 주면 같은 D여야 한다. 같은 T2도 유지되므로 반복 셀을 독립 표본으로 세지 않는다.
부분 관측 평균을 전체 성능으로 확대하거나 임의 효과 임계치·다중검정 승자·채택 기준을 이번에 만들지 않는다.

## 5. 자료 역할·봉인·누출 방지

config의 파일 pin을 고정한다. 입력값은 profile30/prior, 분류는 REC039/040, 콘텐츠 사실은 REC033과 구조 파일,
순위는 REC034 raw500, factor 지원은 REC032 factor의 item_ids만 읽는다. factor 값과 학습 사용자 행은 새 계산에 쓰지 않는다.
입력/학습 사용자 분리는 기존 prepare/train/독립 검수의 봉인으로 검증한다. raw MovieLens·reserve·Locked Test·새 네트워크는 열지 않는다.
E는 기존 conditional-ranking의191,933개 사용자-영화 평점이고 H는 같은 고정 채점용 histogram이다.
이는 이미 본 개발 자료의 정답 재사용이며 새 확증이 아니다. E/H의 실제 값은 추천 score-seal 이후에만 읽는다.
Q를H에서 재계산해 파생 Q와 대조하고 E와O30의 교집합0, 반별점 격자, 고유사용자/영화 및 원천 봉인을 확인한다.
E/H를 입력 선택·ALS·맛 경험·제외·연결·GUARD에 넣지 않는다. E만 남겨 다시 순위를 매겨 대신 채점하지 않는다.
원천 검증의 해시 읽기와 계산용 값 디코딩은 구분한다.

실행 순서: 독립 설계·코드·합성검사 PASS → 역할/원천 봉인 → 두 분류의 자격·동일500/100·네 정책셀 추천 봉인
→ E/H 대조 및 실제 선택 슬롯·기회 채점 → 독립 전수 결과/보고서 검수.
출력은 역할 봉인, packed 자격 mask, typed100, 사용자 공급표/슬롯, score-seal, 기회/품질표·요약, budget, completion-seal이다.
기존 REC040이 핀한 master5개는 먼저 원 해시로 복사하고 현재 총정리·실행 문서만 갱신한다.
부분 실행을 덮어쓰지 않는다. 완료 재사용은 봉인 검증만 수행한다. root만 파일을 쓴다.
py -3.12 기존환경·계산30분/12GiB 상한, 새 학습/임베딩/라이브러리/배포/외부수집은 없다.

## 6. 입력 개수와 어떤 영화를 받을지는 다음 축이다

이번4셀 비교 뒤, 별도 실행 계약에서 기존 n=0/5/10/30과 최대30편 후보 안의 두 순서를 준비한다.
하나는 기존 hash, 다른 하나는 평점·E·KM군집을 보지 않는 TMDB 장르 다양성 우선 순서 ONE이다.
각 순서 안에서는 prefix를 중첩하고 n30은 같은 입력 집합으로 합쳐져야 한다. 실제 카드 선정/skip/시간 실험은 아니다.
이 절은 다음 실험의 설계 방향이며 현재 그 선택기나 n별 추천을 실행하지 않는다.

O(n)을 선호 입력과 경험/제외 이력 양쪽에 쓰면 n증가가 취향 정보뿐 아니라 발견 자격도 바꾼다.
따라서 다음에는 아래 두 의미를 구분해야 한다.

- 관측 상태 증가: O(n)을 경험·제외에도 사용. 입력량과 정책 자격 변화가 함께 포함된다.
- 순수 선호 입력 제한: 별도로 알려진 경험·제외 W를 고정하고 O(n)만 바꿈.
  현재30편 ID를 W로 쓰면 ‘감상30편의 ID는 이미 알고 일부 별점만 아는 상태’이며 신규 온보딩의 시간 전개가 아니다.

최종 정책·후보·입력 선정 방식을 정한 뒤 K_switch를 인기 대비 이득·손실과 별도 확인 자료로 판단한다.
이번n30이나 이전ALS입력곡선을 최종K로 결정하지 않는다. 실제 온보딩의 편의성 주장은 응답시간·skip·이탈 자료가 필요하다.

이번 종료점은4셀의 공급·보류·정답 관측/기회 진단과 한계를 확인한 보고서다. 위험 보장·최적 정책·K·8맛 제품 채택을 하지 않는다.
