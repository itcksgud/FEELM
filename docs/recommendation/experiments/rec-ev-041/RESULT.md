# REC041 — 맛 분류와 발견 정책을 연결한 결과

상태: 실행·독립 전수 검산·최종 문서 검토 완료. 2026-09-08. 개인 연구이며 제품 정책 채택 결과가 아니다.

**ALS에 맛을 추가 학습하지 않고도 두 분류와 두 발견 정책을 연결했다. 보수적 정책은 발견 제공을 줄였지만,
덜 싫어할 영화를 골랐는지는 이번 정답으로 채점할 수 없었다.** 후보 존재와 추천 품질을 나눠 판단해야 한다.

## 1. 질문별로 무엇을 확인했나

| 질문 | 이번 처리와 판단 |
| --- | --- |
| ALS 학습에 팝콘 맛도 넣어야 하나? | 현재 원별점 ALS를 유지했다. 맛은 후보의 맞춤/발견 자격에 사용한다. 함께 학습하는 모델은 별도 변경이므로 지금 필수는 아니다. |
| 입력 몇 편, 어떤 영화를 받을지도 중요한가? | 그렇다. 이번에는 같은 30편으로 고정했다. 입력량과 영화 선정은 다음 축이며, n30을 전환 K나 온보딩 권장량으로 정하지 않았다. |
| 맞춤과 발견을 다르게 채점해야 하나? | 맞춤2의 평균·낮은 쪽 선호를 유지하고, 발견1은 저선호 노출과 제공·보류를 함께 계산했다. |
| 발견은 보수적으로 골라야 하나? | 대체 가능한 맞춤3번째 영화보다 ALS 점수가 낮으면 발견을 보류하는 한 안을 비교했다. 실제 불호를 줄였다는 근거는 없다. |
| 정책에 맞는 좋은 답이 후보에 존재하나? | 자격을 만족하는 후보, 알려진 평점이 있는 후보, 알려진 고선호 후보를 각 단계에서 따로 확인했다. 모르는 것을 오답으로 세지 않았다. |

현재 ALS는 사용자·영화·실제 원별점으로 학습된 고정 모델이다. 팝콘은 이번에 TMDB **장르로 만든8그룹**이며
규칙과 K-means 두 배정을 비교했다. 맞춤/발견의 연결 근거에는 TMDB 장르·감독·키워드를 썼다.
감상 별점은0.5~5.0, 간격0.5를 유지한다. 맞춤 자격을 정하는 상대 가중치와 실제 별점 저장값을 혼동하지 않는다.

## 2. 비교한 네 조합

같은 개발 사용자2,180명, 같은 입력30편, 같은 원별점 ALS 순위를 사용했다. 새 학습·fold-in은0회다.
입력은 기존 hash 순서이며 실제 온보딩 노출·응답을 재현하지 않았다. 입력30편이 부족한331명을 제외한 집단이다.

- **분류:** 전체 장르를 쓰는 개선 규칙 `RULE_GENRE_SET` / 고정 장르 K-means `KM_GENRE`.
- **맞춤 T:** 상대 가중치가 양수인 입력이 하나 이상 속하는 그룹의 영화. 두 정책에서 같은 상위2편을 고른다.
- **발견 D:** 입력30편에 등장하지 않은 그룹이면서, 긍정 입력과 장르·감독·키워드 중 같은 종류의 ID가 연결되는 영화.
- **연결형 CONNECTED:** 발견 자격 중 ALS 최고점1편. 발견이 없으면 맞춤3번째 영화로 대체한다.
- **T3 비교형 T3_GUARD:** 같은 발견 영화의 점수가 같은 최종 후보 안의 맞춤3번째 영화 이상일 때만 발견을 준다.

두 정책 모두 기존 경로인 **제외 전 ALS500 → 맞춤/발견 적격100 → 입력30편 제외 → 선택**을 따랐다.
500과100은 이번 결과를 보고 고른 수가 아니며, 이번에는 크기를 비교하거나 최적으로 확정하지 않았다.
전체 카탈로그와 ALS 지원 영화도 함께 계산하고, 500 단계는100 절단 원인을 확인하는 대조로 썼다.
TV Movie만 있는12편은 두 분류 모두 역할·경험·연결에서 제외했으며 원래 배정과 ALS 입력은 유지했다.

이 발견 정의의 ‘미경험’은 입력30편에서만 모르는 그룹이라는 뜻이다. 실제 전체 감상 이력이나
사용자가 느끼는 새로움을 측정한 결과가 아니다. 초기 연구안의 맛별 평균 상쇄 방식 대신,
[개별 긍정 관측을 보존한 후속 규칙](../rec-ev-034/gating-repair/RESULT.md)을 적용했다.

## 3. 실제로 발견을 제공한 비율

아래는 최종100개 후보 경로의 결과다. 각 행 분모는 같은2,180명이다.

| 분류 | 발견 정책 | 맞춤2+발견1 제공 | 발견 없음 → 맞춤3 | 낮은 예측 점수로 보류 → 맞춤3 |
| --- | --- | ---: | ---: | ---: |
| 개선 규칙 | 연결형 | 2,120명 (97.2%) | 60명 | 0명 |
| 개선 규칙 | T3 비교형 | 1,681명 (77.1%) | 60명 | 439명 |
| 장르 K-means | 연결형 | 2,055명 (94.3%) | 125명 | 0명 |
| 장르 K-means | T3 비교형 | 1,284명 (58.9%) | 125명 | 771명 |

네 조합 모두3편을 제공했다. T부족·T3 기준 부재는 이번 n30 집단에서0명이었다.
같은 분류의 두 정책에서 맞춤2편은 모두 동일했고, 둘 다 발견을 제공한 경우 발견 영화도 동일했다.
발견 제공률 감소는 개선 규칙20.1%p, 장르 K-means35.4%p다. 이는 **발견을 보류하는 대가**이며 품질 향상 수치가 아니다.
개선 규칙의 공급률이 더 높다는 사실만으로 분류의 품질 승자를 정하지 않는다.

ALS 점수는 보정된 별점·불호 확률이 아니다. T3 비교형은 기존 ALS 순위상 대체 비용을 제한하는 안이다.
현재 모델이 익숙하지 않은 영화를 낮게 평가한다면 그 영화의 발견 기회도 줄일 수 있으므로,
‘최악을 피하는 정책’으로 채택하려면 실제 저선호와 새로움의 정답을 함께 확인해야 한다.

## 4. 발견 후보는 어디서 없어졌나

다음은 동일 입력 제외 후 **발견 자격을 만족하는 영화가 한 편 이상 있는 사용자 수**다. 점수 보류 전 구조 자격이다.

| 단계 | 개선 규칙 | 장르 K-means |
| --- | ---: | ---: |
| 전체85,517편 카탈로그 | 2,149명 | 2,061명 |
| ALS factor 지원 영화 | 2,149명 | 2,061명 |
| ALS 상위500 | 2,149명 | 2,061명 |
| 타입 적격 상위100 | 2,120명 | 2,055명 |
| 그중 T3 점수 기준도 통과 | 1,681명 | 1,284명 |

처음부터 정책상 발견 후보가 없는 사람은31명/119명이다. 해당 사용자에게 좋은 영화가 전혀 없다는 뜻이 아니다.
100개 절단으로 구조적 발견 기회를 잃은 사람은29명/6명이다. factor 부재·500 절단·최종 입력 제외 때문에
마지막 구조 후보를 잃은 사람은 각각0명이다. 영화 수의 감소와 마지막 후보까지 사라진 사용자 수는 다르다.

500 단계에서 직접 선택하면 연결형 발견은2,149명/2,061명, T3 비교형은1,681명/1,284명이다.
각 단계의 T3 기준 영화는2,180명 모두 동일했다. 이번 결과에서100 절단이 없애는 발견은 모두 T3 기준보다 낮은 점수였다.
이 사실로 후보100이 일반적으로 충분하거나 낮은 점수 영화가 실제로 나쁘다고 결론 내리지 않는다.

## 5. ‘좋은 답이 있다’는 근거는 얼마나 남았나

이번 정답 E는 기존에 개봉한 **사용자-영화 평점191,933개**다. MovieLens 전체 평점을 새로 조회하지 않았다.
따라서 아래 ‘정답 없음’은 **이번 E에 해당 평점이 없음**을 뜻하며 원본 전체에도 없다는 주장이 아니다.
고선호는 사용자 내 상대 위치 Q>=0.8이다. 절대 별점4점 기준이나 정확히 상위20%라는 뜻은 아니다.

각 칸은 **정답 평점이 있는 발견 후보를 가진 사람 / 그중 고선호 후보가 있는 사람**이다. 전체 분모는2,180명이다.

| 발견 후보 단계 | 개선 규칙 | 장르 K-means |
| --- | ---: | ---: |
| 전체 카탈로그 | 1,795 / 824명 | 1,449 / 675명 |
| ALS 지원 | 1,795 / 823명 | 1,448 / 674명 |
| ALS 상위500 | 38 / 22명 | 24 / 14명 |
| 타입 적격 상위100 | 1 / 1명 | 3 / 2명 |

전체 카탈로그에는 정책에 맞으며 실제 관측 별점도 높은 발견 후보가 적어도824명/675명에게 있었다.
그러나 그 근거를 가진 사용자는500 단계에서22명/14명,100 단계에서1명/2명으로 줄었다.
**구조상 후보 공급은 많아도, 알고 있는 좋은 답이 높은 순위에 남는다는 보장은 없었다.**
이는 이번 관측 정답의 기회가 사라진 사실이며, 남은 미평가 영화가 나쁘거나 선택 순서가 틀렸다는 증명은 아니다.

최종100의 발견 적격 사용자-영화 조합은 개선 규칙37,303개 중 정답1개, 장르 K-means46,618개 중 정답4개였다.
T3 비교 기준을 통과한 후보는4,033개/2,690개였지만 정답은 양쪽 모두0개였다.
발견 후보는 있지만 고선호 존재를 모르는 사람은 연결형 기준2,119명/2,053명이다.
관측 고선호 후보가 있는1명/2명도 최종 선택된 발견의 별점은 몰랐다. 이를 순위 오류나 추천 실패로 세지 않았다.

## 6. 채점 결과와 판정 한계

**최종으로 고른 맞춤2·발견1·대체 맞춤3의 알려진 정답 슬롯은 네 조합 모두0개였다.**
각 조합은6,540슬롯을 제공했지만 이번 E로 실제 별점을 채점할 수 없었다. 동일한 영화·사용자 슬롯이 조합 간
반복되므로 네 조합을 합쳐26,160개의 독립 관측으로 취급하지 않는다. RAW500 대조 선택도 알려진 슬롯0개다.

| 채점 대상 | 이번에 얻은 결과 |
| --- | --- |
| 맞춤2 평균 Q·낮은 영화 Q | 가능한 범위[0,1]. 어느 안이 좋은지 미판정 |
| 맞춤2에 저선호가 포함될 비율 | 가능한 범위0~100%. 미판정 |
| 제공된 발견1의 저선호 비율 | 네 조합 모두 가능한 범위0~100%. 미판정 |
| 실제0.5단위 별점 분포 | 알려진 선택 평점0개이므로 분포 없음 |
| 사용자에게 새로운가·발견을 납득하는가 | 자료 없음 |

여기서 저선호는 Q<=0.2다. 범위는 정답 누락 때문에 생긴 **식별 범위**이며 신뢰구간이 아니다.
전체 요청당 저선호 발견 노출의 범위는 연결형 규칙0~97.2%, 비교형 규칙0~77.1%,
연결형 KM0~94.3%, 비교형 KM0~58.9%다. 상한이 낮아진 것은 발견 노출 자체가 줄었기 때문이다.
그 수치를 ‘실제 불호 감소’로 읽으면 안 된다. 대체 맞춤3이 더 좋은지도 이번에는 모른다.

E에 있는 영화만 남겨 다시 추천하면 이번 질문의 최종 슬롯을 다른 영화로 바꾸게 된다.
그렇게 얻는 조건부 순위 진단과 실제 추천 품질을 섞지 않았다. 채점 불가능을0점·불호0건·동등성으로 처리하지 않았다.

## 7. 다음에 결정할 순서

이번 네 조합의 진단은 여기서 종료한다. 분류·발견 정책·개인화 전환 K의 승자를 정하지 않는다.

1. **품질 판단 자료를 먼저 연결한다.** 이번 실제 슬롯의 선호·저선호, 발견의 새로움·연결 납득을 알 수 있어야 한다.
   기존 [사용자 품질 판단 양식](../../plans/service-policy-redesign/quality-judgment-protocol.md)을 이번 T2/D1/T3 구분과
   제공·보류 기록에 연결한다. 응답을 받지 않은 영화를 AI나 메타데이터로 사용자 정답처럼 채우지 않는다.
2. **입력 개수와 영화 선정은 별도 설계한다.** 같은 최대30편에서 기존 hash 순서와 장르 다양성 우선 순서 하나를
   비교하고, 각 순서의0/5/10/30편을 중첩한다. n30은 같은 영화 집합이어야 한다. 이 선택기·추천은 아직 실행하지 않았다.
   품질 자료가 없는 실행은 공급·동작 진단으로만 제한하며 같은 미채점 순위표를 늘려 K를 결정하지 않는다.
3. **정책·선정 방식이 고정되고 채점할 수 있을 때 전환 K를 판단한다.** 인기 대비 이득·저선호 손실을 확인하고
   별도 확인 자료로 검증한다. 온보딩 편의성은 실제 응답시간·skip·이탈 자료로 따로 확인한다.

입력 n을 늘리면 선호 정보뿐 아니라 ‘이미 경험한 맛’과 제외 영화도 늘어난다.
다음 설계는 **관측 상태 전체가 증가하는 경우**와 **이미 아는 감상 ID 이력 W를 고정하고 별점만 더 받는 경우**를 구분한다.
W를30편으로 고정한 비교는30편의 감상 ID는 이미 안다는 조건이며 실제 신규 온보딩의 시간 흐름을 뜻하지 않는다.
외부 맛 수8, 입력 수 n, 전환 기준 K를 서로 다른 변수로 유지한다.

## 8. 실행과 검수

실행 전 두 독립 검수자가14파일 지문·18원천 pin·12합성검사를 검토했다. 별도 선택 조합18,662건과
