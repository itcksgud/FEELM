## 실제 학습 데이터 대조

`outputs/recommendation-evidence/rec-ev-032/training.parquet`의 `user_id` 열을 전행 읽어
현재 평가 사용자와 직접 대조했다. 문서의 overlap 값이나 저장된 사용자 목록만 확인한 것이 아니다.
평가 user_key를 기존 SHA256 규칙과 원 ID 범위1~200,948에 대조하여2,180명 모두를
중복 없이 해석한 뒤 실제 정수 사용자 ID끼리 비교했다. 개별 ID와 평점은 출력하지 않았다.

| 확인 항목 | 결과 |
| --- | ---: |
| 실제 학습 행 | 7,355,439 |
| 실제 학습 사용자 | 46,376 |
| 이번 평가 사용자 | 2,180 |
| 학습·평가에 함께 있는 사용자 | **0** |
| 평가 사용자의 평점이 들어간 학습 행 | **0** |
| 학습 사용자 ID 누락 | 0 |

실제 학습 파일에서 추출한 사용자 집합은 prepared.npz의 training_user_ids와 정확히 일치했다.
학습 사용자는 모두 calibration 역할에 해당하고 평가 사용자는 그 역할에 한 명도 포함되지 않았다.
원 REC029의 SELECTION/R0 사용자, REC032 profile과 membership, 원실험·조건부·ALS 단독의
추천 출력 사용자 집합도 모두 동일한2,180명이었다.

독립 검토자 conditional_execution_review도 모델 코드의 사용자 변환 함수를 호출하지 않고
SHA256 규칙을 직접 구현하여 실제 학습 user_id 전행을 다시 대조했다.
학습 행/사용자 수, 평가 사용자 수, 교집합0명·겹치는 학습 행0건과 학습 역할 분리가 일치했다.
학습 파일·factor의 hash 및 prepare/train/score/완료 봉인 연결도 별도로 확인했다.

## 이번에 사용한 모델과의 연결

실제 학습 파일의 bytes/SHA256은 최초 prepare 봉인과 일치한다.
train 봉인은 그 prepare와 factors.npz를 가리키며, ALS 단독 score 봉인의 source_factors도
같은 factors.npz를 가리킨다. 학습 코드의 fit 입력은 해당 training.parquet다.

## 사전 학습과 사용자 입력의 구분

평가 사용자는 영화 factor를 만드는 사전 공동 학습에서 제외됐다.
이후 그 사용자의 입력으로 허용한5·10·30개 별점은 고정 영화 factor에 대한 사용자 취향
추정(fold-in)에 사용한다. 이것은 새 사용자에게서 받은 입력으로 추천하는 평가 조건이다.
그 사람의 모든 별점을 미리 영화 factor 학습에 넣었다는 뜻이 아니다.

이번 감사는 기존 학습 파일의 user_id 열만 추가 확인했다. 학습 평점·영화 ID 열은 해석하지 않았고
원본 아카이브도 열지 않았다. 모델 재학습·추천 점수 재계산·품질 지표 변경은 없다.
현재 파일과 봉인 연결을 검증한 것이며 과거 학습 과정을 다시 실행한 감사는 아니다.
앞선 결과 검토의 접근 범위는 당시 기록대로 보존하며 이번 후속 감사를 구분한다.
