# 기존 ALS 단독의 조건부 비교

상태: DRAFT — 독립 설계·실행 검토 PASS 이후 한 번 실행하는 연구 진단.
2026-09-07 / REC032_ALS_ONLY. 제품 계약·추천 모델 채택 문서가 아니다.

## 확인할 질문

이미 학습한 ALS에 사용자 별점을 입력했을 때, 같은 관측 영화 안에서 MovieLens 보정 평균
별점 기준보다 더 좋은 두 편을 고르는가? 기존 콘텐츠 순위 결합을 제거하면 결과가 달라지는가?
기존 비교는 P0와 ALS+콘텐츠 결합만 포함하여 이 질문에 답하지 못했다.

P0는 TMDB popularity나 평가 수 순위가 아니다. MovieLens 학습 평점의
`(영화 별점 합 + 50 × 학습 전체 평균) / (영화 평가 수 + 50)` 기준이다.

## 이번에 바꾸는 것 하나

- A0: REC032의 학습된 영화 factor와 원별점 fold-in을 그대로 사용한 ALS 단독.
- 비교 대상 P0와 M0: 완료된 conditional-ranking의 보정 별점 기준과 ALS+콘텐츠 RRF60 결과를 재사용.
- 새 학습·학습량 변경·파라미터 탐색·콘텐츠 단독 추가·콘텐츠 재계산·원본 평점 추가 조회는 없다.

학습은 평가 사용자와 겹치지 않는46,376명의7,355,439평점으로 이미 수행했다.
rank32, reg0.1, 반복10회, seed42인 기존 영화 factor를 고정한다.
현재 입력 n개의 원별점 중 학습 factor가 있는 영화만으로
`p = solve(Y.T @ Y + 0.1 × n_factor × I, Y.T @ raw_rating)`를 구한다.
원별점은0.5~5.0, 간격0.5이며 ALS 점수는 `movie_factor @ p`다.
예상 점수를 반올림하거나0.5~5.0에 자르지 않고 음수도 유효하게 정렬한다.

## 동일하게 유지할 조건

기존2,180명, 입력0/5/10/30과 기존 profile30의 순서, 공통 카탈로그85,517편,
관측 평가 영화 E191,933개 user/movie, 고정 평가 histogram H를 유지한다.
E는 원래 membership7개 outer의 합집합이며 사용자당20~108편이고 입력30편과 겹치지 않는다.
정답 보충으로 추가된2,244평점은 사용하지 않는다.

점수 함수는 E·H·정답을 받지 않는다. 전체 카탈로그에서 현재 입력 영화를 제외하고
ALS factor가 있는 영화의 점수로 전역 순서를 만든 뒤 평가 측에서 기존 E에 투영한다.
ALS 점수 동점은 movie_id 오름차순이다. P0·M0의 E나 사용자도 그대로 유지한다.
factor가 없는 E 영화는 지원 불가로 표시하되 E를 축소하거나 음수 평점으로 해석하지 않는다.

입력0개, 입력 factor0개 또는 사용자 벡터 norm≤1e-12이면 전역 P0 fallback을 명시한다.
유효 ALS 전역 후보가2편 미만이면 중단한다. E 투영 후2편을 못 채우는 셀이 하나라도 있으면
공급 기록을 남기고 전체 품질 비교를 중단한다. E 내 P0 보충·사용자 제거·지원 교집합 축소는 없다.
fallback 빈도와 E factor 지원률을 별도로 보고하여 ALS만의 기여와 구별한다.
입력별 P0/M0 선택 슬롯 중 factor가 없는 수와 기존 ALS 활성·n_factor 일치도 확인한다.
ALS−M0 차이에는 후보 지원 차이도 포함되므로 순위 결합 수식만의 인과 효과로 해석하지 않는다.

## 실행과 채점 분리

입력은 config의 연구 저장소 내부 경로와 bytes/SHA256으로 고정한다.
기존 prepare/train/score/evaluate 봉인, conditional 완료·점수·request와 출력 연결을 확인한다.
해시 검증은 파일 바이트만 읽고 평점 payload 해석과 구분한다.
기존 membership과 conditional targets의 동일성, 사용자·학습 역할 분리, E와 profile 분리를 확인한다.
ALS 전체 점수와 순서 해시, E 내 전역 순위·점수·상위2편, 지원·fallback 기록을 전부 봉인한 후
기존 conditional의 evaluation-labels와 histograms 및 user-metrics를 읽는다.
P0/M0 추천 ID는 정답이 아닌 고정 비교 출력으로 사전에 읽을 수 있다.

E 전체의 원별점·H·Q를 검증하고 기존 P0/M0의 사용자별 지표를 다시 계산해 일치시킨다.
Q는 사용자 내 상대 선호의0~1 값이며 정확도나 원별점이 아니다.
`A(r)=2×H_below(r)+H_equal(r)`, `N=sum(H)`일 때 상위2편의
MEAN_Q 분자는 A1+A2, 분모4N; MIN_Q 분자는 min(A1,A2), 분모2N이다.
HARM20은 `5×min(A1,A2)≤2N`인 경우1이다. 짝 차이는 정수 분자를 먼저 빼고 나눈다.

## 비교와 종료 규칙

ALS−P0와 ALS−M0 각각 입력5/10/30 × MEAN_Q/MIN_Q/HARM20, 총18개 비교를 한 family로 고정한다.
사용자 동일 가중 paired bootstrap5,000회, seed20260907, alpha0.05,
양쪽 꼬리 각각0.05/(2×18)의 구간을 사용한다. 모든 비교에 같은 사용자 추출을 공유한다.
입력0은 동일성 검사만 하며18개 검정에 포함하지 않는다.
평균과 낮은 쪽 선호는 클수록, HARM20은 작을수록 유리하다.
구간이0을 넘는 방향만 BETTER/WORSE로 표시하고0을 포함하면 UNDECIDED다.
실질 채택 한계는 설정하지 않는다. 동등성·실용 우위·최종 K를 판정하지 않는다.

- ALS가 P0보다 유리하면 이 관측 조건에서 ALS 단독의 추가 이득 근거다.
- ALS가 M0보다 유리하면 현재 고정 RRF 결합이 ALS 단독보다 불리했다는 근거다.
  콘텐츠 단독의 품질이나 모든 하이브리드의 실패를 뜻하지 않는다.
- ALS가 P0보다 불리하면 현재 학습·입력 처리의 ALS 단독도 기본 기준을 넘지 못한 것이다.
  학습 부족·ALS 일반적 한계·입력 수 부족 중 어느 원인인지는 이 비교로 분리하지 않는다.
- 엇갈리거나 구간이0을 포함하면 해당 지표는 그대로 보고하며 승자를 만들지 않는다.

이미 개봉한 관측 E를 이용하는 탐색 진단이다. 관측 영화 선택 편향이 남아 있고 실제 새 영화
추천·한국 FEELM 사용자·맞춤2/발견1·온보딩 효과·학습 수렴을 입증하지 않는다.
결과가 불리해도 이번 실행에 새 모델이나 재학습을 추가하지 않는다.

## 검토·자원·산출물

설계/코드/합성 테스트 → 독립 검토와 필수 수정 → hash 고정 → 한 번 실행 → 독립 결과 검산.
원래 REC032 및 conditional 산출물과 코드·검토 기록은 수정하지 않는다.
별도 output_root만 쓴다. 단일 프로세스15분·4GiB, 자식 프로세스 없음.
자원 중단/공급 부족/오류는 실패·예산 기록을 남기고 부분 실행을 자동 덮어쓰거나 재시도하지 않는다.
완료본은 필수 출력 전체와 의존 봉인·현재 코드의 무결성이 맞을 때만 점수 재계산 없이 재사용한다.
사용자 ID·개별 평점은 콘솔/보고서에 노출하지 않고 집계값만 보고한다.

실행 명령은 [로컬 runbook](../../../../runbook/local-development.md) 7.3을 따른다.
