# 같은 추천의 정답을 보충한 결과

상태: COMPLETED_EXPLORATORY — 원본 조회·재채점·결과 독립 검토 완료. 품질 우열은 미판정.
REC-EV-032의 후속 재채점 / 2026-09-07. 새 추천 실험이나 제품 정책 채택이 아니다.

## 결론

**평점을 더 찾아도, 이번 자료로는 개인화 추천이 인기 추천보다 좋은지 판단할 수 없었다.
같은 추천 목록의 원본 조회는 여기서 종료한다.**

기존 추천 영화에 대해 같은 사용자가 남긴 평점을 **2,244건 더 찾았다.**
하지만 입력30개에서 개인화 추천 슬롯4,360개 중 채점 가능한 것은386개(8.85%)였고,
나머지3,974개(91.15%)는 MovieLens 원본에도 해당 사용자의 평점이 없었다.
기존 정답 집합이 좁았던 문제를 보충한 뒤에도, 전체 추천 품질을 판단할 자료는 부족했다.

이는 인기 추천이 이겼거나 개인화가 실패했다는 뜻이 아니다.
**채점 가능률은 정확도나 만족도가 아니다.** 모르는 선호를 불호로 바꾸지 않았으며,
평균 선호·최저 선호·저선호 위험의9개 비교가 모두 미판정이었다.

## 무엇이 늘었나

추천 사용자2,180명, 입력0/5/10/30개, 두 정책의 상위2편 목록은 그대로다.
모델 학습과 추천 생성은 추가로 수행하지 않았다.

| 입력 영화 수 | 인기: 기존 → 보충 후 | 개인화: 기존 → 보충 후 | 보충 후 개인화 두 편 모두 채점 가능한 사용자 |
| --- | --- | --- | --- |
| 0 | 167 → 1,656 / 4,360 (37.98%) | 167 → 1,656 / 4,360 (37.98%) | 159 / 2,180 |
| 5 | 168 → 1,657 / 4,360 (38.00%) | 109 → 465 / 4,360 (10.67%) | 104 / 2,180 |
| 10 | 168 → 1,657 / 4,360 (38.00%) | 106 → 439 / 4,360 (10.07%) | 83 / 2,180 |
| 30 | 171 → 1,669 / 4,360 (38.28%) | 89 → 386 / 4,360 (8.85%) | 86 / 2,180 |

원본 조회 대상은 모든 조건의 추천을 합친 사용자·영화 조합15,248개였다.
그중 기존에 알던402개를 모두 다시 확인했고, 새2,244개를 더해 총2,646개를 확보했다.
나머지12,602개는 원본에 평점이 없었다. 같은 조합이 여러 입력량·정책에서 반복될 수 있어
이 조합 수와 표의 추천 슬롯 수는 서로 다르다.

입력30개 조건의 슬롯을 원인별로 나누면 다음과 같다.

| 구분 | 인기 추천 | 개인화 추천 |
| --- | --- | --- |
| 기존 정답 | 171 | 89 |
| 원본에서 새로 찾은 정답 | 1,498 | 297 |
| 원본에도 해당 사용자의 평점 없음 | 2,691 | 3,974 |
| 입력용 영화여서 평가 제외 | 0 | 0 |
| 전체 | 4,360 | 4,360 |

앞선 입력량에서는 뒤에 입력할30편에 속하는 추천이 일부 있었다.
입력0/5/10개에서 인기30/27/26슬롯, 개인화30/108/114슬롯이다.
이 영화들은 추천과 분모에 그대로 남기고 평가만 제외했다. 다른 영화로 바꿔 채점 가능률을 높이지 않았다.

## 미판정 범위는 줄었지만 결론을 고르기에는 넓다

개인화−인기의 평균 상대 선호 차이를 계산했다. 양수는 개인화에 유리한 방향,
음수는 인기에 유리한 방향이다. 정답이 없는 영화에 가능한 선호 값을 넣어 만든 범위이며
추천 성공률이나 확률이 아니다.

| 입력 영화 수 | 기존 미채점 고려 범위 | 보충 후 미채점 고려 범위 | 보충 후 사용자 재표집까지 포함한 탐색 구간 |
| --- | --- | --- | --- |
| 5 | [-0.970, 0.965] | [-0.826, 0.687] | [-0.839, 0.702] |
| 10 | [-0.970, 0.965] | [-0.827, 0.691] | [-0.841, 0.706] |
| 30 | [-0.972, 0.965] | [-0.834, 0.694] | [-0.848, 0.708] |

세 입력량 모두 두 방향을 포함한다. 최저 선호와 저선호 위험도 같은 이유로 미판정이다.
입력량3개 × 지표3개를 모두 보고했으며, 평점이 있는 추천만 따로 골라 전체 우위를 발표하지 않았다.

## 이제 어떤 순서로 진행하나

1. **이번 비교는 종료한다.** 동일 사용자·추천 조합은 원본까지 조회했다.
   같은 자료 재조회나 bootstrap 반복 증가로 원본에 없는 평점을 만들 수 없다.
2. **기본 추천은 재현 가능한 연구 기준안으로 보존한다.** 품질 통과로 표시하지 않으며,
   이번 미판정을 이유로 모델·가중치·입력 개수의 비교를 추가하지 않는다.
3. **다음 준비는 계획의3단계다.** 같은 영화 범위에 TMDB 단순8맛과 K-means8 배정안의
   입력 필드·누락·동률·신규 영화 처리 규칙을 작성한다. 이 준비만으로 분류의 승자를 정하지 않는다.
4. **4단계의 품질 비교를 실행하기 전에 채점 자료를 준비한다.** 실제 FEELM 대상 사용자가
   자신의 입력으로 받은 추천을 판단하는 자료가 필요하다. 추천을 보고 생긴 관심과 감상 후 만족은
   별도로 수집하고, 비교 정책의 노출 순서는 무작위화하는 방향으로 설계한다.
   모집 규모·수집 부담·중단 기준은 별도 설계·독립 검토가 필요하며 이번에 임의로 확정하지 않았다.
5. **전환 K는 기존 순서대로5단계에서 정한다.** 맞춤2·발견1, 분류와 입력 처리를 고정한 뒤 판단한다.

기존 오프라인 실험의 조건부 개인화 근거는 재사용할 수 있다. 다만 이번 실제 상위2편의
전체 품질 정답을 대신하지 않는다. 다른 사람이 MovieLens 사용자의 미평가 영화를 대신 채점하는
방식도 그 사용자의 정답을 보충하지 못한다. 온보딩 편의성은 실제 소요 시간·부담 자료가 추가로 필요하다.

## 검토와 실행 기록

실행 전 독립 설계·코드 검토는 PASS, 필수 수정 사항0건이며 합성 테스트10개가 통과했다.
조회할 사용자·영화 조합과 기존 상대 선호 기준 H를 먼저 봉인하고 원본32,000,204행을 확인했다.
사용자 확인 → 요청 영화 확인 → 해당 평점 해석 순서를 지켰고, 요청 밖 평점과 모든 timestamp는
해석하지 않았다. 원별점0.5~5.0·간격0.5를 보존했다.

기존 정답402개와 원별점/Q 일치, 사용자별 원본 행수와 고정 H 합계 일치,
기존 추천·원실험 봉인의 hash 보존을 확인했다. 새 값으로 모든 사용자의 정책 차이 범위가
넓어지지 않는지도 검사했다. 실행은30.468초였다.

결과 독립 검토는 **PASS, 필수 지적0건**이었다. 허용 파생산출물17,440행·8개 집계·9개 차이를
별도로 재계산했고, 사용자 동등 paired bootstrap5,000회(seed20260907, 9개 비교)의 구간도
별도 구현으로 확인했다. 최대 집계 오차는5.55e-16, 구간 오차는1.44e-15였다.
검토자는 원본 archive와 기존 selection labels를 다시 열지 않아 원본 H를 재생성하지 않았다.
파생 H에 따른 Q와 기존 정답의 연결을 확인했으며, 원본의 평점 부재 및 사용자별 원본 행수/H 일치는
실행 계약·스캔 기록에 근거한다. 원본을 독립적으로 다시 조회한 검증은 아니다.

이 결과는 원래 결과를 본 뒤 수행한 탐색 재채점이며 독립 확증이 아니다.
실제 맞춤2·발견1의 품질, 상대값과 원별점의 우열, K-means 효과, 온보딩 효과·부담,
최종 전환 K와 제품 채택은 판정하지 않았다.
