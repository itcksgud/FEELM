# 기준 모델의 입력 구성 비교

상태: DRAFT — 로컬 실행 명세이며 서비스 구현 계약이 아니다. 2026-09-11.

사용자 승인 범위는 ① 기준 모델 정리 → ② 정보 결합과 ALS 보조 → ③ 맞춤·발견 정책의 실제 비교와 결론이다.
이 문서는 첫 단계의 결과를 보기 전에 고정하는 명세다. 이전 봉인과 팀 저장소는 변경하지 않는다.

## 질문과 네 조건

이전 T0의 전체 후보 추천이 투표 한 개·평균10점 영화에 집중된 현상은 원인 확정이 아니다.
대중 평점의 근거량과 학습 입력 구성 두 변경을 분리해 확인한다.

| 조건 | 대중 평점 | 학습 입력 |
|---|---|---|
| B | 기존 원 평균 | 기존180일 창 시작 전 이력 |
| R | 투표 근거량으로 수축 | 기존 이력 |
| H | 기존 원 평균 | 목표 별점의 시각보다 엄격히 이전 이력 |
| RH | 수축 | 목표 시각 이전 이력 |

네 조건 모두 새 공통 행 배정으로 FM 한 번씩 학습한다. 이전 T0는 과거 진단용으로 보존한다.
Parquet 압축 크기에 따라 Spark 입력 partition이 달라질 수 있으므로 이전 T0 모델을 주 대조로 재사용하지 않는다.
모든 조건은 `repartition(8, row_id)` 후 각 partition에서 row_id 순으로 정렬한다.
실제 partition별 행 순서 해시·개수를 저장하고 네 조건의 일치를 확인한다. AQE는 끈다.
이는 입력 행 배정의 통제이며 부동소수 연산·단일 확률 학습의 한계까지 없애지는 않는다.

## 변하지 않는 데이터

- text339의 원 학습 39,859명·4,997,069행, 같은 목표 영화·별점·행 순서.
- 같은 사용자별 창의 cap 배정0/1/5/10/30. 목표·사용자 재표집, 별점 가중치 변경 없음.
- C10,952편은 학습 목표와 학습 입력 모두에서 제외한다. C/W/NATURAL_ZERO 및 지원량은 원 학습 집합 기준으로 고정한다.
- 평가270명·1,350contexts·93,230행, 같은 O/J·시점·입력cap. 학습 사용자와 평가 사용자 분리.
- 실제 별점0.5~5, 0.5단위. 계산용 예측·수축값은 연속값이며 실제 별점으로 저장하지 않는다.
- 현재 TMDB를 사용한 과거 MovieLens 개발 비교다. 과거 시점 재현·2026년 한국 서비스 성능을 입증하지 않는다.
- 기존 개발 정답을 이미 사용했으며 새 최종 test라고 부르지 않는다. 미평가는 UNKNOWN이다.
- 입력은 기존230개 구조 특징. 텍스트·군집·8개 맛·새로운 영화 cutoff는 추가하지 않는다.

## 두 변경의 수식

R은 원 유효 TMDB 평균r, 투표수v에 `(v*r + m*mu)/(v+m)`를 적용한다.
학습 지원 W 영화 중 원 평균이 유효한44,920편의 영화균등 평균 `mu=6.173088067675869`,
양의 투표 수 중앙값 `m=48`을 고정한다. 평가목록으로 W를 재선별하지 않는다.
C 및 학습지원0 영화는 mu/m 추정에서 제외하고, 수축 적용은 입력과 후보 모두 동일하다.
결측은 결측으로 유지한다. 확률적으로 보정된 신뢰구간이나 경험적 베이즈 사후평균이라고 주장하지 않는다.
원 사용자 반응의 수축 강도5는 유지한다. 230열 중200/207/208/210/211/212만 R에서 변경하고 나머지224열은 동일하다.

H는 목표 timestamp보다 작은 동일 사용자의 허용 과거 평점 중 가장 최근 cap편을 쓴다.
timestamp 내림차순, movie_id 오름차순이며 같은 시각의 목표끼리는 입력으로 쓰지 않는다.
cap0 목표도 이후 목표의 과거 이력에는 포함된다. 이 변경은 입력량과 최근성·갱신 빈도를 함께 바꾸는 **학습 이력 구성 효과**다.
정답 값을 보지 않은 전수 감사에서 h0목표는4,114,737(82.34%)→1,051,625(21.04%),
사용한 과거-목표 쌍은41,750,890개다. 새로운 h0 중998,592개는 cap0 배정이고53,033개는 첫 시각의 양의 cap 목표다.

## 구현 및 실행 gate

1. 독립 설계·코드 검토. 원형 특징과 벡터 배치의 train-only 수치 대조: 절대오차≤2e-6(float32),
   같은 시각/입력0/부분cap/결측/동일영화 배제 검사. 결과를 보고 오차 허용폭을 늘리지 않는다.
2. 원 prepared seal 및 입력 핀 확인 후 준비. 모든 목표 row_id/uid/label은 원본과 전수 일치,
   학습/평가 사용자 분리, 시간 및 C 배제, 이력 개수 전수 확인. 새 산출물 독립 검토 후 학습한다.
3. 모델 seed339, FM factor16/reg.01/maxIter150/step.01/minibatch.25/adamW/tol1e-6.
   고정 Spark4.1.3 이미지, local4, 컨테이너12GiB·driver8GiB·CPU4·network none, 조건당 전체 프로세스5400초.
   실패·초과는 보존하고 더 큰 자원/다른seed/데이터 축소로 조용히 재시도하지 않는다.
   정상 종료·수치 검산을 통과해도 peak>12GiB이면 엄격 자원조건은 EXCEPTION이다. 실제 byte를 그대로 보고한다.
   이 경우 같은 자원 한도에서 품질 비교와 후속 연구는 진행할 수 있지만 실행 가능성 PASS나 운영 채택으로 부르지 않는다.
   시간 초과/비정상 종료 모델은 해당 조건의 결과 미확보로 처리하며 품질 승자로 선택하지 않는다.
4. native 계수와 portable 수식·93,230행 예측 독립 검산(≤1e-8). 원본 후보4096chunk로 전체 후보 예측을 확인한다.
   파라미터·평가 순서·예측 봉인 후 별점 채점, 별도 결과 검산을 한다.

## 결과 판정 — 먼저 고정

이번 질문이 개인 입력 활용이므로 주지표는 **H10 실제입력h>0, J≥2, IDCG>0의 NDCG@2**다(기존 분모176명).
직전339의 ALL260명 주지표와 달라진 이유를 명시한다. h0 84명과 ALL260명은 함께 보고한다.
공식 대조는 **R−B, H−B, RH−B, RH−H, RH−R**의5개다. 사용자 UID를 정렬한 짝 bootstrap20,000회,
seed340·공통 재표집을 사용하며 Bonferroni99% 구간(가족 오류율.05)을 낸다.
RH의 차이의 차이는 기술통계이며 별도 상호작용 검정으로 부르지 않는다.

후속 비교 후보 자격은 해당 조건−B의 NDCG 보정구간 하한>0이고, h>0와 h0 각각에서
Top2 평균별점 손실≤0.1점 및 낮은별점(≤2) 비율 증가≤3%p의 **점추정 veto**를 통과해야 한다.
이는 안전성·비열등성 증명이 아니다. 통과가 없으면 B를 유지한다. 여러 조건이면 주지표 점평균 최대,
정확한 동률은 R→H→RH 순으로 결정한다. RH 추가효과는 두 직접 보정대조를 별도로 해석한다.

NDCG·별점·좋음≥4·낮음≤2·Recall·hit·오차·순서 정확도는 Top2/4/6/10과 각 유효 분모로 정리한다.
C/W/자연지원0·학습지원량·활동량·실제h·대중투표 근거량별로 보고하고, 30명 미만 셀은 기술통계로만 본다.
관측 후보 내부 순위와 전체85517 카탈로그의 현재 개봉·기시청 제외 후 공급 진단을 구분한다.
전체 후보는H10 270명에 대해 채점하며 Top2/4/6/10의 UNKNOWN·관측가능 슬롯·영화 종류·HHI·
투표1개 평균10점 노출·학습지원0·비용을 ALL/h0/h>0로 나눈다. 노출 감소 자체는 추천 품질 개선 판정이 아니다.
이전 T0의 h>0 Top2 특이 노출은346/372였고 T3/CLEAN의368/372와 다르다. 새B의 실제값을 별도로 측정한다.

## 이후2·3단계의 범위와 예산

첫 단계4회 FM은 물리적 학습 행 배정을 맞추기 위해 기준 재학습을 포함한다.
그다음 정보 조합은 선택한 구성의 **대중성 개인 반응 제거 FM 한 번**으로 후보 대중지표만 남긴 대조를 하고,
같은 구성의 GBT 한 번을 비교한다. 텍스트 전수조합이나 모든 속성 조합을 탐색하지 않는다.
추가 ALS 한 번은 C를 제거한 동일 W평점으로 학습한다. 기존 C포함 ALS는 정보를 더 아는 참고선으로만 재예측한다.
현재 남은 모델 학습 예산은 FM5회 + GBT1회 + ALS1회 = **7회**이며 정책은 재학습 없이 최대6설정으로 비교한다.
이것은339 이전/정제 학습을 제외한 새 사용자 요청 범위의 예산이다. 추가 학습을 결과에 맞춰 늘리지 않는다.
후속 코드·평가 기준은 각각 새 결과 개봉 전에 독립 검토하며, 정책은 공식 맞춤2+발견1과 대체 동작을 평가한다.
최종 별도 미사용 표본의 출처를 증명하지 못하면 개발 비교 결론과 한계를 명시해 끝낸다.
중간 Jira/MR/commit/push/운영변경은 이 실행에 포함되지 않는다.
