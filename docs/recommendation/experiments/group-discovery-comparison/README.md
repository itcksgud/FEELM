# 그룹 기반 발견 추천 비교 설계

상태: DRAFT 개인 연구안 / 독립 설계 검토 PASS(DESIGN_ONLY). 2026-09-11. 실행하지 않음.

수학·의미, 데이터 출처, 평가·공정성의 세 독립 검토를 통과했다. 1차 검토 뒤 실제 평점의 전용 단계·출처와 관측/카탈로그 시점을 보강하고, 비교 6쌍의 방향을 명시해 수정본을 재검토했다. 설계·단계 구성의 통과이며 모델 성능이나 실행 코드의 통과가 아니다. 최종 파일 해시는 [검토 봉인](design-review.json)에 있다.

| 비교안 | 어디서 찾는가 | 멀다는 기준 |
|---|---|---|
| 방법 1 | 과거 기록에서 경험이 적고 취향과 연결되는 그룹 | 별도 먼 거리 필터 없이 그룹별 사전 순위에서 후보 추출 |
| 방법 2-A | 좋아한 영화가 속한 그룹 | 기존 긍정 영화 중 가장 가까운 영화와도 상대적으로 멂 |
| 방법 2-B | 방법 2-A와 같은 그룹 | 해당 그룹 중심점에서 상대적으로 멂 |

방법 2-A/B는 공통으로 그룹 경계에 가까운 조건을 적용한다. ‘중앙값’은 군집 중심의 산술평균으로 해석했다. 원거리뿐 아니라 같은 그룹 안에서의 상대 위치를 사용하므로 큰 그룹의 넓은 반경만 유리해지는 것을 줄인다. 각 그룹에서 후보 여러 편을 가져와 동일한 FM으로 마지막 한 편을 선택한다.

공통 조건은 같은 영화 벡터·군집·사용자·원후보·사전 순위와 최대 5그룹×10후보다. 실제 추출 수와 거리 계산·스캔 비용은 따로 기록한다. 그룹 상위 한 편만 사용하는 경우도 보조 진단에 포함한다.

새로움은 방법별 거리 수치만으로 승패를 정하지 않는다. 실제 별점, 낮은 평가, 군집 입력에서 뺀 인물 특징의 새로움, 공급률, 좋은 후보를 놓치는 정도를 함께 본다. 인물 특징의 새로움은 보조 지표이며 실제 발견 만족도를 입증하지 않는다.
