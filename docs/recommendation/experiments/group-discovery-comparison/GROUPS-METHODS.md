# 공통 그룹과 세 방법의 정의

상태: DRAFT — 조건부 실행 명세. 현재 계산·학습·추천 실행 금지.

## 1. 공통 벡터와 군집

고정 85,517편 카탈로그의 원 장르 ID와 키워드 ID를 별도 namespace로 사용한다. 영화별 중복 ID 제거 후 장르는 binary multi-hot→L2 정규화한다. 키워드는 전체 카탈로그 영화 document frequency가 5 이상인 ID만 사용하고, binary tf에 `idf=log((1+N)/(1+df))+1`을 곱해 L2 정규화한다. 각 block의 영벡터는 관측 특징 없음이며 부정 선호가 아니다. 비어 있지 않은 block 수가 b일 때 두 block을 연결하고 sqrt(b)로 나누어 영화 단위 벡터 x를 만든다. b=0은 GEOMETRY_UNKNOWN이며 군집 배정/발견 근거를 만들지 않고 공통 P0 후보에는 유지한다. 실제 b별 지원량을 기록한다.

어휘·IDF·군집은 평점을 사용하지 않는 **고정 현재 카탈로그 전체**에서 만든다. 이는 카탈로그를 미리 아는 transductive 개발 비교이며 과거 시점/신규 영화 일반화 평가가 아니다. 타깃 평점, 사용자 프로필, 인기·배우·감독·원어·개봉연도·국가는 군집 입력에 넣지 않는다. 인물은 평가용 별도 특징으로 남긴다.

Euclidean KMeans(init=k-means++, n_init=10, max_iter=300, tol=1e-4, algorithm=lloyd), CSR float64, K 후보 {16,32,64}, 각 K의 random_state {20260911,20260912,20260913}을 고정한다. 평점을 보고 K/벡터/seed를 선택하지 않는다. seed 첫 값의 결과를 사용할 대표 run으로 고정하고 나머지는 안정성 확인에만 쓴다. K마다 다음을 모두 확인한다.

- 모든 run에서 수렴 경고 없음, 실제 K개의 비어 있지 않은 그룹, 각 그룹 100편 이상, 최대 그룹이 유효 영화의 35% 이하.
- 같은 영화 전체의 세 run 쌍별 adjusted Rand index 최솟값 >= .70.
- 서로 다른 중심 거리 > 1e-10, 유한 벡터·중심·거리, 배정과 최근접 중심 일치.

통과한 K 중 가장 작은 K를 공통 K로 선택한다. 아무것도 통과하지 못하면 중단하고 GROUPING_NOT_READY로 보고한다. 이 숫자는 결과를 보기 전 고정한 연구 조건이며 의미 있는 취향 군집의 보증이 아니다. 원래 속성을 제거하거나 8맛에 맞추지 않는다.

중심 c_g는 K-means가 학습한 산술평균이며 **재정규화하지 않는다**. 최종 중심이 실제 배정 영화의 평균과 좌표별 atol=1e-6, rtol=1e-6으로 일치하는지, 배정이 argmin ||x-c||²와 일치하는지 확인한다. 불일치는 중단·재검토 사유이고 임의 보정하지 않는다. 그룹 ID는 각 그룹의 최소 movie_id 순으로 canonicalize한다. 최근접 거리 동률은 이 그룹 ID 오름차순. 동률이 아닌 값을 임의로 동률로 만들지 않는다.

K-means 중심과 Voronoi 배정의 관계는 [scikit-learn 공식 설명](https://scikit-learn.org/stable/modules/clustering.html#k-means)을 따른다. 아래 거리·경계식과 임계값은 이번 비교를 위한 명시적 설계다.

## 2. 거리·경계·경험을 구분한다

사용자 u의 O_u는 cap=10 context의 oi와 stars, V_u는 context의 viewed, P_u={a in O_u: stars(a)>=4}다. V는 해당 기존 자료에서 알려진 과거 기시청 제외용 집합이며 실제 생활의 전체 관람 이력이 아니다. P의 평점은 추천 입력으로 이미 허용된 값이다. 미래 목표 평점은 이 단계에서 읽지 않는다. P의 geometry 유효 영화만 P*_u로 표시한다. 입력 일부가 geometry 결측이면 수를 기록하고, P*가 비면 발견을 보류한다.

- 그룹 경험 E(u,g) = V_u 중 유효 군집이 g인 영화 수. GEOMETRY_UNKNOWN인 V 영화가 하나라도 있으면 미경험을 확정할 수 없어 M1은 abstain한다. M2는 유효 P*의 긍정 그룹만 사용하고 결측을 함께 보고한다.
- 그룹 연결 A(u,g) = max_{a in P*} cosine(x_a,c_g). cosine 계산용 분모만 ||c_g||를 사용하며 배정용 중심을 바꾸지 않는다. centroid norm=0이면 해당 run 오류다.
- 긍정 그룹 G+(u) = {g(a): a in P*}. 한 그룹의 영화 하나에 좋은 평점을 줬다는 것이 그룹 전체를 좋아한다는 정답은 아니다.
- 선호 영화 거리 D_A(u,i) = 1-max_{a in P*} x_i dot x_a. 모든 유효 긍정 입력 중 **가장 가까운 영화와의 거리**다. 소속 그룹 밖 긍정 입력도 포함한다. float 연산 결과 cosine만 [0,1]로 clip한다.
- 중심 거리 D_B(i) = ||x_i-c_g(i)||_2. x는 단위벡터지만 c는 아니다. 그룹의 전형적 위치에서 먼 정도이며 사용자 선호와의 거리가 아니다.
- 경계 거리 B(i) = min_{h!=g(i)} [||x_i-c_h||²-||x_i-c_g(i)||²] / [2||c_h-c_g(i)||]. 자신의 Voronoi 셀의 경계까지 벡터 공간 Euclidean 거리다. 2위 중심의 단순 거리 차이로 대체하지 않는다. 값 < -1e-10은 오류, [-1e-10,0]만 0으로 clip. 정확한 배정 동률은 B=0일 수 있다.

그룹 g 전체 유효 영화 집합 I_g를 고정 기준으로 사용한다. midrank CDF는 `F_g(v)=(#{j:v_j<v} + .5*#{j:v_j=v})/|I_g|`이다. 동률은 같은 percentile을 받으며 movie_id로 깨지 않는다. 전부 같은 거리이면 .5이고 상위/하위 꼬리를 인위적으로 만들지 않는다.

R_A(u,i)는 I_g 전체에 D_A(u,j)를 계산한 midrank, R_B(i)는 I_g의 D_B midrank, R_edge(i)는 I_g의 B midrank다. **시청 제외, 후보 pool, Q 순위, FM 점수 필터 이전의 같은 카탈로그 기준**이다. R_A만 사용자마다 달라지고 R_B/R_edge는 사전 계산 가능하다. 분위수가 높다는 것은 상대적 거리이며 절대적인 생소함은 아니므로 원거리도 저장한다.

공통 outlier guard는 R_B<=.99다. 의미가 떨어질 수 있는 극단 반경 꼬리를 동일하게 제외하되, 이것이 밀도 기반 이상치 검증이나 콘텐츠 품질 보증은 아니다. 그룹 경계 조건은 R_edge<=.20, 먼 조건은 해당 R_A 또는 R_B>=.75다. 경계와 중심에서의 거리, 선호 영화와의 거리는 서로 독립적으로 정의한다.

## 3. 사용자 공통 사전 순위 Q

text339/ratings.parquet의 **허용된 학습 사용자 평점만**으로 영화별 count n_i, 합 s_i, 전체 학습평점 평균 mu를 얻는다. evaluation context 사용자는 전원 제외되어야 하고, timestamp가 기존 평가 origin보다 이른지 확인한다. catalog.train_count와 일치하는지 검증한다. Q_i=(s_i+20*mu)/(n_i+20). n_i=0이면 Q_i=mu다. 정렬은 Q 내림차순, n_i 내림차순, movie_id 오름차순이다. TMDB vote_average나 평가 사용자 별점으로 Q를 만들지 않는다.

학습 자료의 time/role/hash를 확인하지 못하면 Q_READY 실패로 중단한다. 단순 popularity 순위로 자동 대체하지 않는다. Q는 대중 반응의 수축 평균이고 개인별 선호 순위가 아니다. 학습지원 없는 영화가 사라지지 않으며, 실제 추출·노출 편중은 평가한다. 그룹별 이 순위 전체와 각 영화 위치를 미리 저장한다. Q 상위 한 편의 우수성이 전체 그룹의 우수성을 보장하지 않는다.

## 4. 공통 추천 절차

주 비교는 **한 번의 요청에서 한 슬롯**이다. OBSERVED는 context.ei 전체, CATALOG는 기존 공개일 필터 및 V 제외 후 cache.ei 전체를 원후보로 사용한다. 각 pool에서 세 방법의 원후보가 정확히 같다. OBSERVED의 존재 자체가 미래 관측 선택 편향을 가지므로 CATALOG와 성능을 섞지 않는다. release_date 누락/미래 공개 제외는 기존 CATALOG 명세 그대로다.

그룹 선택 예산 q=5, 그룹별 개인화 후보 m=10, 개인화 점수 조회 상한 q*m=50을 고정한다. 각 방법에서 아래 조건을 만족한 그룹을 **A 내림차순, E 오름차순, group_id 오름차순**으로 최대 q개 선택한다. 내부 영화 조건을 적용하기 전 그룹을 정하고, 빈 그룹 때문에 q 밖 그룹을 추가하지 않는다.

- M1 그룹: E<=1 AND A>=.25. 여기서 ‘경험이 적음’은 기록상 0~1편이라는 연구 정의다.
- M2-A/M2-B 그룹: g in G+(u) AND A>=.25. 두 방법의 선택 그룹은 정확히 같아야 한다.

선택한 각 그룹에서 Q 순서대로 원후보·미시청·공통 outlier 조건을 만족하는 영화를 스캔한다. M2-A는 R_A>=.75 AND R_edge<=.20, M2-B는 R_B>=.75 AND R_edge<=.20을 추가로 만족해야 한다. 해당 필터를 통과한 첫 m편을 가져온다. **공통 상위 m편을 먼저 자르고 나서 기하 조건을 거는 순서가 아니다.** 조건 검사를 위해 읽은 행과 거리 계산도 비용에 포함한다. 한 그룹에서 모자라도 다른 그룹으로 quota를 넘기지 않는다. 이 차이는 공급 특성이므로 실제 후보 수를 공개한다.

추출 후보만 고정 FM B 점수 s(u,i)를 조회한다. s>=4.0인 후보 중 s 내림차순, movie_id 오름차순으로 한 편을 고른다. 4.0은 이번 연구의 예측 점수 기준이며 확률도 실제 4점 보장도 아니다. 무조건 먼 영화나 무조건 큰 예측값이 정답이라고 하지 않는다. 점수는 finite raw 값을 유지하며 [0.5,5] 밖 비율을 별도로 보고한다. 서로 다른 방법의 점수를 재보정하지 않는다.

후보 없음, 긍정 근거 없음, 점수 기준 미달은 이유별 abstain이다. 비교용 최종 슬롯에서는 해당 pool 전체의 FM 최고점 P0를 공통 fallback으로 두고, `method_supplied=false`를 기록한다. 원후보 자체가 비면 NO_ITEM이다. fallback은 발견 성공으로 세지 않는다. 후보가 P0와 같아도 규칙을 통과했으면 supplied와 changed_from_P0를 별개로 기록한다. 각 반환 영화의 E/A/D_A/D_B/B/percentile/Q/score/선택그룹·근거를 저장한다.

P0는 성능 비교 및 fallback용 공통 기준이다. 기존 전체 점수 캐시로 얻은 P0 비용을 숨기지 않는다. 실제 서비스가 P0를 이미 제공한다는 전제 없이 ‘전체 50편 계산으로 서비스 추천 완료’라고 주장하지 않는다. 이번 비교는 기존 FM 점수 조회이며 새로운 FM 추론 시간이나 전체 서비스 지연을 측정하지 않는다.

## 5. 사전 고정 진단

세 주방법의 매개변수를 결과로 튜닝하지 않는다. 다음은 이유를 해석하는 보조 진단이며 주승자 선택에 사용하지 않는다.

1. 같은 선택 그룹·Q·필터에서 m=1과 m=10 비교: 그룹 최상단만 비교할 때의 손실과 비용. q는 유지한다.
2. M2-A/M2-B 각각 경계 조건 제거, 그리고 공통 경계만 남긴 M2-edge: 거리 조건과 경계 조건의 추가 역할. outlier guard는 모두 유지한다.
3. 각 주방법의 모든 조건에 맞는 **모든 그룹·모든 영화**를 offline exhaustive reference로 채점한다. q 제한 및 m 제한을 각각 적용하기 전후의 최고점 보존·상위10 회수·score regret를 구분한다. 추천 정답이 아니라 같은 방법 내 후보 축소 손실이다.
4. M1 E=0만의 공급, M1과 M2 선택그룹/후보의 겹침, 경계가 이웃한 그룹의 경험량·긍정 여부, keyword 결측/지원량·원거리 분포를 기술통계로 남긴다.

M2-A의 R_A를 계산하려면 사용자별 positive-후보 거리와 그룹 내 분포 계산이 필요하다. 따라서 centroid/boundary 사전 계산만으로 모든 온라인 계산이 사라지지 않는다. 이 비용과 Q 스캔이 사용자 입력 변화 때 얼마나 달라지는지도 분리 보고한다.
