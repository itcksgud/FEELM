# REC046 데이터 구성 감사

상태: DRAFT — 기존 결과를 본 뒤 설계한 사후 진단. 새 모델 비교나 서비스 채택 검증이 아니다.

질문: 학습·검증·평가가 어떤 사용자·영화에 치우쳐 있고, 그 차이가 기존 5종 비교의
해석을 얼마나 제한하는가? 모델·설정·평가자를 바꾸지 않고 기존 자료를 점검한다.
실행 전 독립 검토와 실행 후 별도 재집계를 거친다. 원 REC046 봉인은 수정하지 않는다.

## 데이터와 정의

- 원본 ZIP에서는 userId/movieId/timestamp 세 열만 읽는다. 별점 열은 로드하지 않는다.
  모든 사용자 수 집계는 분포 감사이며 새 학습·평가 라벨 개방이 아니다.
- 역할과 학습 R은 기존 roles.json, 영화 지원량은 각 회차 train-counts.npy다.
  별점 분포는 이미 사용한 ALS R, 지도학습 목표, 검증·평가 exported labels에서만 읽는다.
  검증·평가 예측은 기존 selected.npz를 그대로 쓴다. 새 원본 별점을 수치화하지 않는다.
- 사용자 활동량: UTC 2019-01-01 이전에 원본 전체 영화에 남긴 평가 수.
  실제 감상 수·영화 지식의 척도라고 주장하지 않는다. 같은 기간 catalog 안의 평가 수도 병기한다.
- 사용자층: 0, 1–9, 10–29, 30–99, 100–299, 300+.
  30은 기존 자격 경계이며 나머지는 해석을 위한 고정 구간이다. 결과를 보고 경계를 조정하지 않는다.
- 영화층: 회차별 실제 R의 평가 수 0, 1–9, 10–49, 50+. 원 REC046 구간을 재사용한다.
  원본 전체 사용자의 catalog 영화 과거 평가 수와 각 회차 동일 학습 사용자의 전체
  허용 과거 평가 수(catalog 안·강제 제외 영화 제거)는 보조 진단이다.
  이를 실제 모델이 받은 지원량으로 바꾸어 쓰지 않는다.
- 입력 K는 사용자 활동량과 다른 축이다. K=0/1/5/10/30을 모두 보존한다.

## 분포 감사

1. 원본 전체·기존 개발 역할 집합·실제 학습·검증·평가 사용자별 사전 활동량 구간·분위수.
   역할 간 사람 ID 중복을 확인한다. 사용자 비중과 관측 행 비중을 구분한다.
   회차별 원래 학습 pool → 역할 제외 → K+8 자격 충족 → 실제 12,000명 선정을 재현한다.
   전체 pool에서의 자격 탈락과 선택 완료까지 방문한 prefix에서의 탈락을 구분한다.
2. 동일 회차 학습자 12,000명의 원본 과거 → catalog → 강제 제외 영화 제거 → 실제 R
   관측 수와 유지율. 지도학습 입력 O와 목표 8편을 분리한다.
3. 학습 R·학습 목표·검증 목표·평가 목표의 영화 지원량·개봉연대·별점·관측 시각 분포.
   train 목표는 과거, 검증/평가 목표는 미래라는 의도된 차이를 누수로 부르지 않는다.
   검증/평가의 전부 미지원 입력도 공개한다.
4. 동일 학습자의 전체 허용 과거 평점에서 지원하는 영화가 실제 R에서 사라진 비율을 확인한다.
   이는 학습량 축소의 가용성 진단이며 모델 성능 학습곡선이 아니다.
5. 영화 속성의 빈 특징 블록·학습 사전 밖 OOV를 역할별로 비교한다.
   빈 블록은 전처리 이후 값이 없다는 뜻이며 원자료의 부분 결측과 동일하지 않다.
   빈 블록/OOV만 있음/known+OOV/known만 있음의 네 상태를 구분한다.
6. 활동량 사용자 비중 및 목표 행의 활동량·지원량·연도·별점 분포 차이를
   총변동거리(비중 차이 절댓값 합의 절반)로 기술한다. 임의의 합격 임계값은 두지 않는다.
   검증 성적은 설정 선택에 사용한 자료이므로 검증–평가 성적 차이를 분포 이동의 효과로 단정하지 않는다.

## 사용자 활동량 × 영화 지원량 성적표

- 검증·평가 각각에서 기존 5종의 MSE, MAE, 원 예측의 영화 쌍 순서 정확도를 계산한다.
  MSE/MAE만 0.5~5로 제한한다. 실제 별점 동점 제외, 예측 동점은 0.5다.
- 같은 셀·사용자의 회차 값을 먼저 평균하고 사용자에게 동일 가중한다.
  사용자·영화·고유 사용자–영화쌍·회차 포함 평가 수, 쌍 정확도 계산 가능 사용자 수를 함께 낸다.
- ALS 직접 점수화율을 같은 셀에서 사용자 평균한다. 영화 factor 유무만으로 대신하지 않는다.
- 사용자 활동량 6층 × 영화 지원량 4층의 빈 셀도 남긴다. 0점으로 채우지 않는다.
- 2,000회 고유 사용자 bootstrap으로 각 평균의 개별 95% 구간을 낸다.
  해당 지표의 고유 사용자 30명 미만이면 구간 대신 지표별 표본 부족을 표시한다.
  이 구간은 다중 비교 보정된 승자 판정이 아니며 새 모델 채택/기각에 사용하지 않는다.
- 기존 전체 사용자 평균과 관측된 셀 평균을 균등 가중한 진단을 분리한다.
  24개 중 관측 셀 수·자료 충분 셀 수를 공개한다. 빈 셀을 제외한 균등 평균은
  저활동 사용자나 현재 한국 인구에 대한 보정이 아니다.
- 셀 내 영화 쌍만 비교하므로 셀 PA 평균은 전체 PA와 다른 지표다. 서로 다른 영화층 간
  쌍을 빠뜨린 값을 전체 순서 정확도로 부르지 않는다. 셀의 사용자/영화 수도 합산하지 않는다.

## 판정과 중단

누수·해시 변경·역할 중복·기존 전체 지표 불일치·모델별 분모 차이·누락 예측이면 중단한다.
원본 count 합계와 기존 32,000,204행을 맞춘다. 학습 count를 R에서 다시 계산한다.
빈 셀·지원 부족·학습/검증 선택 조건 차이·의도된 시간 이동을 실제 수치와 분리해 설명한다.
분포가 다르다는 이유만으로 기존 계산을 무효화하거나 모델의 일반적 열세를 단정하지 않는다.

산출물은 `outputs/recommendation-evidence/rec-ev-046-data-audit`에 새로 보존하며 기존 출력이
있으면 덮어쓰지 않는다. 소형 표·그림·보고서·검토 기록만 이 문서 폴더에 복사한다.
원본 사용자별 count와 예측은 Git 제외·LOCAL_ONLY다. 코드·설계·입력 해시를 봉인한다.
새 학습·재튜닝·평가자 추가·Jira·Git 게시·서비스 변경은 하지 않는다.

학습량별 실제 성능 변화는 이번 감사로 알 수 없다. 이번 지원량 손실 진단을 바탕으로
필요 학습량과 동일 평가 조건을 정한 별도 사전 검토가 필요하다고 명시한다.
