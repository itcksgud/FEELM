# ALS 참고선과 콘텐츠 취향·근거량·대중성 비교

상태: DRAFT — 2026-09-10 로컬 실행 계약. 사용자 ㄱㄱ에 따른 연구이며 외부 게시·서비스 정책 승인이 아니다.

## 판단 질문

MovieLens 학습 평점이 없는 것으로 처리한 같은 영화에서, TMDB와 사용자 사전 입력만 사용하는 모델이 평점 이력을 아는 참고 ALS에 얼마나 접근하는가? 근거량 처리와 대중성·사용자 반응 정보를 추가하면 실제 별점 예측이 개선되는가?

사용자에게 설명한 [설계](../../plans/als-reference-cold-item-comparison.md)를 다음처럼 구체화한다. 기존 REC047 결과·코드·봉인은 수정하지 않는다. 원자료·학습 산출물은 outputs 아래에 남긴다.

## 고정 비교

| 조건 | 입력 차이 | 비교로 답하는 것 |
| --- | --- | --- |
| BASE, 168열 | REC047의 원래 장르·인물·기타 관계와 입력 별점 | 기준 콘텐츠 표현 |
| SUPPORT, 200열 | 근거량에 따른 별점 반응 수축과 가중집중도·reliability | 수축+근거량 표현 묶음의 효과 |
| CROWD_ITEM, 206열 | SUPPORT + 후보의 TMDB 평균 평점·평가 수·popularity와 유효 표시 | 외부 영화 대중 지표 추가 효과 |
| CROWD_RESPONSE, 230열 | CROWD_ITEM + 사용자 입력의 대중성 분포·별점 반응 요약 | 개인 입력 분포+반응 프로필 추가 효과 |

각 조건에서 FM·공유 리지·Spark GBT를 같은 목표 평점으로 학습한다. ALS는 기존 100% 학습 요인을 검증 후 재사용하며 새 입력으로 fold-in한다. 혼합이나 ALS 출력으로 학습하는 증류는 하지 않는다.

모델 설정은 REC047의 전체 학습량 설정으로 고정한다. 새 튜닝이나 모델 선택을 하지 않으므로 검증 시점 모델 12개를 반복 학습하지 않는다. **2023-01-01 기준으로 콘텐츠 12개를 학습**한다. 아래 V 영화 집합은 사용하지 않은 예약 집합이며, 이번에 성능 튜닝에 사용했다고 표현하지 않는다. 문법·합성 테스트·런타임 및 데이터 독립 검토를 실행 전 검증으로 수행한다.

## 데이터와 누수 차단

- 기존 학습/검증/평가 사용자 역할을 그대로 쓴다. ALS를 포함해 평가 사용자는 공동 학습에 넣지 않는다. 입력을 통한 fold-in/프로필 계산만 허용한다.
- 검증 전 기준 2022-07-05의 학습 평점 수로 영화 1–9 / 10–49 / 50+ 층을 나눈다. 각 층의 canonical TMDB ID를 SHA256(`cold-item-47|<id>`) 바이트 오름차순으로 정렬한다. 첫 floor(n/10)은 V, 다음 floor(n/10)은 E, 나머지는 W다. 검증 전 지원 0인 영화는 인위적으로 보류하지 않고 W로 둔다. 현재 카탈로그의 ML/TMDB ID는 각각 유일해야 한다.
- 참고 ALS는 해당 영화의 다른 학습 사용자 과거 평점을 유지한다. 콘텐츠 학습은 V와 E 영화 평점을 **학습 목표·입력 이력·평균·취향 통계 전체에서 먼저 제거**한 뒤 예제와 특징을 다시 만든다. 영화 단위 평균/평가 수를 콘텐츠에 역유입하지 않는다.
- 콘텐츠는 허용된 전체 과거 평점을 각각 한 번 목표로 사용한다. REC047과 같은 180일 학습 episode, 그 시작 전 최근 K 입력 및 사전 hash K 배정을 쓴다. 영화 차단 후 K와 이력을 재계산한다. K0 학습 비중도 별도 공개한다.
- 평가 입력은 W이고 참고 ALS 요인이 있는 영화의 기준 시점 전 최근 정확히 K=1/5/10/30편이다. 전 모델에 같은 입력을 준다. K0과 ALS 기본값은 이번 주 비교에 없다.
- 목표는 동일 평가 사용자가 2023-01-01 이상, 2023-06-30 미만에 실제 평가한 E 영화다. 같은 사용자·영화·시각 목록으로 전 조건을 평가하며 정답은 예측 봉인 후 대조한다. 기존 REC047 개발 정답 재사용임을 명시한다.
- 목표 목록의 시간·존재·개수만 준비에 사용하며 미래 별점 값으로 영화/사용자/seed를 고르지 않는다. 표본이 작아도 seed나 비율을 다시 탐색하지 않고 수와 불확실성을 보고한다. 평점 없는 영화는 UNKNOWN이다.
- 학습된 vocabulary는 없다. 전체 메타데이터의 실제 ID 교집합을 계산하며 다른 신규 ID를 같은 OOV로 합치지 않는다. 현재 TMDB를 사용한다는 정보 조건은 기본 특징에도 공개한다.

정답 값 없이 고정한 분할은 W 74,565편 / 예약 V 5,476편 / 목표 E 5,476편이다. 실제 관측이 있는 주 비교는 K1 118명·482건·317편, K5/10 117명·461건·312편, K30 113명·450건·309편이다. 목표가 두 편 이상인 사용자는 각각 78/77/77/74명이며 실제 다른 별점 쌍이 있는 인원은 개봉 후 집계한다. 순서 지표와 세부 집단의 검정력이 제한될 수 있지만 이 표본 수를 보고 mask/seed를 바꾸지 않는다.

## 근거량 처리와 대중성 특징

7개 관계 묶음에서 입력과 후보의 정규화 ID 교집합 유사도를 w라 한다. 고정 λ=5를 사용한다(서비스 확정값/최적값 아님).

- 가중집중도 `neff=(Σw)²/Σw²`, 무연결은 0. 독립 표본 수나 검증된 신뢰 확률이 아니다.
- 유사도 질량의 reliability=`Σw/(Σw+5)`.
- 원별점 반응은 `(Σw*r+5*사용자입력평균)/(Σw+5)`로 입력 평균 쪽으로 수축한다. 상대 반응은 `Σw*(r−입력평균)/(Σw+5)`다. 무연결 원별점 요약은 기존처럼 0 + 별도 no_link 표시를 유지한다. 단순 연결 평균도 연결 수+5로 같은 방식 적용한다.
- 장르별 별점 요약은 해당 장르 입력 수/(입력 수+5)로 사용자 입력 평균 쪽으로 수축한다. 연결편수 자체는 기존 fraction과 K에서 복원 가능하므로 새 관측 정보가 늘었다고 표현하지 않는다.

대중성 원천은 `metadata.parquet`의 **2026-08-31~09-05 UTC** TMDB 수집본이다. 엄격한 과거 시점 재현이 아니다. 다음 원값과 결측을 원본에서 변경하지 않고 모델 입력에서만 변환한다.

- 평균 평점: 유한한 0<값≤10이고 평가 수>0일 때 유효, /10. 평가 수는 유한한 ≥0일 때 유효, log1p/ log1p(100000), 상한 1. popularity도 유한한 ≥0, log1p/log1p(1000), 상한 1. 범위는 점수 확인 전에 고정한다.
- 결측은 값 0과 별도 유효 표시로 표현한다. count0이나 popularity0을 싫어요로 취급하지 않는다. avg 존재/count0 9편과 avg 결측/count>0 12편도 이 규칙으로 처리하며, 결측을 이유로 모델별 다른 행을 쓰지 않는다.
- 사용자 반응은 각 지표별 유효 입력에서 계산한다. 입력 유효 비율·평균·분산·n/(n+5)·수축 공분산·후보와 입력 평균의 차이·차이×공분산·입력 존재 표시의 8개다. 공분산=`Σ(z−z평균)*(r/5−r평균/5)/(n+5)`. 입력 0/1편 또는 지표 분산 0이면 반응 공분산은 0이다. 후보 지표가 결측이면 차이와 교차값은 0이다.
- CROWD_RESPONSE는 별점 반응만의 인과 효과가 아니라 입력 분포와 반응을 함께 추가한 효과다. 개인마다 고정 비율 가중치를 따로 학습하는 구조는 아니다.
- CROWD 조건은 **MovieLens 학습 평점은 없지만 외부 영화 집계 평점은 있는 상황**이다. “아무 평가 정보도 없는 영화” 또는 2023년에 알려진 대중성이라고 표현하지 않는다. [TMDB popularity 설명](https://developer.themoviedb.org/docs/popularity-and-trending)

## 채점과 판단

- 동일 관측 목록에서 사용자별 실제 MSE(예측만 0.5–5 제한)와 선호 순서 정확도 PA를 구한다. 사용자 평균을 주 보고로 쓴다. 실제 별점은 원래 0.5 단위다.
- ALS 재현도는 원래 점수와 MAE, ALS 순서 일치율이다. ALS를 정답이나 상한으로 취급하지 않는다.
- 순서 지표는 기준 차이≤1e-12인 쌍 제외, 후보만 동점이면 0.5점이다. 비교 쌍이 없으면 결측과 해당 인원을 공개한다.
- K10/30의 세 인접 조건 차이×3모델×2K×2실제 지표=36개를 한 family로 Bonferroni 보정한다. 모든 콘텐츠 조건 대 ALS는 48개 별도 family다. 사용자 단위 짝 차이, seed47 20,000회 percentile bootstrap을 쓴다. 유효 사용자 30명 미만은 구간을 내지 않고 기술 통계로 표시한다. 기준 30은 검정력 보장이 아니다.
- K1/5 및 common-K30, 사용자 활동량×영화 지원량은 기술 분석이다. 각 수치의 사용자·영화·관측 수·유효 쌍 수를 공개한다. 사용자 재표집 구간은 이번 고정 영화 집합에 조건부다. 여러 영화 보류 분할을 했다고 표현하지 않는다.
- 개선은 해당 인접 비교의 보정 구간이 유리한 쪽에 있을 때만 확인한다. 두 실제 지표가 엇갈리면 단일 승자 확정은 보류한다. 차이가 안 잡히는 것을 동급으로 부르지 않는다. ALS 근접/초과와 한국 서비스 채택도 구분한다.

## 실행과 검토

1. 출처 해시, label-free 영화 분할과 실제 가용 표본을 고정한다.
2. 실행 코드·합성 테스트·공통 O/E·차단·특징·자원 제한을 독립 검토하고 fingerprint를 기록한다.
3. 데이터 준비 후 원본 허용 행과 특징을 독립 검산한다. 불일치가 있으면 학습 전 수정·재검토한다.
4. 실제 Spark 4.1.3, 기존 Docker image, local[4], JVM8GiB, 컨테이너12GiB, 네트워크 없음으로 한 번에 한 모델을 학습한다. 1fit 제한 3600초. 런타임 실패는 성능 열위가 아니다.
5. 모든 예측을 봉인하고 기존 개발 정답과 대조한다. 별도 검토자가 누수·수치·주장을 검산한 뒤 사람이 읽을 결과표와 결론을 남긴다. 신규 최종 검증, 전체 카탈로그 Top-N, 2026 한국 사용자 품질, 최적 튜닝/수렴을 주장하지 않는다.
