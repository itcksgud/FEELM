# REC043 — 분류와 사용자 별점의 선호 관계

상태: DRAFT — 실행 전 고정 설계. Jira [S15P21E106-309](https://ssafy.atlassian.net/browse/S15P21E106-309).
2026-09-08. 제품 정책 계약이 아니다.

## 질문과 판단 범위

사용자가 평가한 영화들을 분류했을 때, 많이 평가한 분류와 높게 평가한 분류가 어떻게 다른가?
같은 분류 안에서 선호가 얼마나 섞이며, 일부 별점에서 읽은 분류 선호가 가린 별점에서도 유지되는가?

추천 목록·ALS 순위·발견 정책 없이 분석한다. 개선 장르 규칙8개, 고정 장르 K-means8개,
TMDB 원본 내용 장르18개를 비교한다. TMDB는 복수 장르를 허용하므로 단일8분류와 자유도와
표현 방식이 다르다. K-means 알고리즘만의 우열이나 최적 군집 수 실험으로 해석하지 않는다.

REC042와 기존 결과·봉인은 그대로 보존한다. 현재 개발 자료를 다시 쓰는 탐색적 검증이며,
새로운 독립 확인 표본·실제 서비스 만족도·취향 인과 효과를 측정했다고 하지 않는다.

## 자료와 선호 접근 순서

- 사용자2,180명의 기존 O30(65,400쌍)을 입력으로 유지한다. 별점0.5~5.0·간격0.5다.
- 기존 E191,933쌍 중 TV-only1쌍을 제외한191,932쌍을 세 표현의 공통 검증으로 쓴다.
  O/E는 겹치지 않는다. ALS Factor 지원 여부는 제외 조건이 아니다.
- 장르 어휘에서 TV Movie10770은 내용 장르가 아니므로 원 장르 기준선에서 제외한다.
  KM은 기존 배정을 그대로 쓰며 새 군집 학습·8맛 이름/색상 확정은 하지 않는다.
- 원별점과 학습 사용자 전용 영화별 Bayesian 평균 b_i를 사용한다. 기존 학습 사전 개수50을
  유지하고 학습평점 없는 영화는 학습 전체 평균으로 대체한다. 해당 O8쌍/E779쌍을 공개한다.
  학습 사용자46,376명과 평가 사용자 겹침0은 기존 준비 봉인으로 확인한다.
- 입력 O와 분류·학습 영화 평균만 읽어 진단값을 계산하고 `prediction-seal.json`으로 봉인한다.
  그 후 E의 원별점을 읽는다. 전체 H 기반 Q는 입력 계산과 검증 모두에 사용하지 않는다.

## 같은 고정 진단식

입력 영화의 분류 참여 가중치 X는 단일분류1, TMDB는1/내용 장르 수다. 영화 한 편의
총질량은1이며 복수 장르를 독립 영화 여러 편으로 세지 않는다.

1. 원별점 기준은 O30 평균이다. 원별점 편차는 `r_O - mean(r_O)`다.
2. 영화 평균 보정 기준은 `b_E + mean_O(r_O-b_O)`다. 보정 편차는
   `r_O-b_O-mean_O(r_O-b_O)`다.
3. 두 편차 각각에 분류 효과 `d_g = sum_O(X_g*편차)/(sum_O(X_g)+5)`를 구한다.
   5는 이번 진단에 고정한 수축 강도다. 다섯 편 분량의0편차를 더해 희소 분류의 극단값을
   줄인다. 데이터나 결과로 선택한 값, 서비스 기본값, 입력 개수 권장이 아니다.
4. E의 분류 추가값은 `sum_g(X_Eg*d_g)`다. 각 기준에 이 값을 더해 가린 별점을 설명한다.
   입력에 없는 분류는 효과0으로 돌아가며 불호로 처리하지 않는다. 예측값을 실제 감상 별점으로
   저장하거나0.5 단위로 반올림·범위 clipping하지 않는다.

TMDB 복수 장르는 같은 총질량이 나뉘므로 분류별 지원과 수축 효과도 다르다.
동일한 고정 진단식에서의 표현 비교이며 최적 모델을 비교한 것이 아니다. 계수·정규화·O30·E를
결과에 맞춰 바꾸지 않고 새 ALS/회귀 모델 탐색을 추가하지 않는다.

## 주 검증과 불확실성

각 사용자 E의 모든 영화에서 영화 평균 보정 기준의 MSE에서 분류 추가 MSE를 뺀다.
양수면 분류가 가린 별점을 더 잘 설명한다. 단위는 별점²다. 사용자별 평균을 먼저 구하고
2,180명을 동일 가중으로 집계한다. 추천 적중률이나 정확도%로 바꾸지 않는다.

세 표현의 ΔMSE3개가 주 비교 family다. 사용자 paired bootstrap20,000회,
seed20260909·PCG64·row-major int64 동일 재추출, linear percentile을 사용한다.
Bonferroni family95% 근사 구간의 양끝은1/120,119/120이다. 구간이0에 닿으면 방향 미판정,
전부양수면 개선, 전부음수면 악화다. n<2면 중단한다. 실용적 채택 한계는 합의하지 않았다.
부동소수점의 가짜 방향 판정을 막기 위해 분류 효과와 사용자별 주 ΔMSE의 절대값이
1e-12 이하이면 계산상0으로 처리한다. 합성 null 검토에서 확인한 수치 오차 처리이며
실용적 채택 한계가 아니다. 실제 E를 읽기 전에 고정한다.

영화 평균 보정 후 개선도 영화별 수축 평균의 추정 오차와 관측 선택 편향을 완전히 제거하지
못한다. 조건부 표본 변동 구간이며 실제 서비스나 모든 사용자로의 일반화를 보장하지 않는다.

## 보조 분석

모두 기술통계다. 별도 유의성·제품 승자 판정에 사용하지 않는다.

- **평가량:** O/E 그룹 지원0·1편 비율, 그룹별 참여 영화 수와 질량, 입력에서 못 본 분류의
  E 비율. E는 입력에 등장한 장르 질량이0인 ALL_UNSEEN, 1인 ALL_SEEN, 그 사이인
  PARTIAL_SEEN으로 나눈다. 층별 지표는 해당 층을 가진 사용자 macro 평균과 사용자/쌍 수를
  함께 제시한다. 참여 영화 수는 장르 사이에 겹칠 수 있어 총영화 수처럼 더하지 않는다.
- **분포와 혼재:** O+E의 원별점0.5별 질량, 사용자 안에서의 평균 대비 그룹 별점 차이,
  같은 그룹의 표준편차. 사용자-그룹 질량5 이상에서 그 사용자 전체 평균보다 높은/낮은
  별점이 둘 다 있는 비율을 구한다. 사용자 전체 평균은 이번 공통 O+E의 평균이며 H 전체
  이력을 뜻하지 않는다. 표준편차는 질량 가중 population SD, 질량5 경계와 동점은
  절대오차1e-12로 고정한다. 이5는 서술용 최소 분모이며 서비스 입력K가 아니다.
- **사람마다 다른가:** 위 조건의 그룹별로 본인 평균보다 높음/낮음/동점인 사용자 수를
  제시한다. 사람들의 표본 평균 차이만으로 취향이 확증됐다고 하지 않는다.
- **많이 평가와 좋아함:** O+E에서 질량5 이상 그룹 중 평가 질량 최대 그룹과 별점 평균
  최대 그룹을 비교한다. 두 최대가 모두 유일한 사용자만 일치율 분모에 넣고 동점·부족을 공개한다.
- **가린 별점의 방향:** 보정된 분류 추가값과 E의 `r-b_i`의 사용자 내 공분산, 원별점 기준
  ΔMSE, 사용자별 개선 비율, 입력에서 본 그룹/못 본 그룹의 결과를 제시한다.
- **타인 프로필 대조:** SHA256(`REC043-DONOR|user_key`)순서의 다음 사용자를 순환 donor로
  고정한다. 본인의 영화·사용자 기준값은 유지하고 타인의 보정 분류 효과만 넣은 경우와
  본인 효과를 비교한다. 자기 자신을 donor로 쓰지 않는다. 하나의 고정 교환 대조이고 인접
  비교에서 동일 프로필이 본인/타인에게 재사용되어 의존성이 생기므로 여기에 독립 사용자
  bootstrap CI를 붙이지 않는다.

O+E 서술 통계와 가린 E의 검증을 구분한다. 같은 자료의 최고 그룹 차이나 그룹 내 분산 감소를
독립 검증 근거로 쓰지 않는다. 결과는 ‘관계 있음’이라는 포괄적 문장 대신 확인된 신호와
미확인 범위를 나눠 적는다. 개선 미확인은 모든 가능한 선호 관계가 없다는 증명이 아니다.
