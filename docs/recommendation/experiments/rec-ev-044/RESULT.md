# REC044 결과 — 대중 평가 위에 개인별 취향 차이가 남는다

상태: DRAFT — 실제 실행 및 독립 결과 검산 완료. 2026-09-09. 개인 연구이며 제품 계약이 아니다.

**영화의 대중 평가와 사용자의 전반적인 별점 습관을 감안해도, 장르별로 더 좋아하거나 덜 좋아하는 경향이 다른 영화에서 반복됐다.** 키워드에도 작은 추가 설명력이 있었다. 다만 현재 8개 분류의 추가 개선은 확인되지 않았고, 장르에 키워드를 더하면 장르만 쓸 때보다 확실히 좋아지는지도 아직 미판정이다.

## 무엇을 확인했는가

사용자 2,180명이 입력으로 제공한 30편의 별점으로 개인 취향을 계산하고, 겹치지 않는 나머지 191,932개 별점에서 확인했다. 여기서 대중 평가는 **평가 사용자를 제외한 MovieLens 학습 사용자들의 영화별 보정 평균**이다. TMDB 평점이나 관객 수를 사용한 결과가 아니다.

먼저 영화별 대중 평균에 사용자가 전반적으로 후하거나 박하게 주는 차이를 더했다. 그 위에 장르·키워드·현재8분류에서 읽은 개인별 편차를 추가했을 때 가려 둔 별점을 더 잘 설명하는지 비교했다. 추천 목록은 만들지 않았다.

## 실제 다른 영화에서도 차이가 이어졌나

## 기본 평가 경향과 본인 프로필 대조

개인 평균 별점만 사용한 MSE는 1.033302, 영화의 학습 평균만 사용한 MSE는 0.964388, 둘을 보정해 합친 기준은 0.818115였다. 영화의 대중 평가가 설명에 도움이 되는 경향은 있지만, 사람들이 대중 의견을 보고 따라 했다는 인과 증거는 아니다.

본인의 영화 기준값과 별점 습관을 유지한 채, 취향 프로필만 타인 것으로 바꾼 기술 대조는 다음과 같다.

## 키워드의 범위와 누락

카탈로그85,517편 중 DF≥5 키워드가 없는 영화는23,575편(27.57%)이다. 다만 이번 관측 평가 영화에서는 누락이3,432/191,932쌍(1.79%)으로 훨씬 적다. 이 표본의 결과를 전체 카탈로그·신작에 그대로 확대할 수 없다. 유지한 키워드는10,818종이며 TMDB keyword ID다.

각 층에 해당하는 사용자 내 평균을 먼저 낸 기술통계다. 같은 사용자가 여러 층에 속할 수 있고 분모가 달라 층 평균을 합쳐 전체 MSE를 만들면 안 된다. 키워드가 없거나 공통 키워드가 없으면 키워드 단독 보정값은 정확히0으로 기준에 돌아간다.

## 이번에 내리는 판단

- **확인한 근거:** 대중 평가와 개인 별점 습관을 보정한 뒤에도, 장르와 키워드에서 읽은 개인별 패턴이 다른 관측 영화의 별점을 조금 더 잘 설명했다.
- **유지할 연구 방향:** 내부 취향 분석에서 원본 복수 장르 정보를 보존한다. 키워드는 추가 정보 후보로 남기되 장르에 반드시 합쳐야 한다고 확정하지 않는다.
- **보류:** 현재8분류를 개인화의 핵심 입력으로 채택하거나, 외부8맛을 내부 단일 분류로 강제하는 결정. 외부8표현 자체는 이번에 변경하지 않는다.
- **아직 결정하지 않은 것:** ALS를 바꿀지, 최종 추천·발견 정책, 온보딩 영화 선정과 K, 실제 서비스 표시용 예상 별점. 이번에는 ALS와 비교하지 않았다.

## 검증·재현과 한계

실행 전 두 독립 검토자 PASS, 13개 합성검사 통과, 별도 직접검산4개 통과 후 예측을 먼저 봉인하고 E를 열었다. 실제 실행은 32.547초, 최대 프로세스 트리 메모리 277,065,728bytes였다. Python3.12.5/NumPy1.26.4/SciPy1.15.2/pandas2.2.3. 독립 결과 검산은 전체 MSE/MAE·9개 대비·20,000회 bootstrap·18장르 전수표·키워드 층과 fallback을 통과했다. SHA로 고른64명/5,367쌍은 O만 사용하는 별도 primal SVD 계산으로 예측을 재현했다. [감사 기록](result-review.json)을 남겼다.

기존 REC043의 1.70%와 이번 장르2.04%는 서로 다른 진단식 결과다. 이번에는 모든 표현에 같은 residual ridge와 정규화를 적용했고 같은 개발 표본을 재사용했다. 새 독립 표본에서 성능이 상승했다는 뜻이 아니다. 결합은 두 블록을 각각1/√2로 사용해 키워드가 없는 경우에도 장르 norm²가0.5다. 장르 단독과 결합의 차이에는 키워드 정보뿐 아니라 정규화·수축의 차이도 포함된다.

영화 평균은 추정값이고 관측할 영화의 선택 편향이 남는다. 현재 TMDB 스냅샷과 전체 카탈로그 DF/IDF를 쓰므로 과거 시점의 미래 예측 검증이 아니다. 한국 서비스 사용자·TMDB 집계 평점·KOBIS 관객 수·실제 추천 만족도에 대한 결론은 아니다.

완료 결과만 다시 확인하는 명령은 `py -3.12 -B -X utf8 scripts/verify_rec_ev_044.py`다. 모델을 다시 학습하거나 파일을 쓰지 않고 봉인·MSE/MAE·20,000회 bootstrap·키워드 층을 검증한다.
