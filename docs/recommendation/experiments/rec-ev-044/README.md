# REC044 — 대중 평가를 감안해도 개인의 장르·키워드 취향이 반복되는가

상태: DRAFT — 실행 전 고정 설계, 개인 연구. 2026-09-09. 제품 계약이 아니다.

## 사용자가 판단할 질문

영화에 대한 대중 평가와 개인의 후한/박한 별점 습관을 감안한 뒤에도, 특정 장르나
소재를 더 좋아하는 개인별 경향이 다른 영화에서 반복되는가? 현재 8개 분류가 그 차이를
담아내는가? 관계의 존재를 먼저 분석하며 추천 목록을 생성하거나 정책을 채택하지 않는다.

확정 조건은 실제 별점 0.5~5.0의 0.5 간격, 미평가 UNKNOWN, 외부 팝콘 표현은 8개 구상,
개인 연구의 로컬 검증과 결론 정리다. 내부 표현·취향/발견 정책·전환 K는 미확정이다.
이번 입력 30편은 기존 비교 조건이며 서비스 온보딩 K로 결정하지 않는다.

## 자료와 경계

- REC043과 동일한 평가 사용자 2,180명, 알려 준 O30 총65,400쌍, 숨긴 E191,932쌍.
  E는 이미 평가한 영화의 별점을 가린 것이며, 보지 않은 영화나 향후 평가가 아니다.
- 학습 사용자46,376명과 평가 사용자 겹침0인 기존 REC032 준비 자료를 재검증한다.
  영화별 기준은 학습 사용자 전용 MovieLens Bayesian 평균 b_i(기존 prior50)다.
  학습평점 없는 영화는 학습 전체 평균으로 대체하며 O8/E779쌍을 남긴다.
- REC033 카탈로그85,517편의 TMDB 장르/keyword ID 스냅샷을 사용한다.
  키워드는 TMDB 소재 태그이며 MovieLens 자유 태그나 Tag Genome이 아니다.
- 원본18개 내용 장르는 복수 참여, TV Movie10770 제외. 기존 REC040 규칙8 및
  REC039 KM_GENRE8 배정을 그대로 쓴다. 재군집·새 맛 이름/색상 결정은 없다.
- REC043의 공통 E 유지: TV-only1쌍 제외, ALS 지원 필터 없음. 키워드 결측으로 행을
  버리지 않는다. 원시 평점과 개인별 결과는 outputs 아래 LOCAL_ONLY다.
- 같은 개발 표본을 재사용하는 탐색 분석이다. 현재 메타데이터와 전체 카탈로그 IDF는
  과거 시점 예측을 위한 정보가용성 검증이 아니다. 미래 예측/독립 확인 표본으로 표현하지 않는다.
- TMDB vote_average/popularity와 KOBIS 관객 수는 이번 개인별 편차 분석의 입력이 아니다.
  외부 집계값의 추가 설명력·한국 흥행과 취향의 관계는 측정하지 않는다.

## 실행 전에 고정하는 비교

기준 예상 별점은 `b_i + mean_O(r-b)`다. 각 사용자 입력의 잔차는
`z_O = r_O-b_O-mean_O(r-b)`다. 영화 평균과 개인의 전반적인 별점 습관을 먼저 뺀다.

비교 표현은 규칙8, K-means8, 복수 장르18, 키워드, 장르+키워드 다섯 개다.
규칙/KM은 one-hot, 장르는 binary multi-hot 후 영화별 L2 정규화한다. 키워드는
카탈로그 DF≥5인 ID만 유지하고 `idf=log((1+85517)/(1+df))+1`을 곱한 뒤 L2 정규화한다.
동일 영화의 중복 키워드는 한 번만 센다. 평점으로 단어를 선택하거나 상위 몇 단어로 자르지 않는다.
장르+키워드는 두 정규화 블록을 각각1/√2로 붙이며 전체 재정규화는 하지 않는다.
키워드 없는 영화는 해당 블록0이며, 결측을 불호로 처리하지 않는다.

모든 표현에 동일한 고정 residual ridge 진단기를 적용한다.

`alpha = (X_O X_O^T + 5 I)^(-1) z_O`

`개인 취향 추가값 = X_E X_O^T alpha`

추가값을 기준 예상 별점에 더한다. λ5는 사전에 정한 수축 강도이며 튜닝값이나 서비스
기본값이 아니다. 특성 행을 중심화하지 않아 키워드가 없거나 입력과 공통 키워드가 없으면
키워드 추가값은 정확히0으로 돌아간다. 원별점은 보존하며 예측값은 반올림/clipping하지 않는다.

REC043의 분류별 질량으로 나누는 식과 다르다. 고차원 키워드에 질량이 과도하게 분산되는
차이를 줄이기 위한 공통 진단기로 새로 비교하며, REC043 결과와 수치를 직접 이어 붙이지 않는다.
행 norm과 λ를 맞춰도 차원·중첩·정규화·지원 차이가 있으므로 알고리즘 일반의 우열은 아니다.

## 채점과 판정

- 각 사용자 E의 MSE를 먼저 구하고 2,180명을 동일 가중 평균한다. MAE는 이해를 돕는
  보조값이다. MSE 상대 감소를 추천 정확도 증가로 부르지 않는다.
- 사전 고정9비교: 기준 대비5표현, 결합 대 장르/키워드2개, 장르 대 규칙8/KM8 2개.
  표에서 ΔMSE는 오른쪽 표현이 좋아질수록 양수다. 모든 비교를 빠짐없이 보고한다.
- 사용자 paired bootstrap20,000회, PCG64 seed20260910, row-major int64,
  linear percentile, Bonferroni family95% 근사 구간: 양끝0.05/18,1−0.05/18.
  구간 전체양수=개선, 전체음수=악화, 0포함=방향 미판정. |Δ|≤1e-12는0.
  실용적인 채택 기준은 합의하지 않았으므로 작은 차이로 제품 채택을 선언하지 않는다.
- 같거나 개선이 없으면 해당 고정 표현/진단기의 추가 근거 부족으로 결론낸다.
  신호를 찾을 때까지 λ·키워드 조건·E·K·표현을 바꾸지 않는다.

보조 분석은 기술통계이며 별도 유의성 주장을 하지 않는다.

1. 개인 O평균만/영화 학습평균만의 MSE를 함께 제시해 기본 설명력을 보여준다.
2. 각 표현의 본인 프로필을 고정 타인 프로필로 바꿔 비교한다. REC043 SHA256 순환 donor를
   재사용하고 수신자의 b_i와 Ooffset은 유지한다. 사용자 간 프로필 재사용 의존성이 있으므로
   이 차이에 독립 사용자 CI를 붙이지 않는다. donor O와 수신자 E의 영화 중복 수도 공개한다.
3. 키워드 없음/있지만 O와 공통 키워드 없음/공통 있음 층의 사용자수·평가쌍수·MSE를 제시한다.
4. 18장르 모두에서 O와 E 각각 `r-b`를 해당 집합의 개인 평균으로 별도 중심화하고
   장르 참여1/장르수로 가중 평균한다. O질량≥2/E질량≥5인 사용자만 포함한다.
   O에서 장르 편차가 양수인 사람/음수인 사람의 E편차 평균과 사용자 수, O/E Pearson,
   양쪽0아닌 경우의 방향 일치 수를 남긴다. 공유 O평균 오차로 상관이 생기지 않게 별도 중심화한다.
   이 표의 E평균은 사후 설명에만 쓰고 예측에는 들어가지 않는다. 최고 장르만 골라 보고하지 않는다.

영화별 학습평균도 추정값이므로 그 오차와 평가할 영화 선택의 편향이 남는다. 본인 프로필의
추가 설명력만으로 순수 개인 취향의 인과 효과나 대중 의견을 따라 했다는 주장을 하지 않는다.
