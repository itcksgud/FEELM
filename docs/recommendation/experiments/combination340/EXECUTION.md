# 필요한 정보와 ALS 보조를 구분하는 비교

상태: DRAFT — 로컬 개발 비교 명세. 서비스 계약이 아니다. 2026-09-11.

foundation340의 독립 검토된 선택 S를 고정하고 추가 FM1·GBT1·ALS1만 학습한다.
기존339 텍스트 조건의 미확인 개선을 이유로 조합을 확대하지 않는다. 이전과 같은270명·O/J·시간·카탈로그를 유지한다.
이번 단계도 이미 사용한 개발 정답과 현재 TMDB의 비교이며 미사용 최종 test는 아니다.

## 정보의 역할을 나눠 비교

- **S**: 첫 단계에서 고정한230특징 FM.
- **NO_RESPONSE**: 동일 목표·이력에서 대중 평점/투표수/인기도에 대한 개인 별점 covariance와 response cross
  6열(210,212,218,220,226,228)만 제거한224특징 FM. 후보 지표·입력 분포·근거량 및 다른 취향 반응은 유지한다.
  명시적인6열의 필요성을 묻는 ablation이며 대중성 취향 전부를 제거했다거나 인과효과라고 말하지 않는다.
- **GBT**: S와 동일230특징·목표·이력의 Spark GBT, 기존 고정설정 depth5/60trees/step.05,
  maxBins32/sqrt feature subset/subsample.8. 다른 초모수 탐색은 없다.
- **ACTUAL_ALS**: C10,952편의 평점을 제외한 동일39,859명·4,997,069평점으로 rank32/reg.1/iter15 ALS 한 번.
  사용자 평가 역할은 분리된다. 사용자의 O를 그대로 받아 지원하는 입력만 fold-in하며 다른 영화로 보충하지 않는다.
- **REFERENCE_ALS**: 기존 C평점까지 학습한 REC047 item factors를 동일 O/J에 새로 fold-in한 참고선.
  정보를 더 아는 과거 모델이며 seed/학습 행 구성까지 완전히 통제한 인과적 상한은 아니다.

ALS fold-in은 지원 입력 factor Y와 실제 별점 r로 `(Y'Y + .1*n*I)^-1 Y'r`이다.
후보 factor가 없거나 지원 입력이0이면 **직접 점수 없음**으로 기록한다. 평균값을 ALS 예측으로 채점하지 않는다.
혼합은 직접점수가 있는 행에서 `(1-w)*S + w*ALS`, 나머지 행은 S와 정확히 같다.
고정w=.25/.5/.75/1을 비교한다. w=1도 미지원행은 콘텐츠인 라우팅이며 전체를 순수 ALS라고 부르지 않는다.
GBT 또는 NO_RESPONSE와 ALS의 추가 교차조합은 만들지 않는다.

## 통제·비용·검산

첫 단계의 입력·목표파일을 읽기 전용 재사용한다. FM/GBT는 같은 row_id hash partition8/내부 row_id 정렬,
AQEfalse, modelseed339를 쓴다. 실제 행 partition 해시가 첫 단계와 일치해야 한다.
ALS는 같은 허용 사용자·영화·평점에 시간조건을 다시 확인하고 학습한다. 영화 support는45,074개 예상이다.
고정 Spark 이미지/local4/CPU4/driver8GiB/container12GiB/network none, 각 프로세스5400초.
정상 종료·수치 검산과 엄격 자원 상한을 구분한다. 초과는 실제 bytes와 EXCEPTION, 실패는 결과 미확보로 남긴다.
새 seed·자원 증설·데이터 축소로 추가 학습을 늘리지 않는다.
cgroup v2/v1 메모리 최고값 경로를 차례로 확인하고 둘 다 없으면 계측값과 엄격 준수 여부는 UNKNOWN으로 남긴다.
선행 B의 학습 후 계측 오류는 보존·독립 검산한 모델을 재학습 없이 복구한다. 미확보 시간·peak를 추정해 채우지 않는다.
각 단계 평가 봉인의 실제 fit/catalog 부모와 별도 평가 코드·검토 지문을 연결해 확인한다.
학습 전 독립 코드/입력 검토, 실제 native/portable 모델과93,230행 점수 검산 후 예측을 봉인하고 채점한다.
전체 후보의 순위도 같은 개봉일·기시청 제외 규칙으로 계산한다. 이전 카탈로그 Top500을 입력 후보로 삼지 않는다.

## 결과 판정

학습평점0 영화의 단독 능력과 ALS의 추가효과는 서로 다른 질문이다.
공식6대조는 다음과 같다. 각 고정 집단에서 UID 정렬 paired bootstrap20,000회/seed340,
Bonferroni 양측99.1666667% 구간(가족 오류율.05)을 사용한다.

1. NO_RESPONSE−S와 GBT−S: H10 h>0의 **C 관측 후보 안에서** J_C≥2/IDCG>0 NDCG@2.
2. 혼합4조건−S: H10의 실제 ALS 직접점수가 존재하는 **W 관측 후보 안에서** J_W≥2/IDCG>0 NDCG@2.
후보는 고정 C∩J 또는 W_DIRECT∩J이며 영화 factor와 지원 O 존재로 직접 가능성을 판정한다.
모델별 Top 목록으로 사용자·후보를 다시 고르지 않는다. 유효 사용자가30명 미만이면 CI 및 자격 판정을 하지 않고 기술통계만 낸다.
자연지원0은 C와 합치지 않고 별도 지표·분모로 남긴다.

두 집단의 평균 점수를 서로 나란히 놓고 동급으로 판정하지 않는다. 직접ALS, 콘텐츠, 혼합을 같은 W 대상에서 비교한다.
C에서는 혼합이 S와 정확히 같다는 것을 수치로 확인하며 혼합의 전체 개선을 C 추천 능력의 개선으로 부르지 않는다.
참고ALS는 C/W에서 직접점수 가능한 동일 후보·사용자에 대한 실제 별점 품질 및 순위 일치도를 기술통계로만 낸다.
ALS 순서 자체를 정답으로 쓰지 않는다. 지원 입력 수0과 후보 factor없음을 각각 집계한다.

후속 모델 자격은 각 primary NDCG 구간 하한>0와 ALL h>0/h0의 Top2 평균별점 손실≤.1점·
낮은별점 비율 증가≤3%p의 점추정 veto다. 콘텐츠 대안은 C에도 같은 veto를 적용한다.
콘텐츠의 C 점추정 veto는 h>0/h0 각각에 적용한다.
자격이 없으면 S를 유지한다. 자격 후보와 S 중 공통ALL h>0 NDCG2 점평균 최대를 다음 정책 단계에 고정한다.
정확한 동률의 고정 우선순위는 S→NO_RESPONSE→GBT→낮은ALS비중이다.
이는 개발 단계의 선택 규칙이며 각 후보 간 우월성·안전성 보장이 아니다. 실제 C/W 유효 인원은 따로 보고한다.
이 선택은 ALL 개선검정을 통과했다는 뜻이 아니다. 명목 보정구간은 앞 단계 S 선정 불확실성이나 학습 무작위성까지
교정하지 않으므로 전체 절차의 확증적 오류율 보장으로 표현하지 않는다.

Top2/4/6/10, 평균별점/낮음/좋음/Recall/오차/순서정확도, 실제h·활동량·지원량,
전체 후보의 UNKNOWN·지원 없는 영화·집중도·비용을 함께 정리한다. 후보 노출 확대 자체는 품질의 증거가 아니다.
이 단계의 모델을 정책 결과를 보고 다시 고르지 않는다. 최종 정책 결과로 단독 모델 우월성을 소급해 주장하지 않는다.
