# REC040 — 개선 규칙을 실제로 적용한 결과

상태: 실제 적용·독립 전수 검산·보고서 검토 완료, PASS. 2026-09-08. 개인 연구 자료.

**규칙만으로도 장르 순서에 따라 분류가 바뀌는 문제를 해결했다.** K-means와 비교할 때 첫 장르만
사용하는 기존 규칙 하나로 수작업 규칙 전체를 대표시키면 안 된다. 이번 개선 규칙은 그 비교 기준을 보강한다.
다만 사람이 정한 8개 묶음과 동점 우선순위의 영향은 남았으며 추천 품질의 승자는 아직 정하지 않았다.

## 이번에 만든 규칙

영화의 전체 장르를 읽고 각 묶음과 겹치는 정도를 비교한다. 묶음에 속한 장르 종류가 많다는 이유만으로
유리해지는 영향을 줄이기 위해 묶음 크기도 보정했다. 장르 순서와 중복은 무시한다.
동점이면 사전에 정한 코드 순서로 하나를 고르고, 동점 후보를 모두 기록한다.

8개 묶음은 기존의 액션·모험 / 드라마·로맨스 / 코미디·가족 / 역사·전쟁·서부 /
다큐멘터리 / 음악 / 범죄·공포·미스터리·스릴러 / 애니메이션·판타지·SF를 유지했다.
이 묶음의 의미 자체를 재설계하거나 장르별 가중치를 튜닝한 실험은 아니다.

정확한 식은 [고정 설계](README.md)에 있다. 알려진 내용 장르의 binary cosine을 사용하며,
분수로 계산해 반올림이 동점을 깨지 않게 했다. 좁은 묶음이 상대적으로 유리해지는 설계 가정도 함께 공개한다.

## 같은 85,517편에서 달라진 것

| 확인한 동작 | 기존 첫 장르 규칙 | 개선 전체 장르 규칙 | 고정 장르 K-means |
| --- | ---: | ---: | ---: |
| 장르 순서를 반대로 넣었을 때 그룹이 바뀐 영화 | 42,504편 (49.7%) | 0편 | 0편 |
| 관측된 같은 장르 집합 안에서 배정이 갈린 집합 | 1,093 / 2,402 | 0 / 2,402 | 0 / 2,402 |
| 내용 장르가 있는 영화의 지원 | 85,505편 | 85,505편 | 85,505편 |
| 실제 사용된 그룹 수 | 8개 | 8개 | 8개 |

반전은 전체 순열 검사는 아니다. 개선 규칙의 일반적인 순서 불변성은 집합 계산과 합성 순열 검사로도 확인했다.
같은 집합 안에서 배정이 갈린다는 값은 순서가 달리 저장된 영화들의 메타데이터 비교이며 취향 정답 오류 수가 아니다.
나머지12편은 TV Movie 형식 정보만 있다. 두 규칙은 미지원이고 기존 KM은10770좌표로 배정한다.
따라서 KM의 전체85,517배정을 내용 지원에서12편 더 우수한 것으로 세지 않았다.

기존 규칙과 개선 규칙의 의미 그룹이 달라진 영화는 **22,819 / 85,505편 (26.7%)**이었다.
공통 입력을 읽는 방식이 실제 배정에 영향을 주었음을 보여주며, 이만큼 정답이 늘었다는 뜻은 아니다.

## 동작은 개선했지만 남은 판단

개선 규칙에서 **14,245 / 85,505편 (16.7%)**은 최고 점수가 동점이었다.
13,690편은2개 묶음,555편은3개 묶음이 동점이라 고정 우선순위가 마지막 결정을 했다.
이것은 규칙의 계산상 동점 수이며 K-means의 내용 모호성과 같은 척도로 비교한 수치가 아니다.

저장된 모델·규칙으로 실제 실행한 예시는 다음과 같다.

| 장르 입력 | 기존 규칙 | 개선 규칙 | 장르 K-means |
| --- | --- | --- | --- |
| 코미디 → 드라마 | 코미디·가족 | 드라마·로맨스, 동점 후 선택 | 07 코미디 그룹 |
| 드라마 → 코미디 | 드라마·로맨스 | 드라마·로맨스, 동점 후 선택 | 07 코미디 그룹 |
| 드라마 → 범죄 → 스릴러 | 드라마·로맨스 | 범죄·공포·미스터리·스릴러 | 03 스릴러·범죄 중심 그룹 |
| 음악 → 범죄 → 스릴러 | 음악 | 음악, 동점 후 선택 | 03 스릴러·범죄 중심 그룹 |
| 음악 → 범죄 → 스릴러 → 공포 | 음악 | 범죄·공포·미스터리·스릴러 | 03 스릴러·범죄 중심 그룹 |

KM의 표시 설명은 기존 장르 구성 요약이며 공식 맛 이름이 아니다. 규칙과 같은 숫자 그룹이 같은 뜻인 것도 아니다.
코미디·드라마를 어느 쪽에 넣을지가 중요하다면 사람이 정한 묶음과 동점 기준을 검토해야 한다.
이번 결과를 보고 그 우선순위를 다시 바꿔 더 좋은 숫자를 만드는 작업은 하지 않았다.

## 개선 규칙의 8개 묶음

| 묶음 | 배정 영화 수 |
| --- | ---: |
| 액션·모험 | 10,446 |
| 드라마·로맨스 | 32,522 |
| 코미디·가족 | 12,526 |
| 역사·전쟁·서부 | 1,675 |
| 다큐멘터리 | 9,933 |
| 음악 | 2,099 |
| 범죄·공포·미스터리·스릴러 | 12,783 |
| 애니메이션·판타지·SF | 3,521 |

가장 큰 드라마·로맨스 묶음에 지원 영화의 **38.0%**가 모였다. 기존 규칙의 가장 큰 그룹은29.8%,
KM은 전체 배정 영화 중15.0%였다. 그룹 크기 보정이 영화 수를 균등하게 만드는 보정은 아니다.
균등하다고 좋은 취향 분류라는 기준도 세우지 않았다. 장르 비율과 고정 hash로 고른32행의 영화 사례는
[전체 구성·사례표](../../../../outputs/recommendation-evidence/rec-ev-040/GROUPS.md)에 있다. 사례에는 중복 영화가 있을 수 있다.

내용 장르가2개 이상인55,200편에서 하나씩 제거한143,152개 변형 입력도 비교했다.
배정 변화는 기존42,865건(29.9%), 개선50,378건(35.2%), KM49,947건(34.9%)이었다.
하나라도 배정이 바뀐 영화는 각각42,865 / 40,554 / 46,678편이며 분모는55,200편이다.
장르를 지우면 내용 정보가 달라지므로 변화가 적을수록 좋다는 점수가 아니다. 35.2%와34.9%로 동등성을 주장하지 않는다.
구조 대응표와 ARI도 보존했으며 서로 비슷하게 묶이는 정도이지 정확도가 아니다.

## 검증과 다음 비교

별도 검수자의 설계·코드9파일 fingerprint PASS와 합성 검사9개 통과 후 실제 실행했다.
기존 두 후보의171,034배정을 재현하고 새85,517배정,456장르 구성 행,192대응표 행,
가중치가 있는72,996개 삭제 변형 기록과 합성14입력×3방법 예시를 저장했다.
계산·종료 검증 단계3.09초, 감시 최대 프로세스 메모리422.3MiB였다. 실행 전 원천 검사 시간은 제외했다.
원천6개 pin·이전 봉인·당시 master 문서5개를 보존했으며 독립 전수 결과 검산과 보고서 검토가 모두 PASS했다.
필수 수정사항은0건이며 최종 확인 기록은 [result-review.json](result-review.json)에 있다.

알려지지 않은 장르는 별도로 표시하고 아는 내용 장르로만 계산한다. 새 규칙은 TV+미지 장르만 있을 때도
내용 근거 없음으로 미지원한다. 기존 KM은 이 경우에도 알려진TV좌표로 부분 어휘 배정할 수 있어 내용 적절성을 보장하지 않는다.
추론 코드는 [feelm_genre_set_rule.py](../../../../scripts/feelm_genre_set_rule.py)에 있다.

**다음 추천 비교에는 이 개선 규칙을 포함해 장르 K-means와 비교한다.** 기존 첫 장르 규칙은 변경 원인을
확인하는 대조 자료로 보존한다. 순서 의존 문제가 고쳐졌다는 이유로 개선 규칙의 추천 품질을 승자로 선언하지 않는다.
같은 ALS·맞춤2/발견1 조건의 연결과 공급은 별도 실행이며 REC034의 기존 텍스트 KM 수치를 옮기지 않는다.
이번 작업은 개선 규칙 적용·검증까지다. 새 fit·128편 재채점·평점 접근·추천 슬롯 계산은 없으며
공식 K-means 계약·외부8맛·맛 이름/색상·실제 별점0.5단위를 바꾸지 않았다.
