# 결과를 해석할 때 필요한 범위와 한계

실제 결과의 보충 설명이다. 제품 정책 계약이 아니다.

## 결과를 읽기 전에

| 확인한 점 | 해석에 미치는 영향 |
|---|---|
| 학습 목표 약500만 개 중82.34%는 사용할 이전 입력이0개다. | 전체 향상이 영화 자체 정보의 효과일 수 있다. 곧바로 개인화 개선이라고 부르지 않는다. |
| 개인 입력이 있는 학습 목표는882,332개, 기여 사용자는8,245명이다. | 학습39,859명 모두가 개인 반응 학습에 기여한 것은 아니다. |
| 개발 사용자270명 중84명은 기준일 이전 입력이 없다. | 전체 결과와 입력이 있는 사용자 결과를 함께 봐야 한다. |
| 새로 복원한7편은 평가자의 과거 입력·180일 관측후보에 없다. | 전체 연구 카탈로그에는 남아 있지만, 이7편의 추천 품질이나 결말 정보의 효과는 직접 판단할 수 없다. |
| 본문 변경92편 중 평가 후보에23편·53관측이 있다. | 정제 차이에 대한 근거는 제한적이다. |
| 현재 TMDB 날짜가 기준일보다 늦어도 그 전에 MovieLens 평점이 존재하는 사례가 있다. | 날짜 필터를 역사적 미개봉 판정으로 해석하면 안 된다. |

학습의 입력0 비중이 큰 이유는 **180일 묶음의 시작 전 별점만 입력으로 쓰기 때문**이다.
MovieLens에서 한 시기에 몰아서 남긴 평점은 같은 묶음의 입력으로 쓰지 않았다.
현재 네 조건은 이 규칙과 학습 행·가중치를 동일하게 유지한다. 성능을 본 뒤 바꾸지 않는다.
따라서 이번 판정은 이 고정 설정의 텍스트 추가 비교이며, 서비스 개인화 표현의 최종 우승이나
텍스트의 본질적 불필요를 뜻하지 않는다. 다음 정보 결합 단계에서는 서비스 입력분포와의
정합성을 설계할 때 이 차이를 먼저 반영해야 한다.

82.34%는 **학습 목표 행**의 비율이고, 84/270은 **평가 사용자**의 비율이다.
주 지표의 관측후보2편 이상 사용자만 보면 입력0은84/260명(32.31%)이다.
분모가 다른 비율을 그대로 맞춰 학습 가중치를 계산하지 않는다.
후속 단계의 선택지는 [입력 분포 검토 메모](../../plans/text-to-final-recommendation/training-input-distribution.md)에 남겼다.

현재 날짜 필터는 **최신 TMDB의 단일 release_date ≤ 2023-01-01**이다.
최초271명의314관측을 이 값으로 제외했으며, 평가에 남은270명에서는313관측이다.
그중5편·7관측은 기준일 이전 학습 관측도 있어 역사적으로 미개봉이었다고 단정할 수 없다.
Hamilton의 현재 날짜가2025년인데2021~2022년 입력이 존재하는 사례도 확인했다.
미래 평점이 유출된 것은 아니며, 재개봉 등을 구분하지 못하는 현재 메타데이터의 한계다.
고정 명세·코드의 `not_yet_released` 또는 '미개봉 제외'라는 표기는 **현재 TMDB 날짜 조건에서 제외**된
것으로 읽어야 한다. 과거 실제 공개일·국내 접근 가능성을 복원한 실험이 아니다.

## 무엇을 지켰나

- 현재 학습 사용자와 평가 사용자는 분리했다. 다만 평가 사용자는 과거 실험에서 이미 사용했으므로 새로운 최종 시험은 아니다.
- 이번 실행에서 평가자의 미래 MovieLens 별점을 학습·입력으로 사용하지 않았다. 하지만 최신 TMDB의 평점·투표 수와 Wiki를 사용하므로, 미래에 집계·작성된 정보를 차단한 역사적 예측 시험은 아니다.
- C영화10,952편의 평점은 학습 목표·학습자의 개인 입력·학습 집계에서 모두 제외했다. 평가 사용자가 과거에 남긴 C영화 입력은 허용했다. H10에서는167명이395개를 입력했으며 네 조건 모두 같다.
- 실제 PCA에는 **C와 학습지원0 영화를 제외한 학습지원 영화의 텍스트**를 사용했다. 평가 후보 W영화도 학습지원이 있으면 포함된다. 고정 명세의 '평가/C영화는 PCA fit에서 제외'라는 문구는 이 실제 조건으로 정정해 읽어야 한다. 평가별점으로 PCA를 학습하지 않았다.
- 영화 ID와 벡터 연결을 전수 검산하고, 실제 GPU 계산도 원래 배치 조건으로 독립 재현했다.
- 관측후보 안의 순위 품질과 전체 연구 카탈로그의 UNKNOWN 비율을 별도로 계산한다. 미평가를 싫어요로 취급하지 않는다.
- 조건당 고정seed로 한 번 학습한다. 사용자 재표집 구간은 사용자 표본의 변동을 다루며, 학습seed나 최적화의 변동까지 포함하지 않는다.

## 자원 예외와 고정 보고서의 해석

- T2의 컨테이너 관측 최고값은12,884,901,888바이트로12GiB 상한에 도달했다.
- T3의 관측 최고값은12,884,905,984바이트로 설정12GiB보다4,096바이트 높다.
  엄격한 관측 최고값 상한 검사는 FAIL이다. 임계값을 완화하거나 재학습하지 않았다.
- 두 조건 모두 실행은 완료했지만 자원 여유를 입증하지 않았다. 모델 수식 검산 PASS와 자원 준수를 구분한다.
- 자동 생성 RESULT의12.00GiB 표시는 반올림이다. 이 숫자로 T3의 엄격한 상한 준수를 주장하지 않는다.
- 자동 생성 RESULT의 주표는 H10 기준이다. Top2 세 지표는260명, MSE는270명, 별점쌍 순서 정확도는255명으로 분모가 다르다.
- 최적화 이력은 저장하지 않아 수렴을 독립 확인하지 못했다. 고정 설정에서의 조건 비교다.
- 관측후보 날짜 조건은2023-01-01, 전체 카탈로그 날짜 조건은2026-09-10이다.
  두 조건 모두 최신 TMDB의 날짜를 사용했다. 최초 공개일이나 국내 OTT 접근성을 복원하지 않았다.

실제 모델/벡터/카탈로그 검산 기록과 작은 배치 재계산 차이 등 보조 검사의 한계는
[결과 검토](result-review.json)와 연결된 세부 검토를 따른다.

## 사후 진단: 투표가1개인 영화로 노출이 몰린 현상

전체 카탈로그의 사전 노출 집중도 진단 후, 추천된 영화와 고정 TMDB 메타데이터를 연결했다.
아래 분해는 사후 확인이며 텍스트 채택 기준을 바꾸거나 별도 유의성을 주장하는 데 사용하지 않았다.

| 조건 | TMDB 투표1개·평균10점 노출 /전체540슬롯 | 입력 있는 사용자372슬롯 중 비율 | 특정 두 영화 합계 |
|---|---:|---:|---:|
| T0 | 346 | 93.01% | 252 |
| T1 | 371 | 99.73% | 238 |
| T2 | 367 | 98.66% | 321 |
| T3 | 368 | 98.92% | 317 |

이 노출은 전부 입력 있는186명에게서 발생했다. 입력 없는84명의168슬롯에서는0개다.
특정 두 영화는 Drawn from Memory(ML239496/TMDB266555), Pitkä vaihto(ML278338/TMDB554863)이며
사용한 스냅샷에서 둘 다 평균10점·투표1개였다. 같은 영화의 실제 현재 평점이나 품질을 단정하지 않는다.

현재270명의 실제180일 평가 라벨과 Top10을 다시 연결한 독립 검산에서도
입력 있는186명의 Top2 372슬롯은 네 조건 모두 별점이 없었다.
전체에서 알려진74/25/24/24슬롯은 모두 입력 없는 사용자에게서 나왔다.
따라서 전체 카탈로그의 개인화 Top2 만족도는 이 자료로 직접 채점하지 못했다.
관측후보 안의 입력 있는176명 비교와는 후보·분모가 다르다.

이것은 입력0 학습 비중 때문에 생겼다는 인과적 증거가 아니다.
대중 평점의 근거량과 개인 반응의 상호작용을 다음 설계에서 점검할 구체적인 현상이다.
희귀 영화의 실제 품질을 나쁘다고 취급하거나 임의의 최소 투표 수를 적용하지 않는다.
[실제 라벨·메타데이터 진단 검산](report-result-review.json)에 출처와 재계산 범위를 보존했다.
