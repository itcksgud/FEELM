## 채점·선정 — 결과 개방 전 고정

- 주 지표 H10, J>=2 사용자의 graded NDCG@2. gain=(r-.5)/4.5, log2discount,
  IDCG0은 결측. 동률은 movie_id 오름차순. 점수 예측이 범위를 벗어나도 순위는 원점수를 쓰며
  MSE/MAE만 [.5,5]로 자른 값과 원값을 별도 보고한다.
- 보조 Top2/4/6/10의 평균 별점,좋음>=4 Hit/Precision/Recall,낮음<=2 비율/한편이상낮음,
  사용자 평균 MSE/MAE/다른 별점쌍 순서. N마다 J>=N과 공통J>=6을 구분한다(공통6은Top2/4/6만).
  PA는 실제별점동률 제외, 예측동률0.5점. IDCG0은NDCG만,좋음0은Recall만 결측이다.
  비유한 예측은 사용자삭제로 숨기지 않고 실패시킨다. h=0도H10에 포함돼 전체 개선을 개인화 개선으로 단정하지 않는다.
