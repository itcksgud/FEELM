# 줄거리·Wikipedia를 더하면 추천이 나아지는가

상태: 로컬 실험·독립 수치 검산·결론 정리 완료(메모리 상한 예외 별도). 서비스 모델 확정 문서가 아니다.

**이번 고정 설정에서는 텍스트를 추가하지 않은 T0를 유지한다.**
줄거리나 Wikipedia를 더해서 좋아졌다는 근거를 얻지 못했다.
텍스트가 원래 쓸모없다는 결론이 아니라, 이번 학습 방식에서 추가 비용을 정당화하지 못한 결과다.
다만 **전체 카탈로그의 개인화 추천에서 별도 문제가 확인돼 T0도 서비스 추천안으로 확정하지 않는다.**

## 네 조건을 비교하면

같은 FM 설정·학습 평점·평가 사용자·후보를 유지했다. 입력은 최대10편이며,
관측후보2편 이상인260명 안에서 각자가 나중에 실제 평가한 영화의 순위를 비교했다.

| 조건 | 추가한 정보 | 순위 점수 NDCG@2 ↑ | 상위2편 평균 별점 ↑ | 2점 이하 비율 ↓ | 학습 시간 |
|---|---|---:|---:|---:|---:|
| **T0** | 구조화 정보·사용자 반응 | **0.8450** | **3.985** | **4.42%** | **18.7분** |
| T1 | T0 + TMDB 줄거리 | 0.8368 | 3.941 | 5.38% | 40.8분 |
| T2 | T1 + Wiki 기본 정제 | 0.8320 | 3.925 | 5.58% | 62.4분 |
| T3 | T1 + 검토한 Wiki 본문 복원 | 0.8338 | 3.931 | 5.19% | 60.3분 |

실제 별점은0.5단위이며 표는 그 평균이다. 점수가 높을수록 실제 높은 별점의 영화를 앞에 놓았다.
T1−T0의 순위 점수 차이는−0.0082, 보정98.333% 구간은[−0.0209, +0.0041]이다.
개선 구간의 하한이0보다 높아야 한다는 사전 조건을 통과하지 못해 첫 단계에서 채택을 멈췄다.
나머지 두 인접 비교도 구간에0을 포함했다. 유의한 악화나 동등함을 입증한 것으로 해석하지 않는다.

Top4·6·10의 NDCG 평균도 T0가 가장 높았다. 각 N의 사용자 수는237·218·192명으로 다르며,
이는 보조 비교다. 일부 다른 지표는 조건별 우열이 달라 모든 지표에서 T0가 우세한 것은 아니다.
[그림과 전체 지표](RESULT.md)에서 확인할 수 있다.

## 개인화나 새 영화에는 도움이 됐나

아래는 해당 사용자가 실제 평가한 영화 안에서 비교한 조건부 결과다.

- **입력 있는 사용자176명의 Top2에서도** T0 NDCG가0.8479로 가장 높았다.
  T1/T2/T3는0.8416/0.8369/0.8386이었다. 입력 없는84명만의 영향으로 전체 결론이 나온 것은 아니다.
- **학습 평점을 가린 C영화** 안에서는 T2 평균이 T0보다 약0.0009 높았다.
  이 작은 점추정만으로 별도 채택을 주장하지 않는다. NDCG 유효 사용자는194명이다.
- **원래 학습 평점이 없는 영화**는 Top2를 비교할 수 있는 사용자가45명뿐이었다.
  이 집단도 T0 평균이 가장 높았지만 근거 범위가 작다. Top4·6·10은30명 미만이다.

집단별 수치와 정확한 분모는 [해석 보충](INTERPRETATION.md)에 있다.
입력 유무가 다른 사람끼리 비교한 차이를 입력 효과로 부르거나, 위 비교를2026년 신규 영화 품질로 확대하지 않는다.

## 실제 전체 후보에서 뽑으면

이번에는 미래에 평가했는지로 후보를 줄이지 않고, 연구 카탈로그85,517편에서
알려진 과거 감상을 제외해270명에게 각각 상위2편을 뽑았다.

| 조건 | 실제 별점으로 채점할 수 있는 비율 | 540개 추천 슬롯에 등장한 서로 다른 영화 |
|---|---:|---:|
| T0 | 13.70% | 15편 |
| T1 | 4.63% | 8편 |
| T2 | 4.44% | 10편 |
| T3 | 4.44% | 10편 |

**채점할 수 없는 추천이 많고, 소수 영화에 추천이 집중됐다.**
채점 불가는 해당 사용자의180일 평가창에 그 영화의 별점이 없다는 뜻이다.
미평가는 싫어요가 아니며, 위의 조건부 순위 점수로 전체 추천 만족도를 확정할 수 없다.
이 결과만으로 현재 시스템을 서비스 추천안으로 확정하지 않는다.

입력 있는186명에게 추천한372슬롯은 **네 조건 모두 채점 가능한 별점이0개**였다.
위 표의 채점 가능한 추천은 모두 입력 없는84명에게서 나왔다.

또 사후에 노출 영화의 정보를 확인하니, 실험에 사용한 TMDB 스냅샷에서
**투표1개·평균10점인 영화가 입력 있는 사용자 추천의93.01~99.73%**를 차지했다.
네 조건의 해당 슬롯 수는346/371/367/368개(/372)였다. 영화의 실제 품질이 나쁘다는 뜻은 아니지만,
극소수 평가의 평균과 개인 반응이 어떻게 결합되는지 먼저 점검해야 한다.
이는 사후 진단이며 원인 입증이나 최소 투표 수 정책의 채택 근거로 사용하지 않았다.

## 다음에 먼저 바꿔 볼 것

다음340에서는 **대중 평점의 근거량 처리와 학습 때 사용자 입력 구성을 먼저 설계·검토**한다.
현재처럼 투표 수를 특징으로 넣는 것만으로 극소수 평가의 영향이 통제된다고 전제할 수 없다.
임의로 희귀 영화를 제외하기보다 신뢰도를 표현하는 방법과 비교 기준부터 정한다.
현재 학습 목표의82.34%는 이전 입력이0개여서, 서비스의 개인 반응을 학습하는 조건과 차이가 크다.
이 차이가 이번 결과의 원인이라고 입증한 것은 아니지만, 정보 가중치를 더 섞기 전에 점검할 설계 문제다.
[후속 설계 선택지](../../plans/text-to-final-recommendation/training-input-distribution.md)를 먼저 검토하고,
그다음 개인 반응·콘텐츠 결합과 ALS 보조 기여를 비교한다.

이번 비교는 과거에 사용한 개발 사용자와 최신 TMDB/Wiki를 결합했다.
평가자의 미래 MovieLens 별점을 학습에 넣지는 않았지만, 최신 집계와 본문에 담긴 미래 정보까지 차단한 시험은 아니다.
조건당 학습1회라 seed·최적화 변동도 검증하지 못했다. **2026년 한국 사용자 품질은 미검증**이다.
