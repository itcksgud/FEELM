# REC038 — 같은 영화를 8개로 묶는 방법 비교

상태: DRAFT — 개인 연구의 사전 고정 실행 계약. 2026-09-08.

사용자 요청: 장르만·태그만·장르+태그, K-means 사용/미사용을 실제 비교한다.
추가 답변으로 미사용 비교는 **단순 규칙과 다른 군집 방법 모두**로 확정했다.
이번 질문은 어떤 고정 방법이 8개 단일 배정과 납득 가능한 내용 구별을 함께 제공하는가다.
추천 만족도·맞춤2/발견1·전환 K·온보딩 효과는 이번 판정 대상이 아니다.

## 비교할 8개 안

| 코드 | 입력 | 배정 방법 |
| --- | --- | --- |
| RULE_GENRE | 기존 TMDB 첫 내용 장르 | REC033의 고정8그룹 규칙 재사용 |
| KM_TEXT | 제목·줄거리·장르·감독·배우·키워드의 기존 E5-small384 | REC033의 고정 K-means 재사용 |
| KM_GENRE | 장르 ID만 | K-means8 |
| KM_TAG | TMDB keyword ID만 | K-means8 |
| KM_BOTH | 장르와 keyword ID | K-means8 |
| NMF_GENRE | 장르 ID만 | NMF8성분 + 최대 기여 성분 단일 배정 |
| NMF_TAG | TMDB keyword ID만 | NMF8성분 + 최대 기여 성분 단일 배정 |
| NMF_BOTH | 장르와 keyword ID | NMF8성분 + 최대 기여 성분 단일 배정 |

단순 규칙은 기존 장르안 하나다. 태그/혼합 규칙을 새로 발명해 완전한3×3실험이라고 부르지 않는다.
‘태그’는 TMDB keyword이며 MovieLens 사용자 태그가 아니다. 기존 전체 텍스트 안의 추가 신호는
한꺼번에 묶인 기존 기준안으로만 비교하며 개별 줄거리·배우 등의 인과 효과를 주장하지 않는다.

## 같은 입력·계산 범위

REC033 공통85,517편의 고정 metadata와 영화 ID를 사용한다. 평점·사용자·미개봉 평가셋은 읽지 않는다.
영화마다 고유 장르/키워드 ID의 presence를 만들고 기존 전역DF≥5 어휘를 사용한다.
이는 이전 설명용 어휘를 새로운 군집 입력에 전용하는 고정 선택이며 최적성이 검증된 것은 아니다.
장르19개(178,506등록), 키워드10,818개(337,368등록)를 기존 전수 빈도로 검산한다.
키워드 원시 누락22,834편과 필터 후 전부 탈락741편, 총23,575영벡터를 구분한다.

각 블록에서 presence×`log((N+1)/(DF+1))+1`을 적용하고 영화별L2로 정규화한다.
결합은 두 단위 블록을 같은 비중으로 연결한 뒤 다시L2로 정규화한다. 둘 다 있으면 제곱 norm 기여가
각1/2이고, 태그가 없으면 장르 블록만 남는다. 태그 수 때문에 한 블록이 압도하지 않게 하는 가정이며
결과에 맞춰 가중치·DF·태그목록을 조정하지 않는다. 제작·지명 태그도 사후 삭제하지 않는다.
K-means와 NMF는 같은 표현의 동일 행렬을 받는다. 전체 dense 영화×태그 복원은 만들지 않는다.

각 새 방법은 주 seed20260909, 진단 seed20260910의2회만 fit한다. 총12회 fit이다.
K-means는 k-means++, n_init10, max_iter300, tol1e-4, Lloyd를 사용한다.
NMF는 n_components8, nndsvdar, cd, Frobenius, alpha_W/H0, l1_ratio0, max_iter400,
tol1e-4, shuffleFalse를 사용한다. nndsvdar의 무작위 작은 값 초기화와 SVD의seed를 바꾸는 안정성 진단이다.
NMF의 H행 norm을s라 할 때 H'=H/s, W'=W*s로 복원을 유지하고 W'의 최대 성분에 배정한다.
동점은 낮은 원시 성분 번호, 영성분/영기여 행은 기록한다. L2 입력이 일반 K-means를 구면 K-means로 바꾸지는 않는다.

주 결과는 항상 첫seed다. 진단seed가 좋아도 교체하지 않는다. 수렴 경고/반복 상한 도달은 그대로 기록한다.
NMF8성분이 8개 점유 군집을 보장하지 않으므로, 정보가 있는 native 배정의 점유가8개 미만이면
8군집 조건 미충족이다. 임시 배정으로 빈 군집을 채우거나 추가 fit으로 구제하지 않는다.

## 정보 없는 영화와 8개 표시 코드

영벡터는 fit에서 제외한다. `native_label=-1`과 이유를 보존하며 내용 근거를 주장하지 않는다.
85,517편의 단일 표시를 위해 `display_label`에는 지원 영화의 최빈 군집(동률 낮은 코드)을 임시로 넣는다.
이 규칙은 연구 산출물의 형식 보충일 뿐 서비스 정책이 아니다. 태그에 장르를 몰래 보충하지 않는다.
같은 최빈군집 규칙이어도 방법마다 다른 내용의 군집으로 향하므로 공통 의미의 배정이라고 부르지 않는다.
단순 규칙의 FORMAT_ONLY12편도 같은 방식으로 구분한다. 결합 입력에서 태그 없는 영화는
장르 근거는 있으므로 native 지원이며 별도로 TAG_MISSING/FILTERED_EMPTY를 표시한다.
크기·점유·설명·안정성은 native를 기준으로 하고 display 분포도 따로 공개한다.

## 평가 자료와 블라인드 절차

모델 결과를 보기 전에 영화 ID의 `rec038-eval-v1|` SHA-256 순서로 공통128편 E를 고정한다.
모든 방법은 같은 E를 평가받는다. 기존 E5 군집에서 고른 REC036의120편은 주평가로 재사용하지 않는다.
fit은 전체 카탈로그에서 수행하므로 새 영화 일반화 시험이 아닌 전이적 카탈로그 진단이다.
E5는 원문도 입력으로 썼으므로 새 표본의 선정 독립성과 원자료 독립성을 혼동하지 않는다.

설명용 D는 E를 제외한 native 군집마다 `rec038-description-v1|` SHA 순서4편이다.
부족하면 있는 영화만 사용하고 기록한다. 유리한 중심 영화로 설명을 만들지 않는다.
64개 묶음의 방법·장르·태그·기존 이름·크기·거리·평가배정을 가리고 D의 원문만 제공한다.
별도 AI가 각 묶음의 공통 설명(최대240자), `COHERENT/BROAD/MIXED/INSUFFICIENT`,
영화별 `FIT/PARTIAL/CONFLICT/INSUFFICIENT`와 원문 근거 구절(최대180자)을 기록한다.
COHERENT는 같은 구체적 설명을4편 모두 뒷받침, BROAD는 넓은 공통 범주만 유지,
MIXED는 하나의 설명이 일부 영화만 지지, INSUFFICIENT는 판단 가능한 원문이2편 미만일 때다.
설명은 최대 두 개의 관련된 소재를 연결하고 서로 무관한 소재를 나열해 모두 맞추지 않는다.
설명 불가를 허용한다. 정보가 있는 영화는2편 이상이지만 공통 설명을 하나도 지지하지 않으면 MIXED와
정해진 문구 ‘공통된 내용 설명을 도출하지 못함.’을 사용한다. BROAD는 판단 가능한 영화에 CONFLICT가 없어야 한다.
제공 표본에서 도출한 설명문이며 군집 전체의 확정된 본질은 아니다.
실제 구절의 원문 일치와 전체 묶음/카드 누락·중복을 확인·봉인한다.

그다음 다른 검수자에게 E 원문과 한 방법의 익명8설명만 제공한다. 방법/그룹 순서는 고정 hash로 섞는다.
실제 소속 군집·입력 메타데이터·수치 결과·첫 설명자의 coherence 점수는 보여주지 않는다.
각영화×8방법=1,024건에서 원문 정보 충분 여부, 납득 가능한 그룹 집합(0개/1개/복수), 짧은 이유를 기록한다.
이는 독립영화1,024편이 아니라 같은128편의 반복 평가다. D의4편으로 만든 설명의 우연성도 있으므로
본점수는 군집과 이 설명을 합친 현재 구성의 진단이며 알고리즘만의 우열로 확대하지 않는다.
부분 단어 일치가 아니라 중심 사건·관계·갈등/형식에 근거한다. 여러 그룹에 맞으면 모두 선택하며
forced-choice로 모호함을 숨기지 않는다. 이 판단을 검사·봉인한 뒤 실제 native/display 배정과 연결한다.
AI 판단은 사람의 정답·독립 취향 선호가 아니며 블라인드가 모델의 편향을 제거하지는 않는다.

## 비교표와 종료 결정

전체85,517편의 native 지원율/임시 표시율, 실제 점유8개 여부, 최소/최대 군집크기,
수렴·실행 비용, 진단seed의 native 공통행 ARI/최적정렬 일치를 먼저 보고한다.
E에서는 전체128편, 모든 방법에서 원문이 충분한 공통영화, 그 공통 충분 집합 중 태그도 지원되는 영화를
나누어 같은 분모로 비교한다. 세 번째 분모는 원문 충분과 태그 지원의 교집합이다.
각 안에서 원문 불충분 판단이 다르면 차이를 공개하고, 공통 충분 집합과 각 안의 판단도 별도 기록한다.
native 배정 수용(실제 그룹이 허용 집합에 있음), 유일 수용(집합이 실제 그룹 하나),
모호(2개이상), 어디에도 맞지 않음(0개), 배정 충돌(다른 그룹만), 근거 없는 native 배정을 분리한다.
임시 표시가 우연히 수용돼도 native 성공으로 합산하지 않는다. 군집별 E수와 혼동 쌍도 보여준다.

학습 특징의 일치율·inertia·NMF 복원오차를 표현 간 우승 점수로 쓰지 않는다.
8안의 작은 표본 차이를 통계적 확정 순위로 만들지 않으며 새 임의 제품 통과선을 만들지 않는다.
같은 알고리즘의 입력 비교, 같은 입력의 알고리즘 비교, 기존 두 기준 대비를 구분한다.
이번 비교에서의 기술적 사용 가능성 → 설명의 일관성과 구별 → 정보 확보와 단순성을 함께 보고
잠정 후보(복수 또는 없음 가능)를 제시한다. 전체8개에 평가 사례가 부족하면 그대로 미확인으로 남긴다.
수치만 높고 영화 사례가 납득되지 않으면 채택하지 않는다. 이번 단회 비교로 종료하며 가중치/모델/k/태그
추가 탐색, 설명 수정 후 같은 E 재채점, 후속 추천 품질 실행을 자동 추가하지 않는다.
