# REC038 — 8개 군집을 만드는 방법 비교

상태: 실행·블라인드 판정·연결·독립 검산·보고서 검토 완료. 2026-09-08. 개인 연구 결과.

**이번 비교에서는 장르 단독을 우선 검토할 방향으로 좁힌다. 잠정 후보는 단순 장르 규칙과 장르 K-means다.**
단순 규칙은 더 많은 영화를 설명했지만 설명끼리 더 많이 겹쳤다. 장르 K-means는 겹침이 줄고
배정된 설명 하나에만 맞는 영화가 늘었다. 이 상충 때문에 한쪽을 최종 승자로 정하지 않는다.
현재의 태그 전용·결합·NMF·전체 텍스트 구성은 두 후보를 대체할 근거를 확보하지 못했다.

이 판단은 **고정 군집과 4편으로 만든 설명을 합친 현재 구성**의 비교다.
아래 수치는 추천 정확도나 군집 알고리즘 자체의 성능이 아니다.
어느 안도 서비스의 완성된 8맛으로 채택하지 않는다. 외부 8맛·색상과 0.5 단위 별점은 유지한다.

## 같은 128편에서 실제로 무엇이 달랐나

방법 이름과 실제 배정을 가린 상태에서, 검수자가 영화 줄거리를 각 안의 8개 설명과 대조했다.
설명 하나를 억지로 고르게 하지 않고 0개·1개·여러 개를 허용했다. 모든 128편은 8안에서 원문 충분으로 판단됐다.

- **배정 설명에 맞음**: 그 영화가 실제 들어간 군집의 설명이 허용 집합에 포함됐다.
- **그 설명에만 맞음**: 허용된 설명이 실제 군집 하나뿐이었다. 앞 열에 포함되는 수다.
- **여러 설명에 맞음**: 같은 영화에 2개 이상 설명이 맞았다. 실제 배정 수용 여부와는 별도다.
- **어느 설명에도 안 맞음**: 충분한 줄거리가 있지만 허용할 설명을 찾지 못했다. 자료 부족으로 처리하지 않았다.

전체 128편과 공통 원문 충분 집합이 같으므로 두 집계 결과도 같다.

## 입력과 방법을 나눠 읽으면

**장르만 vs 태그만 vs 결합.** K-means에서 배정 설명 수용은 44 → 10 → 23편이었다.
장르에 태그를 더한 구성은 장르 단독보다 21편 적었다. 같은 영화별로 보면 장르 단독만 수용된 영화가
26편, 결합만 수용된 영화가 5편, 나머지 97편은 같았다.
NMF에서는 장르 단독 29편보다 결합 40편이 많았지만, 장르 K-means 44편을 앞서지 않았고
유일 수용도 둘 다 27편이었다. 따라서 ‘태그는 항상 해롭다’는 결론도, ‘태그를 더하면 좋아진다’는 결론도 아니다.
현재 구성에서는 장르 단독에 추가 복잡성을 더할 이득이 확인되지 않았다.

**같은 입력에서 K-means vs NMF.** 장르 단독은 44/27편 대 29/25편, 태그 단독은 10/2편 대 12/4편,
결합은 23/21편 대 40/27편이었다(배정 수용/유일 수용).
NMF가 모든 입력에서 낫지는 않았다. 결합 NMF가 결합 K-means보다 높다는 결과를 NMF 일반의 우위로 확대하지 않는다.

**단순 규칙 vs 장르 K-means.** 단순 규칙만 배정 수용된 영화는 21편, 장르 K-means만 수용된 영화는 12편이다.
유일 수용에서는 단순 규칙만 8편, 장르 K-means만 14편이다.
단순 규칙의 설명 범위와 K-means의 구별 사이에 상충이 남아 있다.
작은 표본의 점 차이에 통계적 우승·동등성 주장을 붙이지 않는다.

장르·태그 K-means의 겹침 6편만 보고 좋은 분류라고 판단하면 안 된다.
어느 설명에도 안 맞는 영화가 72편이어서 겹칠 기회 자체가 적었다.
장르 NMF의 겹침 10편도 같은 이유로 단독 장점이 될 수 없다.

## 설명 자체가 가진 한계

설명용 D는 평가용 E를 제외하고 군집마다 hash로 4편을 뽑았다. 유리한 중심 영화만 고르지 않았다.
64묶음 × 4편은 256슬롯이지만 **고유 영화는 85편**이고, E 128편과는 겹치지 않는다.
두 작성자가 원문만 보고 설명했고, 별도의 새 평가자 3명이 E를 43/43/42편으로 나눠 판정했다.
한 영화의 8안은 같은 평가자가 판단했다. 평가자 간 반복 채점·일치도 검증은 하지 않았다.

| 방법 | 구체적 공통 설명 | 넓은 공통 범주 | 일부 영화만 설명 |
| --- | ---: | ---: | ---: |
| 단순 장르 규칙 | 0 | 6 | 2 |
| 기존 전체 텍스트 + K-means | 0 | 3 | 5 |
| 장르 + K-means | 0 | 3 | 5 |
| 태그 + K-means | 1 | 1 | 6 |
| 장르·태그 + K-means | 0 | 3 | 5 |
| 장르 + NMF | 0 | 3 | 5 |
| 태그 + NMF | 0 | 0 | 8 |
| 장르·태그 + NMF | 0 | 3 | 5 |

전체 64묶음 중 1개는 구체적 공통 설명, 22개는 넓은 범주, 41개는 일부 영화만 설명했다.
그중 5개는 공통 설명을 만들지 못해 평가에서 선택 가능한 내용 설명으로 취급하지 않았다.
이 비율을 전체 군집 품질의 확정 비율로 읽지 않는다. 4편의 우연성과 AI의 설명 방식에 영향을 받는다.

특히 첫 설명자는 장르·태그·방법 이름을 보지 않았다. 그래서 단순 규칙의 음악 그룹도 네 줄거리에서
‘범죄와 욕망’이라는 설명을 받았다. 장르 분류의 타당성과 제한된 줄거리에서 만든 내용 설명의 타당성이
같은 것은 아니다. 이 한계 때문에 낮은 점수를 ‘그 군집의 모든 영화가 잘못 묶였다’로 해석할 수 없다.
태그 유무와 알고리즘 변경 효과도 설명 변화가 함께 포함된 결과다.

비지도 학습안은 평가용 E를 별도 학습 제외셋으로 두지 않고 카탈로그에서 fit했다. 각 안의 입력 영벡터는 fit에서 제외했다.
단순 규칙에는 fit이 없다. 기존 E5 입력에는 줄거리도 포함되므로 새 영화 일반화나
원자료가 독립적인 확증 시험이 아니다. 1,024건은 **128편의 반복 판정**이며 사람의 취향 정답이 아니다.
새 임의 통과선·통계적 우승·추천 만족도·온보딩 효과·개인화 전환 K를 이 점수로 정하지 않는다.

## 실행·독립 검증과 종료

같은 85,517편에서 기존 두 기준안과 장르/태그/결합 × K-means/NMF의 6개 새 안을 비교했다.
각 새 안은 고정 두 seed로 총 12회 fit했고, 결과가 낮아도 첫 seed를 유지했다.
NMF는 겹치는 8성분을 찾은 뒤 H의 행 norm을 W에 반영하여 최대 기여 성분 하나에 배정했다.
장르 19개·키워드 10,818개, 고정 DF≥5와 IDF/L2 정규화를 사용했다. 결합은 두 블록을 동일 비중으로 연결했다.
이 가중치와 전처리의 최적성은 검증하지 않았다.
