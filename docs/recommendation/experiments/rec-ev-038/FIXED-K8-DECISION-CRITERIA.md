# 8개 팝콘 맛의 판정 기준

상태: DRAFT — 개인 연구의 후속 비교 기준. 2026-09-12.
새 점수 계산·학습·제품 채택은 수행하지 않았다.

## 결정

사용자 요구는 의미를 사전 지정하지 않고 서비스의 모든 영화를 정확히 8종류로 나눈 뒤,
확정한 분류 기준을 유지하는 것이다. 이상한 영화 쌍이 전혀 없는 분류는 요구하지 않는다.

**주판정은 동일한 영화 정보를 8개 라벨로 요약했을 때의 평균 복원 손실이다.**
8종류라는 동일한 제약 아래, 비교한 후보 중 전체 영화 정보를 더 적게 잃는 구성을 선택한다.
‘같은 맛의 모든 영화가 닮아야 함’, ‘다른 맛의 영화는 항상 달라야 함’,
유명작 반례 한 쌍의 존재, 8개 군집의 균등한 크기는 통과·탈락 기준으로 사용하지 않는다.

이 문서는 KOREAN-MOVIE-GUIDE의 정성적 유사성·구별 평가를 주판정으로 삼았던 제안을 대체한다.
기존 영화 배정과 REC038 결과는 그대로 보존한다. 영화 사례와 사람이 붙인 설명은 오류 분석과
맛 이름 작성에 사용하며 주점수를 대신하지 않는다.

## 하나의 공통 평가 정보

모든 후보에 같은 평가 영화와 같은 두 정보 블록을 사용한다.

- **장르:** 영화의 전체 내용 장르를 복수 이진 속성으로 표현한다. 형식 정보는 분리한다.
- **줄거리 내용:** 제목·인물 목록·인기도 등을 덧붙이지 않은 줄거리의 고정 의미 벡터를 사용한다.

줄거리 원문·언어 처리·인코더·전처리·스케일을 후보 실행 전에 고정한다. 후보가 학습에 어떤
입력을 쓰든 평가 정보는 바꾸지 않는다. 기존 모든 필드 혼합 E5 벡터를 검수 없이 의미 정답으로
취급하지 않는다. 참조 표현의 정확한 파일·버전·해시는 실행 명세에서 고정해야 한다.

장르와 줄거리 블록은 정규화한 손실을 **50:50**으로 합친다. 이는 장르와 내용 요약을 동등하게
보겠다는 이번 평가 선택이다. 자연법칙이나 보편적 영화 정답 비중이 아니며, 결과를 보고
특정 후보에 유리하게 바꾸지 않는다. 키워드는 후보 입력으로 사용할 수 있지만 세 번째 점수로
자동 추가하지 않는다.

## 라벨 하나만으로 복원한다

각 후보에 같은 용량의 복원기를 허용한다.

1. 학습 영화의 배정으로 맛별 장르 비율과 줄거리 벡터 평균을 구한다. 정확히 8행짜리 표다.
2. 평가 영화에는 후보가 정한 맛 번호 하나만 붙인다.
3. 복원기는 그 번호에 해당하는 장르 비율과 내용 평균을 반환한다.
4. 반환된 요약과 평가 영화의 실제 장르·내용 벡터를 비교한다.

복원표 계산에 평가 영화를 넣지 않는다. 복원기에 영화 ID·원래 특징·다른 추천 모델의 결과를
추가로 전달하지 않는다. 영화별 정보를 다시 넣으면 라벨 8개의 정보량을 평가하는 실험이 아니다.

## 주점수

장르는 각 내용 장르의 존재 여부와 예측 비율 사이의 제곱오차를 평균한다(Brier 형태).
줄거리는 고정된 벡터의 평균제곱오차를 사용한다.
각 블록의 기준선은 맛 번호 없이 모든 영화에 학습 자료의 전체 평균을 반환하는 복원기다.

```text
장르 상대 손실 = 맛별 장르 비율의 평가 오차 / 전체 평균 장르 비율의 평가 오차
내용 상대 손실 = 맛별 내용 평균의 평가 오차 / 전체 내용 평균의 평가 오차

D8 = (장르 상대 손실 + 내용 상대 손실) / 2
```

**D8은 낮을수록 좋다.** 1은 두 블록의 평균에서 맛 없이 전체 평균을 쓰는 기준과 같은 수준이다.
1보다 크면 그 기준보다 못하다. 기준 오차가 0인 블록은 점수를 만들 수 없으므로 실행 전 자료
검사에서 처리 기준을 고정하고, 결과를 본 뒤 임의로 분모를 바꾸지 않는다.

예를 들어 D8=0.70이라면 이 정의로 정규화한 복원 오차가 기준선보다 30% 낮다는 뜻이다.
영화 의미를 70% 보존했다거나 70%를 올바르게 분류했다는 뜻은 아니다. 이 숫자는 설명용 예시다.

각 방법의 자기 입력 공간에서 계산한 inertia나 silhouette를 서로 직접 비교해 우승을 정하지
않는다. 공통 평가 공간과 동일 복원기를 사용해야 입력 구성이 다른 방법도 같은 기준으로 비교할 수 있다.

## 비교와 선택

- 모든 후보는 K=8과 같은 영화 범위를 사용한다. 영화는 기본적으로 동일 가중한다.
- 기존 장르 K-means 8과 REC040 전체 장르 규칙 8을 실질 기준선으로 둔다.
- 무작위 8분할은 검산용이다. 무작위보다 좋다는 이유만으로 채택하지 않는다.
- 개발 자료에서 입력·가중치·초기화 선택을 끝내고, 기준선과 도전 후보를 고정한 뒤 별도 평가 자료를 비교한다.
- 주점수 차이는 같은 평가 영화의 손실 차이로 계산하고 불확실성을 함께 보고한다.
- 별도 평가에서 개선이 확인되면 도전 후보를 선택한다. 개선을 확인하지 못하면 기준선을 유지한다.
  이때 ‘동등성이 입증됐다’고 표현하지 않는다.
- 현재 후보 전체를 먼저 점수 낸 뒤 유리한 기준·표본·평가 표현으로 바꾸지 않는다.

신작 성능을 말하려면 군집 학습·복원표·후보 선택에 쓰지 않은 영화에서 평가해야 한다.
과거 전체 카탈로그로 만든 고정 배정을 재사용한 계산은 기존 카탈로그의 압축 진단으로 한정한다.
사용하지 않은 최종 평가 자료가 확보됐다고 미리 가정하지 않는다.

## 이상한 영화와 자료 누락을 다루는 방식

평균은 한 영화당 한 표로 집계한다. 임의로 고른 이상한 한 쌍이 전체 결론을 뒤집지 않는다.
영화별 손실 상위 10%의 평균, 사전 고정 장르·언어·자료 누락 계층, 군집별 손실과 편수는
보조 결과로 함께 공개한다. 보조 수치를 보고 새로운 탈락선을 만들지 않는다.

후보가 배정을 못 한 영화를 빼서 좋은 점수를 만들지 않는다. 공통 평가 정보를 가진 영화의
배정 미지원은 전체 평균 복원으로 평가하고 미지원율을 별도 기록한다. 이는 서비스에서
실제로 임의 맛을 부여하는 정책이 아니다.
평가 정보 자체가 없는 영화는 별도의 자료 누락 범위로 전부 공개하고 보강한다.
정보가 없는 영화까지 검증된 분류에 포함했다고 주장하지 않는다.

초기화·표본 변화의 안정성과 동결한 모델의 재현성도 확인한다. 이는 정보 보존 점수를
대체하지 않는다. 최종 선택 뒤에는 전처리·어휘·IDF·인코더·가중치·중심점·코드 매핑을 함께 동결한다.

## 결론의 정확한 범위

이 기준으로 말할 수 있는 것은 **‘비교한 8분류 중, 정해 둔 장르·내용 정보를 더 적게 잃는 안’**이다.
모든 가능한 8분류의 전역 최적해, 사람에게 객관적으로 올바른 8취향, 추천 만족도의 우위를
입증하는 지표는 아니다. 같은 입력 정보의 복원은 압축 목적에는 정당하지만 독립적인 의미 정답
검증으로 바뀌지는 않는다. 공통 의미 벡터 자체도 완전한 진실이 아니다.

현재 REC038의 44/128이나 기존 영화 사례로 이 주점수 순위를 계산한 적은 없다.
따라서 장르 K-means가 이 기준에서도 우승했다고 미리 결론내리지 않는다.
