# 실행·채점 명확화

상태 DRAFT, DESIGN의 후속 구현 명세. GBT 학습 레시피·대상·주 지표를 변경하지 않는다.

- NDCG는 J>=N과 IDCG>0일 때만 유효하다. 평균별점·low 지표의 유효 사용자 수와 별도 표시한다.
- 실제 ALS의 전체 후보 순위를 부분 지원 후보 순위로 대체하지 않는다. 관측 ALL의 ALS 순위는
  N/A이고 같은 W_DIRECT에서만 직접 비교한다. ALS의 ALL 별점오차는 지원행에서만 계산되므로
  전체 지원 모델과 직접 대결하는 표에는 쓰지 않는다. 예측 가능 행/사용자 수를 함께 보존한다.
- 메모리 peak 부재는 UNKNOWN, strict12GiB 초과 실측은 EXCEPTION으로 보고한다.
  상한을 넘긴 실행을 strict 자원 PASS로 보고하지 않는다.
- 순위 모델은 native MSE/별점 범위 이탈 비율 N/A, 별도 보정 MSE를 비교한다.
- 전체 후보 기준의 기존 영화/점수와 새 모델의 raw scores를 보존하며, 후보·viewed 제외 조건을
  기존 캐시와 전량 대조한다. latency는 동일 하드웨어의 Python 계산 비용이며 API 부하테스트가 아니다.
- bootstrap은 고정된 학습·보정 모델에서 비교 사용자만 재표집한다. 보정 계수/학습 변동은 포함하지 않는다.
