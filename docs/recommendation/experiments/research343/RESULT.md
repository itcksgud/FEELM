# 새 모델과 기존 모델의 최종 비교

상태: DRAFT — 로컬 개발 표본 비교. 한국2026 서비스 성능 검증이 아니다.

**이번 세 학습에서 기존 후보를 대체할 전반적인 우위는 확인하지 못했다.**
새 순위 학습 모델은 이번 구성으로 채택하지 않고, 추가 모델 학습은 여기서 멈춘다.
기존 보정 FM(RH)과 GBT가 여전히 서로 다른 장점을 가진다.

| 판단할 내용 | 이번 결과 | 판단 |
| --- | --- | --- |
| GBT에 대중평점 근거량 보정 | native MSE 0.739477→0.741724, NDCG@2 0.844198→0.837866. 두 차이 CI 모두0 포함 | 성능 개선을 입증하지 못함 |
| LightGBM 회귀 대신 순위 학습 | 보정 MSE 0.743117→0.846447, **13.9% 악화**. NDCG@2 0.841793→0.843310의 차이는 불확실 | 이번 순위 모델 채택하지 않음 |
| LightGBM 회귀 | 학습44초로 이번 GBT 보정의927초보다 짧음. 첫2편의 전체 노출 고유영화는20편, 기존 GBT는101편 | 비용상 이점은 있으나 전반적인 추천 우위 없음 |
| MSE만 보고 기존 FM+ALS25% 채택 | native MSE 0.684052로 낮지만, 전체 첫2편248슬롯 중223슬롯이 투표1개·TMDB10점 영화 | 그대로 서비스 모델로 채택하는 근거가 부족함 |

위 MSE는 입력 있는 비교124명, NDCG@2는 유효117명이다. 순위 모델 MSE는 별도 보정90명에서
정한 단조 선형 보정을 거친 수치다. 이 보정 구성의 결과이며 다른 보정·순위 알고리즘 전체를 기각하지 않는다.
사전에 정한 순위−회귀 MSE 차이의98.75% CI는 **[+0.057433,+0.160251]**로 오차 증가를 보였다.
NDCG 차이 CI는 **[-0.018631,+0.021929]**다. 이번 CI는 과거에 열어본 개발 자료에서
고정 모델·보정 계수를 조건으로 계산했으며, 한국2026 성능이나 새로운 최종 test의 증거가 아니다.

**남는 선택은 별점 오차, 관측 후보의 첫2편 품질, 전체 후보의 노출 쏠림 사이의 절충이다.**

- **별점 정확도를 보면 보정 FM(RH)**: native MSE0.692078, MAE0.624529으로 기존 GBT의
  0.739477/0.650030보다 낮다. 인위적 미지원(C)과 자연 미지원의 native MSE도 각각
  0.706008/0.713283으로 기존 GBT의0.739564/0.812399보다 낮다.
- **첫2편과 추천 쏠림을 보면 기존 GBT**: 관측 첫2편의 실제 평균별점3.858974,
  별점≤2 비율5.13%로 보정 FM(RH)의3.811966/7.26%보다 좋았다.
  전체 첫2편의 고유영화101편, HHI0.02933으로 보정 FM(RH)의34편/0.11082보다 덜 몰렸다.
- **근거량 보정 GBT는 별도 절충**: 투표1개·10점 영화 노출이16/248→0/248로 없어졌다.
  하지만 HHI는0.02933→0.04660으로 높아졌고, 관측 품질의 개선도 확인하지 못했다.
  보정이 모든 종류의 쏠림이나 품질 문제를 함께 해결했다고 말할 수 없다.
- **평균 밖의 사용자도 확인해야 한다**: 사용자MAE의95백분위는 보정 FM(RH)1.37718,
  기존 GBT1.25082다. 평균 오차가 낮은 모델이 오차가 큰 사용자 구간까지 좋지는 않았다.

자연 미지원 영화의 Top2 NDCG는23명만 유효하다. 이 작은 구간에서 순위 모델의 점수가
높은 항목도 있지만, 이를 근거로 전체 결론을 뒤집거나 승자를 새로 정하지 않았다.
ALS와의 직접 비교는 같은 W_DIRECT에서만 해석한다. 해당122명의 ALS MSE는 native0.836314,
보정 후0.693813이므로 원점수와 보정값을 섞으면 모델 순위가 달라 보일 수 있다.

따라서 **MSE 하나로 FM+ALS를 고르거나, NDCG 하나로 새 순위 모델을 고르는 것은 권하지 않는다.**
이번 연구는 보정 FM과 GBT의 장단점을 모델 선정 근거로 남긴다. 두 주 지표를 함께 개선한
단일 승자는 없으며, 가중치를 사후에 만들어 승자를 확정하지 않는다.
