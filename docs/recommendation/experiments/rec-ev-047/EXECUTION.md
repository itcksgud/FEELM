# REC047 실행 계약

상태: DRAFT. 실행 전 독립 검토 대상. 개인 연구이며 2026 한국 서비스의 정답 검증이 아니다.

## 이번에 답할 질문

같은 사용자의 같은 미래 별점을 평가할 때, 과거 이력을 임의로 K+8개로 자르지 않고
학습 사용자를 25%→50%→100%로 늘리면 다섯 추천 방식의 결과와 지원 범위가 어떻게 달라지는가?
사용자 활동량과 영화 지원량별 결과도 함께 공개한다. 이번에는 최적 설정을 새로 대량 탐색하지
않고 같은 구성의 학습량 곡선을 비교한다. REC046과 달라진 조건이 여러 개이므로 두 실험의
점수 차이를 특정 수정 하나의 효과로 해석하지 않는다.

## 고정된 데이터와 시간

- 검증 origin V: 2022-07-05 UTC, 평가 T: 2023-01-01 UTC. 예측 기간 H는 정확히 180일이다.
  3열 전수 가용성 점검과 독립 검산을 통과했다. 역할 해시와 개발 사용자 범위는 README를 따른다.
- 학습 역할 40,588명을 독립 SHA256 `rec047-volume|uid` 순으로 정렬한다. 앞 10,147/20,294/
  40,588명을 25/50/100% pool로 고정한다. 시점 이전 관측이 없는 pool 사용자는 학습 행이 0이며
  실제 기여 사용자 수를 별도로 기록한다. 검증·평가 사용자는 어느 학습량에도 들어가지 않는다.
- 각 시점보다 엄격히 이전의 학습 역할 카탈로그 별점을 **모두** 사용한다. 평점 수 제한이나
  최소 K+8 자격이 없다. 이번 자연 분포 비교에서는 인위적인 20% 영화 보류를 적용하지 않는다.
  readiness의 ‘실행 단계에서 고정할 영화 보류 집합’은 빈 집합으로 고정한다. 새 영화 검증은
  해당 시점에 학습 지원이 실제로 0인 영화로 제한된다. 강제 cold-item 능력까지 검증했다고
  주장하지 않는다. 이는 실제 학습 이력의 절삭을 없애기 위한 결정이다.
- ALS의 모든 학습 별점을 지도학습에서도 목표로 정확히 한 번 사용한다. V와 T의 동일한
  역방향 180일 격자로 과거 전체를 나누고, 사용자×window마다 그 시작 이전 최신 K개를 O로 쓴다.
  가능한 K 중 `SHA256(rec047-k|uid|window_start)`로 하나를 배정한다. K는 0/1/5/10/30이다.
  첫 window도 K0으로 남긴다. 시점·학습량이 달라져도 기존 예제의 window와 K는 바뀌지 않는다.
- 목표는 `[window_start, window_start+H)` 전체 관측이다. 동일 timestamp를 경계 양쪽으로
  쪼개지 않는다. 최신 K의 timestamp 동점은 movie ID 오름차순으로 정한다.
- 입력/목표 영화는 분리한다. MovieLens의 uid/movie 중복이 없어야 한다. 목표 별점은 원래
  0.5 단위를 유지한다. 미평가는 UNKNOWN이다. 전체 이력은 오래된 자료와 활동 사용자 비중을
  그대로 포함한다. 모든 모델이 행 기준 손실로 학습하므로 사용자 동일 가중 학습은 아니다.
- 검증·평가에서는 origin 이전 최신 K가 실제로 존재하고 미래 목표 1개 이상인 사용자를
  K별로 전부 사용한다. 같은 K에서는 세 학습량과 모든 모델의 사용자·입력·목표가 같다.
  K0 평가 271명, K1 187명, K5/10 186명, K30 183명이다. K 사이의 구성 차이를 피하는
  별도 민감도는 K30 입력 가능자 183명 공통 집단에서 K별 결과를 다시 집계한다.

## 특징과 다섯 방식

1. ALS: 명시적 원 별점, rank32/reg0.1/15회. 서비스 사용자는 O로 fold-in한다. 학습된 O나
   목표 영화 벡터가 없으면 `(O별점 합+5×해당 학습량의 과거 평균)/(K+5)`로 복귀한다.
2. FM: factor16/reg0.01/150회/step0.01/minibatch0.25, adamW. 목표 원 별점을 학습한다.
3. ALS+FM: ALS 직접 점수가 있는 행에서만 두 raw 점수를 결합하고 나머지는 FM을 쓴다.
4. 공유 리지: reg0.01/150회, 절편 사용. 같은 특징에서 원 별점을 예측한다.
5. Spark GBT: depth5/60개 tree/step0.05, subsample0.8/features sqrt.

설정은 기존 비교의 구성을 참고해 새 정답 개방 전에 고정했다. 새 표현에서 최적이라는
주장은 하지 않는다. FM은 Spark가 목적함수 이력을 제공하지 않으므로 유한 예측·학습 오차·
실행 상한을 확인해도 최적화 수렴을 증명한 것은 아니다. 설정을 성능을 보고 더 추가하지 않는다.

FM·리지·GBT는 같은 168열 특징을 쓴다. 후보의 원 장르 18개/개봉연도/길이·존재 표시,
7개 metadata 묶음(장르/키워드/국가언어/시대길이/감독/배우/제작사컬렉션)의 정확한 ID 연결,
O의 장르 및 별점 가중 장르 profile과 후보 교집합, O의 평균/표준편차/K/입력 존재 표시다.
원 ID는 상한이나 OOV 병합 없이 CSR로 유지한다. 영화 쌍의 유사도는 교집합 크기를 두 영화의
토큰 수 곱의 제곱근으로 나눈 값이다. 각 묶음에서 후보 속성 존재/개수, 사용 가능한 O 비율,
연결 O 비율, 유사도 평균/최대, 유사도 가중 원 별점/사용자 평균 대비 별점, 연결 별점 평균,
무연결 표시를 계산한다. 별점 특징은 5로, K는 30으로 나눈다.

이것은 **입력 영화와 후보 영화의 인물·국가 등의 연결**이다. 특정 배우·감독·국가별 전역
평가 효과를 각각 학습하는 full-ID 모델은 아니다. 현재 TMDB 값이며 역사적 snapshot이 아니다.
TMDB 현재 popularity/vote 평균과 MovieLens 목표의 집계 통계는 특징으로 쓰지 않는다.
K0의 평균 특징은 고정 0과 입력 없음 표시다. 과거 window에 그 이후 평점의 전역 평균을
특징으로 넣지 않는다. 단계별 영화 지원량은 채점 층과 ALS 학습 확인에만 사용한다.

## 순서·검증 선택·봉인

1. 실행 코드·설정·소스 해시를 독립 검토 후 고정하고, 합성 계약 검사를 통과한다.
2. V 이전 학습 별점과 검증 사용자 O만 해석한다. 세 규모×4개 모델을 순차 학습하고 모든
   검증 예측을 봉인한 뒤 검증 목표를 연다. 25%에서 자원 사용을 먼저 확인한다.
3. ALS 결합 비율 0/0.25/0.5/0.75/1 중 **모든 학습량에 공통 비율 하나**를 선택한다.
   각 K의 사용자 평균 clipped MSE를 K에 동일 가중, 이어 세 학습량에 동일 가중 평균한다.
   최소값을 선택하고 정확한 동점이면 작은 ALS 비중을 쓴다. 평가 정답은 아직 해석하지 않는다.
4. T 이전 자료로 동일 설정을 다시 학습한다. T에 추가되는 것은 새로 허용된 과거 한 구간이다.
   검증 사용자 별점은 이 학습에 넣지 않는다. 최종 12개 모델 예측과 공통 결합 비율을 모두
   고정한 뒤 평가 목표를 처음 해석한다. 모델은 총 24회 학습하며 결합은 추가 학습이 없다.
5. 원본·역할·시간·목표 1회 배정·예측/별점 정렬·계산·결론을 독립 검산한 뒤 결과를 정리한다.

준비 자료→개별 모델→전체 예측의 봉인은 부모 준비 봉인의 해시를 대조한다. 최종 평가의
준비·모델·전체 예측은 동일 selection.json 해시에도 연결한다. 예측은 정확한 행 수·유한값,
컨텍스트는 연속 행 구간·고유 사용자/K·입력과 목표의 시간/영화 분리를 확인한다. 깨진 예측을
결측 집계로 조용히 제외하지 않는다. 원본 없는 320행 합성 Spark 실행은 실제 학습과 구분한다.
전체 예측 봉인 전에 개별 모델 봉인을 재검증하고, 최종 단계의 다섯 방식 결합 예측 배열도
평가 별점 개방 전에 저장해 같은 봉인에 포함한다.

## 채점과 판정 범위

- MSE/MAE는 예측을 0.5~5로 자른 뒤 사용자별 평균, 사용자 사이 평균이다. 순서 정확도 PA는
  실제 별점이 다른 두 영화의 raw 예측 순서를 비교한다. 예측 동점은 0.5이며 실제 별점이
  전부 같거나 목표가 하나뿐인 사용자의 PA는 결측이다. 해당 사용자 수를 분리해 공개한다.
- 주 표는 K별 고유 사용자 평균과 bootstrap 10,000회 점별 95% 구간이다. 이 구간만으로
  많은 모델/층 중 가장 좋아 보이는 것을 유의한 승자라고 고르지 않는다.
- 사전 고정 학습량 대조: K10/30 ×5방식의 25→100% MSE 차이 10개. 같은 사용자를 묶어
  bootstrap하고 Bonferroni family 10개를 적용한 99.5% 구간을 기록한다. 평균 차이가 음수이고
  구간 상한도 0 미만일 때만 해당 고정 구성에서 학습량 증가 근거가 있다고 한다.
- 보조 모델 대조: 100%에서 K10/30, ALS 대비 나머지4방식, MSE/PA의16개. family16을 보정한다.
  MSE 개선과 PA 개선을 따로 말한다. 일치하지 않는 결과를 단일 우승으로 합치지 않는다.
- 활동층 0/1~9/10~29/30~99/100~299/300+와 **100% 학습의 영화 지원량** 0/1~9/10~49/50+
  교차표를 고정한다. 각 규모의 실제 영화 지원율과 ALS 직접 점수율은 따로 표시한다.
  빈 칸은 NO_DATA, 지표별 30명 미만은 DESCRIPTIVE_SMALL_N이다. 열마다 사용자가 겹칠 수
  있으므로 셀 사용자 수를 단순 합산하지 않는다. 강제로 균등 표본을 만들어 원래 분포를 숨기지 않는다.
  고유 영화 수·관측 uid/movie 쌍 수·PA에 비교 가능한 비동점 별점 쌍 수도 표시한다. 관측 수는
  셀 전체 사용자의 수치이며 PA 유효자만의 관측 수가 아니다. 별점 쌍들을 독립 표본으로 간주하지 않는다.
- K1의 평가 이력 1~29편은 4명뿐이고 30~99편도 27명이다. 저활동 사용자 일반화는 보류한다.
  신규 입력 K가 적다는 것과 원래 평가 이력이 적은 사용자는 다르다.
- 관측된 미래 별점에 대한 평가다. 카탈로그에서 관측되지 않은 영화의 정답은 없으므로
  서비스 카탈로그 Recall@10/NDCG@10 또는 한국 서비스 품질을 계산했다고 주장하지 않는다.

## 자원과 재현

고정 Spark4.1.3 Docker image, local[4], 컨테이너12GiB/JVM8GiB, swap 추가 없음,
모델당2700초 상한으로 순차 실행한다. host 준비 과정은6GiB RSS 상한이다.
학습용 특징은 원본 토큰 전체를 GBT에 직접 넣지 않고 공통168열로 변환한다. 지도학습
Spark cache는 DISK_ONLY로 두어 전체 특징과 tree 행이 동시에 메모리를 채우지 않게 한다.
실패하면 출력과 원인을 보존하고 자원 또는 구현 문제로 분류한다. 학습량을 몰래 줄이거나
실패 모델을 성능상 패배로 처리하지 않는다. 이미 봉인된 기존 실험은 수정하지 않는다.

원본 별점/모델/사용자별 결과는 LOCAL_ONLY·Git 제외다. 이번 요청은 외부 게시를 포함하지 않는다.
