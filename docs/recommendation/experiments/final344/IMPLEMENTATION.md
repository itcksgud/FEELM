# 최종 FM·GBT 공통 RH 실험 실행 계약

승인 원본은 `../../plans/final-fm-gbt/`이다. 해당 설계·검토 기록은 변경하지 않는다.
이 문서는 사용자 실행 요청에 따라 추가한 실행 명세이며, 코드·입력 독립 검토 PASS 전에는 학습하지 않는다.

## 입력과 비교 범위

- foundation340 RH의 train/score/feature-info 원본을 읽기 전용으로 재사용한다. 4,997,069행, 39,859명, 230개 특징, 행 가중치 1이다.
- 기존 research343 역할 파일을 바이트 그대로 복사한다. 보정 90명과 선택·개발 비교 180명이며 이번 학습 사용자와는 겹치지 않는다.
- 과거 사용 이력 감사는 `outputs/recommendation-evidence/final344-availability-audit/`에 있다. 미사용을 보증할 신규 표본이 없으므로 **DEVELOPMENT_ONLY**이다. 새로운 확인 평가로 부르지 않는다.
- reserve 9,670명 중 기존 사용 확인 8,992명, 사용 미확정 678명은 재현됐다. 옛 평가 271명 중 과거 학습 사용자 수는 REC002만 84명, REC002+REC032 중 한 번이라도 학습한 경우 268명이다. 설계에 인용된 옛 261명과 구분한다. 명시적 학습·평가 union 밖은 10,107명, development membership까지 제외하면 10,084명이다. 옛 10,085명을 미사용 표본 크기로 사용하지 않는다.
- TMDB 최신 지표와 과거 MovieLens 평가의 시점 차이는 그대로이며 2026년 한국 서비스 만족도에 대한 검증이 아니다.

## 학습

- 원본 native metadata의 defaultParamMap을 먼저 넣고 paramMap으로 덮어쓴 전체 값을 기준으로 한다. 변경은 maxIter와 seed뿐이다.
- seed 339에서 FM150/FM300/GBT60/GBT120을 각각 처음부터 학습한다. 선택된 FM·GBT 설정만 seed 344·345로 추가 학습한다. 최대 8회이며 실패도 포함한다.
- hash(row_id) 8개 partition과 내부 row_id 순서를 원본과 일치시킨다. AQE=false, local[4], Docker CPU 4, 메모리 12 GiB, driver 8 GiB, network none이다.
- 각 worker 프로세스 전체에 5,400초 제한을 적용한다. 재시도, 자원 확대, 축소 데이터, 대체 seed를 사용하지 않는다. 실패 파일과 outcome을 보존한다.
- 생성자 전달값과 완성 native의 전체 resolved parameter를 모두 검산한다. FM의 실제 완료 반복 수는 관측할 수 없으면 null이다. GBT는 완성 native의 트리 수를 기록한다. 시간이나 maxIter로 수렴을 추정하지 않는다.
- native 예측 93,230행과 portable 예측의 최대 오차 1e-8 이하를 확인한다. GBT root의 exact float64 경계와 양옆 nextafter fixture도 비교한다.
- cgroup peak ≤12 GiB이면 resource PASS, 초과하면 EXCEPTION, 계측 불가면 UNKNOWN이다. 수치 검산과 자원 판정은 별개이다.

## 평가·설정 선택

- 평가 코드는 별도 exact fingerprint 검토를 거친다. 성공 fit의 모델 독립 검산과 예측 봉인 뒤 개발 라벨을 연다.
- seed·모델·cap별 90명 보정은 사용자 균등 affine a+b*x(b≥0), 최소 20명/40행이다. 보정된 별점 오차만 [0.5,5]로 clip하고 순위는 raw 점수와 movie_id 오름차순 동점을 사용한다.
- 339의 180명 cap10/h>0/ALL에서 큰 설정이 보정 MSE를 높이지 않고 NDCG@2를 낮추지 않으며 하나라도 엄격히 개선할 때만 큰 설정을 선택한다. 충돌·동률이면 작은 설정을 선택한다. 작은 설정 불가 시 해당 가족의 추가 seed를 실행하지 않는다.
- 본 비교는 선택된 설정의 seed 339/344/345 지표를 먼저 사용자별 평균 낸다. 점수를 섞는 ensemble이 아니다. ALL/C × MSE/NDCG@2의 4개 paired bootstrap CI는 98.75%, 20,000회, seed344, 유효 사용자 최소30명이다.
- 한쪽 seed가 누락되면 공식 CI와 3-seed 평균은 내지 않고 완료된 공통 seed별 기술 통계를 낸다. cap10 보정이 유효하지 않으면 공식 비교 불가이다.
- 기존 ALS/FM_RH/GBT_B는 동일 개발 사용자에서 참고 비교이며 신규 3-seed 모델과 같은 재학습 조건으로 표시하지 않는다. ALS는 실제 지원되는 동일 W_DIRECT 집합에서만 비교한다.

## 추가 진단

- MSE/MAE/RMSE/bias, 사용자 MAE P95, 영화 균등·행 균등 오차, 예측 구간별 관측 별점·빈도, clip 비율을 낸다.
- NDCG@1/2/4/6, 선택 영화 실제 별점, 4점 이상·2점 이하 비율, 2편 모두 저평점, J≥6 공통집합의 1–2/3–4/5–6 페이지를 구분한다.
- cap0/1/5/10/30, 실제 입력 수·활동량, W/C/NATURAL_ZERO·학습 지원량·개봉 연도·TMDB 평가 수·메타데이터 누락 집단을 기록한다. 같은 사용자의 같은 target에서 실제 O와 빈 O도 기술적으로 비교한다.
- 전체 카탈로그 진단은 **선택된 모델의 cap10·개발 비교 180명**을 대상으로 한다. 전체 85,517편에서 알려진 개봉일≤고정 snapshot과 모든 기존 감상 제외를 적용한다. 임의 100/500개 후보를 만들지 않는다. 모든 후보 점수를 보존하고 상위 2/4/6의 UNKNOWN·중복·집중도·희소지원 노출 등을 기록한다.
- 고정 230개 특징의 카탈로그 외 ID adapter는 합성 검사로 같은 정보의 같은 특징, 새 인물 일치, missing flags를 확인한다. 이는 점수 계산 가능성 검사이며 신규 영화 품질 증명은 아니다.
- 동일 로컬 runner의 특징 생성·예측·Top-N 시간 p50/p95와 모델 크기를 남긴다. 서비스 API나 다중 노드 성능으로 해석하지 않는다.

코드·입력 리뷰, 모델 검산, 최종 수치·결론 리뷰는 각각 별도 파일로 보존한다. 실행 중 기존 설계와 봉인 자료는 수정하지 않는다.
