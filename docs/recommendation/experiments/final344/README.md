# 최종 FM·GBT 비교

상태: **8회 학습·모델 검산·최종 평가·전체 후보 검사 완료. 최종 수치·결론을 독립 검토 완료.**

**GBT는 제곱오차(MSE)가 조금 작고, FM은 관측한 상위 2편의 정렬 점수가 조금 높았다. 어느 한쪽의 확실한 우세는 확인되지 않았다.**

최종 후보는 FM150과 GBT120이다. 아래는 같은 데이터로 각각 세 번 학습한 성능의 평균이며,
세 모델의 예측을 섞은 결과가 아니다. 모델에 사용자의 과거 별점을 최대 10편까지 제공한 조건이다.

| 비교 기준 | FM150 | GBT120 |
|---|---:|---:|
| 보정 MSE ↓ | 0.6890 | 0.6793 |
| 보정 MAE ↓ | 0.6118 | 0.6183 |
| NDCG@2 ↑ | 0.8373 | 0.8359 |
| 관측 상위 2편 평균 별점 ↑ | 3.8141 | 3.8255 |
| 관측 상위 2편 중 2점 이하 비율 ↓ | 7.41% | 4.99% |

별점 오차는 개인 입력이 있는 124명, 상위 2편 지표는 평가 후보가 충분한 117명 기준이다.
별점 오차와 순위는 서로 다른 기준이며, NDCG는 만족 확률이 아니다. 미평가 영화는 채점하지 않는다.

- **MSE만으로 GBT를 채택할 근거는 부족하다.** 전체 영화·학습 평점을 제외한 영화의 MSE/NDCG@2 네 비교 모두 신뢰구간이 0을 포함했다. 같다고 입증한 것도 아니다.
- **전체 후보에서는 GBT의 추천이 덜 쏠렸다.** 124명에게 첫 2편씩 보여준 248개 슬롯에서 서로 다른 영화가 FM은 31~34편, GBT는 120~182편이었다. 이는 노출 분산이며 만족도 개선의 증거는 아니다.
- 두 모델 모두 이전에 문제였던 **TMDB 투표 1개·평점 10점 영화의 첫 2편 노출은 0개**였다. 다만 해당 전체 추천의 평가 기록 누락은 FM 248/248개, GBT 239~245/248개로, 실제 추천의 대부분은 만족도를 채점할 수 없다.
- ALS가 실제로 지원하는 동일 영화 집합에서는 참고 ALS의 보정 MSE가 0.6938, FM 0.7198, GBT 0.7143이었다. **이번에 ALS의 별점 오차를 넘었다고 주장할 수 없다.** ALS는 이전 단일 학습 참고값이며 지원하지 않는 영화에 점수를 채우지 않았다.

[전체 수치·그림·판정 근거](RESULT.md)에 상위 1/2/4/6의 자료 위치, 2편씩 이어지는 페이지,
학습 미지원 영화, 신뢰구간, 계산 비용과 자원 예외를 정리했다.

## 실험 조건

같은 영화 정보와 사용자 입력을 사용했을 때 FM과 GBT 중 어떤 쪽이 별점을 더 정확히 예상하고,
상위 2편부터 2편씩 이어지는 추천에서 더 나은 결과를 내는지 비교한다.

| 고정하는 것 | 비교하는 것 |
|---|---|
| 학습 4,997,069개 별점·39,859명, 동일 230개 특징 | FM 최대 150회·300회 |
| 보정 90명, 설정 선택·개발 비교 180명 | GBT 최대 60개·120개 트리 |
| 같은 영화 후보·실제 입력·평가 별점 | 선택된 설정을 seed 339·344·345에서 비교 |

큰 설정은 **보정 MSE와 NDCG@2 중 하나도 나빠지지 않고 적어도 하나가 좋아질 때만** 남긴다.
각 모델에서 선택한 설정은 세 번의 학습 결과로 비교한다. 점수를 섞은 앙상블을 만드는 실험은 아니다.

결론은 MSE 하나로 정하지 않는다. 첫 2편·다음 2편·그다음 2편, 학습 평점 없는 영화,
낮은 별점 추천, 전체 후보의 추천 쏠림과 계산 비용도 함께 확인한다.

**평가 사용자는 이전 실험에 사용한 개발 표본이다.** 과거 사용 이력 감사에서 미사용 신규 표본을
입증하지 못했다. 따라서 새 최종 시험이나 2026년 한국 사용자의 만족도 검증으로 해석하지 않는다.
