# REC045 — 시간 경계를 넘는 조건부 진단

상태: DRAFT, 로컬 탐색. 본 실험의 3회 재분할과 별도 가족의 시간 민감도 진단이다.
새로운 확증·실제 과거 TMDB 상태를 재현한 백테스트가 아니다.

## 먼저 고정한 경계

UTC 2019-01-01 00:00:00, timestamp=1546300800. 이전은 `<`, 이후는 `>=`다.
기존 REC032 user-resplits의 학습/평가 사용자 ID와 REC033 카탈로그 85,517편만 사용한다.
학습 사용자의 경계 이전 평점으로만 회차별 영화 평균·평가 수·분산·공통 보정을 다시 학습한다.
TMDB의 현재 누적 평점·인기 수치는 학습에서 제외한다. 다른 정적 메타데이터도 현재 자료이므로
당시 사용할 수 있었던 정보를 보장하지 않는다.

평가 사용자는 이전에 30편 이상, 이후에 2편 이상 기록한 사람이다. 별점 없는 ID·timestamp
점검에서 회차별 170/166/173명, 중복 제외 300명을 확인했다. 회차별 100명 이상이라는
사전 자료량 조건을 만족했다. 이전 전체 기록 중 timestamp 내림차순, 같은 timestamp에서는
movie_id 오름차순으로 30편을 선택한다. 평점 입력 시각은 감상 시각이 아니다.
E는 이후의 모든 관측 카탈로그 영화다. 영화·별점에 따른 사후 선별을 하지 않는다.

## 비교와 채점

개인 입력 K30만 사용한다. BASE, SHARED, GENRE, FULL과 8개 블록 제거, 인물×개봉연대
추가 모형의 수식·블록 스케일·λ는 README.md와 같다. 각 회차의 SHARED는 이전 자료로
새로 학습하며 개인 블록 제거 시 고정한다. 2019년 이후 별점은 모든 시간 조건의 예측이
봉인되기 전까지 수치로 디코딩하지 않는다.

주 시간 대비는 SHARED→FULL, GENRE→FULL, FULL→인물×연대 추가 3개다.
사용자별 E MSE를 계산하고 반복된 회차를 사람 안에서 평균낸 뒤 고유 사람에게 동일 가중치를
준다. PCG64 seed=20260912, 사용자 bootstrap 20,000회, 3개 비교 Bonferroni 보정 양측
95% 구간으로 개선/악화/미확정을 표시한다. MAE와 회차별 결과를 같이 보고한다.
블록 제거 값은 기술적 결과이며 시간 주 비교의 유의성 판정으로 사용하지 않는다.
본 시간 가족과 주 재분할 가족의 보정은 각각이며 전체 연구의 확증적 유의확률로 합치지 않는다.

300명은 원래 평가 사용자 중 약 8%에 해당하는 장기 활동자다. 시간 경계를 통과한 표본으로
편향되었으며 모든 사용자의 미래 성능이라고 일반화하지 않는다. 사용자마다 평점 사이의 기간이
매우 다르므로 간격 분포를 함께 저장한다. 인물×개봉연대는 작품 개봉 시기의 설명력만 다룬다.
여러 사람이 관여한 작품에서 한 인물의 역량·인기의 변화나 원인까지 분리했다고 말하지 않는다.

첫 스캔은 허용 평가 사용자·영화·timestamp만으로 선정한다. 두 번째는 허용 학습 집합의

있지만, 각 회차 학습 시 해당 회차의 모든 평가 사용자는 제외한다. 전체 시간 예측을 봉인한
후 세 번째 스캔에서 허용된 이후 E 별점을 열어 채점한다.

현재 주 실험에서 만들어 봉인한 메타데이터·범주 행렬만 재사용한다. 별점에 의존하는 CROWD와
공통 보정은 재계산한다. 출처 해시, 역할, 시간 경계, O/E 중복, 별점, 수치 및 수렴 검증에서
실패하면 중단한다. 실패 출력은 보존하고 결과에 맞게 cutoff를 바꾸지 않는다.
독립 실행 전 검토와 별도 실제 계산 검산 후에만 결론을 기록한다.
