# 복합 정보와 사용자 별점 — REC045 결과

상태: DRAFT 연구 결과, 2026-09-09. 계산·독립 결과 감사 완료(PASS). 제품 계약이 아니다.

## 이번에 알게 된 것

**여러 정보가 겹쳐도 추가로 쓸 만한 개인 경향은 있었다. 다만 적은 입력의 사용자와
평가가 적은 영화는 서로 다른 문제였고, 인물의 시간 변화를 세분화할 근거는 아직 부족했다.**

모든 원인을 완벽히 분리하는 대신, 같은 학습·입력·정답을 고정하고 여러 정보를 함께 본 뒤
하나를 빼면 예측이 얼마나 달라지는지 비교했다. 이 결과는 조건부 예측 기여다.
배우 때문에 별점을 올렸다는 인과관계나 배우의 역량을 측정한 결과가 아니다.

## 무엇을 실제로 비교했나

학습 사용자와 평가 사용자를 바꾼 3개 분할을 사용했다. 각 회차 학습46,376명,
평가2,180명이다. 회차 간 중복을 제거하면 평가자는3,819명이다. 회차별 관측 E는
192,213 / 192,821 / 192,517개이며 같은 사람을 세 명으로 세지 않았다.

입력은 실제0.5단위 별점5/10/30개다. 5·10개는 같은 O30에서 서로 다른 고정 추출3회를
평균냈다. 정답은 그 사람이 실제로 평가했지만 입력에서 가린 다른 영화들의 원별점이다.
미평가 영화에는 점수를 매기지 않았다. 추천 목록의 적중률이나 서비스 체류 시간을 측정한 것은 아니다.

비교는 네 단계다.

1. **기본 점수(BASE)**: 학습 영화 평균을 수축한 값 + 그 사용자의 후한/박한 별점 습관.
2. **공통 보정(SHARED)**: 8개 정보로 학습 집단에서 공유되는 오차도 보정.
3. **장르 개인 보정(GENRE)**: 동일 공통 보정 위에 사용자의 다중 장르 경향을 추가.
4. **복합 개인 보정(FULL)**: 동일 공통 보정 위에 장르·키워드·대중 평가 특성·국가/언어·
   시기/길이·감독·상위5배우·제작사/시리즈를 함께 추가.

GENRE에도 공통 보정 단계는8개 정보를 사용한다. 따라서 ‘장르만 쓰는 전체 추천 시스템’과
‘모든 정보를 쓰는 시스템’의 비교라고 부르면 안 된다. 기존 ALS와 비교한 실험도 아니다.

## 입력이 적어도 도움이 되었나

MSE는 가린 별점과 예측의 차이를 제곱해 평균한 값으로, 낮을수록 좋다.
사람 안에서 추출·회차를 평균하고 고유 사람에게 동일 가중치를 주었다.

|---|---:|---:|---:|---:|---:|
| 5개 | 0.94496 | 0.92437 | 0.92052 | 0.91636 | 0.87% |
| 10개 | 0.87342 | 0.85317 | 0.84614 | 0.83780 | 1.80% |
| 30개 | 0.82552 | 0.80566 | 0.78897 | 0.76933 | 4.51% |

30개 입력에서 장르 개인 보정→복합 개인 보정의 추가 감소는 **2.49%**였다.

이것은 입력5개만으로 서비스 개인화 전환이 충분하다는 뜻이 아니다.
관측 이력이 많은 기존 사용자에게서5개만 보여준 실험이고, 영화 선정 방식도 고정 추출이다.
실제 온보딩 편의성·초기 사용자·최종 입력 K는 별도 판단이다.

‘인물의 역량이나 인기가 시간에 따라 변하는 것을 모델링했다’는 결론은 보류한다.

TMDB는2026년 현재 메타데이터다. 따라서 당시 제공 가능했던 추천 시스템을 재현한
역사적 백테스트가 아니라 **현재 정적 정보로 평점의 시간 경계를 넘겨 보는 조건부 진단**이다.
timestamp는 평점 입력 시각이다. 감상 시각이나 취향이 바뀐 시각으로 해석하지 않는다.

## TMDB 자료 자체에서 추가로 확인한 것

기존 캐시85,517개, 약1.9GB의 해시를 전부 검사했다. 신규 API 요청은 없다.
제작사 정보는76,046편, 시리즈 정보9,745편, 양수 예산16,389편, 양수 매출16,177편에 있었다.
예산/매출0을 진짜0으로 취급하지 않았다. TMDB 현재 평점·평가 수·인기는 분포 비교에만 쓰고
과거 평점 예측 입력에서 제외했다. Wiki 자료는 이번에 추가 수집하지 않았다.

카탈로그 전체의 수축된 Bayes 평균과 실제 관측 평균을 혼동하지 않기 위해, 학습 영화의
원평균과 현재 TMDB 평균의 순위상관도 따로 진단했다. 첫 분할에서 관측 영화 전체0.550,
학습 평가50~499개 영화0.838, 500개 이상 영화0.869였다. 서로의 대중 평가에 관계가 있지만,
현재 누적 TMDB 점수로 과거 개인 별점을 예측해도 된다는 근거는 아니다.
이 별도 기술통계는 모델·주 비교를 변경하지 않았으며 crowd-metadata-diagnostic.json에 보존했다.

## 실행·검산·파일

메타데이터 준비501.547초, 주 실험131.797초, 시간 진단75.016초.
