# REC045 — 정보가 겹쳐도 개인의 별점 경향을 설명하는가

상태: DRAFT — 로컬 탐색 실험. 제품 정책·인과관계·새로운 독립 확증이 아니다.

## 판단할 질문

같은 영화의 대중적 평가, 개인의 후한/박한 별점 습관, 장르·국가·언어·시기·인물이
겹치는 상황에서도 개인에게서 배운 정보가 다른 관측 영화의 별점을 설명하는가?
입력이 적거나 사용자·영화 집단이 달라도 그 추가 설명력이 유지되는가?
관측하지 못한 연출·관람 상황 등의 영향을 제거했다고 주장하지 않는다.

## 고정된 자료와 경계

- MovieLens 개발 사용자 재분할 3회(REC032 user-resplits)를 사용한다. 회차마다 학습 46,376명,
  평가 2,180명이며 역할은 겹치지 않는다. 평가 고유 사용자는 3,819명이다.
- 이미 열린 개발 자료의 탐색적 재분석이다. LOCKED_TEST/FINAL_RESERVE를 열지 않는다.
- REC033의 동일 85,517편을 사용한다. 다중 장르는 유지하며 TV Movie 표지만 장르 특징에서
  제외한다. TV 표지만 있는 영화도 카탈로그·평가에서 임의 제외하지 않는다.
- 기존 O30 중 영화 ID를 포함한 SHA256 순서로 K5/K10을 선택한다. 추출 3회, 각 추출의
  K5는 K10의 부분집합이다. K30은 한 번만 계산한다. E는 전 조건에서 동일한 관측 영화다.
- 별점은 원래 0.5~5.0의 0.5 단위다. 미평가는 UNKNOWN이며 평가 쌍을 만들지 않는다.
- K는 이번 정보량 민감도 조건이다. 서비스 온보딩 개수 결정이나 추천 1/2/3편 정책이 아니다.
- 현재 TMDB 메타데이터를 사용한다. 현재 TMDB 평점·평가 수·인기도·예산·매출은 전체 자료
  분포 진단에 기록하되, 과거 MovieLens 예측의 학습 특징으로 사용하지 않는다.

## 비교 순서와 모형

1. 회차별 학습 Parquet의 사용자 역할과 별점 범위를 확인한다. 그 파일에 있는 카탈로그
   평점만으로 영화 평균·평가 수·분산과 전역 평균을 다시 계산한다. 타 회차 집계를 재사용하지 않는다.
2. BASE: 영화 Bayes 평균 `b=(sum+50*global_mean)/(n+50)`에 입력 K에서 구한
   `mean(r-b)`를 더한다. 영화 평가 수는 시청자 수가 아닌 MovieLens 관측 평가량이다.
3. SHARED: 학습 사용자의 `r-b` 평균을 제거한 잔차를 영화별로 모으고, 8개 블록을 함께
   쓰는 가중 ridge(λ=50)로 공통 보정을 학습한다. 영화당 가중치는 학습 평가 수다.
   `g=b+공통보정`, 출력은 `g+mean_K(r-g)`다. 이것은 공유되는 예측 보정이며 순수한
   대중성과 개인 취향을 인과적으로 분리한 모형이 아니다.
4. 개인 모형: 선택된 입력 K만으로 `r-g-mean_K(r-g)`를 만들고 ridge λ=5로 맞춘다.
   GENRE는 장르, FULL은 8개 블록을 동시에 사용한다. 정답 E의 별점은 사용하지 않는다.
5. K30에서는 FULL에서 블록 하나를 빼고 개인 모형을 다시 학습한다. SHARED 보정과
   남은 블록의 스케일은 고정한다. 이 비교는 다른 관측 정보가 있는 조건에서의 추가 예측 기여다.
6. 인물×개봉연대 블록을 FULL에 추가한 고정 비교도 한 번 수행한다. 작품이 개봉한 연대에
   따른 정보이며 배우의 역량이나 사용자의 취향이 시간에 따라 변했다는 직접 검증이 아니다.

8개 블록은 다음과 같다. 각각 행 L2 정규화하며 블록끼리 다시 정규화하지 않는다.
블록별 정보량과 희소성은 다르며 한 고정 ridge 설정에서의 비교임을 제한으로 남긴다.

| 블록 | 입력 정보 |
|---|---|
| CROWD | 학습 Bayes 평균, log(1+학습 평가 수), 학습 분산을 50개 전역 분산으로 수축한 값 |
| GENRE | TMDB 다중 장르(TV Movie 표지 제외) |
| KEYWORD | TMDB 키워드, 카탈로그 DF≥5, IDF |
| COUNTRY_LANGUAGE | 다중 제작 국가 + 원어 |
| ERA_RUNTIME | 개봉 10년 단위 + 상영시간 30분 단위 |
| DIRECTOR | 모든 감독 ID |
| CAST | TMDB billing 상위 5명 |
| COMPANY_COLLECTION | 제작사 ID + 시리즈 collection ID |

수치 CROWD는 학습 평가가 있는 영화들의 평균/표준편차로 표준화하고 [-3,3]에서 자른 뒤
행 L2 정규화한다. 장르·국가·인물 등은 복수값을 유지하며 결측은 해당 정보가 없는 0벡터다.
키워드 외 범주형 어휘는 전체 카탈로그에서 만들며 별점을 쓰지 않는다. 범주 ID의 수치 크기는
연속적인 값으로 취급하지 않는다. 예측 점수는 자르거나 0.5 단위로 반올림하지 않는다.
입력의 실제 별점을 변경하는 것이 아니다. E에서 공유되는 범주가 없으면 그 범주의 직접 전이
정보가 없으며, 표본 부족과 효과 없음은 구분한다.

## 채점과 판단을 먼저 고정

주 지표는 사용자별 관측 E의 평균제곱오차(MSE), 보조 지표는 평균절대오차(MAE)다.
먼저 입력 추출을 사용자·회차 안에서 평균낸다. 회차에 반복 등장하는 사용자는 회차별 값을
평균낸 뒤 고유 사용자 3,819명에게 동일 가중치를 준다. 각 회차의 값도 따로 제시한다.
이는 고정된 3회 학습을 조건으로 한 사용자 불확실성이지 학습 자료 전체의 모든 변동을
포함하는 신뢰구간이 아니다.

사전 고정 주 비교 13개:

- SHARED 대비 FULL: K5, K10, K30 (3개)
- GENRE 대비 FULL: K30 (1개)
- 각 블록 제거 모형 대비 FULL: K30 (8개)
- FULL 대비 FULL+인물×연대: K30 (1개)

양의 차이는 정보가 추가된 오른쪽 모형의 MSE 개선이다. 고유 사용자를 20,000회 bootstrap,
PCG64 seed=20260911, 13개 비교에 Bonferroni 보정한 양측 95% 구간을 사용한다.
구간 전체가 0 초과면 개선, 전체가 0 미만이면 악화, 그 외는 미확정이다.
회차별 방향도 함께 보고 불일치 시 안정적이라고 부르지 않는다. 결과를 보고 λ·블록·구간을
재탐색하거나 가장 유리한 K/집단만 고르지 않는다.

K30의 영화 집단 진단은 학습 평가 수 0/1~49/50~499/500+, 원어 en/그 외,
제작국가 KR 포함/알려진 비KR/미상, 1980년 이전 및 이후 10년 단위, O에서 같은 감독/배우/제작사·시리즈가
연결되는 입력 영화 수 0/1/2+를 사용한다. 해당 집단의 관측 E만 사용자 안에서 평균하고,
회차 평균 후 사람 단위로 요약한다. 소집단 결과의 95% 정규근사 구간은 기술적 진단이며
주 비교의 다중검정 판정과 구분한다. 30명 미만은 지원 부족으로 표시한다.
O의 인물 연결 횟수는 같은 단일 인물이 두 번 반복했다는 뜻과 다를 수 있다. 서로 다른
배우가 각각 다른 O 영화에 연결되어도 2+다. 원시 반복 속성 점검과 구분한다.
