## Scope and frozen decisions before outcomes

Classify every one of 237,817 service IDs from the 2026-09-09 export into exactly one of eight K-means tastes and one nested group. Names are assigned after inspecting empirical distributions, never used as training targets. Mapping run-1 is from 09-10. Not a live DB query. Parse every raw JSON body and verify its ID against the archive filename and service set. Preserve 35 ambiguous mapping rows for classification; never resolve their MovieLens identity. Empty keyword array, missing file, empty overview and OOV inputs are distinct flags.

This protocol intentionally replaces the previous proposed semantic D8 with an executable **lexical and structured compression diagnostic**: no suitable reviewed full-service semantic embeddings exist. It cannot measure semantic truth. Genre-only, genre+keyword and genre+keyword+lexical-overview are the three finite comparisons. No additional candidates will be added after seeing results.

Content split is SHA256("k8-content:" + service_movie_id), first 64 bits modulo 100: 0–69 train, 70–84 validation, 85–99 verification. Fit vocabulary, IDF and SVD only on train rows. Genre IDs are train vocabulary, binary then L2-normalized for clustering. Keywords use binary ID presence, min_df=10, smoothed IDF and SVD64 then row normalization. Overview alone uses word TF-IDF (Unicode tokens, lowercase, min_df=5, max_features=16000), SVD48 then normalization. No titles, original language, people, vote counts or popularity in clustering. Missing blocks stay exact zero; missingness flags are not feature columns. Weights apply square roots and the concatenation is L2-normalized per row. Missing all weighted features are excluded from fitting and assigned afterward by the fixed nearest-center rule, visibly marked unsupported. They are never turned into a normal empty-text embedding.

For each G/GK/GKT and seeds 912/913/914 fit K=8, n_init=5, max_iter=150, Lloyd. Each candidate predicts validation rows with frozen train centers. Reconstruct each reference block from eight train-cluster means, using only rows supported in that block. Evaluate binary genre Brier loss, normalized keyword-SVD squared error, normalized lexical-overview-SVD squared error. Divide each by its global train-mean baseline loss on the SAME validation rows; average the three block ratios (equal weights) to select lowest validation D8. Baseline is the best validation seed of G. Select best combined candidate on validation. Verify this single challenger against G on verification rows: paired stratified-by-block bootstrap of movie losses, 95% CI, adopt challenger only if upper delta <0; otherwise G. Zero denominator/nonempty-support failure stops selection; no silent reweighting. Report each support denominator, complete-case D8, missingness/language strata and worst-decile loss; inertia/silhouette/illustrative movie pairs are not selection scores. Seed stability uses ARI and optimal Hungarian label agreement; it is different from frozen-model invariance.

After this selection only, fit chosen top K=8 on ALL supported service rows with selected seed (same train-fitted preprocessing), assign all rows and freeze centers. This is the requested full-catalog partition. Earlier held-out compression estimates describe the selection-stage model, not unbiased performance of this final refit. Canonicalize center order once by lexicographic rounded center coordinates, then never reorder at serving. All ties choose the lowest fixed ID. Production inference does not fit, partial_fit, recompute means or depend on current catalog membership.

## Hierarchy and recommendation spaces

For each of G/GK/GKT child feature spaces, compare per-parent K={1,2,4,8,16,32,64,128,256} using content-train fitting and validation distortion IN THAT SAME space. Evaluate every member-count/distinct-vector-feasible K, including larger values after a smaller value fails. A candidate is feasible for selection only when every train cluster has >=100 members. Choose the smallest feasible K whose validation distortion is within2% of the minimum feasible distortion for that parent and feature space; if none is feasible use K1. Thus asymmetric counts are permitted. K=1 is a legitimate limit for a homogeneous or sparse taste. Also retain fixed K=2 everywhere as a control. Fit these chosen child centers once on all informative members of each final parent, then freeze. The feature-space/hierarchy alternatives are selected by recommendation validation, not cross-space inertia. Child group representatives are unit-normalized frozen child centers; user vectors use exactly the same feature basis and weights. ALS32 is a separate space used ONLY for final prediction.

For group retrieval form signed weighted user profile from capped pre-origin ratings: weights=(r - shrunk_user_mean), shrunk_user_mean=(sum(r)+5*global_train_mean)/(h+5); average content vectors with denominator sum(abs(weights))+5, then normalize nonzero result. Low ratings count as seen and contribute negatively when below the shrunk center. A user's all pre-origin viewed history determines group exposure. Underseen means count<=2 AND count/max(1,total_viewed)<=0.2. Empty/cancelled profile ranks groups by fixed group ID. Empty/noneligible groups skipped. No underseen groups uses global quality fallback, tagged as fallback. History caps 0/1/5/10/30 are supported; cap10 is primary, the others are diagnostics on final policies.

Within selected groups pre-sort quality by: (a) train rating count; (b) unshrunk mean, zero-count fallback global mean; (c) Bayesian mean with prior mass20. All ties use service ID. Lists use ONLY pre-2023 interactions from 39,859 training users. Current TMDb votes/popularity are descriptive snapshot fields, not historical ranking features. Filter viewed films, traverse top P={2,4,8,16} eligible underseen groups, take at most Q={25,50} unseen movies per group, concatenate round-robin, cap at B={50,100,200}. Fill any shortfall from global SAME quality order within B and report fill count. No hidden budget expansion. Baselines: no-group same global quality order and B; full-catalog shared predictor; popularity alone. Same content/recommendation eligibility and predictor for every policy.

Shared final expected-star predictor: existing independently audited ALS32 with fold-in solve (F'F+0.1*h*I)^-1 F'r when >=1 supported history item and candidate factor exists. Other candidates use train Bayesian item mean plus shrunk user bias and per-user ridge on content residuals, ridge alpha5; predict within [0.5,5]. Ridge uses the fixed GKT basis for ALL policies so retrieval-space comparisons cannot alter the reranker. Its only user inputs are capped pre-origin history. No rating calibration fitting on validation or verification targets. Also score observed targets with item Bayesian baseline and pure content fallback to expose predictor quality and ALS support.
