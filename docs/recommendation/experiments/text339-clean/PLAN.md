# 본문 의미 정제 비교

상태: DRAFT — 로컬 연구 실행 계약. 제품·팀 계약이나 채택 결정이 아니다.

## 질문과 범위

기존 T3(줄거리+Wiki)를 그대로 넣는 것보다, 작품 바깥의 제작·개봉·평론·홍보 설명을
보수적으로 덜어낸 본문이 같은 추천 모델에서 도움이 되는가?
기존 text339의 코드·입력·결과·봉인은 모두 보존한다. 이번에는 본문만 바꾸고
대중성 신뢰도, 학습 h=0 비중, 입력 편수, 추천 정책, 사용자/영화 분할은 바꾸지 않는다.
원본은 새로 수집하지 않는다. TMDB overview와 검토된 Wiki T3 판본을 사용한다.

## 정제 계약

여섯 개 좁은 EN/KO 정규식은 삭제 후보 탐색용이다. 자동 삭제 규칙이 아니다.
문장 경계가 불확실하면 더 큰 원문 단위를 유지한다. 후보 문장과 문단 문맥을 보고
독립 검토 에이전트가 REMOVE / KEEP / KEEP_UNCERTAIN으로 의미를 판정한다.
별도 NLI 모델은 추가하지 않는다. 삭제 제안은 다른 검토자가 전수 확인한다.
검토자는 미래 별점·새 모델 점수를 사용하지 않는다. 문장 분할은 완전하지 않으므로
최종 삭제 검토는 영화ID/출처로 연결한 전체 원문과 삭제 전후를 함께 확인한다.
줄바꿈을 넘는 대사·인용·불완전한 문장 경계는 문단만 보고 삭제하지 않는다.
각 삭제 ID에는 제안자와 서로 다른 확인자의 판정을 함께 기록한다.

- REMOVE: 서사 정보가 없는 외부 제작/개봉/상영/수상, 평론, 홍보 문장.
- KEEP: 사건·인물·관계·감정·부정·결말·시대/장소, 극중 영화 제작/수상,
  다큐멘터리의 실제 대상과 활동, 작품 이해에 필요한 주제.
- KEEP_UNCERTAIN: 외부 설명과 서사가 섞이거나 지시 대상/경계가 모호한 문장.
- 문장 일부의 단어 삭제, 요약/번역, 중복 제거, 새로운 사실 보충은 하지 않는다.
- 원문 offset과 문자열 SHA를 대조해 승인된 span만 삭제한다. 남은 문자는 원래 순서로
  보존한다. 비어도 영화는 유지하고 입력 결측으로 처리한다. 기존 격리 Wiki를 복원하지 않는다.

먼저 출처×요청언어별 16개씩 총 64개를 SHA 순서로 뽑아(후보 8+비후보 8)
사전 QA한다. 요청언어는 언어 감지 결과가 아니다. 실제 삭제는 전수 이중 검토한다.
사건·관계·부정/감정 손실, 원문에 없는 생성, 잘못된 offset 삭제는 허용하지 않는다.
발견하면 학습 전에 수정·재검토한다. 성능 결과를 본 뒤 규칙을 바꾸지 않는다.
이는 포착된 외부 설명의 보수적 제거이며 모든 잡음의 완전한 선별은 아니다.

## 고정 비교

- 기준: 봉인된 T3 한 번 학습의 실제 446차원 FM과 예측을 재사용.
- 비교: CLEAN 한 번 추가 학습. 구조 특징 230+overview 108+Wiki 108.
- 학습: 기존 4,997,069행, 같은 평가 제외 사용자와 C 영화 제외, 180일 episode,
  cap/과거 입력/별점/행 순서. 평가 270명과 모든 후보·과거 감상 제외 규칙 동일.
- 같은 E5/토큰화/청크/정밀도. 본문 SHA가 같으면 기존 벡터를 그대로 재사용한다.
  새 본문만 SHA 정렬 후 기존 outer64/inner16 배치로 인코딩한다.
- 기존 PCA 평균·축·스케일을 그대로 사용한다. 정제 후 PCA 최적화는 이 비교에 없다.
- FM factor16, reg .01, maxIter150, step .01, miniBatch .25, seed339,
  adamW/tol1e-6; 기존 Spark image/local4/8GiB JVM/12GiB container/5400초 제한.
- 학습 실행 전 설계·코드·정제·feature 행 정합성을 독립 검토하고 SHA 봉인한다.

## 평가와 판정

주 대조는 H10 ALL, 동일 관측 후보 J≥2 사용자에서 CLEAN−T3 NDCG@2 하나다.
기존 graded gain (rating−.5)/4.5, raw 점수 내림차순·movie_id 오름차순으로 순위를 매긴다.
UID 정렬 사용자 짝 bootstrap 20,000회, seed339, 양측 95% 구간을 고정한다.
구간 하한>0이며 Top2 평균별점 차이≥−.1, 낮은 별점(≤2) 비율 차이≤.03일 때만
기존 T3 대비 개선 근거로 표시한다. 보조 veto는 서비스 안전성 검증이 아니다.

T0는 진단 기준으로만 병기한다. CLEAN>T3만으로 기존 선택 T0를 대체하지 않는다.
Top2/4/6/10 NDCG·평균별점·좋아요(≥4)·낮은 별점·Recall, 평점 오차와 순서 일치,
실제 h, C/W/자연 zero-support를 기술통계로 제시한다. J가 부족하면 해당 N을 제외하고
분모를 표시한다. 별점은 0.5 단위 실측값이며 추정치는 연속값이다.

정제 영향 영화가 학습 목표/입력, H10 J/입력에 포함되는 수를 별점 없이 먼저 집계한다.
후보 또는 입력에 정제 영화가 있는 직접 노출 사용자도 고정 집계한다. 30명 미만인
부분집단은 기술통계만 제공하며 ALL 주 대조를 바꾸지 않는다.

같은 85,517편 연구 카탈로그 중 날짜·기감상 필터를 통과한 후보를 모두 채점해
Top10을 만들고 앞 2/4/6편을 비교한다.
미평가는 UNKNOWN으로 유지한다. 채움률/기평가 비율/노출 집중/학습지원 등을 비교한다.
전체 카탈로그 품질이나 2026 한국 사용자에 대한 정답으로 해석하지 않는다.

## 한계와 완료 조건

이미 여러 번 읽은 개발 사용자·라벨이다. 새로운 확증 실험이 아니다.
동일 seed라도 Spark repartition/확률 최적화가 동일 학습 경로를 보장하지 않는다.
사용자 bootstrap은 두 고정 모델의 차이에 조건부이며 학습 무작위성을 포함하지 않는다.
두 텍스트 출처를 함께 정제하므로 개별 효과는 분리하지 못한다.
기존 T3의 12GiB+4KiB peak 예외를 보존하고 CLEAN의 자원 준수와 별도 보고한다.
기존 h=0 학습 목표 82.34%도 유지하므로 개선을 개인화 개선으로 단정하지 않는다.

결론을 로컬에 남기면 완료다. Jira/GitLab 게시·커밋·Push는 이번 실행에 포함하지 않는다.
