# 데이터 관계 분석의 현재 범위

상태: DRAFT 연구 방침. 2026-09-11까지의 사용자 지시를 기록하며 제품 구현 계약이 아니다.

## 최신 서비스 추천 검토 범위

2026-09-11: K-means나 분류를 기반으로 맞춤·발견 추천을 구분하는 정책은 보류한다.
첫2편을 보여주고 사용자가 요청할 때마다2편씩 추가하는 흐름을 현재 모델 평가의 기준으로 삼는다.
원래 장르·키워드·인물·텍스트 등의 정보를 모델 입력으로 사용하는 것과 서비스에서 분류별
추천 슬롯을 강제하는 것은 구분한다. 이전 policy341의 맞춤2+발견1 성과는 당시 연구 이력이다.
새 모델 선택에서 장르 novelty·발견 공급률·3/6/9편 세트를 필수 채택 기준으로 되가져오지 않는다.
페이지별 추천 품질, 예측 별점 오차, 후보 지원 범위·UNKNOWN·비용을 함께 검토하며,
온라인 페이지 상태·재정렬·피드백 반영 등의 API 계약을 이 검토만으로 변경하지 않는다.

## 유지하는 데이터 관계 분석 원칙

**현재 질문은 원래 영화 정보와 사용자의 별점 사이에 어떤 관계가 있는가다.
8개 분류, 팝콘 맛 개수, K-means 사용을 전제로 두지 않는다.**

## 분석에서 유지할 정보

- 영화의 복수 장르·키워드·감독·배우·제작국가·언어 등을 원래 속성으로 다룬다.
  영화 하나를 대표 장르나 단일 취향 유형으로 먼저 압축하지 않는다.
- 영화 평균, 평가 수, 별점 분산을 서로 구분한다. 제작국가/언어, 개봉연도/상영시간,
  제작사/시리즈도 서로 다른 필드라는 점을 유지한다.
- 원필드의 결측·분포·반복 근거를 먼저 확인하고, 다른 필드를 함께 고려한 추가 관계와
  적은 입력·다른 사용자/영화 집단·시간 조건에서의 안정성을 확인한다.
- 비교를 위해 필드를 묶는다면 그 이유와 묶음 단위 결론의 한계를 명시한다.
  정보 묶음 개수를 8개 또는 다른 수로 고정할 필요는 없다. 지난 실험의 묶음을 그대로
  유지해야 한다는 조건도 없다. 여러 필드를 묶은 결과로 각 필드의 효과를 단정하지 않는다.
- 현재 조사에 필요한 자료 가용성·신원 매칭 조건을 명시한다. 특정 맛에 배정할 수 있다는
  이유로 표본을 고르지 않는다. 공통 표본 비교와 필드별 지원 범위를 구분한다.
- 원별점은0.5단위를 유지하고, 미평가는 UNKNOWN으로 둔다. 근거가 없는 속성이나
  사용자의 관측하지 못한 특성을 만들어 채우지 않는다.

분석에서 필요한 구간·필터·변환은 질문에 맞춰 사전에 정하고 독립 검토한다.
평가 수 구간처럼 불확실성을 확인하기 위한 집단 구분과 서비스 취향 분류를 구분한다.
군집이나 사용자 표시 방식이 필요한지는 관계를 확인한 뒤 별도 판단한다.

## 직전 결과에서 말한 ‘8개’의 의미

REC045의 `blocks: 8`은 **입력 필드 묶음 수**다. 장르·키워드·대중 평가 특성·국가/언어·
연대/상영시간·감독·배우·제작사/시리즈를 함께 비교했다. 영화를8개로 분류한 값이 아니다.

실제 장르 표현은18개 원장르의 다중값이며, 키워드10,818개·감독38,101개·배우144,389개의
개별 ID 표현을 사용했다. 한 영화가 여러 장르·인물을 동시에 가진다. REC045의 예측 특징에는
규칙8/K-means8 배정이나 팝콘 맛 ID가 들어가지 않는다.

원자료 파일 REC033 metadata에는 과거의 `genre_code` 등이 함께 저장돼 있지만, REC045는
그 파일에서 `movie_id` 열만 읽어 카탈로그 축을 가져온다. 속성은 원래의 장르·키워드·인물
목록에서 만들었다. 85,517편의 기존 공통 카탈로그는 구조 정보와 텍스트 정보의 가용성 교집합이며,
모든 MovieLens 영화라는 뜻은 아니다. 이를 향후 모든 필드 분석의 영구적인 표본 조건으로 삼지 않는다.
기존 표본에는 원어·개봉연도·장르·제목·줄거리 보유 조건도 남아 있어, 정보가 부족한 영화까지
포함한 전체 데이터 분석으로 부르지 않는다.

따라서 직전 수치를 ‘8개 취향 유형 안에서만 확인한 관계’라고 해석할 필요는 없다.
그 수치는 당시 고정한 필드 묶음·변환·표본을 조건으로 한 결과다. 이번 지시는 앞으로의
관계 분석을 고정된 분류 수와 연결하지 않도록 하는 범위 수정이며, 이번에 새 모형을 실행한 것은 아니다.

## 문서와 실험 이력

현재 범위는 이 문서를 먼저 따른다. [다각도 분석안](plans/multidimensional-preference-analysis.md)은
필드 목록과 이전 탐색 순서를 참고하는 이력이며, 거기에 남은 ‘공식8맛’ 문장을 현재 분석 제약으로
사용하지 않는다. [REC045 결과](experiments/rec-ev-045/RESULT.md)의 ‘외부8맛 유지/미변경’은
당시 제품을 수정하지 않았다는 기록이다. 현재 관계 분석이 만족해야 할 목표가 아니다.

과거 봉인과 결과는 보존한다. 지침을 바꾸기 위해 과거 수치를 다시 쓰거나 이미 실행한 설정을
다른 설정으로 바꾸지 않는다. 후속 실험의 설계·독립 검토·실행·결과 검산 루프는 유지한다.
Jira·GitLab·GitHub 게시와 운영 계약 변경은 이번 범위 조정에 포함하지 않는다.

읽기 전용 독립 확인(`/root/rec044_design_audit`, PASS_SCOPE_AUDIT): 원자료의 가용성
교집합과 REC045 영화 ID가 전부 일치하고, 규칙 미배정12편도 포함한다. 복수 장르 영화는
55,200편이며 분류·맛 ID를 예측에 쓰는 의존은 발견되지 않았다. 이 전제 조정 때문에 기존
결과를 재실험할 필요는 없다. 평가 별점은 다시 열지 않았다.
